# 🏠 `if` Statement

## 📌 Exercise Overview

Two variables are defined in the sample code:

- `room` — a string that tells you which room of the house we're looking at.
- `area` — the area of that room.

The goal is to use `if` statements to make Python execute code only when a specific condition is `True`.

---

# 🧪 Exercise

Write Python code to:

1. Check whether `room` is equal to `"kit"` and print:
   `"looking around in the kitchen."`
2. Check whether `area` is greater than `15` and print:
   `"big place!"`

---

# ✅ Solution

## 1. `if` Statement for the Room

    room = "kit"
    area = 14.0

    if room == "kit":
        print("looking around in the kitchen.")

### Explanation

The condition:

    room == "kit"

checks whether the value stored in `room` is equal to the string `"kit"`.

Since:

    room = "kit"

the condition is:

    "kit" == "kit"

which evaluates to:

    True

Therefore, Python executes:

    print("looking around in the kitchen.")

### Output

    looking around in the kitchen.

---

## 2. `if` Statement for the Area

    if area > 15:
        print("big place!")

### Explanation

The condition checks whether:

    area > 15

Since:

    area = 14.0

Python evaluates:

    14.0 > 15

which is:

    False

Therefore, the `print()` statement is **not executed**.

### Output

    # No output

---

# 🧠 Complete Code

    # Define variables
    room = "kit"
    area = 14.0

    # if statement for room
    if room == "kit":
        print("looking around in the kitchen.")

    # if statement for area
    if area > 15:
        print("big place!")

---

# 🔑 Key Takeaways

- Use `if` to execute code only when a condition is `True`.
- Use `==` to compare whether two values are equal.
- Use `>` to check whether one value is greater than another.
- A colon `:` is required after the condition.
- The code inside the `if` block must be indented.
- Separate `if` statements are evaluated independently.

### Basic Pattern

    if condition:
        # code to execute when condition is True
