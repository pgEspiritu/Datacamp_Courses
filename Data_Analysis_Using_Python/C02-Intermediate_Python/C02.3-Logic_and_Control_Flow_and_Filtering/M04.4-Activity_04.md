# 🚗 Cars per Capita (2)

## 📌 Exercise Overview

NumPy provides logical functions that can be used to combine multiple conditions:

- `np.logical_and()`
- `np.logical_or()`
- `np.logical_not()`

These functions can also be used with **Pandas Series** to perform more advanced filtering.

---

# 🧠 Example

Suppose we want to find observations where `cars_per_cap` is between `10` and `80`.

The process is:

    cpc = cars["cars_per_cap"]
    between = np.logical_and(cpc > 10, cpc < 80)
    medium = cars[between]

### Step 1: Select the Column

    cpc = cars["cars_per_cap"]

This stores the `cars_per_cap` column as a Pandas Series.

### Step 2: Create the Boolean Condition

    between = np.logical_and(cpc > 10, cpc < 80)

This checks two conditions for each observation:

    cpc > 10
    cpc < 80

Both conditions must be `True`.

### Step 3: Filter the DataFrame

    medium = cars[between]

Only rows where `between` is `True` are kept.

# 🧪 Exercise

Create a DataFrame called `medium` containing all observations in `cars` where:

    cars_per_cap > 100

**and**

    cars_per_cap < 500

In other words, select countries with a `cars_per_cap` **between 100 and 500**.

Then print `medium`.

---

# ✅ Solution

    # Import cars data
    import pandas as pd

    cars = pd.read_csv("cars.csv", index_col=0)

    # Import numpy, you'll need this
    import numpy as np

    # Create medium: observations with cars_per_cap between 100 and 500
    cpc = cars["cars_per_cap"]
    between = np.logical_and(cpc < 500, cpc > 100)
    medium = cars[between]

    # Print medium
    print(medium)

# 📊 Understanding `np.logical_and()`

Consider:

    cpc = cars["cars_per_cap"]

Then:

    np.logical_and(cpc < 500, cpc > 100)

works element by element.

For example:

| `cars_per_cap` | `< 500` | `> 100` | Result |
|---:|---:|---:|---|
| `50` | `True` | `False` | `False` |
| `150` | `True` | `True` | `True` |
| `300` | `True` | `True` | `True` |
| `500` | `False` | `True` | `False` |
| `700` | `False` | `True` | `False` |

Only the values between `100` and `500` produce `True`.

---

# ⚡ One-Liner Alternative

The same filtering operation can be written without storing `cpc` and `between`:

    medium = cars[np.logical_and(cars["cars_per_cap"] < 500, cars["cars_per_cap"] > 100)]

This produces the same result.

However, the step-by-step version can be easier to read and understand, especially when learning Boolean filtering.

---

# 🆚 Comparison with Other Logical Functions

| Function | Purpose |
|---|---|
| `np.logical_and()` | Both conditions must be `True` |
| `np.logical_or()` | At least one condition must be `True` |
| `np.logical_not()` | Reverses the Boolean result |

### Examples

    np.logical_and(condition1, condition2)

    np.logical_or(condition1, condition2)

    np.logical_not(condition)

# 🔑 Key Takeaways

- NumPy logical functions can be used with **Pandas Series**.
- Use `np.logical_and()` when multiple conditions must all be satisfied.
- The Boolean Series can then be used to filter a DataFrame.
- For a range, combine two comparisons:

      np.logical_and(cpc < 500, cpc > 100)

- Then use the result to filter:

      medium = cars[between]

### 📚 Core Pattern

    series = dataframe["column"]
    condition = np.logical_and(series < upper_limit, series > lower_limit)
    result = dataframe[condition]

### 💡 Core Idea

    medium = cars[between]

means:

> Keep only the rows where `between` is `True`, meaning `cars_per_cap` is greater than `100` and less than `500`.
