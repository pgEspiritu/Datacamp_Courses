# 🚗 Driving Right (1)

## 📌 Exercise Overview

The `cars` dataset contains information about different countries, including:

- `country` — country name
- `cars_per_cap` — cars per 1,000 people
- `drives_right` — whether people drive on the right side of the road

The goal is to filter the `cars` DataFrame and keep only the observations where:

    drives_right == True

Because `drives_right` is already a **Boolean column**, it can be used directly as a filtering condition.

---

# 🧪 Exercise

Complete the following steps:

1. Extract the `drives_right` column as a **Pandas Series** and store it as `dr`.
2. Use `dr` to subset the `cars` DataFrame and store the result as `sel`.
3. Print `sel`.
4. Verify that `drives_right` is `True` for all observations in `sel`.

---

# ✅ Solution

## 1. Import the Cars Data

    import pandas as pd

    cars = pd.read_csv("cars.csv", index_col=0)

The `index_col=0` argument tells Pandas to use the first column in the CSV file as the DataFrame index.

---

## 2. Extract `drives_right` as a Series

    dr = cars["drives_right"]

This selects the `drives_right` column as a **Pandas Series**.

Because this column contains Boolean values, `dr` acts as a Boolean filter.

Conceptually, it looks like:

    True
    False
    False
    True
    ...

---

## 3. Use `dr` to Filter `cars`

    sel = cars[dr]

Pandas keeps only the rows where the corresponding value in `dr` is `True`.

This is called **Boolean indexing** or **Boolean filtering**.

---

## 4. Print the Selection

    print(sel)

The result contains only countries where people drive on the right.

---

# 🔍 How Boolean Filtering Works

Suppose the `drives_right` column contains:

    [True, False, True, False]

Then:

    dr = cars["drives_right"]

produces the Boolean Series:

    [True, False, True, False]

When used here:

    cars[dr]

Pandas keeps:

- Row 1 → `True` ✅
- Row 2 → `False` ❌
- Row 3 → `True` ✅
- Row 4 → `False` ❌

So only rows with `True` remain.

---

# ✅ Verifying the Result

The exercise also asks you to assert that `drives_right` is `True` for every observation in `sel`.

You can verify this with:

    assert sel["drives_right"].all()

### How `.all()` Works

The `.all()` method returns:

- `True` → if **every** value is `True`
- `False` → if at least one value is `False`

Therefore:

    sel["drives_right"].all()

should return:

    True

The `assert` statement passes when the result is `True`.

---

# 🧠 Complete Code

    # Import cars data
    import pandas as pd

    cars = pd.read_csv("cars.csv", index_col=0)

    # Extract drives_right column as Series: dr
    dr = cars["drives_right"]

    # Use dr to subset cars: sel
    sel = cars[dr]

    # Print sel
    print(sel)

    # Verify that drives_right is True for all selected observations
    assert sel["drives_right"].all()

---

# 🔑 Key Takeaways

- A single DataFrame column selected with:

      cars["drives_right"]

  returns a **Pandas Series**.

- A Boolean Series can be used to filter a DataFrame:

      cars[dr]

- Only rows corresponding to `True` are retained.
- `.all()` checks whether **all values** in a Boolean Series are `True`.
- `assert` can be used to verify that a condition is satisfied.

### 📚 Core Pattern

    condition = cars["column"]
    selection = cars[condition]

For Boolean columns, the column itself can serve as the filtering condition.

### 💡 Important Concept

    cars[dr]

means:

> Keep the rows of `cars` where the corresponding value in `dr` is `True`.
