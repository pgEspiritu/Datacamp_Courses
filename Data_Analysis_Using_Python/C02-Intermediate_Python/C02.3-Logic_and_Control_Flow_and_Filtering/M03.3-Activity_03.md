# 🔀 Customize Further: `elif`

## 📌 Exercise Overview

Python's `elif` statement allows you to add **additional conditions** to an `if-else` structure.

The sample code already uses `if`, `elif`, and `else` to identify different rooms:

- `"kit"` → kitchen
- `"bed"` → bedroom
- Anything else → elsewhere

The same concept can be applied to the `area` variable to provide more specific messages depending on the size of the room.

---

# 🧪 Exercise

Add an `elif` to the second control structure such that:

    "medium size, nice!"

is printed when:

    area > 10

---

# ✅ Solution

    # Define variables
    room = "bed"
    area = 14.0

    # if-elif-else construct for room
    if room == "kit":
        print("looking around in the kitchen.")
    elif room == "bed":
        print("looking around in the bedroom.")
    else:
        print("looking around elsewhere.")

    # if-elif-else construct for area
    if area > 15:
        print("big place!")
    elif area > 10:
        print("medium size, nice!")
    else:
        print("pretty small.")

---

# 🧠 How It Works

## 1. `if-elif-else` for `room`

    if room == "kit":
        print("looking around in the kitchen.")
    elif room == "bed":
        print("looking around in the bedroom.")
    else:
        print("looking around elsewhere.")

Since:

    room = "bed"

Python first checks:

    room == "kit"

This is `False`.

It then checks:

    room == "bed"

This is `True`.

Therefore, Python prints:

    looking around in the bedroom.

The `else` block is skipped.

---

## 2. `if-elif-else` for `area`

    if area > 15:
        print("big place!")
    elif area > 10:
        print("medium size, nice!")
    else:
        print("pretty small.")

Since:

    area = 14.0

Python checks the conditions from **top to bottom**.

### First condition

    area > 15

becomes:

    14.0 > 15

Result:

    False

Python moves to the `elif`.

### Second condition

    area > 10

becomes:

    14.0 > 10

Result:

    True

Therefore, Python prints:

    medium size, nice!

The `else` block is skipped.

---

# 🔄 How `if-elif-else` Works

Python evaluates the conditions in order:

    if condition1:
        # Executes if condition1 is True
    elif condition2:
        # Executes if condition1 is False and condition2 is True
    else:
        # Executes if all previous conditions are False

### Important Rule

Once Python finds a condition that is `True`, it:

1. Executes that block.
2. Skips all remaining `elif` and `else` blocks.
3. Continues with the code after the entire control structure.

---

# 📊 Area Conditions

With:

    area = 14.0

the conditions are:

| Condition | Result |
|---|---|
| `area > 15` | `False` |
| `area > 10` | `True` |
| `else` | Skipped |

Output:

    medium size, nice!

---

# 💡 Why the Order Matters

The conditions are checked from **top to bottom**.

For example:

    if area > 10:
        print("medium size, nice!")
    elif area > 15:
        print("big place!")
    else:
        print("pretty small.")

If `area = 20`, the first condition `area > 10` is already `True`, so Python would never reach the `elif`.

Therefore, more specific or higher-threshold conditions should be placed appropriately before broader conditions.

---

# 🔑 Key Takeaways

- `elif` means **"else if"**.
- It allows you to test additional conditions.
- You can have multiple `elif` statements in one control structure.
- Python checks conditions **from top to bottom**.
- Once a condition is `True`, its block executes and the remaining conditions are skipped.
- `else` runs only when all previous conditions are `False`.
- `if`, `elif`, and `else` must end with a colon `:`.
- Code inside each block must be indented.

### Basic Pattern

    if condition1:
        # code
    elif condition2:
        # code
    else:
        # code
