# 🔀 Add `else` to an `if` Statement

## 📌 Exercise Overview

The `if` statement for `room` has been extended with an `else` statement.

This means:

- If `room == "kit"` is `True`, Python prints `"looking around in the kitchen."`
- Otherwise, Python prints `"looking around elsewhere."`

The same concept can be applied to the `area` condition.

---

# 🧪 Exercise

Add an `else` statement to the second control structure so that:

    "pretty small."

is printed when:

    area > 15

evaluates to `False`.

---

# ✅ Solution

    # Define variables
    room = "kit"
    area = 14.0

    # if-else construct for room
    if room == "kit":
        print("looking around in the kitchen.")
    else:
        print("looking around elsewhere.")

    # if-else construct for area
    if area > 15:
        print("big place!")
    else:
        print("pretty small.")

---

# 🧠 How It Works

## 1. `if-else` for `room`

    if room == "kit":
        print("looking around in the kitchen.")
    else:
        print("looking around elsewhere.")

Since:

    room = "kit"

the condition:

    room == "kit"

is `True`.

Therefore, Python prints:

    looking around in the kitchen.

The `else` block is skipped.

---

## 2. `if-else` for `area`

    if area > 15:
        print("big place!")
    else:
        print("pretty small.")

Since:

    area = 14.0

the condition:

    14.0 > 15

is `False`.

Therefore, Python executes the `else` block:

    print("pretty small.")

### Output

    pretty small.

---

# 🔄 `if-else` Structure

The general structure is:

    if condition:
        # code when condition is True
    else:
        # code when condition is False

Only **one** of the two blocks is executed.

---

# 🔑 Key Takeaways

- `if` runs when its condition is `True`.
- `else` runs when the `if` condition is `False`.
- An `else` statement does not have its own condition.
- Both `if` and `else` require a colon `:`.
- Code inside each block must be indented.
- An `if-else` structure provides two possible execution paths.

### Example

    if area > 15:
        print("big place!")
    else:
        print("pretty small.")
