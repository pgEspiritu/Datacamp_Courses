# 🔘 Boolean Operators with NumPy

## 📌 Boolean Operators and NumPy Arrays

Comparison operators such as `<`, `>`, `<=`, and `>=` work directly with NumPy arrays.

For example:

    my_house > 18

returns a Boolean array where each element is compared individually.

However, Python's Boolean operators:

    and
    or
    not

do **not** work directly with NumPy arrays.

Instead, NumPy provides special functions for Boolean operations:

| Python | NumPy |
|---|---|
| `and` | `np.logical_and()` |
| `or` | `np.logical_or()` |
| `not` | `np.logical_not()` |

---

# 🏠 Example Arrays

The following arrays contain the areas of different rooms:

    import numpy as np

    my_house = np.array([18.0, 20.0, 10.75, 9.50])
    your_house = np.array([14.0, 24.0, 14.25, 9.0])

The values are ordered as:

1. Kitchen
2. Living room
3. Bedroom
4. Bathroom

---

# 🧠 NumPy Logical Functions

## `np.logical_and()`

Used when **both conditions must be `True`**.

Example:

    np.logical_and(my_house > 13, your_house < 15)

This performs the comparison **element by element**.

---

## `np.logical_or()`

Used when **at least one condition must be `True`**.

Example:

    np.logical_or(my_house > 18.5, my_house < 10)

---

## `np.logical_not()`

Used to **reverse** Boolean values.

Example:

    np.logical_not(my_house > 18)

---

# 🧪 Exercise

Generate Boolean arrays that answer:

1. Which areas in `my_house` are **greater than `18.5` OR smaller than `10`**?
2. Which areas are **smaller than `11` in both `my_house` and `your_house`**?

Wrap both expressions in `print()` statements to inspect the results.

---

# ✅ Solution

## 1. `my_house` Greater Than `18.5` OR Smaller Than `10`

    print(np.logical_or(my_house > 18.5, my_house < 10))

### Output

    [False  True False  True]

### Element-by-Element Breakdown

| `my_house` | `> 18.5` | `< 10` | OR Result |
|---:|---:|---:|---:|
| `18.0` | `False` | `False` | `False` |
| `20.0` | `True` | `False` | `True` |
| `10.75` | `False` | `False` | `False` |
| `9.50` | `False` | `True` | `True` |

So the resulting Boolean array is:

    [False  True False  True]

---

## 2. Both Houses Smaller Than `11`

Use `np.logical_and()` because **both conditions must be true**:

    print(np.logical_and(my_house < 11, your_house < 11))

### Output

    [False False False  True]

### Element-by-Element Breakdown

| `my_house` | `your_house` | `my_house < 11` | `your_house < 11` | AND Result |
|---:|---:|---:|---:|---:|
| `18.0` | `14.0` | `False` | `False` | `False` |
| `20.0` | `24.0` | `False` | `False` | `False` |
| `10.75` | `14.25` | `True` | `False` | `False` |
| `9.50` | `9.0` | `True` | `True` | `True` |

Therefore:

    [False False False  True]

Only the fourth area is smaller than `11` in **both** arrays.

---

# 🔍 Boolean Filtering with NumPy

The Boolean array produced by a logical operation can also be used to **filter the original array**.

For example:

    my_house[np.logical_or(my_house > 18.5, my_house < 10)]

This selects only the areas in `my_house` that are:

- greater than `18.5`, **or**
- smaller than `10`

Result:

    [20.   9.5]

This is a powerful way to select specific values from NumPy arrays.

# 🆚 Python vs NumPy Boolean Operators

| Operation | Python | NumPy |
|---|---|---|
| AND | `and` | `np.logical_and()` |
| OR | `or` | `np.logical_or()` |
| NOT | `not` | `np.logical_not()` |

### Example

For individual Boolean values:

    True and False

For NumPy Boolean arrays:

    np.logical_and(array1, array2)

---

# 💡 Important: Element-Wise Operations

NumPy performs logical operations **element by element**.

For example:

    np.logical_or(
        np.array([False, True, False]),
        np.array([True, False, False])
    )

Result:

    [ True  True False]

Each corresponding pair is evaluated separately.

---

# 🔑 Key Takeaways

- Python's `and`, `or`, and `not` are not suitable for combining NumPy Boolean arrays.
- Use NumPy's logical functions instead:
  - `np.logical_and()`
  - `np.logical_or()`
  - `np.logical_not()`
- NumPy logical functions operate **element-wise**.
- `np.logical_and()` requires both conditions to be `True`.
- `np.logical_or()` requires at least one condition to be `True`.
- `np.logical_not()` reverses Boolean values.
- The resulting Boolean array can be used for **Boolean filtering**.

### Common Patterns

    np.logical_and(condition1, condition2)

    np.logical_or(condition1, condition2)

    np.logical_not(condition)

    array[np.logical_and(condition1, condition2)]
