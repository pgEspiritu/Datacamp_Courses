# 📏 Greater Than and Less Than in Python

## 📌 Comparison Operators

Python provides several operators for comparing values based on whether one value is **greater than**, **less than**, or equal to another.

| Operator | Meaning |
|---|---|
| `<` | Less than |
| `>` | Greater than |
| `<=` | Less than or equal to |
| `>=` | Greater than or equal to |

### ⚠️ Important Syntax

The operators `<=` and `>=` must be written in this order.

✅ Valid:

    <=
    >=

❌ Invalid:

    =<
    =>

---

## 🧪 Examples

All of the following expressions evaluate to `True`:

    3 < 4
    3 <= 4
    "alpha" <= "beta"

### Explanation

- `3 < 4` → `True` because 3 is less than 4.
- `3 <= 4` → `True` because 3 is less than 4.
- `"alpha" <= "beta"` → `True` because `"alpha"` comes before `"beta"` alphabetically.

---

# 🔤 Comparing Strings

When comparing strings, Python determines their relationship based on **lexicographical (alphabetical) order**.

For example:

    "alpha" < "beta"

returns:

    True

because `"alpha"` comes before `"beta"`.

### ⚠️ Case Sensitivity

String comparisons are case-sensitive.

For example:

    "Alpha" < "alpha"

The result depends on the characters' Unicode values, so uppercase and lowercase letters are not treated as identical.

# 🧪 Exercise: Greater Than and Less Than

### 🎯 Instructions

Write Python expressions wrapped in `print()` to check whether:

1. `x` is greater than or equal to `-10`.
2. `"test"` is less than or equal to `y`.
3. `True` is greater than `False`.

---

## ✅ Solution

### 1. Compare Integers

    x = -3 * 6

    print(x >= -10)

First calculate:

    -3 * 6 = -18

Then compare:

    -18 >= -10

### Output

    False

Because `-18` is less than `-10`.

---

### 2. Compare Strings

    y = "test"

    print(y <= "test")

Compare:

    "test" <= "test"

### Output

    True

A string is considered less than or equal to itself.

---

### 3. Compare Booleans

    print(True > False)

### Output

    True

In Python, Boolean values behave like integers in comparisons:

    True  = 1
    False = 0

Therefore:

    True > False

is equivalent to:

    1 > 0

which evaluates to:

    True

---

# 🔑 Key Takeaways

- `<` → less than
- `>` → greater than
- `<=` → less than or equal to
- `>=` → greater than or equal to
- `<=` is valid syntax; `=<` is not.
- `>=` is valid syntax; `=>` is not.
- String comparisons use lexicographical/alphabetical order.
- String comparisons are **case-sensitive**.
- `True > False` evaluates to `True` because `True` behaves like `1` and `False` behaves like `0`.
- Comparison expressions return either `True` or `False`.
