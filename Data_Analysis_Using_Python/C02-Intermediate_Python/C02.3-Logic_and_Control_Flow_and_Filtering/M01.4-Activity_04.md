# 🔘 `and`, `or`, `not` — Boolean Operators (1)

## 📌 Boolean Values

A Boolean value can be represented as:

- `True` or `False`
- `1` or `0`

Boolean operators such as `and`, `or`, and `not` allow you to combine Boolean expressions and perform more advanced queries on your data.

---

# 🏠 Example Variables

The sample code defines two variables representing kitchen areas:

    my_kitchen = 18.0
    your_kitchen = 14.0

---

# 🧪 Exercise

Write Python expressions inside `print()` to check whether:

1. `my_kitchen` is **bigger than 10 and smaller than 18**.
2. `my_kitchen` is **smaller than 14 or bigger than 17**.
3. Double the area of `my_kitchen` is **smaller than triple the area of `your_kitchen`**.

---

# ✅ Solution

## 1. `my_kitchen` Bigger Than 10 AND Smaller Than 18

    print(my_kitchen > 10 and my_kitchen < 18)

### Evaluation

    my_kitchen > 10
    18.0 > 10
    True

    my_kitchen < 18
    18.0 < 18
    False

Therefore:

    True and False

Result:

    False

> 💡 `18.0` is not smaller than `18`; it is equal to `18`.

---

## 2. `my_kitchen` Smaller Than 14 OR Bigger Than 17

    print(my_kitchen < 14 or my_kitchen > 17)

### Evaluation

    my_kitchen < 14
    18.0 < 14
    False

    my_kitchen > 17
    18.0 > 17
    True

Therefore:

    False or True

Result:

    True

### ⚠️ Important Correction

The supplied exercise solution used:

    print(my_kitchen < 14 or my_kitchen < 17)

However, the instruction says **"smaller than 14 or bigger than 17"**, so the correct second comparison is:

    my_kitchen > 17

---

## 3. Double `my_kitchen` Smaller Than Triple `your_kitchen`

    print((my_kitchen * 2) < (your_kitchen * 3))

### Calculate Each Side

Double the area of `my_kitchen`:

    18.0 * 2 = 36.0

Triple the area of `your_kitchen`:

    14.0 * 3 = 42.0

Compare:

    36.0 < 42.0

Result:

    True

---

# 📊 Results Summary

| Condition | Result |
|---|---|
| `my_kitchen > 10 and my_kitchen < 18` | `False` |
| `my_kitchen < 14 or my_kitchen > 17` | `True` |
| `(my_kitchen * 2) < (your_kitchen * 3)` | `True` |

---

# 🧠 Boolean Logic Breakdown

### `and`

Both conditions must be `True`.

    True and True    → True
    True and False   → False
    False and True   → False
    False and False  → False

### `or`

At least one condition must be `True`.

    True or True     → True
    True or False    → True
    False or True    → True
    False or False   → False

### `not`

Reverses a Boolean value.

    not True     → False
    not False    → True

---

# 🔑 Key Takeaways

- `and` requires **both conditions** to be true.
- `or` requires **at least one condition** to be true.
- Comparison expressions such as `>` and `<` produce Boolean values.
- Parentheses can make arithmetic comparisons easier to read:
  
      (my_kitchen * 2) < (your_kitchen * 3)

- Always match the comparison operator to the wording of the condition:
  - **smaller than** → `<`
  - **bigger than** → `>`
  - **smaller than or equal to** → `<=`
  - **bigger than or equal to** → `>=`
