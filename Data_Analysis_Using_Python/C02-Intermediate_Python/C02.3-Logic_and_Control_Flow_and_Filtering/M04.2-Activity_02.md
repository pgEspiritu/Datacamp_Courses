# 🚗 Driving Right (2)

## 📌 Exercise Overview

In the previous exercise, we first created a separate Boolean Series:

    dr = cars["drives_right"]

Then we used it to filter the DataFrame:

    sel = cars[dr]

This works, but the intermediate variable `dr` is not necessary.

We can place the expression that creates the Boolean Series **directly inside the square brackets**.

This creates a **one-liner**.

---

# 🧪 Exercise

Convert the previous code so that `sel` is calculated directly using the `drives_right` column.

The goal is to filter `cars` and keep only observations where:

    drives_right == True

---

# ✅ Solution

    # Import cars data
    import pandas as pd

    cars = pd.read_csv("cars.csv", index_col=0)

    # Convert code to a one-liner
    sel = cars[cars["drives_right"]]

    # Print sel
    print(sel)

---

# 🧠 How the One-Liner Works

The code:

    sel = cars[cars["drives_right"]]

performs two operations at once.

### Outer `cars[...]`

    cars[...]

selects rows from the `cars` DataFrame.

### Inner `cars["drives_right"]`

    cars["drives_right"]

returns the Boolean Series used as the filtering condition.

So:

    cars[cars["drives_right"]]

means:

> Select the rows from `cars` where `drives_right` is `True`.

---

# 🔄 Comparing the Two Approaches

## Two-Step Approach

    dr = cars["drives_right"]
    sel = cars[dr]

## One-Liner

    sel = cars[cars["drives_right"]]

Both approaches produce the **same result**.

The one-liner is useful when the filtering condition is simple and does not need to be reused elsewhere.

---

# 🔍 Boolean Filtering Pattern

The general pattern is:

    dataframe[dataframe["boolean_column"]]

For example:

    cars[cars["drives_right"]]

This keeps only the rows where the Boolean column contains `True`.

---

# 🔑 Key Takeaways

- You do not always need an intermediate variable for a filtering condition.
- A Boolean Series can be created directly inside `[]`.
- The one-liner:

      cars[cars["drives_right"]]

  is equivalent to:

      dr = cars["drives_right"]
      cars[dr]

- This is a common and convenient way to filter Pandas DataFrames.
- Boolean indexing allows you to select only the rows that satisfy a condition.

### 📚 Core Pattern

    result = dataframe[dataframe["column"]]
