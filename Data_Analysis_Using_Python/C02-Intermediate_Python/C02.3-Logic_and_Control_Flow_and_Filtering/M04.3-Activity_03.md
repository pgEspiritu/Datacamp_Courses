# 🚗 Cars per Capita (1)

## 📌 Exercise Overview

Let's continue working with the `cars` dataset.

This time, the goal is to find the countries with a **high cars per capita** value.

The `cars_per_cap` column represents the number of cars per 1,000 people.

We want to identify countries where:

    cars_per_cap > 500

To do this, we will create a Boolean Series and use it to filter the `cars` DataFrame.

---

# 🧪 Exercise

Complete the following steps:

1. Select the `cars_per_cap` column as a Pandas Series and store it as `cpc`.
2. Compare `cpc` with `500` and create a Boolean Series called `many_cars`.
3. Use `many_cars` to filter `cars` and store the result as `car_maniac`.
4. Print `car_maniac`.

A one-liner can also be used, but the exercise demonstrates the step-by-step approach.

---

# ✅ Solution

    # Import cars data
    import pandas as pd

    cars = pd.read_csv("cars.csv", index_col=0)

    # Create car_maniac: observations that have a cars_per_cap over 500
    cpc = cars["cars_per_cap"]
    many_cars = cpc > 500
    car_maniac = cars[many_cars]

    print(car_maniac)

---

# 1️⃣ Select the `cars_per_cap` Column

    cpc = cars["cars_per_cap"]

This extracts the `cars_per_cap` column as a **Pandas Series**.

For example, the Series contains values such as:

    809
    731
    588
    18
    200
    70
    45

---

# 2️⃣ Create a Boolean Series

Next, compare each value with `500`:

    many_cars = cpc > 500

This performs the comparison element by element.

The result is a Boolean Series:

    True
    True
    True
    False
    False
    False
    False

The meaning is:

- `True` → `cars_per_cap` is greater than `500`
- `False` → `cars_per_cap` is `500` or less

---

# 3️⃣ Filter the DataFrame

Use the Boolean Series to select the matching rows:

    car_maniac = cars[many_cars]

Pandas keeps only the observations where `many_cars` is `True`.

---

# 4️⃣ Print the Result

    print(car_maniac)

The resulting DataFrame contains only countries with:

    cars_per_cap > 500

---

# 🔍 Boolean Filtering Breakdown

The process can be visualized as:

    cars["cars_per_cap"]
            ↓
        cpc > 500
            ↓
       many_cars
            ↓
      cars[many_cars]
            ↓
       car_maniac

This is the same Boolean filtering technique used in the previous exercises.

---

# ⚡ One-Liner Alternative

You can also perform the filtering without creating `cpc` or `many_cars`:

    car_maniac = cars[cars["cars_per_cap"] > 500]

This produces the same result.

---

# 🧠 Important Concept

The expression:

    cars["cars_per_cap"] > 500

creates a Boolean Series.

When that Boolean Series is placed inside:

    cars[...]

Pandas keeps only the corresponding rows where the value is `True`.

So:

    cars[cars["cars_per_cap"] > 500]

means:

> Select the rows where `cars_per_cap` is greater than `500`.

---

# 🔑 Key Takeaways

- Select a DataFrame column as a Series using:

      cars["cars_per_cap"]

- Use a comparison operator to create a Boolean Series:

      many_cars = cpc > 500

- Use the Boolean Series to filter the DataFrame:

      car_maniac = cars[many_cars]

- You can combine the steps into a one-liner:

      car_maniac = cars[cars["cars_per_cap"] > 500]

### 📚 Core Pattern

    series = dataframe["column"]
    condition = series > value
    result = dataframe[condition]

Or, as a one-liner:

    result = dataframe[dataframe["column"] > value]
