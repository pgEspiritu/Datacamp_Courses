# 🔢 Compare NumPy Arrays

## 📌 Comparison Operators with NumPy Arrays

Comparison operators can also be used with **NumPy arrays**.

When you compare a NumPy array with a single value, Python performs the comparison **element by element** and returns a **Boolean array** containing `True` or `False` for each element.

You can also compare **two NumPy arrays element-wise**, as long as their elements correspond to each other.

---

## 🏠 Example: House Areas

Two NumPy arrays are provided:

    my_house = np.array([18.0, 20.0, 10.75, 9.50])
    your_house = np.array([14.0, 24.0, 14.25, 9.0])

The values represent the areas of the:

1. Kitchen
2. Living room
3. Bedroom
4. Bathroom

The areas are stored in the **same order** in both arrays.

---

# 🧪 Exercise: Compare Arrays

### 🎯 Instructions

Using comparison operators, generate Boolean arrays that answer:

1. Which areas in `my_house` are **greater than or equal to `18`**?
2. Which areas in `my_house` are **smaller than the corresponding areas in `your_house`**?
3. Wrap both commands in `print()` so the results can be inspected.

---

## ✅ Solution

### 1. `my_house` Greater Than or Equal to `18`

    import numpy as np

    my_house = np.array([18.0, 20.0, 10.75, 9.50])
    your_house = np.array([14.0, 24.0, 14.25, 9.0])

    print(my_house >= 18)

### Output

    [ True  True False False]

### Explanation

Python checks every value in `my_house`:

| Area | Comparison | Result |
|---:|---|---|
| `18.0` | `18.0 >= 18` | `True` |
| `20.0` | `20.0 >= 18` | `True` |
| `10.75` | `10.75 >= 18` | `False` |
| `9.50` | `9.50 >= 18` | `False` |

---

### 2. Compare `my_house` with `your_house`

NumPy allows two arrays to be compared **element-wise**:

    print(my_house < your_house)

### Output

    [False  True  True False]

### Explanation

Each corresponding element is compared:

| `my_house` | `your_house` | Comparison | Result |
|---:|---:|---|---|
| `18.0` | `14.0` | `18.0 < 14.0` | `False` |
| `20.0` | `24.0` | `20.0 < 24.0` | `True` |
| `10.75` | `14.25` | `10.75 < 14.25` | `True` |
| `9.50` | `9.0` | `9.50 < 9.0` | `False` |

---

# 🧠 Element-Wise Comparison

With NumPy arrays, a comparison such as:

    my_house < your_house

does **not** compare the arrays as a whole.

Instead, NumPy compares corresponding elements:

    my_house[0] < your_house[0]
    my_house[1] < your_house[1]
    my_house[2] < your_house[2]
    my_house[3] < your_house[3]

The result is a Boolean array:

    [False  True  True False]

---

# 🔑 Key Takeaways

- NumPy arrays support comparison operators such as `<`, `>`, `<=`, and `>=`.
- Comparing an array with a single value performs the comparison **element by element**.
- Comparing two NumPy arrays also works **element-wise**.
- The result is a **Boolean array** containing `True` or `False`.
- Boolean arrays are useful for **filtering and selecting data**.

### Common Examples

    my_house >= 18
    my_house < your_house
    my_house == your_house
    my_house != your_house
