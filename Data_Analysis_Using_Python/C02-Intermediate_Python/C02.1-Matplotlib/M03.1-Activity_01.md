# 🏷️ Labels - Customizing Matplotlib Plots

## 🎯 Exercise Description

It's time to customize your own plot! This is where data visualization becomes more meaningful and easier to understand. 📊

In this exercise, you will work with a **scatter plot** showing world development data:

- 💰 GDP per capita on the X-axis
- ❤️ Life expectancy on the Y-axis
- 📈 GDP displayed using a logarithmic scale

The goal is to improve the visualization by adding:

- 🏷️ Axis labels
- 📝 A descriptive title

---

# 📊 Starting Scatter Plot

The basic scatter plot is created using:

```python
plt.scatter(gdp_cap, life_exp)
```

This creates a plot where:

| Axis | Data |
|---|---|
| X-axis | GDP per capita |
| Y-axis | Life expectancy |

Each point represents a country.

---

# 📈 Applying Logarithmic Scale

GDP values vary significantly between countries.

A logarithmic scale helps display both low-income and high-income countries more clearly.

```python
plt.xscale('log')
```

This changes the X-axis into a logarithmic scale.

---

# 🏷️ Adding Axis Labels

Matplotlib provides functions to label the axes:

```python
plt.xlabel()
plt.ylabel()
```

Example:

```python
plt.xlabel("GDP per Capita [in USD]")
plt.ylabel("Life Expectancy [in years]")
```

Explanation:

| Function | Purpose |
|---|---|
| `plt.xlabel()` | Adds a label to the X-axis |
| `plt.ylabel()` | Adds a label to the Y-axis |

---

# 📝 Adding a Plot Title

A title explains what the visualization represents.

Use:

```python
plt.title()
```

Example:

```python
plt.title("World Development in 2007")
```

---

# 💻 Solution

```python
# Basic scatter plot, log scale

plt.scatter(gdp_cap, life_exp)

plt.xscale('log')

# Strings

xlab = 'GDP per Capita [in USD]'

ylab = 'Life Expectancy [in years]'

title = 'World Development in 2007'

# Add axis labels

plt.xlabel(xlab)

plt.ylabel(ylab)

# Add title

plt.title(title)

# After customizing, display the plot

plt.show()
```

---
