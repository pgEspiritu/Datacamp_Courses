# 📊 Build a Histogram (1) - Matplotlib

## 🎯 Exercise Description

A histogram is a visualization tool used to understand the **distribution of numerical data**.

In this exercise, we will analyze:

```
Life Expectancy of Different Countries in 2007
```

The dataset is stored in:

```python
life_exp
```

This list contains life expectancy values for different countries.

The goal is to create a histogram to see how life expectancy values are distributed around the world. 🌍

---

# 📌 Histogram Reminder

A histogram groups values into ranges called:

```
Bins
```

Each bar represents:

```
Number of observations within a range
```

Example:

```
Life Expectancy

Frequency
   |
   |        █
   |     █  █  █
   |  █  █  █  █
   |________________
      40 50 60 70 80
```

---

# 🐍 Matplotlib Histogram Syntax

The general structure is:

```python
import matplotlib.pyplot as plt

plt.hist(data)

plt.show()
```

Where:

| Component | Description |
|---|---|
| `plt.hist()` | Creates the histogram |
| `data` | Numerical values to visualize |
| `plt.show()` | Displays the chart |

---

# 🎯 Instructions

Complete the following tasks:

1. Create a histogram using:

```python
plt.hist()
```

2. Use:

```python
life_exp
```

as the data source.

3. Do not specify the number of bins.

Matplotlib will automatically use:

```
10 bins (default)
```

4. Display the histogram using:

```python
plt.show()
```

5. Analyze the chart:

- Which life expectancy range contains the most observations?
- What does the distribution tell us about global life expectancy?

# 💡 Solution

```python
# Create histogram of life_exp data
plt.hist(life_exp)

# Display histogram
plt.show()
```

---

# 📚 Explanation

## 1️⃣ Creating the Histogram

```python
plt.hist(life_exp)
```

This tells Matplotlib to:

- Take all values from `life_exp`
- Divide them into bins
- Count how many values fall into each bin
- Draw bars representing the frequency

---

## 2️⃣ Default Number of Bins

Because we did not specify:

```python
bins=
```

Matplotlib automatically uses:

```
10 bins
```

Example:

```python
plt.hist(life_exp, bins=10)
```

would produce the same result.

---

## 3️⃣ Displaying the Plot

```python
plt.show()
```

This renders the histogram and displays the visualization.
