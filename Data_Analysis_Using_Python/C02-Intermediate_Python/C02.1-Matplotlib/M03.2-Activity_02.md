---

# 📌 What Are Ticks?

Ticks are the values displayed along the axes of a plot.

Example:

```
1000     10000     100000
```

These values represent positions on the axis.

However, large numbers can make a graph harder to read.

Instead of displaying:

```
1000
10000
100000
```

we can replace them with:

```
1k
10k
100k
```

This creates a cleaner visualization.

---

# 🔢 Using xticks()

Matplotlib provides:

```python
plt.xticks()
```

to customize X-axis tick values and labels.

Syntax:

```python
plt.xticks(values, labels)
```

Example:

```python
plt.xticks(
    [1000, 10000, 100000],
    ['1k', '10k', '100k']
)
```

Explanation:

| Input | Purpose |
|---|---|
| First list | Original tick positions |
| Second list | New labels displayed |

---

# 💻 Solution

```python
# Scatter plot

plt.scatter(gdp_cap, life_exp)

# Previous customizations

plt.xscale('log')

plt.xlabel('GDP per Capita [in USD]')

plt.ylabel('Life Expectancy [in years]')

plt.title('World Development in 2007')

# Definition of tick_val and tick_lab

tick_val = [1000, 10000, 100000]

tick_lab = ['1k', '10k', '100k']

# Adapt the ticks on the x-axis

plt.xticks(tick_val, tick_lab)

# After customizing, display the plot

plt.show()
```

---

# 📚 Explanation

## 1️⃣ Creating the Scatter Plot

```python
plt.scatter(gdp_cap, life_exp)
```

Creates a scatter plot where:

- X-axis → GDP per capita
- Y-axis → Life expectancy

Each point represents a country.

---

## 2️⃣ Applying Logarithmic Scale

```python
plt.xscale('log')
```

Changes the X-axis into a logarithmic scale.

This helps display GDP values that range from very small to very large.

---

## 3️⃣ Defining Tick Values

```python
tick_val = [1000, 10000, 100000]
```

These are the original positions of the X-axis ticks.

---

## 4️⃣ Defining Tick Labels

```python
tick_lab = ['1k', '10k', '100k']
```

These are the replacement labels.

The graph will display:

| Original Value | New Label |
|---|---|
| 1000 | 1k |
| 10000 | 10k |
| 100000 | 100k |

---

## 5️⃣ Applying Custom Tick Labels

```python
plt.xticks(tick_val, tick_lab)
```

Replaces the default X-axis labels with the customized labels.
