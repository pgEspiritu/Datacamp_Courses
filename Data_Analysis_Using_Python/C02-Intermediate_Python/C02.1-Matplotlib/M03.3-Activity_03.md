# 🔵 Sizes - Customizing Scatter Plot Markers

## 🎯 Exercise Description

Scatter plots can show relationships between two variables, but sometimes we want to display additional information.

In this exercise, you will customize the **size of scatter plot points** based on population.

The world development scatter plot contains:

- 💰 GDP per capita on the X-axis
- ❤️ Life expectancy on the Y-axis
- 👥 Population represented by bubble size

Larger countries will appear as larger bubbles.

---

# 📊 Scatter Plot Marker Size

In Matplotlib, the size of scatter plot markers can be controlled using the:

```python
s
```

argument.

Example:

```python
plt.scatter(x, y, s=size)
```

Where:

| Parameter | Description |
|---|---|
| `x` | X-axis data |
| `y` | Y-axis data |
| `s` | Size of each marker |

---

# 👥 Using Population as Bubble Size

The population data is stored in:

```python
pop
```

The values represent:

```
Population in millions
```

Example:

```python
plt.scatter(gdp_cap, life_exp, s=pop)
```

This creates bubbles where:

- Small populations → smaller dots
- Large populations → larger dots

---

# 🔢 Converting List to NumPy Array

To perform calculations on all population values at once, convert the list into a NumPy array.

Import NumPy:

```python
import numpy as np
```

Convert the list:

```python
np_pop = np.array(pop)
```

Now `np_pop` is a NumPy array.

---

# ✖️ Doubling Population Values

NumPy allows element-wise calculations.

Example:

```python
np_pop = np_pop * 2
```

This doubles every value inside the array.

Before:

```
[10, 50, 100]
```

After:

```
[20, 100, 200]
```

This makes the bubbles larger and easier to see.

---

# 💻 Solution

```python
# Import numpy as np

import numpy as np

# Store pop as a numpy array: np_pop

np_pop = np.array(pop)

# Double np_pop

np_pop = np_pop * 2

# Update: set s argument to np_pop

plt.scatter(gdp_cap, life_exp, s=np_pop)

# Previous customizations

plt.xscale('log')

plt.xlabel('GDP per Capita [in USD]')

plt.ylabel('Life Expectancy [in years]')

plt.title('World Development in 2007')

plt.xticks(
    [1000, 10000, 100000],
    ['1k', '10k', '100k']
)

# Display the plot

plt.show()
```

# 📚 Explanation

## 1️⃣ Import NumPy

```python
import numpy as np
```

Imports the NumPy package and gives it the shorter name:

```python
np
```

---

## 2️⃣ Convert Population Data

```python
np_pop = np.array(pop)
```

Converts the population list into a NumPy array.

This allows mathematical operations on all values.

---

## 3️⃣ Increase Bubble Size

```python
np_pop = np_pop * 2
```

Doubles every population value.

Because NumPy performs element-wise calculations, each value is multiplied individually.

---

## 4️⃣ Apply Bubble Sizes

```python
plt.scatter(gdp_cap, life_exp, s=np_pop)
```

The `s` parameter controls marker size.

Now:

- 👥 Large population countries → larger bubbles
- 👤 Small population countries → smaller bubbles
