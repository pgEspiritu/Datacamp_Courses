# 🔄 Basic `while` Loop

## 📌 Exercise Overview

A `while` loop repeatedly executes a block of code as long as its condition is `True`.

The previous example was:

    error = 50.0

    while error > 1:
        error = error / 4
        print(error)

This exercise applies the same idea to a simple control system for an **inverted pendulum**.

The `offset` variable represents how far the pendulum is from standing perfectly straight. The loop will gradually reduce this offset until it reaches `0`.

---

# 🧪 Exercise

Create a `while` loop that corrects the offset.

### Requirements

1. Create `offset` with an initial value of `8`.
2. Continue the loop while `offset` is **not equal to `0`**.
3. Inside the loop:
   - Print `"correcting..."`
   - Decrease `offset` by `1`
   - Print the updated value of `offset`

---

# ✅ Solution

    # Initialize offset
    offset = 8

    # Code the while loop
    while offset != 0:
        print("correcting...")
        offset = offset - 1
        print(offset)

---

# 🧠 Step-by-Step Explanation

## 1️⃣ Initialize `offset`

    offset = 8

The starting offset is:

    8

---

## 2️⃣ Set the `while` Condition

    while offset != 0:

The loop continues as long as:

    offset != 0

is `True`.

Since:

    8 != 0

is `True`, the loop starts.

---

## 3️⃣ Print `"correcting..."`

Inside the loop:

    print("correcting...")

This displays the correction message on every iteration.

---

## 4️⃣ Decrease `offset`

    offset = offset - 1

Each time the loop runs, `offset` decreases by `1`.

For example:

    8 → 7 → 6 → 5 → 4 → 3 → 2 → 1 → 0

This update is what eventually allows the loop to stop.

---

## 5️⃣ Print the Updated `offset`

    print(offset)

This lets you observe the value as it changes.

---

The loop produces:

    offset != 0

    0 != 0

# 🔄 How the Loop Progresses

| Iteration | `offset` Before | Condition `offset != 0` | `offset` After |
|---:|---:|---|---:|
| 1 | `8` | `True` | `7` |
| 2 | `7` | `True` | `6` |
| 3 | `6` | `True` | `5` |
| 4 | `5` | `True` | `4` |
| 5 | `4` | `True` | `3` |
| 6 | `3` | `True` | `2` |
| 7 | `2` | `True` | `1` |
| 8 | `1` | `True` | `0` |
| 9 | `0` | `False` | Loop stops |

---

# ⚠️ Avoiding an Infinite Loop

The update:

    offset = offset - 1

is essential.

Without it:

    offset = 8

    while offset != 0:
        print("correcting...")

`offset` would always remain `8`.

Therefore:

    offset != 0

would always be `True`, creating an **infinite loop**.

### ✅ Correct

    while offset != 0:
        offset = offset - 1

### ❌ Infinite Loop

    while offset != 0:
        print("correcting...")

---

# 💡 Shorter Alternative

Python also supports the shorthand:

    offset -= 1

which is equivalent to:

    offset = offset - 1

So the loop could also be written as:

    offset = 8

    while offset != 0:
        print("correcting...")
        offset -= 1
        print(offset)

---

# 🔑 Key Takeaways

- Initialize the loop variable before the `while` loop.
- Use a condition that determines when the loop should continue.
- Update the loop variable inside the loop.
- The update must eventually make the condition `False`.
- `offset = offset - 1` decreases `offset` by `1`.
- `offset -= 1` is a shorter equivalent.
- Always make sure a `while` loop has a **stopping point**.

### 📚 Core Pattern

    variable = starting_value

    while condition:
        # perform an action
        variable = updated_value
        # inspect the updated value
