# 🏠 Loop Over a List

## 📌 Exercise Overview

A `for` loop allows you to iterate over every element in a list and execute the same code for each element.

The basic syntax is:

    for variable in sequence:
        # code to execute

For example:

    fam = [1.73, 1.68, 1.71, 1.89]

    for height in fam:
        print(height)

This prints every height separately.

---

# 🏠 `areas` List

The `areas` list contains the areas of different rooms in the house:

    areas = [11.25, 18.0, 20.0, 10.75, 9.50]

---

# 🧪 Exercise

Write a `for` loop that:

- Iterates over every element in `areas`.
- Prints each element separately.

---

# ✅ Solution

    # areas list
    areas = [11.25, 18.0, 20.0, 10.75, 9.50]

    # Code the for loop
    for area in areas:
        print(area)

---

# 🔍 How It Works

The loop:

    for area in areas:
        print(area)

goes through the list one element at a time.

### Iterations

| Iteration | `area` | Output |
|---:|---:|---:|
| 1 | `11.25` | `11.25` |
| 2 | `18.0` | `18.0` |
| 3 | `20.0` | `20.0` |
| 4 | `10.75` | `10.75` |
| 5 | `9.50` | `9.5` |

### Output

    11.25
    18.0
    20.0
    10.75
    9.5

> 💡 Python displays `9.50` as `9.5` because trailing zeros are not significant for a floating-point value.

---

# 🧠 Important Parts

### `for`

Starts the loop:

    for

### `area`

The loop variable that stores the current element:

    for area

### `in areas`

Tells Python to take each element from the `areas` list:

    for area in areas

### `print(area)`

Executes once for every element.

---

# ⚠️ Indentation

The code inside the `for` loop must be indented.

### ✅ Correct

    for area in areas:
        print(area)

### ❌ Incorrect

    for area in areas:
    print(area)

The indentation tells Python that `print(area)` belongs to the loop.

---

# 🔑 Key Takeaways

- A `for` loop processes each item in a sequence.
- The syntax is:

      for variable in sequence:
          # code

- In this exercise:

      area

  stores the current element from:

      areas

- The loop automatically stops after all elements have been processed.

### 📚 Core Pattern

    for item in my_list:
        print(item)
