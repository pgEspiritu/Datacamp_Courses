# 🔄 Add Conditionals to a `while` Loop

## 📌 Exercise Overview

The previous `while` loop worked when `offset` was positive because the code continuously decreased `offset` until it reached `0`.

However, if `offset` starts as a **negative value**, decreasing it further will never make it reach `0`.

### ❌ Problem

For example:

    offset = -6

    while offset != 0:
        print("correcting...")
        offset = offset - 1
        print(offset)

The values would become:

    -6 → -7 → -8 → -9 → ...

The condition:

    offset != 0

would always remain `True`.

This creates an **infinite loop**.

---

# 🧠 Solution

We need the correction to depend on whether `offset` is positive or negative:

- If `offset > 0`, decrease it by `1`.
- Otherwise, increase it by `1`.

This can be done using an `if-else` statement inside the `while` loop.

---

# 🧪 Exercise

### Requirements

1. Initialize `offset` to `-6`.
2. Create a `while` loop that continues while:

       offset != 0

3. Inside the loop:
   - Print `"correcting..."`
   - If `offset > 0`, decrease `offset` by `1`.
   - Otherwise, increase `offset` by `1`.
   - Print the updated `offset`.

---

# ✅ Solution

    # Initialize offset
    offset = -6

    # Code the while loop
    while offset != 0:
        print("correcting...")

        if offset > 0:
            offset = offset - 1
        else:
            offset = offset + 1

        print(offset)

---

# 🔍 How It Works

## 1️⃣ Initialize `offset`

    offset = -6

The initial value is negative.

---

## 2️⃣ Start the `while` Loop

    while offset != 0:

Since:

    -6 != 0

is `True`, the loop starts.

---

## 3️⃣ Check Whether `offset` is Positive

Inside the loop:

    if offset > 0:
        offset = offset - 1
    else:
        offset = offset + 1

Because:

    -6 > 0

is `False`, Python executes the `else` block:

    offset = offset + 1

So:

    -6 + 1 = -5

---

# 🔄 Loop Progression

The value moves toward `0`:

    -6
    -5
    -4
    -3
    -2
    -1
     0

Once `offset` becomes `0`, Python checks:

    offset != 0

which becomes:

    0 != 0

Result:

    False

The loop stops.

---

# 📊 Execution Summary

| Iteration | `offset` Before | `offset > 0` | Action | `offset` After |
|---:|---:|---|---|---:|
| 1 | `-6` | `False` | `+1` | `-5` |
| 2 | `-5` | `False` | `+1` | `-4` |
| 3 | `-4` | `False` | `+1` | `-3` |
| 4 | `-3` | `False` | `+1` | `-2` |
| 5 | `-2` | `False` | `+1` | `-1` |
| 6 | `-1` | `False` | `+1` | `0` |

The loop then ends.

---

# 🧠 What Happens with a Positive Offset?

The same code also works when `offset` is positive.

For example:

    offset = 4

The condition:

    offset > 0

is `True`, so Python executes:

    offset = offset - 1

The values become:

    4 → 3 → 2 → 1 → 0

Again, the loop stops.

---

# 🔄 The Control Logic

The loop effectively says:

    while offset != 0:
        if offset > 0:
            decrease offset
        else:
            increase offset

In other words:

> **Move the offset toward zero regardless of whether it starts positive or negative.**

---

# ⚠️ Avoiding Infinite Loops

The important part is that every iteration must move `offset` closer to `0`.

### ✅ Positive offset

    offset > 0
    offset = offset - 1

### ✅ Negative offset

    offset <= 0
    offset = offset + 1

### ❌ Problematic approach

    offset = offset - 1

for every value would move negative offsets farther away from zero.

---

# 💡 Alternative Shorthand

These:

    offset = offset - 1

and:

    offset = offset + 1

can also be written as:

    offset -= 1
    offset += 1

So the loop could be written as:

    offset = -6

    while offset != 0:
        print("correcting...")

        if offset > 0:
            offset -= 1
        else:
            offset += 1

        print(offset)

---

# 🔑 Key Takeaways

- A `while` loop can contain an `if-else` statement.
- The conditional logic can determine how a variable should be updated.
- When `offset > 0`, decrease it:

      offset = offset - 1

- When `offset` is not positive, increase it:

      offset = offset + 1

- The goal is to make `offset` move toward `0`.
- The loop stops when:

      offset == 0

- Always make sure the loop's condition will eventually become `False`.
- This is a common pattern for correcting a value toward a target.

### 📚 Core Pattern

    offset = starting_value

    while offset != 0:
        if offset > 0:
            offset -= 1
        else:
            offset += 1
