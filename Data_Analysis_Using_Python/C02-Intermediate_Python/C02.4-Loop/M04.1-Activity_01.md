# 🐼 Loop Over DataFrame (1)

## 📌 Exercise Overview

When you want to iterate over the **rows** of a Pandas DataFrame, use the `iterrows()` method.

The general pattern is:

    for lab, row in dataframe.iterrows():
        ...

On each iteration, `iterrows()` provides two values:

- `lab` → the **row label**
- `row` → the **row contents as a Pandas Series**

---

# 🚗 The `cars` DataFrame

The exercise uses the `cars` DataFrame, which contains information about:

- `cars_per_cap` — cars per 1,000 people
- `drives_right` — whether people drive on the right side of the road

The first column is used as the DataFrame index:

    cars = pd.read_csv("cars.csv", index_col=0)

---

# 🧪 Exercise

Write a `for` loop that:

1. Iterates over every row in `cars`.
2. Prints the **row label**.
3. Prints the **entire row contents**.

---

# ✅ Solution

    # Import cars data
    import pandas as pd

    cars = pd.read_csv("cars.csv", index_col=0)

    # Iterate over rows of cars
    for car, row in cars.iterrows():
        print(car)
        print(row)

---

# 🔍 How It Works

The key line is:

    for car, row in cars.iterrows():

During each iteration:

- `car` receives the row label.
- `row` receives the corresponding row as a Pandas Series.

Then:

    print(car)

prints the row label.

And:

    print(row)

prints all values in that row.

---

# 📊 Example of One Iteration

Suppose one row has the label:

    US

Then `car` contains:

    "US"

while `row` contains something similar to:

    country         United States
    cars_per_cap             809
    drives_right            True
    Name: US, dtype: object

So:

    print(car)

produces:

    US

and:

    print(row)

prints the complete Series for that row.

---

# 🧠 Understanding `iterrows()`

The expression:

    cars.iterrows()

returns row information one row at a time.

Conceptually:

    (row_label, row_data)

For example:

    ("US", row_for_US)
    ("AUS", row_for_AUS)
    ("JPN", row_for_JPN)
    ...

The `for` loop unpacks each pair into:

    car
    row

---

# 🆚 DataFrame Iteration vs Row Iteration

A basic loop:

    for column in cars:
        print(column)

iterates over **column names**.

To iterate over rows:

    for car, row in cars.iterrows():
        print(car)
        print(row)

### Important

> Use `.iterrows()` when you explicitly want to process DataFrame rows.

---

# ⚠️ The Variable Names Are Arbitrary

The exercise uses:

    for car, row in cars.iterrows():

But the names can be changed:

    for label, data in cars.iterrows():
        print(label)
        print(data)

Or:

    for index, row in cars.iterrows():
        print(index)
        print(row)

The important part is the order:

- First variable → row label
- Second variable → row contents

---

# 🔑 Key Takeaways

- Use `.iterrows()` to iterate over **rows** of a Pandas DataFrame.
- Each iteration gives you:

      row_label, row_data

- The row data is returned as a **Pandas Series**.
- A common pattern is:

      for label, row in dataframe.iterrows():
          print(label)
          print(row)

- The variable names are arbitrary, but the order matters.
- A basic `for` loop over a DataFrame iterates over **columns**, not rows.

### 📚 Core Pattern

    for label, row in dataframe.iterrows():
        print(label)
        print(row)
