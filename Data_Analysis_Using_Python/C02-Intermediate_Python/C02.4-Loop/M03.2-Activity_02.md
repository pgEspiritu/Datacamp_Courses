# 🔢 Loop Over a NumPy Array

## 📌 Exercise Overview

NumPy arrays can be used with `for` loops.

The approach depends on whether the array is **1D** or **2D**.

### 1D NumPy Array

For a one-dimensional array, a regular `for` loop is enough:

    for x in my_array:
        print(x)

### 2D NumPy Array

A two-dimensional array contains multiple 1D arrays, so a basic `for` loop processes one row at a time.

To iterate over **every individual element**, use:

    for x in np.nditer(my_array):
        print(x)

---

# ⚾ NumPy Arrays

Two NumPy arrays are available:

### `np_height`

A 1D NumPy array containing the heights of Major League Baseball players.

### `np_baseball`

A 2D NumPy array containing:

- First column → player heights
- Second column → player weights

---

# 🧪 Exercise

Complete the following tasks:

1. Import NumPy using the alias `np`.
2. Loop over every element in `np_height` and print:

       x inches

   where `x` is the value in the array.
3. Loop over every element in `np_baseball` and print it.

---

# ✅ Solution

    # Import numpy as np
    import numpy as np

    # For loop over np_height
    for x in np_height:
        print(str(x) + " inches")

    # For loop over np_baseball
    for y in np.nditer(np_baseball):
        print(str(y))

---

# 🔍 Step-by-Step Explanation

## 1️⃣ Import NumPy

    import numpy as np

This imports the NumPy package and gives it the local alias:

    np

This allows us to use functions such as:

    np.nditer()

---

# 2️⃣ Loop Over `np_height`

Because `np_height` is a **1D NumPy array**, a regular `for` loop is sufficient:

    for x in np_height:
        print(str(x) + " inches")

Each iteration places one height value into `x`.

For example, if:

    np_height = [74, 70, 72]

the loop produces:

    74 inches
    70 inches
    72 inches

---

# 3️⃣ Why Use `str(x)`?

The value stored in `x` is numeric, while:

    " inches"

is a string.

Using:

    str(x)

converts the number into a string so it can be joined with the text using `+`.

Example:

    str(74) + " inches"

produces:

    "74 inches"

---

# 4️⃣ Loop Over `np_baseball`

Because `np_baseball` is a **2D array**, use `np.nditer()`:

    for y in np.nditer(np_baseball):
        print(str(y))

This iterates through every individual value in the array.

Instead of processing one row at a time, `np.nditer()` visits each element separately.

---

# 📊 1D vs 2D NumPy Arrays

| Array Type | Loop |
|---|---|
| 1D | `for x in array:` |
| 2D — each row | `for x in array:` |
| 2D — every element | `for x in np.nditer(array):` |

### Example

A 1D array:

    np_height = [74, 70, 72]

    for x in np_height:
        print(x)

A 2D array:

    np_baseball = [
        [74, 180],
        [70, 160],
        [72, 190]
    ]

To access every value:

    for x in np.nditer(np_baseball):
        print(x)

---

# 🧠 What Does `np.nditer()` Do?

`np.nditer()` creates an iterator that moves through **all elements** of a NumPy array, regardless of its number of dimensions.

For example:

    np_baseball = np.array([
        [74, 180],
        [70, 160]
    ])

Using:

    for x in np.nditer(np_baseball):
        print(x)

processes:

    74
    180
    70
    160

one element at a time.

---

# 🔑 Key Takeaways

- A **1D NumPy array** can be looped over with a regular `for` loop.
- A **2D NumPy array** normally returns one row at a time with a basic loop.
- Use `np.nditer()` to iterate over **every individual element** of a multidimensional array.
- Import NumPy with:

      import numpy as np

- Use `str()` when combining numeric values with strings using `+`.

### 📚 Core Patterns

**1D NumPy array:**

    for x in my_array:
        print(x)

**Every element of a multidimensional array:**

    for x in np.nditer(my_array):
        print(x)
