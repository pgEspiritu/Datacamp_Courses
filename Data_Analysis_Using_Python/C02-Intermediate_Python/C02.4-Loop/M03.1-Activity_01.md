# 🌍 Loop Over a Dictionary

## 📌 Exercise Overview

In Python, you can use a `for` loop to iterate over a dictionary's **key-value pairs**.

To access both the key and its corresponding value, use the `.items()` method:

    for key, value in dictionary.items():
        # code

---

# 🗺️ Example

A dictionary can contain countries as keys and their capitals as values:

    europe = {
        "spain": "madrid",
        "france": "paris",
        "germany": "berlin",
        "norway": "oslo",
        "italy": "rome",
        "poland": "warsaw",
        "austria": "vienna"
    }

Each entry follows the pattern:

    key : value

For example:

    "spain" : "madrid"

where:

- `"spain"` → key
- `"madrid"` → value

---

# 🧪 Exercise

Write a `for` loop that:

1. Goes through every key-value pair in `europe`.
2. Prints the following format:

       the capital of x is y

Where:

- `x` = the country name (key)
- `y` = the capital (value)

---

# ✅ Solution

    # Definition of dictionary
    europe = {
        "spain": "madrid",
        "france": "paris",
        "germany": "berlin",
        "norway": "oslo",
        "italy": "rome",
        "poland": "warsaw",
        "austria": "vienna"
    }

    # Iterate over europe
    for x, y in europe.items():
        print("the capital of " + x + " is " + y)

---

# 🔍 How It Works

The key part is:

    for x, y in europe.items():

The `.items()` method provides both the **key** and the **value** for each dictionary entry.

During each iteration:

- `x` receives the key.
- `y` receives the corresponding value.

For example:

    x = "spain"
    y = "madrid"

Then:

    print("the capital of " + x + " is " + y)

produces:

    the capital of spain is madrid

# 🧠 Why Use `.items()`?

If you simply write:

    for x in europe:
        print(x)

you only get the dictionary's keys.

To get both the keys and values:

    for x, y in europe.items():
        print(x, y)

### Important

The variable names are arbitrary.

This is also valid:

    for country, capital in europe.items():
        print(country, capital)

Here:

- `country` → key
- `capital` → value

---

# 🔄 Dictionary Loop Patterns

## Keys Only

    for key in europe:
        print(key)

## Values Only

    for value in europe.values():
        print(value)

## Keys and Values

    for key, value in europe.items():
        print(key, value)

---

# 🔑 Key Takeaways

- Use `.items()` when you need both **keys and values** from a dictionary.
- The basic pattern is:

      for key, value in dictionary.items():
          # code

- The first loop variable receives the **key**.
- The second loop variable receives the **value**.
- Variable names such as `x`, `y`, `key`, `value`, `country`, and `capital` are arbitrary.
- `.items()` is a **dictionary method**.

### 📚 Core Pattern

    for key, value in my_dict.items():
        print(key, value)
