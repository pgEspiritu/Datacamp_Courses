# 🚗 Loop Over DataFrame (2)

## 📌 Exercise Overview

When using `iterrows()`, the row data returned on each iteration is a **Pandas Series**.

For example:

    for lab, row in cars.iterrows():
        print(row)

Printing the entire `row` Series is not always convenient.

Fortunately, you can select a specific value from the Series using square brackets:

    row["cars_per_cap"]

You can also use the row label stored in `lab`.

---

# 🧪 Exercise

Adapt the `for` loop so that each iteration prints:

    country: cars_per_cap

For example:

    US: 809
    AUS: 731
    JPN: 588

Use:

- `lab` → the country label
- `row["cars_per_cap"]` → the cars per capita value

Because `cars_per_cap` is an integer, use `str()` to convert it to a string before concatenating it with text.

---

# ✅ Solution

    # Import cars data
    import pandas as pd

    cars = pd.read_csv("cars.csv", index_col=0)

    print(cars)

    # Adapt for loop
    for lab, row in cars.iterrows():
        print(lab + ": " + str(row["cars_per_cap"]))

---

# 🔍 How It Works

The loop:

    for lab, row in cars.iterrows():

provides two pieces of information on every iteration:

- `lab` → row label
- `row` → current row as a Pandas Series

For example, on the first iteration:

    lab = "US"

and:

    row["cars_per_cap"] = 809

The print statement:

    print(lab + ": " + str(row["cars_per_cap"]))

becomes:

    print("US" + ": " + "809")

which produces:

    US: 809

# 🧠 Selecting Values from the Row

Because `row` is a Pandas Series, you can select individual values using:

    row["cars_per_cap"]

You could also select other columns:

    row["country"]

    row["drives_right"]

This makes `iterrows()` useful when you need to work with specific values from each row.

---

# 🔤 Why Use `str()`?

The expression:

    lab + ": " + row["cars_per_cap"]

would cause a type error because:

- `lab` is a string
- `": "` is a string
- `row["cars_per_cap"]` is an integer

Python cannot concatenate a string and an integer using `+`.

Convert the integer first:

    str(row["cars_per_cap"])

Then all parts are strings:

    lab + ": " + str(row["cars_per_cap"])

---

# 📚 Common Pattern

    for label, row in dataframe.iterrows():
        print(label + ": " + str(row["column"]))

This pattern combines:

- `.iterrows()` → iterate through rows
- `label` → access the row label
- `row["column"]` → select a value from the current row
- `str()` → convert numeric data to text

---

# 🔑 Key Takeaways

- `.iterrows()` returns each row as a **Pandas Series**.
- Use square brackets to select a value from the current row:

      row["column_name"]

- The first iterator variable contains the row label.
- Use `str()` when combining numeric values with strings using `+`.
- The pattern:

      for lab, row in cars.iterrows():
          print(lab + ": " + str(row["cars_per_cap"]))

  prints a selected value together with its row label.

### 💡 Core Idea

> `iterrows()` gives you the row label and the row data, while `row["column_name"]` lets you select exactly the value you need from that row.
