# 🔢 Indexes and Values with `enumerate()`

## 📌 Using `enumerate()`

A normal `for` loop gives access to the values in a list:

```
for area in areas:
    print(area)
```

When you also need the **index**, use `enumerate()`:

```
for index, area in enumerate(areas):
    print(index, area)
```

---

# 🏠 Example: `areas`

```
areas = [11.25, 18.0, 20.0, 10.75, 9.50]
```

Python indexes lists starting at `0`:

| Python Index |    Area |
| -----------: | ------: |
|          `0` | `11.25` |
|          `1` |  `18.0` |
|          `2` |  `20.0` |
|          `3` | `10.75` |
|          `4` |  `9.50` |

---

# 1️⃣ Using the Original Index

```
for index, a in enumerate(areas):
    print("room " + str(index) + ": " + str(a))
```

### Output

```
room 0: 11.25
room 1: 18.0
room 2: 20.0
room 3: 10.75
room 4: 9.5
```

Here, `index` is the actual Python list index.

---

# 2️⃣ Converting the Index to Room Number

Sometimes you do not want room numbering to start at `0`.

You can add `1`:

```
for index, area in enumerate(areas):
    print("room " + str(index + 1) + ": " + str(area))
```

### Output

```
room 1: 11.25
room 2: 18.0
room 3: 20.0
room 4: 10.75
room 5: 9.5
```

---

# 🧠 Why Use `index + 1`?

Python uses **zero-based indexing**, meaning the first item has index `0`.

But when displaying room numbers to a person, it is often more natural to start with `1`.

So:

```
index = 0
index + 1 = 1

index = 1
index + 1 = 2

index = 2
index + 1 = 3
```

and so on.

---

# 🆚 Comparison

| Code             | First Output | Last Output | Purpose                       |
| ---------------- | ------------ | ----------- | ----------------------------- |
| `str(index)`     | `room 0`     | `room 4`    | Uses Python's actual index    |
| `str(index + 1)` | `room 1`     | `room 5`    | Uses human-friendly numbering |

---

# 💡 Important Distinction

`index` itself is not changed.

For example:

```
index = 0
```

still means the first position in the list.

Using:

```
index + 1
```

only changes the **displayed number**.

It does not change how the list is indexed.

### Example

```
areas[index]
```

still uses the original zero-based index.

---

# 🔑 Key Takeaways

* `enumerate()` provides both the **index** and the **value**.
* Python list indexes start at `0`.
* Use `index` when you need the actual Python position.
* Use `index + 1` when you want numbering to start at `1`.
* `str()` converts numbers into strings so they can be joined with text using `+`.

### 📚 Common Patterns

**Actual Python index:**

```
for index, value in enumerate(my_list):
    print("item " + str(index) + ": " + str(value))
```

**Human-friendly numbering:**

```
for index, value in enumerate(my_list):
    print("item " + str(index + 1) + ": " + str(value))
```
