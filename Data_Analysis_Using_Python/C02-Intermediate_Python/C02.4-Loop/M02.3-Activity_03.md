# 🏠 Loop Over a List of Lists

## 📌 Exercise Overview

A **list of lists** is a list where each element is itself another list.

The `house` variable contains the name and area of each room:

    house = [
        ["hallway", 11.25],
        ["kitchen", 18.0],
        ["living room", 20.0],
        ["bedroom", 10.75],
        ["bathroom", 9.50]
    ]

Each sublist contains:

1. The **room name**
2. The **room area**

For example:

    ["kitchen", 18.0]

contains:

- `"kitchen"` → room name
- `18.0` → room area

---

# 🧪 Exercise

Write a `for` loop that goes through each sublist of `house` and prints:

    the x is y sqm

Where:

- `x` = the room name
- `y` = the area of the room

---

# ✅ Solution

    # house list of lists
    house = [["hallway", 11.25],
             ["kitchen", 18.0],
             ["living room", 20.0],
             ["bedroom", 10.75],
             ["bathroom", 9.50]]

    # Build a for loop from scratch
    for x, y in house:
        print("the " + x + " is " + str(y) + " sqm")

---

# 🔍 How It Works

The important part is:

    for x, y in house:

Each element of `house` is a two-item list.

For example:

    ["hallway", 11.25]

Python automatically **unpacks** the two values:

    x = "hallway"
    y = 11.25

On the next iteration:

    ["kitchen", 18.0]

becomes:

    x = "kitchen"
    y = 18.0

This continues for every room.

---

# 📊 Iteration Breakdown

| Iteration | `x` (Room) | `y` (Area) |
|---:|---|---:|
| 1 | `hallway` | `11.25` |
| 2 | `kitchen` | `18.0` |
| 3 | `living room` | `20.0` |
| 4 | `bedroom` | `10.75` |
| 5 | `bathroom` | `9.50` |

---

# 🖨️ Output

The loop produces:

    the hallway is 11.25 sqm
    the kitchen is 18.0 sqm
    the living room is 20.0 sqm
    the bedroom is 10.75 sqm
    the bathroom is 9.5 sqm

> 💡 `9.50` is displayed as `9.5` because Python does not preserve trailing zeros in a floating-point value.

---

# 🧠 List Unpacking

This technique is called **unpacking**.

For a two-item list:

    room = ["kitchen", 18.0]

You can unpack it with:

    x, y = room

Now:

    x == "kitchen"
    y == 18.0

The `for` loop performs this unpacking automatically:

    for x, y in house:
        ...

---

# 🔄 Comparing Different `for` Loop Patterns

## Simple List

For a normal list of values:

    for area in areas:
        print(area)

Only one variable is needed.

---

## List with Index

Use `enumerate()` when you need the index and value:

    for index, area in enumerate(areas):
        print(index, area)

---

## List of Lists

When each sublist contains two values, you can unpack both directly:

    for room, area in house:
        print(room, area)

---

# 💡 Why `str(y)` is Needed

The expression:

    print("the " + x + " is " + str(y) + " sqm")

uses `+` to concatenate strings.

`x` is already a string:

    "kitchen"

But `y` is a floating-point number:

    18.0

So it must be converted to a string:

    str(y)

Without `str(y)`, Python would raise a `TypeError` when trying to concatenate the number with text.

---

# ⚠️ Variable Names Are Flexible

The variables `x` and `y` are arbitrary.

This is equally valid and more descriptive:

    for room, area in house:
        print("the " + room + " is " + str(area) + " sqm")

Using meaningful variable names often makes code easier to understand.

---

# 🔑 Key Takeaways

- A **list of lists** contains multiple sublists.
- Each sublist can be unpacked into separate variables.
- The pattern:

      for x, y in house:

  assigns the first value to `x` and the second value to `y`.
- This is called **sequence unpacking** or **unpacking**.
- `str()` converts a number to a string so it can be combined with text.
- Meaningful variable names such as `room` and `area` can make the code easier to read.

### 📚 Core Pattern

    for value1, value2 in list_of_lists:
        print(value1, value2)

### 🧠 Example

    house = [
        ["hallway", 11.25],
        ["kitchen", 18.0]
    ]

    for room, area in house:
        print(room, area)

This processes each sublist and automatically assigns its values to `room` and `area`.
