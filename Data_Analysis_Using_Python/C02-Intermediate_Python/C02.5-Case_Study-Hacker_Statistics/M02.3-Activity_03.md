# 🏢 How Low Can You Go?

## 📌 Exercise Overview

The random walk now calculates your position in the Empire State Building after `100` dice throws.

However, there is an important rule:

> You can never go below **step 0**.

Without a restriction, if you are at:

    step = 0

and roll `1` or `2`, the code:

    step = step - 1

would produce:

    -1

This violates the rules of the game.

---

# 🧠 Using `max()`

Python's `max()` function returns the **largest** value among its arguments.

For example:

    max(10, 15)

returns:

    15

And:

    max(10, 5)

returns:

    10

This makes `max()` useful when you want to enforce a **minimum value**.

---

# 🛑 Preventing `step` from Going Below `0`

The problematic code is:

    step = step - 1

Instead, use:

    step = max(0, step - 1)

This guarantees that `step` can never be smaller than `0`.

### Example 1

If:

    step = 5

then:

    max(0, 5 - 1)

becomes:

    max(0, 4)

Result:

    4

### Example 2

If:

    step = 0

then:

    max(0, 0 - 1)

becomes:

    max(0, -1)

Result:

    0

So the position stays at `0`.

---

# 🧪 Exercise

Use `max()` to ensure that `step` never goes below `0` when:

    dice <= 2

Then inspect the completed `random_walk`.

---

# ✅ Solution

    # NumPy is imported, seed is set

    # Initialize random_walk
    random_walk = [0]

    for x in range(100):
        step = random_walk[-1]
        dice = np.random.randint(1, 7)

        if dice <= 2:
            # Make sure step can't go below 0
            step = max(0, step - 1)
        elif dice <= 5:
            step = step + 1
        else:
            step = step + np.random.randint(1, 7)

        random_walk.append(step)

    print(random_walk)

# 📊 Why `max(0, step - 1)` Works

Suppose the current position is:

| Current `step` | `step - 1` | `max(0, step - 1)` | Final Step |
|---:|---:|---:|---:|
| `5` | `4` | `4` | `4` |
| `2` | `1` | `1` | `1` |
| `1` | `0` | `0` | `0` |
| `0` | `-1` | `0` | `0` |

The result is never negative.

---

# 🧠 Minimum Value Pattern

This is a general programming pattern:

    max(minimum_value, expression)

It guarantees that the result is at least the specified minimum.

For this exercise:

    max(0, step - 1)

means:

> Decrease `step` by `1`, but never let the result go below `0`.

# 📌 Important Concept

`max()` does **not** change the original variable automatically.

For example:

    max(0, step - 1)

only calculates the protected value.

You need to assign it back:

    step = max(0, step - 1)

---

# 🔑 Key Takeaways

- The Empire State Building game cannot have a position below `0`.
- `max()` can enforce a minimum value.
- Use:

      step = max(0, step - 1)

  to prevent negative positions.
- `max(a, b)` returns the larger of `a` and `b`.
- This pattern is useful whenever a value must have a **lower bound**.

### 📚 Core Pattern

    variable = max(minimum_value, variable - amount)

### Example

    step = max(0, step - 1)

> 🎯 **Core idea:** Use `max()` to enforce a minimum position of `0` in the random walk.
