# 🚶 The Next Step — Building a Random Walk

## 📌 Exercise Overview

Previously, you wrote code that determines the next position based on a dice roll.

Now we place that logic inside a `for` loop to simulate a **random walk of 100 steps**.

The important idea is that every new step should be based on the **previous step**.

---

# 🧪 Exercise

Complete the random-walk simulation by:

1. Creating a list called `random_walk` with an initial value of `0`.
2. Running the `for` loop **100 times**.
3. On every iteration, setting `step` to the **last element** of `random_walk`.
4. Rolling a die.
5. Updating `step` based on the dice value.
6. Appending the new `step` to `random_walk`.
7. Printing the complete `random_walk`.

---

# ✅ Correct Solution

    # NumPy is imported, seed is set

    # Initialize random_walk
    random_walk = [0]

    # Complete the for loop
    for x in range(100):

        # Set step: last element in random_walk
        step = random_walk[-1]

        # Roll the dice
        dice = np.random.randint(1, 7)

        # Determine next step
        if dice <= 2:
            step = step - 1
        elif dice <= 5:
            step = step + 1
        else:
            step = step + np.random.randint(1, 7)

        # Append next step to random_walk
        random_walk.append(step)

    # Print random_walk
    print(random_walk)

# ⚠️ Important Correction

The supplied code used:

    step = random_walk[x]

But the instruction specifically says to use the **last element** of `random_walk`.

The correct expression is:

    step = random_walk[-1]

### Why?

`-1` always refers to the last element of a list.

For example:

    random_walk = [0, 1, 2, 1]

Then:

    random_walk[-1]

returns:

    1

That is the current position from which the next step should be calculated.

Using:

    random_walk[x]

does not reliably represent the current last position and is not what the exercise asks for.

---

# 🔍 Step-by-Step Explanation

## 1️⃣ Initialize the Random Walk

    random_walk = [0]

The starting position is:

    0

So initially:

    random_walk[-1]

is also:

    0

---

## 2️⃣ Run the Loop 100 Times

    for x in range(100):

`range(100)` produces `100` iterations:

    0, 1, 2, ..., 99

Each iteration calculates and stores one new position.

---

# 3️⃣ Get the Previous Position

Inside the loop:

    step = random_walk[-1]

This is one of the most important lines.

It means:

> Start the next movement from the most recent position.

For example, if:

    random_walk = [0, 1, 2, 3]

then:

    step = random_walk[-1]

gives:

    step = 3

The next dice roll will determine how this `3` changes.

---

# 4️⃣ Roll the Dice

    dice = np.random.randint(1, 7)

Possible values:

    1
    2
    3
    4
    5
    6

Remember:

> `randint(1, 7)` includes `1` but excludes `7`.

---

# 5️⃣ Determine the Next Step

The dice rules are:

### Dice = 1 or 2

    if dice <= 2:
        step = step - 1

Move down by one.

### Dice = 3, 4, or 5

    elif dice <= 5:
        step = step + 1

Move up by one.

### Dice = 6

    else:
        step = step + np.random.randint(1, 7)

Roll the dice again and move up by that many steps.

---

# 6️⃣ Append the New Position

The next position is added to the list:

    random_walk.append(step)

For example:

    random_walk = [0]

Suppose the first roll results in a step of `1`:

    random_walk.append(1)

Now:

    random_walk = [0, 1]

If the next step becomes `2`:

    random_walk.append(2)

Now:

    random_walk = [0, 1, 2]

The list therefore records the entire path.

---

# 📊 How the Random Walk Grows

Imagine the simulation produces these steps:

    0
    1
    2
    1
    2
    3

Then the list becomes:

    [0, 1, 2, 1, 2, 3]

Each value represents the position **after that step**.

---

# 🔄 Random Walk Process

The complete process is:

    Starting position
          ↓
    Get previous position
          ↓
       Roll dice
          ↓
    Calculate next step
          ↓
    Append new position
          ↓
    Repeat 100 times

The key relationship is:

    new_step = previous_step + random_movement

---

# 🧠 Why `random_walk[-1]` Matters

A random walk depends on the **previous position**.

For example:

    random_walk = [0, 1, 2]

The current position is:

    2

So the next step must start from:

    2

Using:

    random_walk[-1]

returns the current position regardless of how long the list has become.

After another step:

    random_walk = [0, 1, 2, 1]

Now:

    random_walk[-1]

returns:

    1

This makes `-1` ideal for tracking the current endpoint of the walk.

---

# 📌 Number of Values in the Final List

The list starts with one value:

    [0]

Then the loop runs `100` times, adding one new value each time.

Therefore, the final list contains:

    101

values.

### Calculation

    1 starting value + 100 new positions = 101 values

---

# 🧪 Example of One Iteration

Suppose:

    random_walk = [0, 1, 2]

Then:

    step = random_walk[-1]

gives:

    step = 2

Suppose the die produces:

    dice = 4

Since:

    dice <= 5

the code runs:

    step = step + 1

So:

    step = 3

Then:

    random_walk.append(step)

produces:

    [0, 1, 2, 3]

---

# 🆚 `random_walk[x]` vs `random_walk[-1]`

| Expression | Meaning |
|---|---|
| `random_walk[x]` | Element at index `x` |
| `random_walk[-1]` | Last element of the list |

For this exercise, the goal is to use:

    random_walk[-1]

because the next step must be based on the **current/latest position**.

# 🔑 Key Takeaways

- Start the random walk with:

      random_walk = [0]

- Use:

      for x in range(100):

  to generate 100 new steps.
- Get the current position with:

      step = random_walk[-1]

- Roll the die using:

      dice = np.random.randint(1, 7)

- Apply the movement rules with `if`-`elif`-`else`.
- Add the new position using:

      random_walk.append(step)

- Print the completed random walk:

      print(random_walk)

- The final list contains **101 values** because the initial `0` is included.

### 📚 Core Pattern

    random_walk = [0]

    for x in range(100):
        step = random_walk[-1]

        dice = np.random.randint(1, 7)

        if dice <= 2:
            step -= 1
        elif dice <= 5:
            step += 1
        else:
            step += np.random.randint(1, 7)

        random_walk.append(step)

> 🎯 **Core idea:** A random walk is built by repeatedly taking the previous position, calculating a random movement, and appending the new position to the list.
