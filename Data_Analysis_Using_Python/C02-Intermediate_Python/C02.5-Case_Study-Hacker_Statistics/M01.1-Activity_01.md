In this exercise, you'll start using NumPy's `random` package to generate random numbers.

The required functionality comes from:

    np.random

Two important functions are introduced:

| Function | Purpose |
|---|---|
| `seed()` | Sets the random seed for reproducible results |
| `rand()` | Generates a random floating-point number between `0` and `1` |

---

# 🌱 `np.random.seed()`

The `seed()` function sets the starting point for NumPy's pseudo-random number generator.

Example:

    np.random.seed(123)

The number `123` is the seed.

The seed can be any integer you choose.

### Why Set a Seed?

Using the same seed means that the same sequence of pseudo-random numbers will be generated again.

This makes your simulations **reproducible**.

For example:

    np.random.seed(123)
    print(np.random.rand())

If you run the same code again with the same seed, you get the same random float.

> 💡 `seed()` itself does not produce any output.

---

# 🔢 `np.random.rand()`

The `rand()` function generates a random floating-point number between `0` and `1`.

Example:

    np.random.rand()

A possible result could look like:

    0.6964691855978616

The exact value depends on the random seed.

### Important

The generated value is:

    0 <= random_value < 1

So the result is always at least `0` and less than `1`.

# 🧠 Reproducibility Example

Consider:

    np.random.seed(123)

    print(np.random.rand())
    print(np.random.rand())

The two generated values form a deterministic sequence based on seed `123`.

If you reset the seed:

    np.random.seed(123)

and generate the numbers again:

    print(np.random.rand())
    print(np.random.rand())

you get the same sequence again.
