# 🎲 Determine Your Next Move

## 📌 Exercise Overview

In the **Empire State Building** game, your next move depends on the number you get from rolling the dice.

The rules are:

| Dice Roll | Movement |
|---|---|
| `1` or `2` | Go **1 step down** |
| `3`, `4`, or `5` | Go **1 step up** |
| `6` | Roll the dice again and go up by the resulting number of steps |

This can be implemented using an `if`-`elif`-`else` statement.

---

# 🧪 Exercise

The starting position is:

    step = 50

Complete the following:

1. Roll the dice and store the result in `dice`.
2. Finish the `if`-`elif`-`else` structure:
   - If `dice` is `1` or `2`, decrease `step` by `1`.
   - If `dice` is `3`, `4`, or `5`, increase `step` by `1`.
   - Otherwise (`dice == 6`), roll the dice again and increase `step` by the new dice value.
3. Print `dice` and `step`.

---

# ✅ Solution

    # NumPy is imported, seed is set

    # Starting step
    step = 50

    # Roll the dice
    dice = np.random.randint(1, 7)

    # Finish the control construct
    if dice <= 2:
        step = step - 1
    elif dice <= 5:
        step = step + 1
    else:
        step = step + np.random.randint(1, 7)

    # Print out dice and step
    print(dice)
    print(step)

---

# 🔍 How It Works

## 1️⃣ Roll the Dice

    dice = np.random.randint(1, 7)

Because the upper bound `7` is excluded, the possible values are:

    1, 2, 3, 4, 5, 6

---

## 2️⃣ Dice is `1` or `2`

    if dice <= 2:
        step = step - 1

If the dice roll is `1` or `2`, the player moves down one step.

For example:

    dice = 2
    step = 50

Then:

    step = 50 - 1

Result:

    step = 49

---

## 3️⃣ Dice is `3`, `4`, or `5`

    elif dice <= 5:
        step = step + 1

If the first condition is `False`, this condition checks whether the dice value is at most `5`.

That means the possible values here are:

    3
    4
    5

The player moves up one step.

For example:

    dice = 4
    step = 50

Then:

    step = 50 + 1

Result:

    step = 51

---

## 4️⃣ Dice is `6`

If neither of the first two conditions is true, the only remaining possible dice value is:

    6

The `else` block executes:

    step = step + np.random.randint(1, 7)

A second dice roll is generated, and that number is added to `step`.

For example, if the second roll is `5`:

    step = 50 + 5

Result:

    step = 55

---

# 🧠 Why `<=` Works Here

The conditions are checked from top to bottom:

    if dice <= 2:
        ...

    elif dice <= 5:
        ...

Since the first condition catches `1` and `2`, the `elif` only needs to check whether the value is `5` or lower.

Therefore:

| Dice | First Condition | Second Condition | Action |
|---:|---|---|---|
| `1` | `True` | Not checked | `-1` |
| `2` | `True` | Not checked | `-1` |
| `3` | `False` | `True` | `+1` |
| `4` | `False` | `True` | `+1` |
| `5` | `False` | `True` | `+1` |
| `6` | `False` | `False` | Roll again |

# 🔄 Complete Logic

The game rule can be summarized as:

    roll dice

    if dice is 1 or 2:
        move down 1

    elif dice is 3, 4, or 5:
        move up 1

    else:
        roll again
        move up by the second roll

---

# 🔑 Key Takeaways

- Use `np.random.randint(1, 7)` to simulate a six-sided die.
- `if` handles rolls `1` and `2`.
- `elif` handles rolls `3`, `4`, and `5`.
- `else` handles the remaining possibility: `6`.
- When the roll is `6`, roll the die again and use that result as the number of steps to move up.
- Conditions are checked from **top to bottom**, and only the first matching block is executed.

### 📚 Core Pattern

    dice = np.random.randint(1, 7)

    if dice <= 2:
        step -= 1
    elif dice <= 5:
        step += 1
    else:
        step += np.random.randint(1, 7)
