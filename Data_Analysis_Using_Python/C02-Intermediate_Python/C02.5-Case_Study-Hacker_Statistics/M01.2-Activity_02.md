# 🎲 Roll the Dice

## 📌 Exercise Overview

In the previous exercise, you used:

    np.random.rand()

to generate a random floating-point number between `0` and `1`.

NumPy's `random` package also provides:

    np.random.randint()

which generates a random **integer** within a specified range.

---

# 🔢 `np.random.randint()`

The general syntax is:

    np.random.randint(low, high)

The rules are:

- `low` is **included**.
- `high` is **excluded**.

For example:

    np.random.randint(4, 8)

can produce:

    4
    5
    6
    7

But it can **never** produce:

    8

---

# 🎲 Simulating a Dice Roll

A standard six-sided die has the possible outcomes:

    1
    2
    3
    4
    5
    6

Because the upper limit is excluded, use:

    np.random.randint(1, 7)

This means:

    1 <= result < 7

so the possible results are exactly `1` through `6`.

---

# 🧪 Exercise

Complete the following tasks:

1. Use `randint()` to randomly generate a number from `1` to `6`.
2. Print the result.
3. Use `randint()` again to simulate a second dice roll.
4. Print the second result.

---

# ✅ Solution

    # Import numpy and set seed
    import numpy as np

    np.random.seed(123)

    # Use randint() to simulate a dice
    print(np.random.randint(1, 7))

    # Use randint() again
    print(np.random.randint(1, 7))

# 🎯 Why Is `7` Used?

You might wonder why we write:

    np.random.randint(1, 7)

instead of:

    np.random.randint(1, 6)

The reason is that the upper limit is **excluded**.

### `randint(1, 6)`

Possible values:

    1
    2
    3
    4
    5

❌ `6` is excluded.

### `randint(1, 7)`

Possible values:

    1
    2
    3
    4
    5
    6

✅ Exactly what we need for a six-sided die.

---

# 📊 `rand()` vs `randint()`

| Function | Returns | Example |
|---|---|---|
| `np.random.rand()` | Random float between `0` and `1` | `0.6964...` |
| `np.random.randint(1, 7)` | Random integer from `1` to `6` | `6` |

---

# 🧠 Important Rule

For:

    np.random.randint(low, high)

remember:

> **Include `low`, exclude `high`.**

Examples:

    np.random.randint(0, 2)
    # 0 or 1

    np.random.randint(1, 7)
    # 1, 2, 3, 4, 5, or 6

    np.random.randint(10, 15)
    # 10, 11, 12, 13, or 14

---

# 🔑 Key Takeaways

- `np.random.randint()` generates random integers.
- The lower bound is included.
- The upper bound is excluded.
- To simulate a six-sided die, use:

      np.random.randint(1, 7)

- Calling `randint()` again generates another value from the pseudo-random sequence.
- Setting the same seed makes the sequence reproducible.

### 📚 Core Pattern

    import numpy as np

    np.random.seed(123)

    first_roll = np.random.randint(1, 7)
    second_roll = np.random.randint(1, 7)

    print(first_roll)
    print(second_roll)

> 🎯 **Core idea:** To simulate a standard die with `randint()`, use `1` as the lower bound and `7` as the upper bound because the upper bound is excluded.
