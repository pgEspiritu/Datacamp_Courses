# 🚶 Simulate Multiple Random Walks

## 📌 Exercise Overview

A single random walk gives you only **one possible outcome**.

That is not enough to determine whether you have a good chance of reaching **60 steps** in the Empire State Building game.

Instead, we can simulate the random walk multiple times and store the results.

In this exercise, the random walk will be simulated **five times**.

---

# 🧠 The Basic Idea

One random walk looks like:

    random_walk = [0]

    for x in range(100):
        # calculate next step
        ...
        random_walk.append(step)

This produces one list containing the starting position and `100` additional positions.

To simulate the walk multiple times, we place this entire process inside another `for` loop.

The structure becomes:

    for i in range(5):
        # create one random walk
        # ...
        # store the result

This creates **five separate random walks**.

---

# 🧪 Exercise

Complete the following:

1. Make the top-level `for` loop run **5 times**.
2. After each `random_walk` has been completely generated, append it to `all_walks`.
3. After the top-level loop finishes, print `all_walks`.

### ⚠️ Important

Do **not** change:

    all_walks = []

The exercise specifically requires this exact initialization.

---

# ✅ Solution

    # NumPy is imported; seed is set

    # Initialize all_walks (don't change this line)
    all_walks = []

    # Simulate random walk five times
    for i in range(5):

        # Code from before
        random_walk = [0]

        for x in range(100):
            step = random_walk[-1]
            dice = np.random.randint(1, 7)

            if dice <= 2:
                step = max(0, step - 1)
            elif dice <= 5:
                step = step + 1
            else:
                step = step + np.random.randint(1, 7)

            random_walk.append(step)

        # Append random_walk to all_walks
        all_walks.append(random_walk)

    # Print all_walks
    print(all_walks)

# 🔍 Step-by-Step Explanation

## 1️⃣ Initialize `all_walks`

    all_walks = []

This is an empty list that will eventually contain all five random walks.

After the simulation, the structure looks conceptually like:

    [
        random_walk_1,
        random_walk_2,
        random_walk_3,
        random_walk_4,
        random_walk_5
    ]

---

# 2️⃣ Simulate Five Walks

The outer loop is:

    for i in range(5):

This runs five times:

    i = 0
    i = 1
    i = 2
    i = 3
    i = 4

Each iteration creates a completely new random walk.

---

# 3️⃣ Create a New Random Walk

Inside the outer loop:

    random_walk = [0]

This is important because every simulation must start again at position `0`.

Each new iteration creates a fresh list.

---

# 4️⃣ Simulate 100 Dice Rolls

The inner loop:

    for x in range(100):

runs `100` times.

Each iteration:

1. Gets the previous position.
2. Rolls the die.
3. Determines the movement.
4. Adds the new position to `random_walk`.

---

# 5️⃣ Get the Current Position

    step = random_walk[-1]

`-1` selects the last element of the list.

This is the position from which the next step starts.

---

# 6️⃣ Roll the Dice

    dice = np.random.randint(1, 7)

Possible values:

    1, 2, 3, 4, 5, 6

---

# 7️⃣ Determine the Next Step

The movement rules are:

### Roll `1` or `2`

    if dice <= 2:
        step = max(0, step - 1)

Move down one step, but never below `0`.

### Roll `3`, `4`, or `5`

    elif dice <= 5:
        step = step + 1

Move up one step.

### Roll `6`

    else:
        step = step + np.random.randint(1, 7)

Roll again and move up by the new dice value.

---

# 8️⃣ Append the New Position

After determining the new position:

    random_walk.append(step)

This adds the new position to the current walk.

After `100` iterations, the walk contains:

    101 values

because it includes the initial `0`.

---

# 9️⃣ Store the Completed Walk

Once the **inner loop is finished**, append the entire random walk:

    all_walks.append(random_walk)

This line must be **outside the inner loop**.

### Correct Structure

    for i in range(5):
        random_walk = [0]

        for x in range(100):
            # build random walk
            ...

        all_walks.append(random_walk)

This ensures that one complete random walk is added to `all_walks` after each simulation.

---

# ⚠️ Why Indentation Matters

This line:

    all_walks.append(random_walk)

should be indented at the level of the **outer loop**, but not inside the inner loop.

### ✅ Correct

    for i in range(5):
        random_walk = [0]

        for x in range(100):
            # update random walk
            random_walk.append(step)

        all_walks.append(random_walk)

### ❌ Incorrect

    for i in range(5):
        random_walk = [0]

        for x in range(100):
            # update random walk
            random_walk.append(step)
            all_walks.append(random_walk)

The incorrect version would append the partially completed walk after every step instead of once after each complete simulation.

---

# 📊 Structure of `all_walks`

After five simulations:

    all_walks = [
        [0, ..., final_step_1],
        [0, ..., final_step_2],
        [0, ..., final_step_3],
        [0, ..., final_step_4],
        [0, ..., final_step_5]
    ]

There are:

    5

random walks.

Each random walk contains:

    101

positions.

Therefore, conceptually:

    5 × 101

values are stored.

---

# 🧠 Nested Loop Structure

This exercise uses a **nested `for` loop**.

### Outer Loop

    for i in range(5):

Controls the number of random walks.

### Inner Loop

    for x in range(100):

Controls the number of steps in each random walk.

So the program means:

> Repeat the 100-step random walk five times.

---

# 🔄 Simulation Flow

    all_walks = []

            ↓

    Repeat 5 times
            ↓
    Start random_walk at 0
            ↓
    Repeat 100 times
            ↓
    Calculate next position
            ↓
    Append position
            ↓
    Store completed random_walk
            ↓
    Repeat
            ↓
    print(all_walks)

---

# 📌 Why Simulate Multiple Walks?

A single simulation can end anywhere.

For example:

    Walk 1 → 43
    Walk 2 → 58
    Walk 3 → 61
    Walk 4 → 49
    Walk 5 → 67

By running many simulations, we can study the **distribution of final positions**.

The more simulations we perform, the more useful the results become for estimating probabilities.

---

# 🔑 Key Takeaways

- `all_walks` stores multiple complete random walks.
- Use:

      for i in range(5):

  to simulate five walks.
- Each walk should start with:

      random_walk = [0]

- Each walk contains `100` simulated moves.
- Append the completed walk with:

      all_walks.append(random_walk)

- Place the append statement **after** the inner loop.
- Nested loops allow you to repeat a complete simulation multiple times.
- The final structure is a **list of lists**.

### 📚 Core Pattern

    all_walks = []

    for i in range(number_of_walks):

        random_walk = [0]

        for j in range(number_of_steps):
            step = random_walk[-1]

            # calculate next step

            random_walk.append(step)

        all_walks.append(random_walk)

> 🎯 **Core idea:** Use an outer loop to repeat the entire random walk and an inner loop to generate the individual steps of each walk.
