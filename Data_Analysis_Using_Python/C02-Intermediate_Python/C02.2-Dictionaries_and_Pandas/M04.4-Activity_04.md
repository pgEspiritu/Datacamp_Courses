# 🐼 loc and iloc (2) - Selecting Rows and Columns

## 🎯 Exercise Description

The `loc[]` and `iloc[]` methods can select not only rows, but also **specific rows and columns at the same time**.

This makes them much more powerful than basic square bracket selection.

---

# 🏷️ Selecting Rows and Columns with `loc[]`

`loc[]` uses **labels** for both rows and columns.

General syntax:

    dataframe.loc[row_label, column_label]

Example:

    cars.loc['IN', 'cars_per_cap']

This selects:

- 🇮🇳 Row label → `IN`
- 🚗 Column label → `cars_per_cap`

---

# 🔢 Selecting Rows and Columns with `iloc[]`

`iloc[]` uses **integer positions**.

General syntax:

    dataframe.iloc[row_index, column_index]

Example:

    cars.iloc[3, 0]

This selects:

- Row position → `3`
- Column position → `0`

---

# 🔄 `loc` and `iloc` Equivalents

The following pairs return the same results:

    cars.loc['IN', 'cars_per_cap']
    cars.iloc[3, 0]

Both select India's `cars_per_cap` value.

---

    cars.loc[['IN', 'RU'], 'cars_per_cap']
    cars.iloc[[3, 4], 0]

Both select the `cars_per_cap` values for India and Russia.

---

    cars.loc[['IN', 'RU'], ['cars_per_cap', 'country']]
    cars.iloc[[3, 4], [0, 1]]

Both select:

- India
- Russia
- `cars_per_cap`
- `country`

# 🎯 Instructions

Complete the following tasks:

1. Print the `drives_right` value for **Morocco**.
   - Row label: `MOR`
   - Column: `drives_right`

2. Create and print a sub-DataFrame containing:
   - 🇷🇺 Russia
   - 🇲🇦 Morocco
   - `country`
   - `drives_right`

---

# 💡 Solution

    # Import cars data
    import pandas as pd

    cars = pd.read_csv('cars.csv', index_col=0)

    # Print out drives_right value of Morocco
    print(cars.loc['MOR', 'drives_right'])

    # Print sub-DataFrame
    print(cars.iloc[[4, 5], [1, 2]])

---

# 📚 Explanation

## 1️⃣ Selecting Morocco's `drives_right` Value

Using `loc[]`:

    cars.loc['MOR', 'drives_right']

The first value:

    'MOR'

identifies the row.

The second value:

    'drives_right'

identifies the column.

The result is:

    True

---

## 2️⃣ Selecting Russia and Morocco

Using `iloc[]`:

    cars.iloc[[4, 5], [1, 2]]

The first list:

    [4, 5]

selects rows at positions:

- `4` → Russia
- `5` → Morocco

The second list:

    [1, 2]

selects columns at positions:

- `1` → `country`
- `2` → `drives_right`

The resulting DataFrame contains:

| Index | country | drives_right |
|---|---|---|
| `RU` | Russia | `True` |
| `MOR` | Morocco | `True` |

---

# 🔍 `loc` vs `iloc`

| Method | Rows | Columns |
|---|---|---|
| `loc[]` | Labels 🏷️ | Labels 🏷️ |
| `iloc[]` | Positions 🔢 | Positions 🔢 |

Examples:

    cars.loc['MOR', 'drives_right']

Uses labels.

    cars.iloc[5, 2]

Uses integer positions.

---

# 🧠 Key Takeaways

- 🏷️ `loc[]` selects data using **row and column labels**.
- 🔢 `iloc[]` selects data using **integer positions**.
- 📊 Both can select rows and columns simultaneously.
- 🧩 The syntax follows the pattern:

      dataframe.loc[rows, columns]

      dataframe.iloc[rows, columns]

- ✅ Use `loc` when working with meaningful labels.
- ✅ Use `iloc` when working with numeric positions.
- 🚀 These methods provide powerful and precise control over Pandas DataFrames.
