# 🏷️ Dictionary to DataFrame (2) - Setting Row Labels

## 🎯 Exercise Description

In the previous exercise, you created a Pandas DataFrame called `cars` from a dictionary.

By default, Pandas automatically assigns integer row labels:

    0
    1
    2
    3
    4
    5
    6

These default labels are not always meaningful. In this exercise, you will replace them with custom labels that identify each country.

---

# 📋 Row Labels

A list called `row_labels` has been created for you:

    row_labels = ['US', 'AUS', 'JPN', 'IN', 'RU', 'MOR', 'EG']

Each label corresponds to a country in the same order as the rows in the DataFrame.

| Row Label | Country |
|---|---|
| `US` | United States |
| `AUS` | Australia |
| `JPN` | Japan |
| `IN` | India |
| `RU` | Russia |
| `MOR` | Morocco |
| `EG` | Egypt |

---

# 🏷️ Setting the DataFrame Index

Pandas allows you to customize row labels using the `.index` attribute.

Syntax:

    dataframe.index = row_labels

For the `cars` DataFrame:

    cars.index = row_labels

This replaces the automatically generated numeric indexes with meaningful labels.

---

# 🎯 Instructions

Complete the following tasks:

1. Run the code and observe the default row labels.
2. Set the row labels of `cars` using `row_labels`.
3. Print `cars` again.
4. Verify that the new row labels are correctly assigned.

---

# 💡 Solution

    import pandas as pd

    # Build cars DataFrame
    names = ['United States', 'Australia', 'Japan', 'India', 'Russia', 'Morocco', 'Egypt']
    dr = [True, False, False, False, True, True, True]
    cpc = [809, 731, 588, 18, 200, 70, 45]

    cars_dict = {
        'country': names,
        'drives_right': dr,
        'cars_per_cap': cpc
    }

    cars = pd.DataFrame(cars_dict)

    print(cars)

    # Definition of row_labels
    row_labels = ['US', 'AUS', 'JPN', 'IN', 'RU', 'MOR', 'EG']

    # Specify row labels of cars
    cars.index = row_labels

    # Print cars again
    print(cars)

# 🔍 Understanding `cars.index`

The `.index` attribute controls the row labels of a DataFrame.

Example:

    cars.index = row_labels

This does not change the actual data inside the columns. It only changes how the rows are labeled.

---

# 🧠 Key Takeaways

- 🐼 Pandas automatically assigns numeric row labels when no index is provided.
- 🏷️ The `.index` attribute allows you to specify custom row labels.
- 🔄 Assigning `cars.index = row_labels` replaces the default indexes.
- 🌍 Meaningful row labels make DataFrames easier to read and work with.
- 📊 Row labels can represent country codes, IDs, dates, or other meaningful identifiers.
