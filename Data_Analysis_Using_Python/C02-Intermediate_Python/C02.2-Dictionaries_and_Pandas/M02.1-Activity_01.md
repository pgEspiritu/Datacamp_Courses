# 🗂️ Dictionary Manipulation (1)

## 🎯 Exercise Description

Dictionaries can be modified after they are created.

You can **add new key-value pairs** by using square brackets `[]` and the assignment operator `=`.

Example:

    europe['iceland'] = 'reykjavik'

This adds a new key:

    'iceland'

with the corresponding value:

    'reykjavik'

---

# ➕ Adding New Key-Value Pairs

The general syntax is:

    dictionary[key] = value

Example:

    europe['italy'] = 'rome'

This adds:

    'italy': 'rome'

to the dictionary.

---

# 🔎 Checking if a Key Exists

You can use the `in` operator to check whether a key exists in a dictionary.

Example:

    'italy' in europe

If the key exists, Python returns:

    True

If it does not exist, Python returns:

    False

---

# 🎯 Instructions

Complete the following tasks:

1. Add `'italy'` with the value `'rome'` to `europe`.
2. Check whether `'italy'` is now a key in `europe`.
3. Add `'poland'` with the value `'warsaw'` to `europe`.
4. Print the complete `europe` dictionary.

---

# 💡 Solution

    # Definition of dictionary
    europe = {
        'spain': 'madrid',
        'france': 'paris',
        'germany': 'berlin',
        'norway': 'oslo'
    }

    # Add italy to europe
    europe['italy'] = 'rome'

    # Print out italy in europe
    print('italy' in europe)

    # Add poland to europe
    europe['poland'] = 'warsaw'

    # Print europe
    print(europe)

---

# 📤 Output

    True

    {'spain': 'madrid',
     'france': 'paris',
     'germany': 'berlin',
     'norway': 'oslo',
     'italy': 'rome',
     'poland': 'warsaw'}

---

# 🔍 Explanation

## 1️⃣ Adding Italy

    europe['italy'] = 'rome'

This creates a new key-value pair:

    'italy': 'rome'

---

## 2️⃣ Checking for Italy

    'italy' in europe

Python checks whether `'italy'` exists as a key.

Result:

    True

---

## 3️⃣ Adding Poland

    europe['poland'] = 'warsaw'

This adds:

    'poland': 'warsaw'

to the dictionary.

---

# 🧠 Key Takeaways

- ➕ Use `dictionary[key] = value` to add a new key-value pair.
- 🔎 Use `key in dictionary` to check whether a key exists.
- 🔄 The same assignment syntax can also be used to update an existing value.
- 🗂️ Dictionaries make it easy to expand and manage related data.
- ✅ Meaningful keys make dictionary lookups intuitive and readable.
