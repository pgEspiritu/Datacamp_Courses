# 🐼 loc and iloc (1) - Selecting Rows in Pandas

## 🎯 Exercise Description

Pandas provides two powerful methods for selecting data from DataFrames:

- 🏷️ `loc[]` → **label-based** selection
- 🔢 `iloc[]` → **integer position-based** selection

With `loc` and `iloc`, you can select rows, columns, or both.

---

# 🏷️ `loc[]` - Label-Based Selection

`loc[]` uses the **labels** of rows and columns.

Syntax:

    dataframe.loc[row_label]

Example:

    cars.loc['RU']

This selects the row with the label:

    RU

---

# 🔢 `iloc[]` - Integer Position-Based Selection

`iloc[]` uses the **integer position** of rows and columns.

Syntax:

    dataframe.iloc[row_index]

Example:

    cars.iloc[4]

This selects the row at integer position:

    4

---

# 🔄 `loc` and `iloc` Equivalents

The following pairs return the same data:

    cars.loc['RU']
    cars.iloc[4]

Both select the Russia observation as a Series.

---

    cars.loc[['RU']]
    cars.iloc[[4]]

Both select Russia as a DataFrame.

---

    cars.loc[['RU', 'AUS']]
    cars.iloc[[4, 1]]

Both select Russia and Australia as a DataFrame.

---

# 📌 Series vs DataFrame

The number of brackets matters.

## Single Row

    cars.loc['RU']

Returns a:

    Pandas Series

## Single Row as DataFrame

    cars.loc[['RU']]

Returns a:

    Pandas DataFrame

## Multiple Rows

    cars.loc[['RU', 'AUS']]

Returns a:

    Pandas DataFrame

---

# 🚗 Cars Dataset

The DataFrame contains vehicle information from several countries.

Example row labels:

| Label | Country |
|---|---|
| `US` | United States |

# 🎯 Instructions

Complete the following tasks:

1. Use `loc` or `iloc` to select the observation for **Japan** as a Series.
   - Row label: `JPN`
   - Integer index: `2`
2. Print the resulting Series.
3. Use `loc` or `iloc` to select the observations for:
   - Australia
   - Egypt
4. Print the resulting observations as a DataFrame.

---

# 💡 Solution

    # Import cars data
    import pandas as pd

    cars = pd.read_csv('cars.csv', index_col=0)

    # Print out observation for Japan
    print(cars.loc['JPN'])

    # Print out observations for Australia and Egypt
    print(cars.loc[['AUS', 'EG']])

---

# 📚 Explanation

## 1️⃣ Selecting Japan as a Series

    cars.loc['JPN']

`loc[]` uses the row label:

    'JPN'

Because only one label is provided without an additional list, the result is a Series.

---

## 2️⃣ Selecting Australia and Egypt

    cars.loc[['AUS', 'EG']]

The list contains two row labels:

    'AUS'
    'EG'

Because multiple rows are selected, the result is a DataFrame.

---

# 🔢 Equivalent `iloc` Solution

The same operations can be performed using integer positions.

Japan is at index position `2`:

    print(cars.iloc[2])

Australia is at index position `1` and Egypt is at index position `6`:

    print(cars.iloc[[1, 6]])

Both approaches produce the same selections.

---

# ⚖️ `loc` vs `iloc`

| Method | Selection Basis | Example |
|---|---|---|
| `loc[]` | 🏷️ Labels | `cars.loc['JPN']` |
| `iloc[]` | 🔢 Integer positions | `cars.iloc[2]` |

---

# 🧠 Key Takeaways

- 🏷️ Use `loc[]` when you know the row or column **label**.
- 🔢 Use `iloc[]` when you know the integer **position**.
- 📋 Single row selection returns a Series.
- 🗂️ Multiple row selection returns a DataFrame.
- 🔗 Double brackets can preserve DataFrame structure when selecting a single row.
- 🚀 `loc` and `iloc` provide more powerful and flexible selection than basic square brackets.
