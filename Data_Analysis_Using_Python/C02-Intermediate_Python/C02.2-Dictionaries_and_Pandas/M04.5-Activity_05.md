# 🐼 loc and iloc (3) - Selecting Columns

## 🎯 Exercise Description

The `loc[]` and `iloc[]` methods can also be used to select **only columns** from a Pandas DataFrame.

To select all rows and specific columns, use a slice for the rows before the comma:

    cars.loc[:, 'country']
    cars.iloc[:, 1]

The `:` means:

    Select all rows

---

# 🚗 Cars DataFrame

The `cars` DataFrame contains vehicle information for different countries.

| Index | country | drives_right | cars_per_cap |
|---|---|---|---:|
| `US` | United States | `True` | 809 |
| `AUS` | Australia | `False` | 731 |

The DataFrame is imported from `cars.csv` using the first column as the row index.

    import pandas as pd

    cars = pd.read_csv('cars.csv', index_col=0)

---

# 🏷️ Selecting Columns with `loc[]`

`loc[]` uses **column labels**.

Syntax:

    dataframe.loc[:, column_label]

Example:

    cars.loc[:, 'country']

This selects the entire `country` column.

The result is a:

    Pandas Series

---

# 🔢 Selecting Columns with `iloc[]`

`iloc[]` uses **integer column positions**.

Syntax:

    dataframe.iloc[:, column_index]

Example:

    cars.iloc[:, 1]

This selects the column at position `1`.

The result is a:

    Pandas Series

---

# 📊 Selecting Multiple Columns

To select multiple columns, provide a list of labels or positions.

Using `loc[]`:

    cars.loc[:, ['country', 'drives_right']]

Using `iloc[]`:

    cars.iloc[:, [1, 2]]

Both return a:

    Pandas DataFrame

---

# 📌 Understanding the Colon `:`

In:

    cars.loc[:, 'drives_right']

the two parts mean:

    rows, columns

The colon:

    :

means:

    All rows

The column label:

    'drives_right'

means:

    Select the drives_right column

---

# 🎯 Instructions

Complete the following tasks:

1. Print the `drives_right` column as a **Pandas Series** using `loc` or `iloc`.
2. Print the `drives_right` column as a **Pandas DataFrame** using `loc` or `iloc`.
3. Print both the `cars_per_cap` and `drives_right` columns as a **Pandas DataFrame** using `loc` or `iloc`.

---

# 💡 Solution

    # Import cars data
    import pandas as pd

    cars = pd.read_csv('cars.csv', index_col=0)

    # Print out drives_right column as Series
    print(cars.loc[:, 'drives_right'])

    # Print out drives_right column as DataFrame
    print(cars.loc[:, ['drives_right']])

    # Print out cars_per_cap and drives_right as DataFrame
    print(cars.loc[:, ['cars_per_cap', 'drives_right']])

---

# 📚 Explanation

## 1️⃣ `drives_right` as a Series

    cars.loc[:, 'drives_right']

The `:` selects all rows.

The column label:

    'drives_right'

selects the required column.

Because only one column label is provided without a list, the result is a:

    Pandas Series

---

## 2️⃣ `drives_right` as a DataFrame

    cars.loc[:, ['drives_right']]

The column name is placed inside a list.

This keeps the result as a:

    Pandas DataFrame

---

## 3️⃣ Selecting Multiple Columns

    cars.loc[:, ['cars_per_cap', 'drives_right']]

The `:` selects all rows.

The list:

    ['cars_per_cap', 'drives_right']

selects both columns.

The result is a DataFrame.

---

# 🔍 Series vs DataFrame

| Syntax | Result |
|---|---|
| `cars.loc[:, 'drives_right']` | Series |
| `cars.loc[:, ['drives_right']]` | DataFrame |
| `cars.loc[:, ['cars_per_cap', 'drives_right']]` | DataFrame |

The same principle applies when using `iloc[]`.

---

# 🆚 loc vs iloc

| Method | Selection | Example |
|---|---|---|
| `loc[]` | Uses labels 🏷️ | `cars.loc[:, 'drives_right']` |
| `iloc[]` | Uses positions 🔢 | `cars.iloc[:, 2]` |

For multiple columns:

    cars.loc[:, ['cars_per_cap', 'drives_right']]

or:

    cars.iloc[:, [1, 2]]

---

# 🧠 Key Takeaways

- 🐼 `loc[]` and `iloc[]` can select columns as well as rows.
- `:` means **all rows**.
- 🏷️ `loc[]` uses column labels.
- 🔢 `iloc[]` uses integer column positions.
- 📋 A single column selected without a list returns a **Series**.
- 🗂️ A column selected inside a list returns a **DataFrame**.
- 📊 Multiple columns are selected by providing a list of labels or positions.
- 🚀 `loc` and `iloc` provide flexible control over DataFrame selection.
