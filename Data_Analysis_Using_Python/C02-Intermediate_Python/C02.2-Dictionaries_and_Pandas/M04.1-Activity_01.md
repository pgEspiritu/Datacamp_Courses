# 📊 Square Brackets (1) - Pandas DataFrame Indexing

## 🎯 Exercise Description

In Pandas, there are many ways to select and index data from a DataFrame.

The simplest method is by using square brackets `[]`.

Although it is not the most powerful method, square brackets are useful for selecting columns from a DataFrame.

---

# 📌 Selecting Columns Using Square Brackets

## 1️⃣ Single Square Brackets

Using a single pair of square brackets:

    cars['cars_per_cap']

returns a:

    Pandas Series

A Series is a one-dimensional labeled data structure.

Example:

    cars['country']

Output:

    US       United States
    AUS          Australia
    JPN             Japan
    ...
    Name: country, dtype: object

---

## 2️⃣ Double Square Brackets

Using double square brackets:

    cars[['cars_per_cap']]

returns a:

    Pandas DataFrame

Even though only one column is selected, the output keeps the DataFrame structure.

Example:

    cars[['country']]

Output:

                  country
    US       United States
    AUS          Australia
    JPN             Japan

---

## 3️⃣ Selecting Multiple Columns

To select multiple columns, provide a list of column names inside the brackets.

Example:

    cars[['country', 'drives_right']]

This returns a DataFrame containing:

- `country`
- `drives_right`

in the specified order.

---

# 🚗 Vehicle Dataset

The dataset contains information about vehicles from different countries.

| Column | Description |
|---|---|
| `country` | Name of the country 🌍 |
| `drives_right` | Whether vehicles drive on the right side 🚗 |
| `cars_per_cap` | Number of cars per 1,000 people 🚘 |

---

# 🎯 Instructions

Complete the following tasks:

1. Use single square brackets to print the `country` column as a Pandas Series.
2. Use double square brackets to print the `country` column as a Pandas DataFrame.
3. Use double square brackets to print a DataFrame containing:
   - `country`
   - `drives_right`

---

# 💡 Solution

    # Import cars data
    import pandas as pd

    cars = pd.read_csv('cars.csv', index_col=0)

    # Print out country column as Pandas Series
    print(cars['country'])

    # Print out country column as Pandas DataFrame
    print(cars[['country']])

    # Print out DataFrame with country and drives_right columns
    print(cars[['country', 'drives_right']])

---

# 📚 Explanation

## 1️⃣ Importing the Dataset

    import pandas as pd

Imports the Pandas library.

The alias `pd` is the standard convention used when working with Pandas.

---

## 2️⃣ Reading the CSV File

    cars = pd.read_csv('cars.csv', index_col=0)

Loads the CSV file into a DataFrame.

The argument `index_col=0` tells Pandas to use the first column as the DataFrame row labels.

---

## 3️⃣ Selecting a Column as a Series

    cars['country']

Uses a single pair of brackets to select one column.

The result is a Pandas Series.

---

## 4️⃣ Selecting a Column as a DataFrame

    cars[['country']]

Uses double brackets.

The additional brackets preserve the DataFrame structure.

---

## 5️⃣ Selecting Multiple Columns

    cars[['country', 'drives_right']]

Creates a smaller DataFrame containing only the selected columns.

The column order follows the order specified inside the list.

---

# 🔍 Series vs DataFrame

| Syntax | Result |
|---|---|
| `cars['country']` | Pandas Series |
| `cars[['country']]` | Pandas DataFrame |
| `cars[['country', 'drives_right']]` | Pandas DataFrame |

---

# 🧠 Key Takeaways

✅ `cars['column']` returns a Pandas Series.

✅ `cars[['column']]` returns a Pandas DataFrame.

✅ Double square brackets can be used to select multiple columns.

✅ Column names must match exactly.

✅ Pandas DataFrames are powerful structures for working with tabular data.
