# 📄 CSV to DataFrame (2) - Using `index_col`

## 🎯 Exercise Description

In the previous exercise, you imported `cars.csv` using:

    cars = pd.read_csv('cars.csv')

The import worked, but there was a problem:

⚠️ The first column, which contains the row labels, was imported as a regular DataFrame column.

The first column should instead be used as the **row index**.

---

# 📌 Using `index_col`

The `pd.read_csv()` function provides an argument called:

    index_col

This allows you to specify which column in the CSV file should be used as the DataFrame index.

### Syntax

    pd.read_csv('file.csv', index_col=0)

The value:

    index_col=0

means:

> Use the first column of the CSV file as the row labels.

Remember that Python uses **zero-based indexing**:

| Index | Column |
|---:|---|
| `0` | First column |
| `1` | Second column |
| `2` | Third column |

---

# 🎯 Instructions

Complete the following tasks:

1. Run the original code and observe that the first column is incorrectly imported as a normal column.
2. Add the `index_col` argument to `pd.read_csv()`.
3. Set `index_col` to `0`.
4. Print `cars` again and verify that the first column is now used as the row labels.

---

# 💡 Solution

    # Import pandas as pd
    import pandas as pd

    # Fix import by including index_col
    cars = pd.read_csv('cars.csv', index_col=0)

    # Print out cars
    print(cars)

---

# 🔍 Understanding the Solution

## Without `index_col`

    cars = pd.read_csv('cars.csv')

The first column is treated as regular data.

The DataFrame may look like:

              country  drives_right  cars_per_cap
    0     United States          True           809
    1         Australia         False           731
    2             Japan         False           588
    ...

---

## With `index_col=0`

    cars = pd.read_csv('cars.csv', index_col=0)

The first column becomes the DataFrame index.

The result is cleaner:

            country  drives_right  cars_per_cap
    US     United States         True           809
    AUS        Australia        False           731
    JPN            Japan        False           588
    IN             India        False            18
    RU             Russia         True           200
    MOR          Morocco         True            70
    EG             Egypt         True            45

---

# 🧠 Key Takeaways

- 📄 `pd.read_csv()` imports CSV data into a DataFrame.
- 🏷️ `index_col` specifies which CSV column should become the row index.
- 🔢 `index_col=0` uses the **first column** as the index.
- 📊 Using the correct index makes the DataFrame cleaner and easier to work with.
- 🐼 `index_col` is especially useful when the source CSV already contains meaningful row labels.
