# 📄 CSV to DataFrame (1) - Pandas

## 🎯 Exercise Description

Creating a DataFrame manually from a dictionary works well for small datasets, but it is not practical when working with **millions of observations**.

In real-world data science, datasets are often stored in files with a regular structure.

One of the most common file formats is:

    CSV

CSV stands for:

    Comma-Separated Values

Pandas provides the `read_csv()` function to import CSV files directly into a DataFrame.

---

# 📌 Why Use CSV Files?

CSV files are commonly used because they:

- 📊 Store tabular data
- 📄 Are easy to create and share
- 💻 Can be opened by spreadsheet applications
- 🐼 Can be imported easily into Pandas
- 🚀 Are practical for large datasets

Example CSV structure:

    country,drives_right,cars_per_cap
    United States,True,809
    Australia,False,731
    Japan,False,588
    India,False,18

---

# 📥 Importing a CSV File

To work with CSV files using Pandas, first import Pandas:

    import pandas as pd

Then use:

    pd.read_csv()

The general syntax is:

    dataframe = pd.read_csv('file_name.csv')

---

# 🚗 Cars Dataset

The file for this exercise is:

    cars.csv

The file is already available in the current working directory, so only the filename is required.

---

# 🎯 Instructions

Complete the following tasks:

1. Import Pandas as `pd`.
2. Use `pd.read_csv()` to import `cars.csv`.
3. Store the resulting DataFrame in a variable called `cars`.
4. Print the DataFrame.
5. Check whether the imported data looks correct.

---

# 💡 Solution

    # Import pandas as pd
    import pandas as pd

    # Import the cars.csv data: cars
    cars = pd.read_csv('cars.csv')

    # Print out cars
    print(cars)

---

# 🔍 Understanding the Code

## 1️⃣ Import Pandas

    import pandas as pd

This imports the Pandas package and gives it the standard alias:

    pd

---

## 2️⃣ Read the CSV File

    cars = pd.read_csv('cars.csv')

The `read_csv()` function:

- 📂 Opens the CSV file
- 📖 Reads the tabular data
- 🐼 Converts it into a Pandas DataFrame
- 📦 Stores the DataFrame in `cars`

---

## 3️⃣ Print the DataFrame

    print(cars)

This displays the imported dataset so you can inspect its structure and values.

---

# 🧠 Key Takeaways

- 📄 CSV means **Comma-Separated Values**.
- 🐼 Use `pd.read_csv()` to import CSV data into Pandas.
