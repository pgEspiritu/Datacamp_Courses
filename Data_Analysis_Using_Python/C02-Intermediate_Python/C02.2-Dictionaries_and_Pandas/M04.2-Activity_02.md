# 📊 Square Brackets (2) - Selecting Rows in Pandas

## 🎯 Exercise Description

Square brackets `[]` can be used not only to select columns from a Pandas DataFrame, but also to select **rows or observations**.

For example:

    cars[0:5]

returns the first five rows of the `cars` DataFrame.

The result is another DataFrame containing only the selected rows.

---

# 📌 Selecting Rows with Square Brackets

When selecting rows using square brackets, you must use a **slice**.

Syntax:

    dataframe[start:end]

Example:

    cars[0:5]

This selects rows:

    0, 1, 2, 3, 4

Remember that the ending index is **excluded**.

---

# ⚠️ Important: Integer Indexes

When using square brackets to select rows, you use the **integer row positions**, not the DataFrame's row labels.

For example:

    cars[0:3]

selects the first three rows regardless of whether their row labels are:

    0, 1, 2

or:

    US, AUS, JPN

The slicing is based on the row positions.

---

# 🔢 Understanding Slicing

Pandas follows Python's normal slicing rules.

The syntax is:

    start:end

where:

- `start` is included ✅
- `end` is excluded ❌

Examples:

    cars[0:3]

selects:

    0, 1, 2

And:

    cars[3:6]

selects:

    3, 4, 5

---

# 🎯 Instructions

Complete the following tasks:

1. Select the **first 3 observations** from `cars` and print them.
2. Select the **fourth, fifth, and sixth observations**, corresponding to row indexes `3`, `4`, and `5`, and print them.

---

# 💡 Solution

    # Import cars data
    import pandas as pd

    cars = pd.read_csv('cars.csv', index_col=0)

    # Print out first 3 observations
    print(cars[0:3])

    # Print out fourth, fifth and sixth observation
    print(cars[3:6])

---

# 📚 Explanation

## 1️⃣ Selecting the First Three Observations

    cars[0:3]

The slice starts at row `0` and stops before row `3`.

Therefore, it selects:

    0
    1
    2

These correspond to the first three observations.

---

## 2️⃣ Selecting the Fourth, Fifth, and Sixth Observations

    cars[3:6]

The slice starts at row `3` and stops before row `6`.

Therefore, it selects:

    3
    4
    5

These correspond to the fourth, fifth, and sixth observations.

---

# 🔍 Square Brackets for Rows vs Columns

Square brackets can be used for both columns and rows, but the syntax is different.

## Select a Column

    cars['country']

Returns a Pandas Series.

## Select Multiple Columns

    cars[['country', 'drives_right']]

Returns a Pandas DataFrame.

## Select Rows with a Slice

    cars[0:3]

Returns the first three rows as a DataFrame.

---

# 🧠 Key Takeaways

- 📊 Square brackets can select both columns and rows.
- 📋 Use `cars['column']` to select a single column.
- 🗂️ Use `cars[['column1', 'column2']]` to select multiple columns.
- ✂️ Use a slice such as `cars[0:3]` to select rows.
- 🔢 Row slicing with square brackets uses **integer positions**.
- ✅ The start index is included.
- ❌ The end index is excluded.
- 🐼 For more advanced row and column selection, use `loc[]` and `iloc[]`.
