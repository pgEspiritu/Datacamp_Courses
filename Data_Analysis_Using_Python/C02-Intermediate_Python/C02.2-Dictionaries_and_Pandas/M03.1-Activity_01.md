# 🚗 Create a DataFrame from a Dictionary - Pandas

## 🎯 Exercise Description

In this exercise, you will work with **vehicle data from different countries**.

Each observation represents a country, while the columns provide information about:

- 🌍 Country name
- 🚘 Whether people drive on the right or left
- 🚗 Number of motor vehicles per 1,000 people

Pandas can convert a dictionary into a **DataFrame**, where:

- 🔑 Dictionary keys become column names.
- 📋 Dictionary values become the data in those columns.

---

# 📋 Pre-defined Lists

Three lists are already available:

### `names`

Contains the country names:

    names = [
        'United States',
        'Australia',
        'Japan',
        'India',
        'Russia',
        'Morocco',
        'Egypt'
    ]

### `dr`

Contains Boolean values indicating whether people drive on the right side:

    dr = [True, False, False, False, True, True, True]

- `True` → Drives on the right 🚘
- `False` → Drives on the left 🚙

### `cpc`

Contains the number of motor vehicles per 1,000 people:

    cpc = [809, 731, 588, 18, 200, 70, 45]

---

# 🗂️ Creating the Dictionary

Create a dictionary named `my_dict` with three key-value pairs:

    my_dict = {
        'country': names,
        'drives_right': dr,
        'cars_per_cap': cpc
    }

The dictionary structure is:

| Key | Value | Data |
|---|---|---|
| `country` | `names` | Country names 🌍 |
| `drives_right` | `dr` | Right/left driving 🚘 |
| `cars_per_cap` | `cpc` | Vehicles per 1,000 people 🚗 |

---

# 🐼 Creating the DataFrame

Use `pd.DataFrame()` to convert the dictionary into a Pandas DataFrame.

    cars = pd.DataFrame(my_dict)

Each dictionary key becomes a DataFrame column.

---

# 🎯 Instructions

Complete the following tasks:

1. Import Pandas as `pd`.
2. Create `my_dict` using:
   - `'country'` → `names`
   - `'drives_right'` → `dr`
   - `'cars_per_cap'` → `cpc`
3. Convert `my_dict` into a DataFrame called `cars`.
4. Print `cars`.

---

# 💡 Solution

    # Pre-defined lists
    names = ['United States', 'Australia', 'Japan', 'India', 'Russia', 'Morocco', 'Egypt']
    dr = [True, False, False, False, True, True, True]
    cpc = [809, 731, 588, 18, 200, 70, 45]

    # Import pandas as pd
    import pandas as pd

    # Create dictionary my_dict with three key:value pairs
    my_dict = {
        'country': names,
        'drives_right': dr,
        'cars_per_cap': cpc
    }

    # Build a DataFrame cars from my_dict
    cars = pd.DataFrame(my_dict)

    # Print cars
    print(cars)

# 🧠 Key Takeaways

- 🐼 `pd.DataFrame()` converts structured data into a Pandas DataFrame.
- 🗂️ Dictionary keys become DataFrame column names.
- 📋 Dictionary values become column contents.
- 🌍 Each row represents an observation.
- 🔢 Pandas automatically creates numeric row indexes when no custom index is specified.
- 🚗 DataFrames are ideal for working with structured, tabular data.
