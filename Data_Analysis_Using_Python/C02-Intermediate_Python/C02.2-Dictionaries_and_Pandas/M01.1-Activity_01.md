# 🗂️ Motivation for Dictionaries - Python

## 🎯 Exercise Description

Before learning dictionaries, let's understand why they are useful.

In this exercise, you are given two lists:

- `countries` → contains country names
- `capitals` → contains the corresponding capital cities

Example:

```python
countries = ['spain', 'france', 'germany', 'norway']

capitals = ['madrid', 'paris', 'berlin', 'oslo']
```

The lists are connected through their **index positions**.

---

# 📌 Understanding the List Relationship

| Index | Country | Capital |
|---|---|---|
| 0 | spain | madrid |
| 1 | france | paris |
| 2 | germany | berlin |
| 3 | norway | oslo |

To find Germany's capital, we need to:

1. Find Germany's index in the `countries` list.
2. Use the same index to retrieve the value from the `capitals` list.

---

# 🔎 Finding an Index Using `index()`

Python lists have an `index()` method.

Syntax:

```python
list.index(value)
```

Example:

```python
countries.index('germany')
```

Output:

```python
2
```

This means `"germany"` is located at index `2`.

---

# 🎯 Instructions

Complete the following tasks:

1. Use the `index()` method on `countries` to find the index of:

```python
'germany'
```

2. Store the result in a variable:

```python
ind_ger
```

3. Use `ind_ger` to access Germany's capital from the `capitals` list.

4. Print the result.

---

# 💡 Solution

```python
# Definition of countries and capital
countries = ['spain', 'france', 'germany', 'norway']

capitals = ['madrid', 'paris', 'berlin', 'oslo']


# Get index of 'germany': ind_ger

ind_ger = countries.index('germany')


# Use ind_ger to print out capital of Germany

print(capitals[ind_ger])
```

---

# 📚 Explanation

## 1️⃣ Finding Germany's Index

```python
ind_ger = countries.index('germany')
```

The `index()` method searches the list and returns the position of the specified item.

Result:

```python
ind_ger = 2
```

---

## 2️⃣ Accessing the Capital

```python
capitals[ind_ger]
```

Since:

```python
ind_ger = 2
```

Python retrieves:

```python
capitals[2]
```

Result:

```python
berlin
```

---

# ⚠️ Limitation of This Approach

Although this works, using two separate lists has disadvantages:

❌ You must remember matching indexes  
❌ Data can become misaligned  
❌ Searching becomes harder with large datasets  

Example problem:

```python
countries[2]
```

must always match:

```python
capitals[2]
```

---

# 🗂️ Dictionary Solution

A dictionary removes the need for indexes:

```python
europe = {
    "spain": "madrid",
    "france": "paris",
    "germany": "berlin",
    "norway": "oslo"
}
```

Now Germany's capital can be accessed directly:

```python
europe["germany"]
```

Output:

```python
berlin
```

---

# 🧠 Key Takeaways

✅ `index()` finds the position of an item in a list  
✅ Lists require matching indexes to connect data  
✅ Dictionaries provide direct key-value relationships  
✅ Dictionaries are easier and more efficient for structured data
