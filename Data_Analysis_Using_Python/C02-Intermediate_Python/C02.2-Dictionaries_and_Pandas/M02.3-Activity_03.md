# 🗂️ Dictionariception - Nested Dictionaries

## 🎯 Exercise Description

Just like lists can contain other lists, **dictionaries can contain other dictionaries**.

This creates a **nested dictionary** or a **dictionary of dictionaries**.

Nested dictionaries are useful when each key needs to store multiple related pieces of information.

For example:

- 🌍 Country → Capital + Population
- 👤 Person → Name + Age + Address
- 📦 Product → Price + Stock + Category

---

# 🧩 Dictionary of Dictionaries

The `europe` dictionary contains country names as keys.

Each country's value is another dictionary containing:

- 🏛️ `capital`
- 👥 `population`

Example:

    europe = {
        'spain': {
            'capital': 'madrid',
            'population': 46.77
        },
        'france': {
            'capital': 'paris',
            'population': 66.03
        },
        'germany': {
            'capital': 'berlin',
            'population': 80.62
        },
        'norway': {
            'capital': 'oslo',
            'population': 5.084
        }
    }

---

# 🔗 Accessing Nested Dictionary Values

You can use **chained square brackets** to access values inside nested dictionaries.

Example:

    europe['spain']['population']

This works in two steps:

1. `europe['spain']` → selects Spain's dictionary.
2. `['population']` → selects the population value inside Spain's dictionary.

Result:

    46.77

---

# 🇫🇷 Accessing France's Capital

To access France's capital:

    europe['france']['capital']

Result:

    paris

The first key selects the country:

    'france'

The second key selects the information:

    'capital'

---

# 🎯 Instructions

Complete the following tasks:

1. Use chained square brackets to print the capital of France.
2. Create a dictionary named `data` with:
   - `'capital'` → `'rome'`
   - `'population'` → `59.83`
3. Add `data` to `europe` using:
   - Key → `'italy'`
   - Value → `data`
4. Print the updated `europe` dictionary.

---

# 💡 Solution

    # Dictionary of dictionaries
    europe = {
        'spain': {
            'capital': 'madrid',
            'population': 46.77
        },
        'france': {
            'capital': 'paris',
            'population': 66.03
        },
        'germany': {
            'capital': 'berlin',
            'population': 80.62
        },
        'norway': {
            'capital': 'oslo',
            'population': 5.084
        }
    }

    # Print out the capital of France
    print(europe['france']['capital'])

    # Create sub-dictionary data
    data = {
        'capital': 'rome',
        'population': 59.83
    }

    # Add data to europe under key 'italy'
    europe['italy'] = data

    # Print europe
    print(europe)

# 🔍 Understanding Chained Brackets

To access Spain's population:

    europe['spain']['population']

To access Germany's capital:

    europe['germany']['capital']

To access Italy's population:

    europe['italy']['population']

The general pattern is:

    dictionary['outer_key']['inner_key']

---

# ➕ Adding a Nested Dictionary

The new Italy information is stored separately:

    data = {
        'capital': 'rome',
        'population': 59.83
    }

Then added to `europe`:

    europe['italy'] = data

This makes `data` the value associated with the key `'italy'`.

---

# 🧠 Key Takeaways

- 🗂️ Dictionaries can contain other dictionaries.
- 🪆 A dictionary containing dictionaries is called a **nested dictionary**.
- 🔗 Use chained square brackets to access nested values.
- `europe['france']['capital']` accesses France's capital.
- ➕ A nested dictionary can be added like any other dictionary value.
- 📊 Nested dictionaries are useful for storing multiple attributes associated with a single key.
- 🚀 They are especially useful for organizing structured and hierarchical data in Python.
