# 🔑 Access Dictionary - Python

## 🎯 Exercise Description

Dictionaries make it easy to access information because values are connected directly to meaningful keys.

Example dictionary:

```python
europe = {
    'spain': 'madrid',
    'france': 'paris',
    'germany': 'berlin',
    'norway': 'oslo'
}
```

Instead of using indexes like lists, dictionaries allow direct access using keys.

---

# 📌 Accessing Dictionary Values

To get France's capital:

```python
europe['france']
```

Output:

```python
paris
```

Explanation:

- `'france'` → key 🔑
- `'paris'` → value 📦

The key is used to retrieve its corresponding value.

---

# 🔍 Viewing Dictionary Keys

Python dictionaries have a `keys()` method.

Syntax:

```python
dictionary.keys()
```

Example:

```python
europe.keys()
```

Output:

```python
dict_keys(['spain', 'france', 'germany', 'norway'])
```

This displays all available keys in the dictionary.

---

# 🎯 Instructions

Complete the following tasks:

1. Check the keys available in `europe` using:

```python
europe.keys()
```

2. Print the result.

3. Access the value associated with the key:

```python
'norway'
```

4. Print the capital of Norway.

---

# 💡 Solution

```python
# Definition of dictionary

europe = {
    'spain': 'madrid',
    'france': 'paris',
    'germany': 'berlin',
    'norway': 'oslo'
}


# Print out the keys in europe

print(europe.keys())


# Print out value that belongs to key 'norway'

print(europe['norway'])
```

---

# 📚 Explanation

## 1️⃣ Getting Dictionary Keys

```python
europe.keys()
```

returns all keys stored in the dictionary.

Output:

```python
dict_keys(['spain', 'france', 'germany', 'norway'])
```

The keys are:

- `spain`
- `france`
- `germany`
- `norway`

---

## 2️⃣ Accessing Norway's Capital

```python
europe['norway']
```

Python searches for the key:

```python
'norway'
```

and returns its value:

```python
oslo
```

---

# 🆚 Dictionary vs List Access

## List Example:

```python
capitals[3]
```

You need to remember the index position.

---

## Dictionary Example:

```python
europe['norway']
```

You directly use the meaningful key.
