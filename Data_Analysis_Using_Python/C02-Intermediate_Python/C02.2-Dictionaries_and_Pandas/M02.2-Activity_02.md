# 🧹 Dictionary Manipulation (2)

## 🎯 Exercise Description

Dictionaries can be **updated and cleaned** after they are created.

Instead of changing the original dictionary definition, you can use Python commands to:

- ✏️ Update existing values
- 🗑️ Remove incorrect key-value pairs

In this exercise, the `europe` dictionary contains two incorrect pieces of information.

---

# 📌 Given Dictionary

The dictionary contains:

    europe = {
        'spain': 'madrid',
        'france': 'paris',
        'germany': 'bonn',
        'norway': 'oslo',
        'italy': 'rome',
        'poland': 'warsaw',
        'australia': 'vienna'
    }

There are two problems:

1. 🇩🇪 Germany's capital is incorrectly listed as `'bonn'`.
2. 🇦🇺 Australia should not be included in a dictionary of European countries.

---

# 🎯 Instructions

Complete the following tasks:

1. Update Germany's capital from `'bonn'` to `'berlin'`.
2. Remove the key `'australia'` from `europe`.
3. Print the updated dictionary.

---

# ✏️ Updating a Dictionary Value

To change an existing value, use:

    dictionary[key] = new_value

For Germany:

    europe['germany'] = 'berlin'

This changes:

    'germany': 'bonn'

into:

    'germany': 'berlin'

---

# 🗑️ Removing a Dictionary Entry

Use the `del` statement to remove a key-value pair:

    del dictionary[key]

For Australia:

    del europe['australia']

This removes both the key and its associated value.

---

# 💡 Solution

    # Definition of dictionary
    europe = {
        'spain': 'madrid',
        'france': 'paris',
        'germany': 'bonn',
        'norway': 'oslo',
        'italy': 'rome',
        'poland': 'warsaw',
        'australia': 'vienna'
    }

    # Update capital of Germany
    europe['germany'] = 'berlin'

    # Remove Australia
    del europe['australia']

    # Print europe
    print(europe)

---

# 📤 Output

    {
        'spain': 'madrid',
        'france': 'paris',
        'germany': 'berlin',
        'norway': 'oslo',
        'italy': 'rome',
        'poland': 'warsaw'
    }

---

# 🔍 Explanation

## 1️⃣ Update Germany

    europe['germany'] = 'berlin'

The value associated with the existing key `'germany'` is replaced.

---

## 2️⃣ Remove Australia

    del europe['australia']

The `'australia'` key and its value are completely removed from the dictionary.

---

## 3️⃣ Print the Updated Dictionary

    print(europe)

This displays the cleaned dictionary so you can verify the changes.

---

# 🧠 Key Takeaways

- ✏️ Use `dictionary[key] = new_value` to update an existing value.
- 🗑️ Use `del dictionary[key]` to remove a key-value pair.
- 🔄 You do not need to redefine the entire dictionary to make changes.
- 🔑 The key identifies which value will be updated or removed.
- 🧹 Dictionary manipulation is useful for cleaning and maintaining data.
