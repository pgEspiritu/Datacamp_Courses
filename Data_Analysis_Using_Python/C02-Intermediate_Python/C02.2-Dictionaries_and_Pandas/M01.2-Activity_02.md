# 🗂️ Create Dictionary - Python

## 🎯 Exercise Description

The `countries` and `capitals` lists contain related information:

- 🌍 `countries` → Country names
- 🏛️ `capitals` → Corresponding capital cities

Example:

```python
countries = ['spain', 'france', 'germany', 'norway']

capitals = ['madrid', 'paris', 'berlin', 'oslo']
```

Previously, these were stored in two separate lists and connected using index positions.

A better approach is to convert them into a **dictionary**.

---

# 📌 Dictionary Structure

A dictionary stores information using:

```
key : value
```

For this exercise:

- 🔑 Key → Country name
- 📦 Value → Capital city

Example:

```python
my_dict = {
    "key1": "value1",
    "key2": "value2"
}
```

---

# 🌍 Creating a Country Dictionary

The goal is to create a dictionary named:

```python
europe
```

with this structure:

| Key | Value |
|---|---|
| spain | madrid |
| france | paris |
| germany | berlin |
| norway | oslo |

Important:

⚠️ Use lowercase characters for all keys and values.

---

# 🎯 Instructions

Complete the following tasks:

1. Create a dictionary called `europe`.
2. Add 4 key-value pairs:
   - `"spain"` → `"madrid"`
   - `"france"` → `"paris"`
   - `"germany"` → `"berlin"`
   - `"norway"` → `"oslo"`
3. Print the dictionary.

---

# 💡 Solution

```python
# Definition of countries and capital
countries = ['spain', 'france', 'germany', 'norway']

capitals = ['madrid', 'paris', 'berlin', 'oslo']


# From string in countries and capitals, create dictionary europe

europe = {
    'spain': 'madrid',
    'france': 'paris',
    'germany': 'berlin',
    'norway': 'oslo'
}


# Print europe

print(europe)
```

---

# 📚 Explanation

## 1️⃣ Creating the Dictionary

```python
europe = {
    'spain': 'madrid',
    'france': 'paris',
    'germany': 'berlin',
    'norway': 'oslo'
}
```

Each country is a **key** and each capital is its corresponding **value**.

---

## 2️⃣ Accessing Dictionary Data

Instead of using indexes:

```python
capitals[countries.index('germany')]
```

You can directly access the value:

```python
europe['germany']
```

Output:

```python
berlin
```

---

# ⚡ Why Dictionaries Are Better

Using lists:

❌ Requires matching indexes  
❌ Harder to read  
❌ Easier to make mistakes  

Using dictionaries:

✅ Direct lookup using keys  
✅ More organized data  
✅ Easier to maintain  
✅ Faster access for large datasets  

---

# 🧠 Key Takeaways

✅ Dictionaries use curly brackets `{}`  
✅ Data is stored as key-value pairs  
✅ Keys and values are separated by `:`  
✅ Dictionary keys must be unique  
✅ Dictionaries make related data easier to manage 🐍📊
