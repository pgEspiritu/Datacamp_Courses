# 🎯 Selective Import

Python allows you to import only the specific functionality you need from a package.

A general import:

    import math

makes all features from the `math` package available.

However, if you only need a specific feature, you can perform a **selective import**.

---

# 📥 Selective Import Syntax

### General Import

    import math

Usage:

    math.pi

---

### Selective Import

    from math import pi

Usage:

    pi

With selective imports, you no longer need to use the package name prefix.

---

# 🥧 Using `pi` from the Math Package

The `math` package contains the mathematical constant π (`pi`).

Instead of:

    math.pi

you can directly use:

    pi

after importing it.

---

# 📐 Circle Formulas

## Circumference

    C = 2 × π × r

Python:

    C = 2 * r * pi

---

## Area

    A = π × r²

Python:

    A = pi * r ** 2

---

# 📝 Exercise

Using a circle radius of:

    r = 0.43

Complete the following tasks:

1. Perform a selective import from the `math` package.
2. Import only the `pi` function.
3. Calculate the circumference and store it in `C`.
4. Calculate the area and store it in `A`.
5. Print both results.

---

# ✅ Solution

    # Import pi function of math package
    from math import pi

    # Calculate C
    C = 2 * 0.43 * pi

    # Calculate A
    A = pi * 0.43 ** 2

    print("Circumference: " + str(C))
    print("Area: " + str(A))

---

# 📤 Output

    Circumference: 2.701769682087222
    Area: 0.580880481648397

---

# 🔍 Understanding the Code

## Import Only `pi`

    from math import pi

This imports only the `pi` constant from the `math` package.

---

## Calculate Circumference

    C = 2 * 0.43 * pi

Equivalent to:

    C = 2 × π × r

where:

    r = 0.43

---

## Calculate Area

    A = pi * 0.43 ** 2

Equivalent to:

    A = π × r²

The operator:

    **

means exponentiation.

Example:

    2 ** 3

means:

    2³ = 8

---

# ⚖️ Import Comparison

| Import Style | Example | Usage |
|---|---|---|
| General import | `import math` | `math.pi` |
| Selective import | `from math import pi` | `pi` |

---

# 💡 When to Use Selective Imports

✅ Use selective imports when:

- You only need one or a few functions.
- You want shorter code.
- The imported name is clear and unlikely to conflict.

⚠️ Be careful when:

- Different packages have functions with the same name.
- The source of a function becomes unclear in large projects.

---

# 🎯 Key Takeaways

- 📦 Packages contain reusable Python functionality.
- 🎯 Selective imports allow you to import only what you need.
- 🥧 `from math import pi` imports only the value of π.
- 🔢 After importing, use `pi` directly instead of `math.pi`.
- 📐 `**` is used for exponentiation.
- 🧠 Selective imports can make code shorter and cleaner.
