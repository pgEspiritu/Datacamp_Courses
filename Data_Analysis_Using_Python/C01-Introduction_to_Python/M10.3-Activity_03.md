# 🧮 2D NumPy Arithmetic

## 📌 Performing Calculations on 2D Arrays

One of NumPy's biggest advantages is the ability to perform **element-wise calculations** on entire arrays.

With 2D NumPy arrays, mathematical operations are applied to each corresponding element.

Example:

```python
array_a + array_b
```

NumPy automatically adds:

```
element 1 + element 1
element 2 + element 2
element 3 + element 3
```

No loops are required. 🚀

---

# ⚾ Baseball Dataset

In this exercise, `np_baseball` contains baseball player information:

| Column | Description | Unit |
|---|---|---|
| Column 0 | Height | Inches 📏 |
| Column 1 | Weight | Pounds ⚖️ |
| Column 2 | Age | Years 🎂 |

Example:

```python
np_baseball
```

Structure:

```text
[
 [height, weight, age],
 [height, weight, age],
 ...
]
```

---

# ➕ Adding 2D NumPy Arrays

Player updates are stored in another 2D NumPy array:

```python
updated
```

To apply these changes:

```python
np_baseball + updated
```

NumPy adds each value with its corresponding value.

Example:

```text
Original height + Height change
Original weight + Weight change
Original age + Age change
```

---

# 🔄 Converting Units with NumPy

Baseball data uses:

- Height → inches
- Weight → pounds

Data science often requires metric units:

- Inches → Meters
- Pounds → Kilograms

Conversion factors:

```
1 inch = 0.0254 meters
1 pound = 0.453592 kilograms
1 year = 1 year
```

Create a conversion array:

```python
conversion = np.array([0.0254, 0.453592, 1])
```

---

# ⚡ Applying Conversion to Data

Because NumPy performs element-wise multiplication:

```python
np_baseball * conversion
```

The conversion applies by column:

| Column | Conversion |
|---|---|
| Height | × 0.0254 |
| Weight | × 0.453592 |
| Age | × 1 |

Example:

```text
Height: 75 inches × 0.0254 = 1.905 meters

Weight: 200 pounds × 0.453592 = 90.7184 kg

Age: 25 × 1 = 25 years
```

---

# 💻 Complete Solution

```python
import numpy as np

# Add updated values to np_baseball
print(np_baseball + updated)

# Create conversion array
conversion = np.array([0.0254, 0.453592, 1])

# Convert height and weight to metric units
print(np_baseball * conversion)
```
