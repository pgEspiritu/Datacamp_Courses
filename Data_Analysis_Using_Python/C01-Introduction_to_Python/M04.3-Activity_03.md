# 📋 Subsetting Lists of Lists

A Python list can contain other lists. This is called a **list of lists** or a **nested list**.

To access elements inside a list of lists, use multiple sets of square brackets:

    house[2][0]

- The first index selects the **inner list**.
- The second index selects an **element inside that inner list**.

## 📌 Example

Given:

    house = [
        ["hallway", 11.25],
        ["kitchen", 18.0],
        ["living room", 20.0],
        ["bedroom", 10.75],
        ["bathroom", 9.50]
    ]

The structure is:

| Outer Index | Inner List |
|---:|---|
| `0` | `["hallway", 11.25]` |
| `1` | `["kitchen", 18.0]` |
| `2` | `["living room", 20.0]` |
| `3` | `["bedroom", 10.75]` |
| `4` | `["bathroom", 9.50]` |

## 🔍 Accessing Nested Elements

To get the area `9.5` from the bathroom:

    house[-1][1]

Breakdown:

- `house[-1]` → selects the **last inner list**: `["bathroom", 9.50]`
- `[1]` → selects the **second element** of that inner list: `9.50`

Therefore:

    house[-1][1]

returns:

    9.5

## 📝 Exercise

### Task

Subset the `house` list to get the float `9.5`.

## ✅ Solution

    house = [["hallway", 11.25],
             ["kitchen", 18.0],
             ["living room", 20.0],
             ["bedroom", 10.75],
             ["bathroom", 9.50]]

    # Subset the house list
    house[-1][1]

## 📤 Output

    9.5

## 🎯 Quick Reference

    house[0][0]    # "hallway"
    house[0][1]    # 11.25

    house[2][0]    # "living room"
    house[2][1]    # 20.0

    house[-1][0]   # "bathroom"
    house[-1][1]   # 9.5

## 💡 Key Takeaways

- 📋 A list can contain other lists.
- 🪆 A list containing other lists is called a **nested list**.
- 🔢 The first index selects the **inner list**.
- 🎯 The second index selects an **element inside the inner list**.
- 👉 `house[-1]` selects the last inner list.
- 👉 `house[-1][1]` selects the second element of the last inner list.
- 🧠 Multiple square brackets can be used to access values inside nested lists.
