# 📋 Create a List

A **list** is a **compound data type** that allows you to group multiple values together.

## 🧩 Creating a List

Use square brackets `[]` and separate elements with commas:

```python
a = "is"
b = "nice"

my_list = ["my", "list", a, b]
```

Output:

```text
['my', 'list', 'is', 'nice']
```

💡 A list can contain both **direct values** and **variables**.

---

# 🏠 Exercise: Create a List

The areas of different parts of a house are stored in separate variables:

```python
hall = 11.25
kit = 18.0
liv = 20.0
bed = 10.75
bath = 9.50
```

### 🎯 Instructions

Create a list called `areas` containing the areas in this order:

1. 🚪 Hallway → `hall`
2. 🍳 Kitchen → `kit`
3. 🛋️ Living room → `liv`
4. 🛏️ Bedroom → `bed`
5. 🛁 Bathroom → `bath`

Then print the list.

---

# ✅ Solution

```python
hall = 11.25
kit = 18.0
liv = 20.0
bed = 10.75
bath = 9.50

# Create list areas
areas = [hall, kit, liv, bed, bath]

# Print areas
print(areas)
```

### 📤 Output

```text
[11.25, 18.0, 20.0, 10.75, 9.5]
```

---

# 🔑 Key Takeaways

* 📋 Lists group multiple values together.
* `[]` are used to create a list.
* `,` separates list elements.
* 📦 Lists can contain variables.
* 🔢 The elements can be numbers, strings, booleans, or other lists.
* 🔢 **Order matters** — elements appear in the order you provide them.

### 💡 Basic Syntax

```python
my_list = [value1, value2, value3]
```

Example:

```python
areas = [hall, kit, liv, bed, bath]
```
