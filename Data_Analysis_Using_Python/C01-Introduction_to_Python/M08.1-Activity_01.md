# 📐 Import Package

The `math` package provides useful mathematical constants and functions.

For this exercise, you'll use `math.pi` to calculate the **circumference** and **area** of a circle.

## 📌 Circle Formulas

### Circumference

    C = 2 × π × r

### Area

    A = π × r²

In Python:

    C = 2 * r * math.pi
    A = math.pi * r ** 2

## 🔢 Exponentiation in Python

The `**` operator is used for exponentiation.

For example:

    3 ** 4

means:

    3⁴ = 81

Therefore:

    0.43 ** 2

calculates:

    0.43²

## 📦 Importing the `math` Package

Before using `math.pi`, import the package:

    import math

You can then access `pi` using:

    math.pi

## 📝 Exercise

Use a circle radius of `0.43`.

### Tasks

1. Import the `math` package.
2. Use `math.pi` to calculate the circumference and store the result in `C`.
3. Use `math.pi` to calculate the area and store the result in `A`.
4. Print both results.

## ✅ Solution

    # Import the math package
    import math

    # Calculate C
    C = 2 * 0.43 * math.pi

    # Calculate A
    A = math.pi * 0.43 ** 2

    print("Circumference: " + str(C))
    print("Area: " + str(A))

## 📤 Output

    Circumference: 2.701769682087222
    Area: 0.580880481648397

    import math

### Calculate Circumference

    C = 2 * 0.43 * math.pi

    C = 2 × π × r

### Calculate Area

    A = math.pi * 0.43 ** 2

This applies:

    A = π × r²

The `** 2` means the radius is squared.

    str(C)
    str(A)

The `str()` function converts the numerical results into strings so they can be combined with text using `+`.

For example:
