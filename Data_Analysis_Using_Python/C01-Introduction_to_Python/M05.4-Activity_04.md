# 🧠 Inner Workings of Lists

When assigning one list to another using `=`, Python does **not** create a separate copy of the list.

Instead, both variables point to the **same list in memory**.

## 📌 Example

Suppose:

    areas = [11.25, 18.0, 20.0, 10.75, 9.50]
    areas_copy = areas

Both variables point to the same list:

    areas ───────────► [11.25, 18.0, 20.0, 10.75, 9.50]
                         ▲
                         │
    areas_copy ──────────┘

If you change `areas_copy`:

    areas_copy[0] = 5.0

The change also appears in `areas` because both variables reference the same list.

## ⚠️ Why This Matters

Using:

    areas_copy = areas

does **not** create an independent copy.

To prevent changes in `areas_copy` from affecting `areas`, you need to explicitly create a copy.

Two common methods are:

    areas_copy = list(areas)

or:

    areas_copy = areas[:]

Both create a new list containing the same values.

## 📝 Exercise

The following code creates an `areas` list and a copy called `areas_copy`.

The goal is to modify `areas_copy` without changing the original `areas` list.

### Task

Change the command that creates `areas_copy` so that it becomes an **explicit copy** of `areas`.

## ✅ Solution

Using list slicing:

    # Create list areas
    areas = [11.25, 18.0, 20.0, 10.75, 9.50]

    # Create an explicit copy of areas
    areas_copy = areas[:]

    # Change areas_copy
    areas_copy[0] = 5.0

    # Print areas
    print(areas)

## 📤 Output

    [11.25, 18.0, 20.0, 10.75, 9.5]

The original `areas` list remains unchanged even though `areas_copy[0]` was changed to `5.0`.

## 🔍 Alternative Solution

You can also use the `list()` function:

    areas_copy = list(areas)

This also creates an independent copy.

## 🎯 Comparing the Methods

| Method | Creates Independent Copy? | Changes Affect Original? |
|---|---|---|
| `areas_copy = areas` | ❌ No | ✅ Yes |
| `areas_copy = areas[:]` | ✅ Yes | ❌ No |
| `areas_copy = list(areas)` | ✅ Yes | ❌ No |

## 💡 Key Takeaways

- 🧠 `areas_copy = areas` copies the **reference**, not the list itself.
- 📋 `areas_copy = areas[:]` creates a **new list**.
- 📋 `areas_copy = list(areas)` also creates a **new list**.
- ✅ Changes to an explicitly copied list do not affect the original list.
- ⚠️ Understanding references and copies is important when manipulating Python lists.
- 🎯 For a simple list copy, `list(areas)` and `areas[:]` are both useful approaches.
