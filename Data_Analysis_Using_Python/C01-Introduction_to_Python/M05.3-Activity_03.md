# 🗑️ Delete List Elements

Python allows you to remove elements from a list using the `del` statement.

## 📌 Syntax

    del list[index]

### Example

    x = ["a", "b", "c", "d"]

    del x[1]

After deleting the element at index `1`, the list becomes:

    ["a", "c", "d"]

## ⚠️ Important

When an element is removed, the indexes of the elements that come **after** it change.

For example:

    Before deletion:

    Index    Element
    0        "a"
    1        "b"
    2        "c"
    3        "d"

    After del x[1]:

    Index    Element
    0        "a"
    1        "c"
    2        "d"

The elements after the deleted element shift one position to the left.

## 📝 Exercise

The lottery winnings were not enough to build the poolhouse, so the poolhouse information needs to be removed from the `areas` list.

The `areas` list contains:

    areas = ["hallway", 11.25, "kitchen", 18.0,
             "chill zone", 20.0, "bedroom", 10.75,
             "bathroom", 10.50, "poolhouse", 24.5,
             "garage", 15.45]

### Tasks

1. Delete both the string `"poolhouse"` and the float `24.5` from the `areas` list.
2. Print the updated `areas` list.

## 🔍 Identifying the Poolhouse Indexes

The relevant part of the list is:

    Index    Element
    10       "poolhouse"
    11       24.5
    12       "garage"
    13       15.45

The poolhouse occupies indexes `10` and `11`.

You can remove both elements using slicing:

    del areas[10:12]

Remember that the **end index is excluded**, so `10:12` removes indexes `10` and `11`.

## ✅ Solution

    areas = ["hallway", 11.25, "kitchen", 18.0,
             "chill zone", 20.0, "bedroom", 10.75,
             "bathroom", 10.50, "poolhouse", 24.5,
             "garage", 15.45]

    # Delete the poolhouse items from the list
    del areas[10:12]

    # Print the updated list
    print(areas)

## 📤 Output

    ['hallway', 11.25, 'kitchen', 18.0, 'chill zone', 20.0, 'bedroom', 10.75, 'bathroom', 10.5, 'garage', 15.45]

## 🎯 Quick Reference

    del areas[10]      # Delete one element
    del areas[10:12]   # Delete multiple elements

- `del` removes elements from a list.
- `list[start:end]` can be used with `del` to remove multiple consecutive elements.
- The `start` index is included.
- The `end` index is excluded.
- After deletion, the remaining elements move to fill the empty positions.

## 💡 Key Takeaways

- 🗑️ Use `del` to remove elements from a list.
- 🎯 `del areas[10:12]` removes indexes `10` and `11`.
- ✂️ Slicing with `del` allows multiple elements to be deleted at once.
- ⚠️ Deleting elements changes the indexes of the elements that follow.
- 🧠 Always check the indexes carefully when deleting elements from a list.
