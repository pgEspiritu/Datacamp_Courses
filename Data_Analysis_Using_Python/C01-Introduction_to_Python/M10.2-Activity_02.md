# 🔍 Subsetting 2D NumPy Arrays

## 📌 Accessing Data in 2D Arrays

A **2D NumPy array** is structured like a table with:

- Rows → Individual records or observations 👤
- Columns → Features or variables 📊

Example:

```python
np_baseball
```

Structure:

| Row | Height | Weight |
|---|---:|---:|
| 0 | 180 | 78.4 |
| 1 | 215 | 102.7 |
| 2 | 210 | 98.5 |

---

# 🧩 NumPy Subsetting Syntax

For 2D arrays, NumPy uses:

```python
array[row, column]
```

Example:

```python
np_baseball[0, 1]
```

Meaning:

- Select row `0`
- Select column `1`

---

# ✂️ Selecting Rows and Columns

## Select All Rows from a Column

Use `:` to select all rows.

Example:

```python
np_baseball[:, 1]
```

Meaning:

- `:` → All rows
- `1` → Second column

Result:

```text
[78.4, 102.7, 98.5, ...]
```

---

## Select a Specific Row

Example:

```python
np_baseball[49]
```

This selects the 50th row.

Remember:

Python uses **zero-based indexing**:

| Player Number | Index |
|---|---|
| 1st player | 0 |
| 50th player | 49 |
| 124th player | 123 |

---

# ⚾ Baseball Dataset Example

np_baseball = np.array(baseball)

# 💻 Complete Solution

```python
import numpy as np

np_baseball = np.array(baseball)

# Print out the 50th row of np_baseball
print(np_baseball[49])

# Select the entire second column of np_baseball
np_weight_lb = np_baseball[:, 1]

# Print out height of 124th player
print(np_baseball[123, 0])
```

---

# 🎯 Key Takeaways

✅ Use `[row, column]` syntax for 2D NumPy arrays  
✅ Use `:` to select all rows or columns  
✅ NumPy uses zero-based indexing  
✅ `array[:, 1]` selects an entire column  
✅ `array[123, 0]` selects the height of the 124th player  

🚀 Efficient subsetting is one of NumPy's most powerful features for data analysis!
