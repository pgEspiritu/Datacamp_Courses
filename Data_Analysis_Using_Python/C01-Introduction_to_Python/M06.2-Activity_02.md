# 🔢 Multiple Arguments

Python functions can accept **multiple arguments**. Some arguments are required, while others are optional.

For this exercise, you'll work with the built-in `sorted()` function.

## 📌 The `sorted()` Function

You can view the documentation using:

    help(sorted)

The `sorted()` function accepts three arguments:

    sorted(iterable, key=None, reverse=False)

| Argument | Purpose | Required? |
|---|---|---|
| `iterable` | The data to sort | ✅ Yes |
| `key` | Defines how items should be sorted | ❌ Optional |
| `reverse` | Controls ascending or descending order | ❌ Optional |

In this exercise, only `iterable` and `reverse` are needed.

## 🔽 Sorting in Descending Order

By default, `sorted()` sorts values in **ascending order**:

    sorted(full)

To sort in **descending order**, use:

    sorted(full, reverse=True)

The `reverse` argument is a **keyword argument**, because its name is explicitly specified.

## 📝 Exercise

Two lists have already been created:

    first = [11.25, 18.0, 20.0]
    second = [10.75, 9.50]

### Tasks

1. Use `+` to merge `first` and `second` into a new list called `full`.
2. Use `sorted()` to sort `full` in **descending order**.
3. Set the `reverse` argument to `True`.
4. Store the result as `full_sorted`.
5. Print `full_sorted`.

## ✅ Solution

    # Create lists first and second
    first = [11.25, 18.0, 20.0]
    second = [10.75, 9.50]

    # Paste together first and second: full
    full = first + second

    # Sort full in descending order: full_sorted
    full_sorted = sorted(full, reverse=True)

    # Print out full_sorted
    print(full_sorted)

## 📤 Output

    [20.0, 18.0, 11.25, 10.75, 9.5]

## 🔍 Understanding the Solution

### 1. Merge the lists

    full = first + second

Result:

    [11.25, 18.0, 20.0, 10.75, 9.5]

### 2. Sort in descending order

    full_sorted = sorted(full, reverse=True)

The `reverse=True` argument changes the default ascending order into descending order.

Result:

    [20.0, 18.0, 11.25, 10.75, 9.5]

### 3. Print the result

    print(full_sorted)

Output:

    [20.0, 18.0, 11.25, 10.75, 9.5]

## ⚠️ Note About the Provided Solution

The supplied solution in the exercise text shows:

    full_sorted = sorted(full)

However, this sorts the list in **ascending order**, not descending order.

That would produce:

    [9.5, 10.75, 11.25, 18.0, 20.0]

To satisfy the exercise requirement of **descending order**, the correct code is:

    full_sorted = sorted(full, reverse=True)

## 🎯 Quick Reference

    sorted(full)
    # Ascending order

    sorted(full, reverse=True)
    # Descending order

## 💡 Key Takeaways

- 🧩 Functions can accept multiple arguments.
- 🔑 Keyword arguments allow you to specify an argument by name.
- 📋 `sorted()` sorts an iterable and returns a **new sorted list**.
- ⬆️ `sorted(full)` sorts in ascending order by default.
- ⬇️ `sorted(full, reverse=True)` sorts in descending order.
- ➕ `first + second` combines two lists.
- 🧠 Optional arguments can change how a function behaves.
