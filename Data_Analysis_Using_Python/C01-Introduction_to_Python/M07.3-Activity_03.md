# 📋 List Methods (2)

Most list methods **modify the original list** they are called on.

In this exercise, you'll work with three useful list methods:

- `.append()` → adds an element to a list.
- `.remove()` → removes the first matching element from a list.
- `.reverse()` → reverses the order of the elements in a list.

You can explore list methods with:

    help(list)

## ➕ `.append()` Method

The `.append()` method adds an element to the **end** of a list.

### Syntax

    list.append(value)

### Example

    areas.append(24.5)

This adds `24.5` to the end of `areas`.

You can use `.append()` multiple times:

    areas.append(24.5)
    areas.append(15.45)

The values are added in the same order.

---

## ➖ `.remove()` Method

The `.remove()` method removes the **first element** that matches the specified value.

### Syntax

    list.remove(value)

### Example

    areas.remove(24.5)

This removes the first occurrence of `24.5` from `areas`.

⚠️ If the value does not exist in the list, Python raises a `ValueError`.

---

## 🔄 `.reverse()` Method

The `.reverse()` method reverses the order of all elements in the list.

### Syntax

    list.reverse()

### Example

    areas.reverse()

If the list is:

    [11.25, 18.0, 20.0, 10.75, 9.50]

After calling `.reverse()`:

    [9.50, 10.75, 20.0, 18.0, 11.25]

⚠️ `.reverse()` changes the original list.

---

# 📝 Exercise

You are working with the following `areas` list:

    areas = [11.25, 18.0, 20.0, 10.75, 9.50]

### Tasks

1. Use `.append()` twice to add:
   - `24.5` for the poolhouse
   - `15.45` for the garage
2. Make sure the values are added in that order.
3. Print `areas`.
4. Use `.reverse()` to reverse the order of the elements.
5. Print `areas` again.

---

# ✅ Solution

    # Create list areas
    areas = [11.25, 18.0, 20.0, 10.75, 9.50]

    # Use append twice to add poolhouse and garage size
    areas.append(24.5)
    areas.append(15.45)

    # Print out areas
    print(areas)

    # Reverse the order of the elements in areas
    areas.reverse()

    # Print out areas
    print(areas)

---

# 📤 Output

After using `.append()`:

    [11.25, 18.0, 20.0, 10.75, 9.5, 24.5, 15.45]

After using `.reverse()`:

    [15.45, 24.5, 9.5, 10.75, 20.0, 18.0, 11.25]

# ⚠️ Important: Methods That Modify Lists

Unlike methods such as some string methods that return a new value, these list methods modify the original list:

| Method | Purpose | Modifies Original List? |
|---|---|---|
| `.append()` | Adds an element | ✅ Yes |
| `.remove()` | Removes an element | ✅ Yes |
| `.reverse()` | Reverses the list | ✅ Yes |
| `.index()` | Finds an index | ❌ No |
| `.count()` | Counts occurrences | ❌ No |

## 💡 Key Takeaways

- ➕ `.append()` adds an element to the **end** of a list.
- ➖ `.remove()` removes the **first matching element**.
- 🔄 `.reverse()` reverses the order of the elements.
- ⚠️ `.append()`, `.remove()`, and `.reverse()` **modify the original list**.
- 🔗 List methods are called using **dot notation**: `list.method()`.
- 🧠 Always check whether a method changes the original object or simply returns a result.
