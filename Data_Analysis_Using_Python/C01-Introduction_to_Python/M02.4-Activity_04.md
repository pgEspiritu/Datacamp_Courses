# 🔄 Operations with Other Types

Python variables can contain different **data types**, and operations can behave differently depending on the type of data.

You can check the data type of a variable using `type()`:

```python
type(variable)
```

Example:

```python
print(type(total_savings))
```

---

# 🔢 1. Operations with Numbers

When adding two integers, Python performs **numeric addition**.

Given:

```python
savings = 100
new_savings = 40
```

Calculate the total:

```python
total_savings = savings + new_savings
```

Print the result:

```python
print(total_savings)
```

Output:

```text
140
```

You can check its data type:

```python
print(type(total_savings))
```

Output:

```text
<class 'int'>
```

### ✅ Complete Solution

```python
savings = 100
new_savings = 40

# Calculate total_savings
total_savings = savings + new_savings
print(total_savings)

# Print the type of total_savings
print(type(total_savings))
```

# 🔤 2. Operations with Strings

The `+` operator behaves differently when working with strings.

Instead of performing mathematical addition, `+` **concatenates** (joins) strings together.

Given:

```python
intro = "Hello! How are you?"
```

Add the string to itself:

```python
doubleintro = intro + intro
```

Print the result:

```python
print(doubleintro)
```

Output:

```text
Hello! How are you?Hello! How are you?
```

### ✅ Complete Solution

```python
intro = "Hello! How are you?"

# Assign sum of intro and intro to doubleintro
doubleintro = intro + intro

# Print out doubleintro
print(doubleintro)
```

---

# 🧠 Key Concept: Type Determines Behavior

The same operator can behave differently depending on the data type.

### 🔢 Numbers

```python
100 + 40
```

Output:

```text
140
```

➡️ Performs **addition**.

### 🔤 Strings

```python
"Hello" + "Hello"
```

Output:

```text
HelloHello
```

➡️ Performs **concatenation**.

---

# 🔑 Key Takeaways

| Data Type  | `+` Operation | Example             | Result         |
| ---------- | ------------- | ------------------- | -------------- |
| 🔢 `int`   | Addition      | `100 + 40`          | `140`          |
| 🔢 `float` | Addition      | `1.5 + 2.5`         | `4.0`          |
| 🔤 `str`   | Concatenation | `"Hello" + "Hello"` | `"HelloHello"` |

### 💡 Remember

> 🧠 **Python's operators can behave differently depending on the data types being used.**

> 🔍 Use `type()` to determine the type of a variable.

```python
print(type(variable))
```
