# 🐍 Hello Python!

## 🎯 What is Python?

**Python** is a general-purpose, open-source programming language created by **Guido van Rossum**.

### 🌟 Why Python?

* 🔓 **Open source** — Free to use.
* 📦 **Extensive packages** — Many reusable packages are available for different tasks.
* 📊 **Great for Data Science** — Strong ecosystem for data analysis, visualization, machine learning, and databases.
* 🛠️ **Versatile** — Can be used to build many types of software.
* 🧩 **Easy to learn and use** — Python has a simple and readable syntax.

> 💡 Python is often described as the **"Swiss Army knife" of programming languages** because it can be used for many different purposes.

---

# 💻 IPython Shell

The **Python Shell** allows you to type Python code and immediately see the result.

For example:

```python
4 + 5
```

Output:

```text
9
```

### ⚡ IPython

**IPython** stands for **Interactive Python**.

It is an enhanced version of the standard Python shell and is part of the broader **Jupyter ecosystem**.

👉 Use the IPython Shell mainly for:

* 🧪 Experimenting
* 🔍 Testing code
* 💡 Exploring Python commands
* 🧮 Performing quick calculations

---

# 📜 Python Scripts

A **Python script** is a text file containing Python commands.

Python scripts use the `.py` file extension.

Example:

```text
hello.py
```

A script can contain multiple Python commands that are executed sequentially.

---

# 🖨️ Using `print()`

When running code inside a Python script, use `print()` to display output.

### ❌ Without `print()`

```python
4 + 5
```

The result may not be displayed when the script runs.

### ✅ With `print()`

```python
print(4 + 5)
```

Output:

```text
9
```

> 💡 **Remember:** Use `print()` when you want to explicitly display a result from a Python script.
