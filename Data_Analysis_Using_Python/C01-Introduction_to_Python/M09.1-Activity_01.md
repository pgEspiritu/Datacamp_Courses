# ⚾ Your First NumPy Array

## 📌 Creating NumPy Arrays

NumPy is a powerful Python package used for numerical computing and data science.

A **NumPy array** is an improved version of a Python list that allows faster calculations and efficient data manipulation.

In this exercise, we work with baseball player heights stored in centimeters.

---

# 📦 Import NumPy

To use NumPy, first import the package.

```python
import numpy as np
```

The `as np` syntax creates a shortcut, allowing us to use `np` instead of writing `numpy` every time.

Example:

```python
np.array()
```

instead of:

```python
numpy.array()
```

---

# 🏗️ Creating a NumPy Array

A Python list can be converted into a NumPy array using:

```python
np.array()
```

Example:

```python
baseball = [180, 215, 210, 210, 188, 176, 209, 200]

np_baseball = np.array(baseball)
```

The list is now converted into a NumPy array.

---

# 🔎 Checking the NumPy Array Type

To confirm that the conversion was successful, use:

```python
type(np_baseball)
```

Example:

```python
print(type(np_baseball))
```

Output:

```python
<class 'numpy.ndarray'>
```

`ndarray` means **N-dimensional array**, which is NumPy's main data structure.

---

# 💻 Complete Solution

```python
# Import the numpy package as np
import numpy as np

baseball = [180, 215, 210, 210, 188, 176, 209, 200]

# Create a numpy array from baseball
np_baseball = np.array(baseball)

# Print the numpy array
print(np_baseball)

# Print the type of np_baseball
print(type(np_baseball))
```

---

# 🎯 Key Takeaways

✅ NumPy provides powerful tools for data science  
✅ Use `import numpy as np` to import NumPy with a shortcut  
✅ Use `np.array()` to convert Python lists into NumPy arrays  
✅ NumPy arrays are stored as `numpy.ndarray` objects  
✅ NumPy arrays allow faster mathematical operations compared to regular Python lists  

🚀 Creating NumPy arrays is the first step toward efficient data analysis with Python!
