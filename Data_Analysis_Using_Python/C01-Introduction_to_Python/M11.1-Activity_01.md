# 📏 Average versus Median 📊

## 🎯 Overview

You now know how to use NumPy functions to better understand your data.

In this exercise, we will compare two important statistical measures:

- 📊 **Mean (Average)**
- 📍 **Median**

The goal is to understand which statistic is more reliable when dealing with **outliers**.

---

# 🧢 Baseball Dataset

The baseball dataset is available as a 2D NumPy array:

    np_baseball

The array contains:

- 📏 Column 0 → Height (inches)
- ⚖️ Column 1 → Weight (pounds)
- 🎂 Column 2 → Age (years)

The dataset contains:

- 👥 1,015 baseball players
- 📋 3 variables per player

After restructuring the data, you notice that some height values are unusually high.

These unusually large or small values are called **outliers** ⚠️.

---

# 🧩 Step 1: Select Height Data

To analyze player heights, select the first column of `np_baseball`.

Code:

    np_height_in = np_baseball[:, 0]

Explanation:

- `:` selects all rows.
- `0` selects the first column.
- The result contains all baseball player heights.

---

# 📊 Step 2: Calculate the Mean

The **mean** is the average value of all observations.

Formula:

    Mean = Sum of all values / Number of values

Using NumPy:

    print(np.mean(np_height_in))

Example:

    73.68

The mean gives the average height of all players.

---

# 📍 Step 3: Calculate the Median

The **median** is the middle value after sorting all observations.

Using NumPy:

    print(np.median(np_height_in))

Example:

    74.0

The median represents the central value of the dataset.

---

# ⚖️ Mean vs Median

| Statistic | Description | Effect of Outliers |
|---|---|---|
| 📊 Mean | Average of all values | Sensitive to outliers |
| 📍 Median | Middle value after sorting | Less affected by outliers |

Example:

Dataset:

    [70, 72, 74, 75, 150]

Mean:

    88.2

Median:

    74

The extremely high value `150` affects the mean but does not significantly change the median.

---

# 🧠 Key Takeaways

- 📊 Use the **mean** when data does not contain extreme values.
- 📍 Use the **median** when your dataset contains outliers.
- ⚠️ Outliers can heavily influence averages.
- 🐍 NumPy provides simple functions for statistical analysis:

    np.mean()

    np.median()

For real-world data analysis, always check whether outliers exist before choosing the best summary statistic. 🚀
