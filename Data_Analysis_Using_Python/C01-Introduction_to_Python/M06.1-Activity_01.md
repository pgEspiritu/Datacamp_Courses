# 🧩 Familiar Functions

Python provides many **built-in functions** that make programming easier.

Some familiar built-in functions include:

- `print()` → displays output
- `type()` → checks the data type
- `str()` → converts a value to a string
- `int()` → converts a value to an integer
- `bool()` → converts a value to a Boolean
- `float()` → converts a value to a floating-point number
- `len()` → returns the number of elements in a collection

📚 Python's complete list of built-in functions is available in the official Python documentation:
https://docs.python.org/3/library/functions.html

## 📌 Calling a Function

Functions are called using parentheses `()`.

For example:

    result = type(3.0)

The `type()` function determines the data type of `3.0`, and the result is stored in the variable `result`.

## 📝 Exercise

Given:

    var1 = [1, 2, 3, 4]
    var2 = True

### Tasks

1. Use `print()` together with `type()` to print the type of `var1`.
2. Use `len()` to determine the length of `var1` and print the result.
3. Use `int()` to convert `var2` to an integer and store the result as `out2`.

## ✅ Solution

    # Create variables var1 and var2
    var1 = [1, 2, 3, 4]
    var2 = True

    # Print out type of var1
    print(type(var1))

    # Print out length of var1
    print(len(var1))

    # Convert var2 to an integer: out2
    out2 = int(var2)

## 📤 Output

The first `print()` statement produces:

    <class 'list'>

The second `print()` statement produces:

    4

The value of `out2` is:

    1

## 🧠 Understanding the Functions

### `type()`

Checks the data type of a value.

    type(var1)

Since `var1` is a list:

    <class 'list'>

### `len()`

Returns the number of elements in a list.

    len(var1)

Since `var1` contains four elements:

    4

### `int()`

Converts a value to an integer.

    int(var2)

Since:

    var2 = True

The conversion produces:

    1

In Python:

- `True` converts to `1`
- `False` converts to `0`

## 🎯 Quick Reference

| Function | Purpose | Example |
|---|---|---|
| `print()` | Display output | `print(var1)` |
| `type()` | Check data type | `type(var1)` |
| `len()` | Get number of elements | `len(var1)` |
| `int()` | Convert to integer | `int(var2)` |
| `str()` | Convert to string | `str(123)` |
| `bool()` | Convert to Boolean | `bool(1)` |
| `float()` | Convert to float | `float(10)` |

## 💡 Key Takeaways

- 🧩 Python has many built-in functions that you can use directly.
- 🔍 `type()` identifies the data type.
- 📏 `len()` returns the number of elements.
- 🔢 `int()` converts a value to an integer.
- 🖨️ `print()` displays values and function results.
- 🔄 Functions can be combined, such as `print(type(var1))`.
- 📦 Function results can be stored in variables for later use.
