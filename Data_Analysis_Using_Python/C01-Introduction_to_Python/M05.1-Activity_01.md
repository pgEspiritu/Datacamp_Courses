# ✏️ Replace List Elements

To replace list elements, **subset the list** and assign new values to the selected elements.

You can replace:

- 🎯 A single element
- ✂️ Multiple elements using list slicing

For this exercise, continue working with the `areas` list containing the names and areas of different rooms in a house.

## 📌 Key Concept

The basic syntax for replacing an element is:

    list[index] = new_value

You can also use **negative indexing** to replace elements from the end of the list.

## 📝 Exercise

### Tasks

1. Update the area of the **bathroom** from `9.50` to `10.50` square meters using **negative indexing**.
2. Change `"living room"` to `"chill zone"` without using negative indexing.

## 🧠 Understanding the Indexes

The `areas` list is:

    areas = ["hallway", 11.25, "kitchen", 18.0, "living room", 20.0, "bedroom", 10.75, "bathroom", 9.50]

The bathroom area is the **last element**, so it can be accessed using:

    areas[-1]

The `"living room"` string is at index `4`:

    areas[4]

## ✅ Solution

    # Create the areas list
    areas = ["hallway", 11.25, "kitchen", 18.0, "living room", 20.0, "bedroom", 10.75, "bathroom", 9.50]

    # Correct the bathroom area
    areas[-1] = 10.50

    # Change "living room" to "chill zone"
    areas[4] = "chill zone"

## 📤 Result

After the changes, the `areas` list becomes:

    ["hallway", 11.25, "kitchen", 18.0, "chill zone", 20.0, "bedroom", 10.75, "bathroom", 10.50]

## 🎯 Quick Reference

    areas[-1] = 10.50
    areas[4] = "chill zone"

- `areas[-1]` → selects the **last element**.
- `areas[4]` → selects the element at **index 4**.
- `=` assigns the new value to the selected element.

## 💡 Key Takeaways

- ✏️ Use `list[index] = new_value` to replace a list element.
- 🔚 Negative indexing is useful for accessing elements from the end.
- 🎯 `areas[-1]` accesses the last element.
- 🔢 `areas[4]` accesses the fifth element.
- 🧠 Replacing an element changes the original list.
