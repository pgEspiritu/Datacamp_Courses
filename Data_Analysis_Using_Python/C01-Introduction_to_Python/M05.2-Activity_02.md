# ➕ Extend a List

You can add elements to a Python list by using the `+` operator.

The `+` operator combines two lists and returns a **new list**.

## 📌 Example

    x = ["a", "b", "c", "d"]
    y = x + ["e", "f"]

The resulting list is:

    ["a", "b", "c", "d", "e", "f"]

## 📝 Exercise

You won the lottery and decided to build a **poolhouse** and a **garage**. Add their information to the `areas` list.

### Tasks

1. Use the `+` operator to add `["poolhouse", 24.5]` to the end of `areas`.
   - Store the resulting list as `areas_1`.
2. Extend `areas_1` by adding the garage information:
   - `"garage"`
   - `15.45`
   - Store the resulting list as `areas_2`.

## 🧠 Key Concept

The general syntax is:

    new_list = existing_list + [new_elements]

The original list remains unchanged, while the `+` operation creates a new list.

## ✅ Solution

    # Create the areas list and make some changes
    areas = ["hallway", 11.25, "kitchen", 18.0, "chill zone", 20.0,
             "bedroom", 10.75, "bathroom", 10.50]

    # Add poolhouse data to areas, new list is areas_1
    areas_1 = areas + ["poolhouse", 24.5]

    # Add garage data to areas_1, new list is areas_2
    areas_2 = areas_1 + ["garage", 15.45]

## 📤 Result

### `areas`

    ["hallway", 11.25, "kitchen", 18.0, "chill zone", 20.0,
     "bedroom", 10.75, "bathroom", 10.50]

### `areas_1`

    ["hallway", 11.25, "kitchen", 18.0, "chill zone", 20.0,
     "bedroom", 10.75, "bathroom", 10.50, "poolhouse", 24.5]

### `areas_2`

    ["hallway", 11.25, "kitchen", 18.0, "chill zone", 20.0,
     "bedroom", 10.75, "bathroom", 10.50, "poolhouse", 24.5,
     "garage", 15.45]

## 🎯 Quick Reference

    areas_1 = areas + ["poolhouse", 24.5]

    areas_2 = areas_1 + ["garage", 15.45]

- ➕ `+` combines lists.
- 📋 The result is stored in a **new list**.
- 🔄 You can continue extending the new list.

## 💡 Key Takeaways

- ➕ Use `+` to combine two lists.
- 🆕 The `+` operator creates a **new list**.
- 📌 The original list is not changed.
- 🔗 You can extend a list in multiple steps by combining it with additional lists.
- 🧠 `areas_1` contains the poolhouse data, while `areas_2` contains both the poolhouse and garage data.
