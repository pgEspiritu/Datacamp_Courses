# 🧩 Create Lists with Different Types

Python lists can contain **different data types** in the same list, including:

* 🔤 `str` — strings/text
* 🔢 `int` — integers
* 🔢 `float` — decimal numbers
* ✅ `bool` — Boolean values
* 📋 `list` — other lists

For example:

```python
my_list = ["Python", 3.14, True, 10]
```

---

# 🏠 Mixing Strings and Variables

You can combine **room names (strings)** with **room areas (float variables)**.

⚠️ Pay attention to the difference:

```python
"bathroom"
```

is a **string**, while:

```python
bath
```

is a **variable** containing the float:

```python
9.50
```

Therefore, use quotation marks for the room name but **not** for the variable.

---

# 🎯 Exercise

Create an `areas` list where each room name is followed by its corresponding area.

The required order is:

```text
"hallway", hall,
"kitchen", kit,
"living room", liv,
"bedroom", bed,
"bathroom", bath
```

---

# ✅ Solution

```python
hall = 11.25
kit = 18.0
liv = 20.0
bed = 10.75
bath = 9.50

# Adapt list areas
areas = [
    "hallway", hall,
    "kitchen", kit,
    "living room", liv,
    "bedroom", bed,
    "bathroom", bath
]

# Print areas
print(areas)
```

### 📤 Output

```text
['hallway', 11.25, 'kitchen', 18.0, 'living room', 20.0, 'bedroom', 10.75, 'bathroom', 9.5]
```

---

# 🔑 Key Takeaways

### 📋 Lists Can Mix Data Types

A single list can contain different types:

```python
example = ["Python", 3.14, True, 10]
```

### 🔤 String vs. Variable

```python
"bathroom"   # 🔤 String
bath         # 🔢 Variable containing 9.50
```

### 💡 Important

> 🧠 **Use quotes when you want to write a string directly. Don't use quotes when referring to a variable.**

Example:

```python
areas = ["hallway", hall]
```

Here:

* `"hallway"` → 🔤 String
* `hall` → 📦 Variable containing a number

🚀 **Python lists are flexible and can store different types of data together.**
