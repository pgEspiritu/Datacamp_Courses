# 📋 List Methods

Lists are Python objects with useful methods, just like strings.

In this exercise, you'll work with:

- `.index()` → finds the index of the **first element** that matches a value.
- `.count()` → counts how many times a value appears in a list.

You can explore list methods with:

    help(list)

## 🔍 `.index()` Method

The `.index()` method returns the index of the first matching element.

### Syntax

    list.index(value)

### Example

    areas = [11.25, 18.0, 20.0, 10.75, 9.50]

    areas.index(20.0)

Output:

    2

The value `20.0` is located at index `2`.

## 🔢 `.count()` Method

The `.count()` method returns the number of times a value occurs in a list.

### Syntax

    list.count(value)

### Example

    areas.count(9.50)

Output:

    1

The value `9.50` appears once in the list.

## 📝 Exercise

Given:

    areas = [11.25, 18.0, 20.0, 10.75, 9.50]

### Tasks

1. Use `.index()` to find the index of `20.0` in `areas`.
2. Print the index.
3. Use `.count()` to determine how many times `9.50` appears in `areas`.
4. Print the count.

## ✅ Solution

    # Create list areas
    areas = [11.25, 18.0, 20.0, 10.75, 9.50]

    # Print out the index of the element 20.0
    print(areas.index(20.0))

    # Print out how often 9.50 appears in areas
    print(areas.count(9.50))

## 📤 Output

    2
    1

## 🎯 Quick Reference

    areas.index(20.0)
    # Returns 2

    areas.count(9.50)
    # Returns 1

## 🧠 Key Takeaways

- 🔍 `.index()` finds the index of the **first matching element**.
- 🔢 `.count()` counts how many times an element appears.
- 📋 Both are **list methods**.
- 🔗 Use dot notation: `list.method()`.
- ⚠️ `.index()` returns the first match if the value appears multiple times.
- 💡 List methods are useful for searching and analyzing list contents.
