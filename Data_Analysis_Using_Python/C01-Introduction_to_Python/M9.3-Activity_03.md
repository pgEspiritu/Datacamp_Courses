# 🔢 Subsetting NumPy Arrays

## 📌 Accessing Data in NumPy Arrays

Subsetting means selecting specific elements from a list or array.

NumPy arrays use the same square bracket notation (`[]`) as Python lists.

Example:

```python
array[index]
```

The index determines which element will be accessed.

Remember:

| Index | Description |
|---|---|
| `0` | First element |
| `1` | Second element |
| `-1` | Last element |

---

# ⚾ Working with Baseball Data

In this exercise, we work with MLB player data:

- `height_in` → Player heights in inches 📏
- `weight_lb` → Player weights in pounds ⚖️

The data is converted into NumPy arrays:

```python
np_weight_lb = np.array(weight_lb)
np_height_in = np.array(height_in)
```

---

# 🎯 Selecting a Single Element

To access one value, use its index.

Example:

```python
np_weight_lb[50]
```

This retrieves the weight of the player stored at index `50`.

---

# ✂️ Selecting Multiple Elements (Slicing)

To select a range of values, use slicing:

```python
array[start:end]
```

Important:

- Start index is included ✅
- End index is excluded ❌

Example:

```python
np_height_in[100:111]
```

This selects:

```
Index 100 → Index 110
```

because index `111` is not included.

---

# 💻 Complete Solution

```python
import numpy as np

np_weight_lb = np.array(weight_lb)
np_height_in = np.array(height_in)

# Print out the weight at index 50
print(np_weight_lb[50])

# Print out sub-array of np_height_in:
# index 100 up to and including index 110
print(np_height_in[100:111])
```

---

# 🎯 Key Takeaways

✅ NumPy arrays use the same indexing system as Python lists  
✅ Use `array[index]` to select a single value  
✅ Use slicing `array[start:end]` to select multiple values  
✅ The start index is included, but the end index is excluded  
✅ NumPy makes working with large datasets simple and efficient  

🚀 Mastering array subsetting is essential for data analysis and machine learning workflows!
