# 📦 Variable Assignment

In Python, a **variable** allows you to refer to a value using a name.

## 📝 Creating a Variable

Use the assignment operator `=` to assign a value to a variable.

```python
x = 5
```

You can then use the variable name instead of the actual value:

```python
print(x)
```

Output:

```text
5
```

### ⚠️ Important

In Python:

```python
=
```

means **assignment**.

It does **not** test equality.

> 💡 Think of `=` as **"assign this value to this variable."**

# 🎯 Exercise

### Instructions

Create a variable called `savings` with a value of `100`, then print the value.

### ✅ Solution

```python
# Create a variable savings
savings = 100

# Print out savings
print(savings)
```

Output:

```text
100
```

---

# 🔑 Key Takeaway

```python
variable = value
```

Example:

```python
savings = 100
```

* 📦 `savings` → variable name
* `=` → assignment operator
* `100` → assigned value

🚀 **Remember: `=` assigns a value; it does not compare values.**
