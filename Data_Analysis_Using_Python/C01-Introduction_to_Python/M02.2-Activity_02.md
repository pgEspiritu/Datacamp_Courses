# 🧮 Calculations with Variables

Instead of calculating directly with values, you can use **variables** in your calculations.

For example, if you save **$10 per month** for **4 months**:

```text
10 × 4 = 40
```

Python allows you to store these values in variables and use them in calculations.

---

# 🎯 Exercise

### Instructions

1. Create a variable `monthly_savings` with a value of `10`.
2. Create a variable `num_months` with a value of `4`.
3. Multiply `monthly_savings` by `num_months` and store the result in `new_savings`.
4. Print the value of `new_savings`.

---

# ✅ Solution

```python
# Create the variables monthly_savings and num_months
monthly_savings = 10
num_months = 4

# Multiply monthly_savings and num_months
new_savings = monthly_savings * num_months

# Print new_savings
print(new_savings)
```

### 📤 Output

```text
40
```

---

# 🔑 Key Takeaways

* 📦 Variables can store values used in calculations.
* ✖️ Use `*` for multiplication.
* 🔄 Store calculation results in another variable.
* 🖨️ Use `print()` to display the result.

### 💡 General Pattern

```python
result = variable1 * variable2
print(result)
```

🚀 **Using variables makes calculations easier to read, modify, and reuse.**
