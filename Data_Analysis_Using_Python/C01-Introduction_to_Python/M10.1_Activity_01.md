# ⚾ Your First 2D NumPy Array

## 📌 Creating a Two-Dimensional NumPy Array

A **2D NumPy array** is a data structure organized into rows and columns.

It is commonly used for:

- 📊 Tabular data
- 🧮 Mathematical matrices
- 📈 Data science datasets

In this exercise, we use baseball player data containing:

- Height (cm) 📏
- Weight (kg) ⚖️

The data is stored as a **list of lists**.

---

# 📝 Python List of Lists

Example:

```python
baseball = [
    [180, 78.4],
    [215, 102.7],
    [210, 98.5],
    [188, 75.2]
]
```

Each inner list represents one baseball player:

| Player | Height (cm) | Weight (kg) |
|---|---:|---:|
| 1 | 180 | 78.4 |
| 2 | 215 | 102.7 |
| 3 | 210 | 98.5 |
| 4 | 188 | 75.2 |

---

# 🏗️ Creating a 2D NumPy Array

Use `np.array()` to convert the list of lists into a NumPy array.

Example:

```python
np_baseball = np.array(baseball)
```

The result becomes a 2D NumPy array:

```text
[
 [180.0  78.4]
 [215.0 102.7]
 [210.0  98.5]
 [188.0  75.2]
]
```

---

# 🔎 Checking the Array Type

Use `type()` to verify that the object is a NumPy array.

Example:

```python
print(type(np_baseball))
```

Output:

```text
<class 'numpy.ndarray'>
```

`ndarray` means **N-dimensional array**.

---

# 📐 Checking the Shape of the Array

The `.shape` attribute shows the dimensions of the array.

Example:

```python
print(np_baseball.shape)
```

Output:

```text
(4, 2)
```

Meaning:

- `4` → Number of rows (players)
- `2` → Number of columns (height and weight)

---

# 💻 Complete Solution

```python
import numpy as np

baseball = [
    [180, 78.4],
    [215, 102.7],
    [210, 98.5],
    [188, 75.2]
]

# Create a 2D numpy array from baseball
np_baseball = np.array(baseball)

# Print out the type of np_baseball
print(type(np_baseball))

# Print out the shape of np_baseball
print(np_baseball.shape)
```

---

# 🎯 Key Takeaways

✅ A list of lists can be converted into a 2D NumPy array  
✅ Use `np.array()` to create NumPy arrays  
✅ `type()` confirms the object type  
✅ `.shape` shows rows and columns  
✅ 2D arrays are useful for storing structured datasets  

🚀 Understanding 2D arrays is an important step toward working with real-world data using NumPy!
