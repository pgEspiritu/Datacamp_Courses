# 🔤 String Methods

Strings are Python objects with many built-in methods that make it easier to work with text.

You can explore string methods using:

    help(str)

A string variable called `place` has already been created for this exercise.

## 📌 Calling String Methods

String methods use **dot notation**:

    string.method()

For example:

    place.upper()

This calls the `upper()` method on the `place` string.

---

## ⬆️ `upper()` Method

The `upper()` method converts all letters in a string to uppercase.

### Example

    place = "poolhouse"

    place_up = place.upper()

The result stored in `place_up` is:

    "POOLHOUSE"

### 📌 Important

The `upper()` method does **not** change the original string stored in `place`.

Instead, it returns a new string.

---

## 🔢 `count()` Method

The `count()` method counts how many times a specific character or substring appears in a string.

### Example

    place.count("o")

For:

    place = "poolhouse"

The letter `"o"` appears twice.

Therefore:

    place.count("o")

returns:

    2

### 📌 Syntax

    string.count(value)

# 📝 Exercise

A string variable `place` has already been created:

    place = "poolhouse"

### Tasks

1. Use the `.upper()` method on `place` and store the result in `place_up`.
2. Print both `place` and `place_up`.
3. Check whether the original `place` changed.
4. Count the number of `"o"` characters in `place` using `.count()` and print the result.

## ✅ Solution

    # String to experiment with: place
    place = "poolhouse"

    # Use upper() on place
    place_up = place.upper()

    # Print out place and place_up
    print(place)
    print(place_up)

    # Print out the number of o's in place
    print(place.count("o"))

## 📤 Output

    poolhouse
    POOLHOUSE
    2

## 🔍 What Happened?

### Original String

    place

Output:

    poolhouse

The original string remains unchanged.

### Uppercase String

    place_up

Output:

    POOLHOUSE

The `upper()` method returned a new string and stored it in `place_up`.

### Counting Characters

    place.count("o")

Output:

    2

There are two `"o"` characters in `"poolhouse"`.

## 🧠 Key Takeaways

- 🔤 Strings have many useful built-in methods.
- ⬆️ `.upper()` converts a string to uppercase.
- 🔢 `.count()` counts occurrences of a character or substring.
- 🔗 String methods use **dot notation**: `string.method()`.
- ⚠️ `upper()` does not modify the original string; it returns a new string.
- 📦 You can store the result of a string method in another variable.
- 🔍 Use `help(str)` to explore available string methods.
