# 📋 List of Lists

When working with a lot of data, it is often useful to **group related values together**.

Instead of putting room names and areas into one long list, you can create a **list of lists**.

---

# 🪆 What Is a List of Lists?

A **list of lists** is a list where each element is itself another list.

Example:

```python id="r0n2xq"
house = [
    ["hallway", 11.25],
    ["kitchen", 18.0],
    ["living room", 20.0]
]
```

Each inner list contains related information:

```text
["hallway", 11.25]
     ↓          ↓
   name       area
```

This makes the data more organized and easier to understand.

---

# 🏠 House Data

Given the room areas:

```python id="b5f9qk"
hall = 11.25
kit = 18.0
liv = 20.0
bed = 10.75
bath = 9.50
```

Create a list of lists containing the **room name** and **area**.

---

# 🎯 Exercise

Complete the `house` list so that it contains:

1. 🚪 Hallway
2. 🍳 Kitchen
3. 🛋️ Living room
4. 🛏️ Bedroom
5. 🛁 Bathroom

Make sure they are entered in the correct order.

---

# ✅ Solution

```python id="y0x7h4"
hall = 11.25
kit = 18.0
liv = 20.0
bed = 10.75
bath = 9.50

# House information as list of lists
house = [
    ["hallway", hall],
    ["kitchen", kit],
    ["living room", liv],
    ["bedroom", bed],
    ["bathroom", bath]
]

# Print out house
print(house)
```

### 📤 Output

```text
[['hallway', 11.25],
 ['kitchen', 18.0],
 ['living room', 20.0],
 ['bedroom', 10.75],
 ['bathroom', 9.5]]
```

---

# 🧠 Why Use a List of Lists?

A list of lists keeps **related information together**.

Instead of:

```python id="1d8x1m"
["hallway", 11.25, "kitchen", 18.0, "living room", 20.0]
```

you can structure it as:

```python id="2v5n8k"
[
    ["hallway", 11.25],
    ["kitchen", 18.0],
    ["living room", 20.0]
]
```

This structure is:

* 🗂️ More organized
* 👀 Easier to read
* 🔗 Keeps related values together
* 📊 More useful for working with structured data

---

# 🔑 Key Takeaways

* 📋 A **list of lists** is a list containing other lists.
* 🪆 Inner lists can group related pieces of information.
* 🏷️ Each inner list can contain different data types.
* 📊 This structure is useful for organizing structured data.
* 🔢 Lists can contain variables representing values.

### 💡 Basic Structure

```python
data = [
    [value1, value2],
    [value3, value4],
    [value5, value6]
]
```

### 🏠 Example

```python
house = [
    ["hallway", 11.25],
    ["kitchen", 18.0],
    ["living room", 20.0],
    ["bedroom", 10.75],
    ["bathroom", 9.5]
]
```

> 🧠 **Think of each inner list as a small record containing related information.**

🚀 **List of lists is an important step toward working with more structured data in Python.**
