# ⚾ Baseball Players' Height Conversion Using NumPy

## 📌 Working with Real-World Data

NumPy is commonly used in data science to process large datasets efficiently.

In this exercise, we work with **Major League Baseball (MLB) player height data**.

The original data:

- Stored as a Python list: `height_in`
- Unit: inches 📏
- Goal: Convert height measurements from inches to meters

---

# 📦 Creating a NumPy Array

Python lists are useful for storing data, but NumPy arrays allow faster mathematical operations.

Convert the existing list into a NumPy array:

```python
np_height_in = np.array(height_in)
```

Now the data can be processed using NumPy operations.

---

# 🔎 Displaying the NumPy Array

Print the converted array:

```python
print(np_height_in)
```

Example output:

```text
[74 74 72 72 75 ...]
```

The values represent player heights in inches.

---

# 🔄 Converting Inches to Meters

To convert inches to meters, use the conversion factor:

```
1 inch = 0.0254 meters
```

NumPy allows multiplication across the entire array:

```python
np_height_m = np_height_in * 0.0254
```

Instead of using a loop, NumPy automatically applies the calculation to every element.

Example:

```python
74 inches × 0.0254 = 1.8796 meters
```

---

# 💻 Complete Solution

```python
# Import numpy
import numpy as np

# Create a numpy array from height_in
np_height_in = np.array(height_in)

# Print out np_height_in
print(np_height_in)

# Convert height from inches to meters
np_height_m = np_height_in * 0.0254

# Print converted heights
print(np_height_m)
```
