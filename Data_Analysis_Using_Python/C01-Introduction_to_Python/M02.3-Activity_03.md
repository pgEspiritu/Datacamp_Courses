# 🔢 Other Variable Types

Python has several common data types used to store different kinds of values.

## 🧩 Common Python Data Types

### 🔢 `int` — Integer

An **integer** is a whole number without a fractional part.

```python
savings = 100
```

Examples:

```text
10
100
-5
0
```

---

### 🔢 `float` — Floating Point

A **float** is a number that contains a fractional/decimal part.

```python
half = 0.5
```

Examples:

```text
1.1
0.5
3.14
-2.5
```

---

### 🔤 `str` — String

A **string** represents text.

You can use either **single quotes** or **double quotes**.

```python
intro = "Hello! How are you?"
```

or:

```python
intro = 'Hello! How are you?'
```

Examples:

```python
"Hello"
'Python'
"Data Science"
```

---

### ✅ `bool` — Boolean

A **Boolean** represents a logical value.

It can only be:

```python
True
False
```

⚠️ **Capitalization is important.**

Example:

```python
is_good = True
```

# 🔑 Key Takeaways

| Data Type  | Description    | Example          |
| ---------- | -------------- | ---------------- |
| 🔢 `int`   | Whole number   | `100`            |
| 🔢 `float` | Decimal number | `0.5`            |
| 🔤 `str`   | Text           | `"Hello!"`       |
| ✅ `bool`   | Logical value  | `True` / `False` |
