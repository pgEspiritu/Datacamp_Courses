# ✂️ Slicing and Dicing

Selecting individual values from a list is useful, but Python also allows you to **slice** a list to select multiple elements at once.

## 📌 List Slicing

The basic syntax is:

    my_list[start:end]

- `start` = index where the slice begins (**included**)
- `end` = index where the slice stops (**not included**)
- If `start` is omitted, Python starts from the beginning of the list.
- If `end` is omitted, Python continues to the end of the list.

### Example

    areas[0:5]

This selects elements at indexes `0`, `1`, `2`, `3`, and `4`.

    areas[6:]

This selects everything from index `6` through the end of the list.

## 📝 Exercise

Given the following `areas` list:

    areas = ["hallway", 11.25, "kitchen", 18.0, "living room", 20.0, "bedroom", 10.75, "bathroom", 9.50]

### Tasks

1. Use slicing to create a list called `downstairs` containing the first **5 elements** of `areas`.
2. Create `upstairs` containing the last **4 elements** of `areas`.
3. Simplify the `upstairs` slicing by omitting the `end` index.
4. Print both `downstairs` and `upstairs`.

## 🔢 Understanding the Indexes

| Index | Element |
|---:|---|
| `0` | `"hallway"` |
| `1` | `11.25` |
| `2` | `"kitchen"` |
| `3` | `18.0` |
| `4` | `"living room"` |
| `5` | `20.0` |
| `6` | `"bedroom"` |
| `7` | `10.75` |
| `8` | `"bathroom"` |
| `9` | `9.50` |

### Downstairs

To get the first 5 elements:

    areas[0:5]

Remember that the **end index is excluded**, so index `5` is not included.

Result:

    ["hallway", 11.25, "kitchen", 18.0, "living room"]

### Upstairs

To get the elements from index `6` to the end:

    areas[6:]

Because the `end` index is omitted, Python automatically continues to the end of the list.

Result:

    ["bedroom", 10.75, "bathroom", 9.50]

## ✅ Solution

    # Create the areas list
    areas = ["hallway", 11.25, "kitchen", 18.0, "living room", 20.0, "bedroom", 10.75, "bathroom", 9.50]

    # Use slicing to create downstairs
    downstairs = areas[0:6]

    # Use slicing to create upstairs
    upstairs = areas[6:]

    # Print out downstairs and upstairs
    print(downstairs)
    print(upstairs)

## 📤 Output

    ['hallway', 11.25, 'kitchen', 18.0, 'living room', 20.0]
    ['bedroom', 10.75, 'bathroom', 9.5]

## 🎯 Quick Reference

    areas[0:6]   # Elements from index 0 to 5
    areas[6:]    # Elements from index 6 to the end
    areas[:5]    # First 5 elements
    areas[5:]    # From index 5 to the end

## 💡 Key Takeaways

- ✂️ Slicing selects **multiple elements** from a list.
- 🔢 Syntax: `list[start:end]`
- ✅ The `start` index is **included**.
- ❌ The `end` index is **excluded**.
- ⬅️ Omitting `start` means slicing starts from the beginning.
- ➡️ Omitting `end` means slicing continues to the end.
- 🧠 `areas[0:5]` gives the first 5 elements.
- 🧠 `areas[6:]` gives everything from index `6` to the end.
