# 🔍 Subset and Conquer

Subsetting a Python list means selecting specific elements using **indexes**.

## 📌 Key Concepts

- Python uses **zero-based indexing**.
- The **second element** has index `1`.
- The **last element** can be accessed using `-1`.
- Use `list[index]` to access a specific element.
- Negative indexing counts from the end of the list.

## 🧪 Example

The list below contains four elements:

    x = ["a", "b", "c", "d"]

The second element is `"b"`, which has index `1`.

    x[1]

You can also use negative indexing:

    x[-3]

Both return:

    "b"

## 📝 Exercise

Given the following `areas` list:

    areas = ["hallway", 11.25, "kitchen", 18.0, "living room", 20.0, "bedroom", 10.75, "bathroom", 9.50]

### Tasks

1. Print the **second element** from `areas`, which has the value `11.25`.
2. Subset and print the **last element** of `areas`, which is `9.50`. Using a negative index makes sense here.
3. Select the number representing the area of the **living room**, which is `20.0`, and print it.

## 🔢 Index Breakdown

| Element | Index |
|---|---:|
| `"hallway"` | `0` |
| `11.25` | `1` |
| `"kitchen"` | `2` |
| `18.0` | `3` |
| `"living room"` | `4` |
| `20.0` | `5` |
| `"bedroom"` | `6` |
| `10.75` | `7` |
| `"bathroom"` | `8` |
| `9.50` | `9` |

### Negative Indexing

Negative indexes count from the end of the list:

| Element | Negative Index |
|---|---:|
| `9.50` | `-1` |
| `"bathroom"` | `-2` |
| `10.75` | `-3` |
| `"bedroom"` | `-4` |
| `20.0` | `-5` |

## ✅ Solution

    # Create the areas list
    areas = ["hallway", 11.25, "kitchen", 18.0, "living room", 20.0, "bedroom", 10.75, "bathroom", 9.50]

    # Print out second element from areas
    print(areas[1])

    # Print out last element from areas
    print(areas[-1])

    # Print out the area of the living room
    print(areas[5])

## 📤 Output

    11.25
    9.5
    20.0

## 🎯 Quick Reference

    areas[1]    # Second element → 11.25
    areas[-1]   # Last element → 9.5
    areas[5]    # Living room area → 20.0

## 💡 Key Takeaways

- 🔢 Python list indexes start at **0**.
- 👉 `areas[1]` accesses the **second element**.
- 🔚 `areas[-1]` accesses the **last element**.
- 🎯 `areas[5]` accesses the **sixth element**, which contains `20.0`.
- 🐍 Use square brackets `[]` to access list elements.
- ↩️ Negative indexing is useful when accessing elements from the end of a list.
- 🧠 Remember: **index ≠ position**. The first position has index `0`, the second has index `1`, and so on.
