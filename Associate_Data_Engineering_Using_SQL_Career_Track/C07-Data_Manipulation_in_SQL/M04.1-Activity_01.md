# 🎯 Filtering Using Scalar Subqueries

## 📌 Objective

Generate a list of matches where the **total goals scored by both teams** is more than **3 times the average total goals** across all matches in the `matches_2013_2014` table.

---

## 🧠 Key Concept: Scalar Subquery

A **scalar subquery** is a subquery that returns **one single value**.

Here, the subquery calculates:

    3 × average(home goals + away goals)

That single value is then used by the outer query as a filtering threshold.

---

## 🔍 Step-by-Step

### 1. Calculate total goals for each match

    home_goal + away_goal

Example:

    home_goal = 2
    away_goal = 1

Total goals:

    2 + 1 = 3

---

### 2. Calculate the average total goals

The subquery:

    SELECT AVG(home_goal + away_goal)
    FROM matches_2013_2014

This calculates the average number of total goals across **all matches**.

---

### 3. Multiply the average by 3

    SELECT 3 * AVG(home_goal + away_goal)
    FROM matches_2013_2014

The subquery now returns **one scalar value**.

For example, if the average total goals were:

    2.5

Then:

    3 × 2.5 = 7.5

The main query would therefore look for matches with more than `7.5` total goals.

---

## 💻 Complete Query

    SELECT 
        date,
        home_goal,
        away_goal
    FROM matches_2013_2014
    WHERE (home_goal + away_goal) > 
        (
            SELECT 3 * AVG(home_goal + away_goal)
            FROM matches_2013_2014
        );

---

## 🧩 Understanding the Query

### Outer Query

    SELECT 
        date,
        home_goal,
        away_goal
    FROM matches_2013_2014

This retrieves the match information we want to display.

---

### WHERE Condition

    WHERE (home_goal + away_goal) > (...)

For every match, calculate:

    home_goal + away_goal

Then check whether that value is greater than the result of the subquery.

---

### Scalar Subquery

    (
        SELECT 3 * AVG(home_goal + away_goal)
        FROM matches_2013_2014
    )

This produces **one value**.

Conceptually:

    Average total goals
            ↓
       Multiply by 3
            ↓
      One threshold
            ↓
    Compare each match

---

## ⭐ Important Pattern

A scalar subquery can be used when you need to compare individual rows against a **calculated overall value**.

General pattern:

    SELECT columns
    FROM table
    WHERE column > (
        SELECT aggregate_function(column)
        FROM table
    );

With a calculation:

    WHERE column > (
        SELECT 3 * AVG(column)
        FROM table
    );

---

## 🧠 Why Use a Subquery?

Without a subquery, you would have difficulty directly comparing every individual match against an aggregate value calculated from the entire table.

The subquery allows you to:

1. Calculate an overall value.
2. Return that value.
3. Use it as a filter in the outer query.

Think of it as:

    Inner query → calculates the threshold
                    ↓
    Outer query → filters individual rows

---

## 🔑 Key Takeaways

- A **scalar subquery** returns a **single value**.
- Scalar subqueries are useful for comparing individual rows against an overall calculation.
- `AVG()` calculates the average.
- `3 * AVG(...)` calculates three times the average.
- `(home_goal + away_goal)` calculates total goals in a match.
- The subquery is placed inside parentheses.
- The outer `WHERE` clause compares each row against the scalar result.

### Quick Reference

| SQL Concept | Purpose |
|---|---|
| `AVG()` | Calculate an average |
| `home_goal + away_goal` | Calculate total goals |
| `3 * AVG(...)` | Calculate three times the average |
| `(SELECT ...)` | Create a subquery |
| Scalar subquery | Returns one value |
| `WHERE ... > subquery` | Filter rows based on the calculated value |
