# 🪆 Getting Started with Nested Subqueries

## 🎯 Objective

This exercise introduces **nested subqueries** by placing one subquery inside another subquery.

The goal is to compare:

1. ⚽ The maximum number of goals scored in a single match for **each season**
2. 🏴 The maximum number of goals scored in an **England Premier League** match for that same season

This requires multiple levels of queries.

---

# 📝 Original Question

Time to take your subqueries up a gear!

You only have time to watch so much soccer, and want to know if the `England Premier League` is exciting as people say.

You'll compare the maximum number of goals scored in a single match across each season against the maximum for the `England Premier League`.

### Instructions

- Complete a nested subquery to select the `country_id` for `'England Premier League'` from `league`, which will be used to filter the parent subquery.

---

# ✅ Answer

    SELECT
        season,

        -- Maximum goals scored in any match during the season
        MAX(home_goal + away_goal) AS max_goals,

        -- Maximum goals scored in an England Premier League match
        -- during the same season
        (
            SELECT MAX(home_goal + away_goal)

            FROM match

            -- Match the season of the main query
            WHERE season = main.season

              -- Filter for the England Premier League
              AND country_id IN
              (
                  SELECT id
                  FROM league
                  WHERE name = 'England Premier League'
              )
        ) AS pl_max_goals

    FROM match AS main

    GROUP BY season;

---

# 🧠 What Makes This a Nested Subquery?

Look at this structure:

    (
        SELECT MAX(home_goal + away_goal)
        FROM match
        WHERE season = main.season
          AND country_id IN
          (
              SELECT id
              FROM league
              WHERE name = 'England Premier League'
          )
    )

There are **two levels of subqueries**.

### Outer Subquery

    SELECT MAX(home_goal + away_goal)
    FROM match
    WHERE ...

### Inner Subquery

    SELECT id
    FROM league
    WHERE name = 'England Premier League'

The inner subquery is **inside the outer subquery**.

Therefore, this is a:

> 🪆 **Nested subquery**

---

# 1. 🏆 Main Query — Maximum Goals per Season

The main query starts with:

    SELECT
        season,
        MAX(home_goal + away_goal) AS max_goals
    FROM match AS main
    GROUP BY season;

This calculates the maximum total goals scored in a single match for each season.

Conceptually:

| season | max_goals |
|---|---:|
| 2010/2011 | 10 |
| 2011/2012 | 9 |
| 2012/2013 | 11 |
| 2013/2014 | 10 |

The exact values depend on the database.

---

# 2. ⚽ Calculate Total Goals

The expression:

    home_goal + away_goal

calculates the total goals in a match.

For example:

    home_goal = 7
    away_goal = 3

Then:

    7 + 3 = 10

The `MAX()` function finds the largest total:

    MAX(home_goal + away_goal)

So:

    MAX()
    ↓
    Highest total goals in a match

---

# 3. 🧮 Outer Subquery — Premier League Maximum

The first subquery is:

    (
        SELECT MAX(home_goal + away_goal)
        FROM match
        WHERE season = main.season
          AND country_id IN (...)
    ) AS pl_max_goals

Its purpose is to calculate:

> The maximum goals scored in an England Premier League match for the same season.

---

# 4. 📅 Match the Season

The outer subquery contains:

    WHERE season = main.season

This is important because we don't want the maximum Premier League score from all seasons.

We want the maximum for the **same season currently being processed by the main query**.

For example, if the main query is processing:

    main.season = '2012/2013'

the subquery looks for:

    season = '2012/2013'

This makes the outer subquery **correlated** with the main query.

---

# 5. 🪆 Inner Subquery — Find England Premier League ID

Inside the outer subquery we have:

    (
        SELECT id
        FROM league
        WHERE name = 'England Premier League'
    )

This is the **inner subquery**.

Its job is to find the `id` associated with:

    England Premier League

Conceptually:

| id | name |
|---:|---|
| 1729 | England Premier League |

The actual ID depends on the database.

---

# 6. 🔎 Why Use an Inner Subquery?

The `match` table contains:

    country_id

But we need to identify which `country_id` corresponds to:

    England Premier League

The `league` table contains:

    id
    name

Therefore, the inner query:

    SELECT id
    FROM league
    WHERE name = 'England Premier League'

finds the appropriate ID.

That ID can then be used by the outer subquery.

---

# 7. 🔗 Understanding `IN`

The outer subquery uses:

    country_id IN
    (
        SELECT id
        FROM league
        WHERE name = 'England Premier League'
    )

This means:

> Keep matches whose `country_id` is included in the IDs returned by the inner subquery.

If the inner subquery returns:

    1729

then the condition is effectively:

    country_id IN (1729)

For a single returned value, this behaves similarly to:

    country_id = 1729

---

# 8. 🧩 Three Query Levels

This exercise has three levels:

    MAIN QUERY
        ↓
    Find maximum goals for each season
        ↓
    OUTER SUBQUERY
        ↓
    Find maximum Premier League goals
        ↓
    INNER SUBQUERY
        ↓
    Find the Premier League ID

Think of it as:

    MAIN
      │
      └── OUTER SUBQUERY
              │
              └── INNER SUBQUERY

---

# 9. 🔄 Step-by-Step Example

Suppose the main query is processing:

    season = '2012/2013'

### Step 1 — Main Query

Calculate:

    MAX(home_goal + away_goal)

for all matches in `2012/2013`.

Suppose:

    max_goals = 11

---

### Step 2 — Outer Subquery

The correlated condition:

    season = main.season

means:

    season = '2012/2013'

The query now looks only at that season.

---

### Step 3 — Inner Subquery

The inner query:

    SELECT id
    FROM league
    WHERE name = 'England Premier League'

finds the ID of the England Premier League.

Suppose it returns:

    1729

---

### Step 4 — Filter Matches

The outer subquery now considers matches where:

    country_id = 1729

and:

    season = '2012/2013'

---

### Step 5 — Find Maximum

The outer subquery calculates:

    MAX(home_goal + away_goal)

Suppose the result is:

    8

---

### Step 6 — Return Both Values

The final row would conceptually be:

| season | max_goals | pl_max_goals |
|---|---:|---:|
| 2012/2013 | 11 | 8 |

The exact values depend on the database.

---

# 10. 📊 Understanding the Final Output

The final result has three columns:

| Column | Meaning |
|---|---|
| `season` | Soccer season |
| `max_goals` | Highest total goals in any match during that season |
| `pl_max_goals` | Highest total goals in an England Premier League match during that season |

For example:

| season | max_goals | pl_max_goals |
|---|---:|---:|
| 2011/2012 | 9 | 7 |
| 2012/2013 | 11 | 8 |
| 2013/2014 | 10 | 9 |

The values shown are illustrative.

---

# 11. 🔗 Why Is the Outer Subquery Correlated?

Look at:

    WHERE season = main.season

`main.season` comes from the main query.

Therefore, the outer subquery depends on the current season being processed by the main query.

That makes it a:

> **Correlated subquery**

---

# 12. 🪆 Why Is the Inner Subquery Nested?

Look at:

    country_id IN
    (
        SELECT id
        FROM league
        WHERE name = 'England Premier League'
    )

The inner query is physically located inside the outer subquery.

Therefore:

> The inner subquery is nested inside the outer subquery.

---

# 13. 🧠 This Exercise Combines Two Concepts

This exercise demonstrates:

### 🪆 Nested

The inner query is inside the outer query.

### 🔗 Correlated

The outer subquery references:

    main.season

Therefore, the query combines:

    Nested Subquery
          +
    Correlated Subquery

# 16. ⚠️ Important: `main.season`

Do not overlook:

    WHERE season = main.season

The `main.` prefix is important.

It tells SQL:

> Use the season from the current row/group of the main query.

Without the correlation, the subquery could calculate a maximum without being tied to the current season.

---

# 17. ⚠️ Important: `country_id` vs. `league.id`

The inner subquery returns:

    league.id

The outer query compares it against:

    match.country_id

The database structure is designed so that these IDs can be used to connect the relevant records.

The logical flow is:

    league.name
        ↓
    league.id
        ↓
    match.country_id
        ↓
    England Premier League matches

# 18. 🆚 Simple vs. Nested Subquery

## Simple

    SELECT AVG(home_goal + away_goal)
    FROM match

One subquery.

---

## Nested

    SELECT MAX(home_goal + away_goal)
    FROM match
    WHERE country_id IN
        (
            SELECT id
            FROM league
            WHERE name = 'England Premier League'
        )

A subquery exists inside another query level.

---

# 19. 🆚 Nested vs. Correlated

| Concept | Example | Meaning |
|---|---|---|
| Simple subquery | `SELECT AVG(...)` | Independent calculation |
| Nested subquery | Subquery inside subquery | Multiple query levels |
| Correlated subquery | `main.season = sub.season` | References outer query |
| Correlated nested subquery | This exercise | Nested + outer reference |

# 🎯 Key Takeaways

- **Nested subqueries** are subqueries inside other subqueries.
- The main query calculates the maximum goals for each season.
- The outer subquery calculates the maximum goals for the England Premier League for that same season.
- The inner subquery finds the ID of the England Premier League.
- `main.season` creates a correlation between the main query and the outer subquery.
- `IN` uses the result of the inner subquery to filter matches.
- `MAX(home_goal + away_goal)` finds the highest total goals.
- Multiple query levels can be combined to solve more complicated data questions.
- A nested subquery can also contain a correlated subquery.
- Always identify which query level each column belongs to.
