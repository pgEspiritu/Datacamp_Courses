# 🔗 Joining Subqueries in FROM

## 🎯 Objective

Use a subquery in the `FROM` clause and then **join it to an existing table**.

In this exercise, we first create a subquery from the `match` table that identifies matches with **10 or more total goals**.

The subquery will return:

- `country_id`
- `id` (match ID)

---

# 1. 🧠 Why Use a Subquery?

The `match` table contains information such as:

    country_id
    id
    home_goal
    away_goal

But it does **not** contain the country name.

The `country` table contains the country information.

So we can:

    match table
         ↓
    Filter matches
    with 10+ goals
         ↓
    Subquery
         ↓
    JOIN to country table
         ↓
    Analyze the results

---

# 2. 🔍 Calculate Total Goals

For every match:

    home_goal + away_goal

This gives the total goals scored in the match.

We want matches where:

    (home_goal + away_goal) >= 10

---

# 3. 🛠️ Create the Subquery

The first step is to create the query that will later be placed inside the `FROM` clause.

    SELECT
        country_id,
        id
    FROM match
    WHERE (home_goal + away_goal) >= 10

### What does it return?

It returns the:

- `country_id` → identifies the country
- `id` → identifies the match

Only matches with **10 or more total goals** are included.

---

# 4. 📋 Example Result

Conceptually, the subquery might produce:

| country_id | id |
|---:|---:|
| 1 | 1001 |
| 1 | 1025 |
| 2 | 2040 |
| 3 | 3055 |

This result can then be treated as a temporary table.

---

# 5. 🔑 Important Point

The subquery needs to include the column that will be used for the `JOIN`.

Here, that column is:

    country_id

The outer query can use this column to connect the subquery to the `country` table.

---

# 6. 🧩 Complete Subquery for Step 1

    SELECT
        country_id,
        id
    FROM match
    WHERE (home_goal + away_goal) >= 10;

This is the subquery that will be used in the next step.

---

# 🧠 Mental Model

Think of the process as:

    match
      ↓
    Calculate total goals
      ↓
    Keep matches >= 10 goals
      ↓
    Return country_id + match id
      ↓
    Temporary result
      ↓
    JOIN to country
      ↓
    Country information

---

# 🔄 `FROM` Subquery Structure

When this query is eventually placed inside `FROM`, the structure will look like:

    FROM (
        SELECT
            country_id,
            id
        FROM match
        WHERE (home_goal + away_goal) >= 10
    ) AS subquery

The alias is required:

    AS subquery

The outer query can then reference the result using that alias.

---

# ⭐ Key Takeaways

- A subquery in `FROM` can be used to **filter data before joining**.
- The subquery can return **multiple columns and rows**.
- `(home_goal + away_goal)` calculates total goals.
- `>= 10` keeps matches with 10 or more total goals.
- `country_id` is important because it can be used to join the subquery to the `country` table.
- `id` identifies the individual match.
- The subquery becomes a **temporary table-like result** for the outer query.

## ⚡ Quick Reference

    SELECT
        country_id,
        id
    FROM match
    WHERE (home_goal + away_goal) >= 10;

### Pattern

    FROM (
        SELECT columns
        FROM table
        WHERE condition
    ) AS subquery

> **Filter first → create the subquery → JOIN the prepared result later.**
