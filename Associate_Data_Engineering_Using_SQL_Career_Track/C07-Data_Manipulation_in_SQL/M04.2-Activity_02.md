# 📋 Filtering Using a Subquery with a List

## 🎯 Objective

Generate a list of teams that **never played a game in their home city**.

The goal is to:

1. Get all unique `hometeam_id` values from the `match` table.
2. Use those values as a list.
3. Exclude those teams from the `team` table.
4. Display the remaining teams' long and short names.

---

## 🧠 Key Concept: Subquery with a List

Unlike a **scalar subquery**, which returns one value, a **list subquery** returns multiple values in a **single column**.

Example:

    SELECT DISTINCT hometeam_id
    FROM match;

This could return:

    101
    102
    103
    104
    ...

The outer query can then use this list with `IN` or `NOT IN`.

---

## 🔍 Step-by-Step

### 1. Get the unique home team IDs

    SELECT DISTINCT hometeam_id
    FROM match;

`DISTINCT` removes duplicate team IDs.

The result is a **one-column list** of teams that have appeared as home teams.

---

### 2. Compare the list with `team_api_id`

The `team` table contains:

    team_api_id

The `match` table contains:

    hometeam_id

These values identify the same teams.

Because the values can be directly compared, a `JOIN` is not required.

---

### 3. Exclude teams found in the list

Use:

    WHERE team_api_id NOT IN (...)

`NOT IN` means:

> Keep the rows whose `team_api_id` does **not** appear in the subquery result.

---

## 💻 Complete Query

    SELECT 
        team_long_name,
        team_short_name
    FROM team 
    WHERE team_api_id NOT IN
        (
            SELECT DISTINCT hometeam_id
            FROM match
        );

---

## 🧩 Understanding the Query

### Outer Query

    SELECT 
        team_long_name,
        team_short_name
    FROM team

This selects the team names that we want to display.

---

### WHERE + NOT IN

    WHERE team_api_id NOT IN (...)

This excludes teams whose `team_api_id` appears in the list generated by the subquery.

---

### Inner Query

    SELECT DISTINCT hometeam_id
    FROM match

This generates the list of all teams that have played at home.

---

## 🔄 How the Query Works

Think of the process like this:

    match table
         ↓
    Get hometeam_id
         ↓
    Remove duplicates with DISTINCT
         ↓
    Create a list
         ↓
    Compare with team_api_id
         ↓
    NOT IN
         ↓
    Keep teams NOT found in the list

---

## 🆚 Scalar Subquery vs. List Subquery

| Type | Result | Common Operator | Example |
|---|---|---|---|
| Scalar subquery | One value | `>`, `<`, `=`, etc. | `price > (SELECT AVG(price)...)` |
| List subquery | Multiple values in one column | `IN`, `NOT IN` | `id NOT IN (SELECT id...)` |

### Scalar Example

    WHERE home_goal > (
        SELECT AVG(home_goal)
        FROM match
    )

The subquery returns **one value**.

### List Example

    WHERE team_api_id NOT IN (
        SELECT DISTINCT hometeam_id
        FROM match
    )

The subquery returns **multiple values**.

---

## ⭐ Why `DISTINCT`?

The `match` table contains many matches, so the same team can appear as `hometeam_id` many times.

For example:

    hometeam_id
    101
    101
    102
    103
    103
    103

Using:

    SELECT DISTINCT hometeam_id
    FROM match

produces:

    101
    102
    103

This creates a clean list of unique team IDs.

---

## 🔑 Important Pattern

### List-based filtering with `IN`

    WHERE column IN (
        SELECT column
        FROM another_table
    )

Means:

> Keep rows whose value appears in the subquery list.

### List-based filtering with `NOT IN`

    WHERE column NOT IN (
        SELECT column
        FROM another_table
    )

Means:

> Keep rows whose value does **not** appear in the subquery list.

---

## 🧠 Key Takeaways

- A list subquery returns **multiple values in one column**.
- `IN` checks whether a value appears in the subquery list.
- `NOT IN` excludes values appearing in the subquery list.
- `DISTINCT` removes duplicate values.
- A subquery can compare values from different tables **without requiring a JOIN**.
- The values returned by the subquery must be compatible with the column being compared.

### Quick Reference

| SQL | Purpose |
|---|---|
| `SELECT DISTINCT` | Return unique values |
| `IN` | Keep values found in a list |
| `NOT IN` | Exclude values found in a list |
| `(SELECT ...)` | Create a subquery |
| List subquery | Returns multiple values in one column |
