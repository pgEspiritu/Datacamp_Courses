# 🧩 CTEs with Nested Subqueries

## 🎯 Overview

If you find yourself listing multiple subqueries in the `FROM` clause with nested statements, your query can quickly become:

- 📏 Long
- 🧩 Complex
- 😵 Difficult to understand
- 🛠️ Difficult to maintain

Many SQL queries are written with the intention of being **saved and re-run** in the future.

Because of this, proper organization is important.

Using **CTEs** to organize subqueries can make your SQL easier to read, understand, modify, and reuse.

---

# 📝 Instructions

**100 XP**

- Declare a CTE that calculates the **total goals** from matches in **August** of the `'2013/2014'` season.
- Filter the list on the inner subquery to only select matches in **August** of the `'2013/2014'` season.
- `LEFT JOIN` the CTE onto the `league` table using `country_id` from the `match_list` CTE.

---

# ✅ Answer

    -- Set up your CTE
    WITH match_list AS (
        SELECT
            country_id,
            (home_goal + away_goal) AS goals
        FROM match

        -- Create a list of match IDs to filter data in the CTE
        WHERE id IN (
            SELECT id
            FROM match
            WHERE season = '2013/2014'
              AND EXTRACT(MONTH FROM date) = 8
        )
    )

    -- Select the league name and average of goals in the CTE
    SELECT
        l.name,
        AVG(match_list.goals)
    FROM league AS l

    -- Join the CTE onto the league table using country_id
    LEFT JOIN match_list
        ON l.id = match_list.country_id

    GROUP BY l.name;

---

# 🔍 Step-by-Step Explanation

## 1️⃣ Declare the CTE

The query starts with:

    WITH match_list AS (
        ...
    )

This creates a CTE named:

    match_list

The CTE prepares the match data that will later be joined to the `league` table.

---

# 2️⃣ Calculate Total Goals

Inside the CTE, we calculate:

    (home_goal + away_goal) AS goals

This combines the goals scored by both teams.

For example:

| home_goal | away_goal | goals |
|---:|---:|---:|
| 3 | 2 | 5 |
| 4 | 4 | 8 |
| 1 | 0 | 1 |
| 5 | 3 | 8 |

The new column is named:

    goals

So the CTE produces information like:

| country_id | goals |
|---:|---:|
| 1 | 5 |
| 1 | 8 |
| 2 | 3 |
| 3 | 7 |

---

# 3️⃣ Use a Nested Subquery Inside the CTE

The CTE contains another query:

    WHERE id IN (
        SELECT id
        FROM match
        WHERE season = '2013/2014'
          AND EXTRACT(MONTH FROM date) = 8
    )

This is a **nested subquery**.

The structure is:

    WITH match_list AS (
        SELECT ...
        FROM match
        WHERE id IN (
            SELECT ...
            FROM match
            WHERE ...
        )
    )

There are therefore two query levels:

    CTE
      ↓
    Inner subquery

---

# 4️⃣ Filter for the 2013/2014 Season

The inner subquery contains:

    WHERE season = '2013/2014'

This restricts the matches to the specified season.

Only matches from:

    2013/2014

are considered.

---

# 5️⃣ Filter for August

The inner subquery also contains:

    EXTRACT(MONTH FROM date) = 8

`EXTRACT(MONTH FROM date)` retrieves the month number from the match date.

Month numbers are:

| Month | Number |
|:---|---:|
| January | 1 |
| February | 2 |
| March | 3 |
| April | 4 |
| May | 5 |
| June | 6 |
| July | 7 |
| **August** | **8** |
| September | 9 |
| October | 10 |
| November | 11 |
| December | 12 |

Therefore:

    EXTRACT(MONTH FROM date) = 8

means:

> Only matches played in August.

Together:

    WHERE season = '2013/2014'
      AND EXTRACT(MONTH FROM date) = 8

means:

> Find matches played in **August of the 2013/2014 season**.

---

# 6️⃣ What Does the Inner Subquery Return?

The inner query:

    SELECT id
    FROM match
    WHERE season = '2013/2014'
      AND EXTRACT(MONTH FROM date) = 8

returns a list of match IDs.

Conceptually:

| id |
|---:|
| 101 |
| 105 |
| 109 |
| 115 |

These IDs are then used by the outer part of the CTE.

---

# 7️⃣ How Does `IN` Work?

The CTE uses:

    WHERE id IN (
        SELECT id
        FROM match
        ...
    )

This means:

> Keep the match if its `id` appears in the list produced by the inner query.

Conceptually:

    Inner query
        ↓
    [101, 105, 109, 115]
        ↓
    Check each match.id
        ↓
    Keep matching IDs

This is another example of using a subquery to create a **list of values** for filtering.

---

# 8️⃣ Why Is the Subquery Nested Inside the CTE?

The CTE is responsible for preparing the final dataset.

The inner subquery determines:

    Which matches?
        ↓
    August 2013/2014

The CTE then determines:

    What information do we need?
        ↓
    country_id
    total goals

So the process is:

    Inner subquery
    ↓
    Find August 2013/2014 match IDs
    ↓
    CTE
    ↓
    Retrieve country + total goals
    ↓
    Main query
    ↓
    Calculate league averages

---

# 9️⃣ LEFT JOIN the CTE to League

The main query uses:

    FROM league AS l
    LEFT JOIN match_list
        ON l.id = match_list.country_id

The relationship is:

    league.id
        ↓
    match_list.country_id

This connects each match to its league.

The `LEFT JOIN` ensures that all leagues from the `league` table are retained, even if there are no matching August 2013/2014 records.

---

# 🔟 Calculate the Average Goals

The main query uses:

    AVG(match_list.goals)

This calculates the **average total goals per league** for the qualifying matches.

For example, if a league had:

| Match | Goals |
|:---|---:|
| Match 1 | 4 |
| Match 2 | 6 |
| Match 3 | 8 |

then:

    AVG(match_list.goals)

is:

    (4 + 6 + 8) / 3 = 6

---

# 1️⃣1️⃣ Group by League

Finally:

    GROUP BY l.name;

This calculates a separate average for every league.

The final result is conceptually:

| league | avg goals |
|:---|---:|
| England Premier League | 4.25 |
| Germany 1. Bundesliga | 3.80 |
| Spain LIGA BBVA | 4.10 |

The actual values depend on the dataset.

# 🧠 Understanding the Query Levels

This exercise combines **CTEs and nested subqueries**.

## Level 1 — Inner Subquery

    SELECT id
    FROM match
    WHERE season = '2013/2014'
      AND EXTRACT(MONTH FROM date) = 8

🎯 **Purpose:** Find match IDs from August of the 2013/2014 season.

---

## Level 2 — CTE

    WITH match_list AS (
        SELECT
            country_id,
            (home_goal + away_goal) AS goals
        FROM match
        WHERE id IN (...)
    )

🎯 **Purpose:** Retrieve the country and calculate total goals for those matches.

---

## Level 3 — Main Query

    SELECT
        l.name,
        AVG(match_list.goals)
    FROM league AS l
    LEFT JOIN match_list
        ON l.id = match_list.country_id
    GROUP BY l.name;

🎯 **Purpose:** Calculate the average total goals for each league.

---

        │
        ├─────────────────────────────┐
        │                             │
        │                      Inner subquery
        │                             │
        │                      Filter season
        │                      = 2013/2014
        │                             │
        │                      Filter month = 8
        │                             │
        │                      Return match IDs
        │                             │

                       ↓

                       ↓
              Calculate total goals

# 🧩 Why Use a CTE Here?

Without a CTE, the query could become difficult to read because the nested filtering logic would be buried inside the main query.

The CTE separates the process into logical stages:

    WITH match_list AS (
        -- Prepare the data
    )

    SELECT
        -- Analyze the prepared data
    FROM league
    LEFT JOIN match_list
        -- Connect the prepared data
    GROUP BY ...;

This makes the query easier to understand.

---

# 🔑 Key Takeaways

- 🧩 A CTE can contain a nested subquery.
- `WITH match_list AS (...)` creates the CTE.
- The inner subquery returns a list of match IDs.
- `IN` filters the CTE using that list of IDs.
- `season = '2013/2014'` filters the season.
- `EXTRACT(MONTH FROM date) = 8` filters for August.
- `(home_goal + away_goal) AS goals` calculates total goals.
- `LEFT JOIN` connects the CTE to the `league` table.
- `l.id = match_list.country_id` is the join condition.
- `AVG(match_list.goals)` calculates the average total goals.
- `GROUP BY l.name` calculates the average separately for each league.
- CTEs help organize complex queries into logical steps.
