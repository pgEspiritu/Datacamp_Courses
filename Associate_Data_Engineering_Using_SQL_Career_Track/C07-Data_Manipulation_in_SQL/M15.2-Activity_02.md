# Setting Up the Away Team CTE

Great job! Now that you have a query identifying matches where Manchester United played as the home team, you will perform a similar set of steps to identify matches where Manchester United played as the *away team*.

Just like the previous step, you will join the `match` and `team` tables. Each of these two queries will be declared as a Common Table Expression (CTE) in the following step.

The primary difference in this query is that you will join the tables using `awayteam_id` and reverse the match outcomes in the `CASE` statement.

When altering `CASE` statement logic, you can reverse either the logical condition (e.g., `home_goal > away_goal`) or the outcome in `THEN`—just make sure you reverse only one of the two.

## Instructions

**100 XP**

- Complete the `CASE` statement syntax.
- Fill out the logical operators identifying each match as a win, loss, or tie for Manchester United.
- Join the tables using `awayteam_id` and `team_api_id`.

## SQL Solution

```sql
SELECT
    m.id,
    t.team_long_name,

    -- Identify match outcomes from Manchester United's perspective
    CASE
        WHEN m.home_goal > m.away_goal THEN 'MU Loss'
        WHEN m.home_goal < m.away_goal THEN 'MU Win'
        ELSE 'Tie'
    END AS outcome

-- Join the match table's awayteam_id to the team table
FROM match AS m
LEFT JOIN team AS t
    ON m.awayteam_id = t.team_api_id

WHERE
    -- Filter for 2014/2015 and Manchester United as the away team
    m.season = '2014/2015'
    AND t.team_long_name = 'Manchester United';
```

## Code Explanation

### 1. `SELECT`

```sql
SELECT
    m.id,
    t.team_long_name,
```

- `m.id` retrieves the match ID.
- `t.team_long_name` retrieves the team's full name.
- `m` and `t` are aliases for the `match` and `team` tables.

### 2. `CASE` Statement

```sql
CASE
    WHEN m.home_goal > m.away_goal THEN 'MU Loss'
    WHEN m.home_goal < m.away_goal THEN 'MU Win'
    ELSE 'Tie'
END AS outcome
```

Because Manchester United is playing as the away team, the outcomes are reversed compared with the home-team query.

| Condition | Outcome | Explanation |
|---|---|---|
| `home_goal > away_goal` | `MU Loss` | The home team scored more goals than Manchester United. |
| `home_goal < away_goal` | `MU Win` | Manchester United scored more goals than the home team. |
| `ELSE` | `Tie` | Both teams scored the same number of goals. |

The `CASE` statement evaluates each condition and assigns the appropriate result to the `outcome` column.

### 3. `FROM match AS m`

```sql
FROM match AS m
```

Specifies the `match` table as the primary source of match information and assigns it the alias `m`.

### 4. `LEFT JOIN team AS t`

```sql
LEFT JOIN team AS t
    ON m.awayteam_id = t.team_api_id
```

Connects the match table to the team table using the away team's ID.

- `m.awayteam_id` identifies the away team in each match.
- `t.team_api_id` identifies the corresponding team in the team table.
- `LEFT JOIN` retains rows from the match table even if a matching team record is missing.

### 5. `WHERE` Clause

```sql
WHERE
    m.season = '2014/2015'
    AND t.team_long_name = 'Manchester United';
```

Filters the records to include only:

- Matches from the 2014/2015 season.
- Matches in which Manchester United played as the away team.

Both conditions must be satisfied.

## Key Takeaways

- Use `awayteam_id` to identify the away team.
- Reverse the match outcome labels when evaluating the result from the away team's perspective.
- Use `CASE` to categorize matches as wins, losses, or ties.
- Use `WHERE` to filter by season and team.
- This query will become the second CTE in the next exercise, where the home-team and away-team results will be combined.

**Important:** The `outcome` logic is correct because the query filters for matches where Manchester United is the away team. The goals are still compared using `home_goal` and `away_goal`; only the labels assigned to the outcomes change.
