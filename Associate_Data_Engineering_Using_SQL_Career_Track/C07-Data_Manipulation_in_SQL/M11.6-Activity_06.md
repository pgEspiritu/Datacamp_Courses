# 🧩 Get Team Names with CTEs

## 📝 Exercise 3/3 — Join the Home and Away CTEs

### 🎯 Original Question

Let's declare the second CTE, `away`, and join it to the first CTE, `home`, using the `id` column.

The `date`, `home_goal`, and `away_goal` columns have already been added to the CTEs.

Select the following into the main query:

- `date`
- `hometeam`
- `awayteam`
- `home_goal`
- `away_goal`

---

# ✅ Answer

    WITH home AS (
        SELECT
            m.id,
            m.date,
            t.team_long_name AS hometeam,
            m.home_goal
        FROM match AS m
        LEFT JOIN team AS t
            ON m.hometeam_id = t.team_api_id
    ),

    -- Declare and set up the away CTE
    away AS (
        SELECT
            m.id,
            m.date,
            t.team_long_name AS awayteam,
            m.away_goal
        FROM match AS m
        LEFT JOIN team AS t
            ON m.awayteam_id = t.team_api_id
    )

    -- Select date, home_goal, and away_goal
    SELECT
        home.date,
        home.hometeam,
        away.awayteam,
        home.home_goal,
        away.away_goal

    -- Join away and home on the id column
    FROM home
    INNER JOIN away
        ON home.id = away.id;

# 🔍 Step-by-Step Explanation

## 1. Create the `home` CTE

The first CTE prepares the **home-team information**:

    WITH home AS (
        SELECT
            m.id,
            m.date,
            t.team_long_name AS hometeam,
            m.home_goal
        FROM match AS m
        LEFT JOIN team AS t
            ON m.hometeam_id = t.team_api_id
    )

It contains:

- `id` → Match ID
- `date` → Match date
- `hometeam` → Home team name
- `home_goal` → Home team's goals

Think of it as:

    home CTE
    ┌────┬────────────┬──────────┬───────────┐
    │ id │ date       │ hometeam │ home_goal │
    └────┴────────────┴──────────┴───────────┘

---

## 2. Create the `away` CTE

The second CTE prepares the **away-team information**:

    away AS (
        SELECT
            m.id,
            m.date,
            t.team_long_name AS awayteam,
            m.away_goal
        FROM match AS m
        LEFT JOIN team AS t
            ON m.awayteam_id = t.team_api_id
    )

It contains:

- `id` → Match ID
- `date` → Match date
- `awayteam` → Away team name
- `away_goal` → Away team's goals

Think of it as:

    away CTE
    ┌────┬────────────┬──────────┬───────────┐
    │ id │ date       │ awayteam │ away_goal │
    └────┴────────────┴──────────┴───────────┘

---

# 3. Why Is There a Comma Between the CTEs?

When declaring multiple CTEs, separate them with a comma:

    WITH home AS (
        ...
    ),
    away AS (
        ...
    )

The comma tells SQL:

> "Another CTE is being declared."

There is **no comma after the final CTE**.

---

# 4. Join the Two CTEs

The main query starts with:

    FROM home

Then joins `away`:

    INNER JOIN away
        ON home.id = away.id

Both CTEs contain the same match `id`.

Therefore, `id` acts as the connection between them.

### Relationship

    home.id
       │
       │ =
       ▼
    away.id

This combines the home and away information belonging to the same match.

---

# 5. Select the Final Columns

The main query selects:

    SELECT
        home.date,
        home.hometeam,
        away.awayteam,
        home.home_goal,
        away.away_goal

Notice that we specify which CTE each column comes from.

### From `home`

    home.date
    home.hometeam
    home.home_goal

### From `away`

    away.awayteam
    away.away_goal

# 🔗 Comparing the Three Approaches

This exercise demonstrates that the same problem can be solved using different SQL techniques.

## 1. 🔍 Subqueries in `FROM`

    FROM (
        SELECT ...
    ) AS home
    LEFT JOIN (
        SELECT ...
    ) AS away
        ON home.id = away.id

The queries are placed directly inside the `FROM` clause.

---

## 2. 🔄 Correlated Subqueries

    SELECT
        (
            SELECT team_long_name
            FROM team
            WHERE team_api_id = m.hometeam_id
        ) AS hometeam,

        (
            SELECT team_long_name
            FROM team
            WHERE team_api_id = m.awayteam_id
        ) AS awayteam

    FROM match AS m;

The team names are retrieved using subqueries that depend on the current match row.

---

## 3. 🧩 CTEs

    WITH home AS (
        SELECT ...
    ),
    away AS (
        SELECT ...
    )
    SELECT ...
    FROM home
    INNER JOIN away
        ON home.id = away.id;

The preparation steps are declared first and then used by the main query.

---

# 📊 Technique Comparison

| Technique | How It Works |
|---|---|
| 🔗 JOIN | Directly combines tables |
| 🔍 FROM Subquery | Creates intermediate query results inside `FROM` |
| 🔄 Correlated Subquery | Looks up values based on the current outer row |
| 🧩 CTE | Names intermediate query results using `WITH` |

---

# ⭐ Key Takeaways

- 🧩 A CTE is declared using `WITH`.
- Multiple CTEs are separated by commas.
- The `home` CTE retrieves the home team.
- The `away` CTE retrieves the away team.
- Both CTEs contain the match `id`.
- The CTEs are joined using:

    ON home.id = away.id

- `home.hometeam` provides the home team name.
- `away.awayteam` provides the away team name.
- `home.home_goal` provides the home team's score.
- `away.away_goal` provides the away team's score.
- CTEs allow complex query steps to be organized sequentially.
- The final result contains both team names and both scores.
