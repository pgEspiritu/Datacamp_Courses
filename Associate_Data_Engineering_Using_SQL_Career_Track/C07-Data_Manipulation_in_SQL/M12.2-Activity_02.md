# 🪟 What's OVER Here?

Window functions allow you to rank information according to a variable or calculation you specify.

To create a ranking, use `RANK()` with an `OVER()` clause containing `ORDER BY`.

Example:

    SELECT
        id,
        RANK() OVER (ORDER BY home_goal) AS rank
    FROM match;

In this example, matches are ranked according to `home_goal`, from the smallest value to the largest by default.

---

## 🎯 Exercise

**Question:** Create a dataset of ranked matches according to which leagues, on average, score the most goals in a match.

**Instructions (100 XP)**

- Select the league name and average total goals scored from `league` and `match`.
- Complete the window function so it calculates the `RANK()` of average goals scored across all leagues in the database.
- Order the rank `OVER` the average total of home and away goals scored.

---

## ✅ Answer

    SELECT
        -- Select the league name and average goals scored
        name AS league,
        AVG(m.home_goal + m.away_goal) AS avg_goals,

        -- Rank each league over the average goals
        RANK() OVER (
            ORDER BY AVG(m.home_goal + m.away_goal)
        ) AS league_rank

    FROM league AS l
    LEFT JOIN match AS m
        ON l.id = m.country_id
    WHERE m.season = '2011/2012'
    GROUP BY l.name

    -- Order the query by the rank you created
    ORDER BY league_rank;

---

## 🔍 Step-by-Step Explanation

### 1. Select the league name

    name AS league

Retrieves the league name and labels the output column `league`.

### 2. Calculate the average total goals

    AVG(m.home_goal + m.away_goal) AS avg_goals

First, add the home and away goals for each match:

    home_goal + away_goal

Then, calculate the average total goals for each league.

### 3. Rank the leagues

    RANK() OVER (
        ORDER BY AVG(m.home_goal + m.away_goal)
    ) AS league_rank

This is the most important part of the exercise.

- `RANK()` creates a ranking.
- `OVER()` defines the window used for the ranking.
- `ORDER BY AVG(...)` sorts the league averages to determine their ranks.
- `AS league_rank` names the resulting column.

**Important:** The ranking is based on the average goals per league, not the goals from individual matches.

Because `DESC` is not specified, the ranking goes from the lowest average to the highest average.

If you want the league with the highest average goals to receive Rank 1, use:

    RANK() OVER (
        ORDER BY AVG(m.home_goal + m.away_goal) DESC
    ) AS league_rank

### 4. Join the tables

    FROM league AS l
    LEFT JOIN match AS m
        ON l.id = m.country_id

Connects league records with their corresponding matches.

### 5. Filter the season

    WHERE m.season = '2011/2012'

Includes matches from the 2011/2012 season only.

**Note:** Because this `WHERE` condition excludes rows without a matching match record, the `LEFT JOIN` effectively behaves like an `INNER JOIN` for this query.

### 6. Group by league

    GROUP BY l.name

Calculates one average per league.

This is necessary because the query calculates an aggregate average for each league.

### 7. Sort by rank

    ORDER BY league_rank;

Displays the leagues in ascending rank order.

This final `ORDER BY` controls the order of the output rows. The `ORDER BY` inside `OVER()` determines the ranking itself.

## 📊 Example Result

Illustrative values only:

| league | avg_goals | league_rank |
|---|---:|---:|
| League A | 1.80 | 1 |
| League B | 2.10 | 2 |
| League C | 2.45 | 3 |
| League D | 2.45 | 3 |
| League E | 2.80 | 5 |

Notice that League C and League D have the same average, so both receive Rank 3. The next rank is 5 because `RANK()` skips a position after a tie.

---

## 🧠 Key Difference: Two `ORDER BY` Clauses

| Clause | Purpose |
|---|---|
| `ORDER BY` inside `OVER()` | Determines how ranks are assigned |
| Final `ORDER BY league_rank` | Determines the display order of the result rows |

### ⭐ Quick takeaway

    RANK() OVER (ORDER BY AVG(home_goal + away_goal))

means:

**Rank each league according to its average total goals, from lowest to highest.**

To rank from highest to lowest, add `DESC` inside the window's `ORDER BY`.
