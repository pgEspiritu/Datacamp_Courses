# Putting the CTEs Together

Now that you've created two subqueries identifying matches where Manchester United played as the home or away team, it's time to rearrange your query using the `home` and `away` subqueries as Common Table Expressions (CTEs).

You'll notice that the main query includes `SELECT DISTINCT`. Without selecting only distinct matches, you might return duplicate records for each game played.

The goal is to extract all matches played by Manchester United during the 2014/2015 season.

## Instructions

**100 XP**

- Declare the `home` and `away` CTEs before the main query.
- Join your CTEs to the `match` table using `LEFT JOIN`.
- Select the relevant data from the CTEs into the main query.
- Select the date from `match`, team names from the CTEs, and home/away goals from `match`.

## SQL Solution

```sql
-- Set up the home team CTE
WITH home AS (
    SELECT
        m.id,
        t.team_long_name,
        CASE
            WHEN m.home_goal > m.away_goal THEN 'MU Win'
            WHEN m.home_goal < m.away_goal THEN 'MU Loss'
            ELSE 'Tie'
        END AS outcome
    FROM match AS m
    LEFT JOIN team AS t
        ON m.hometeam_id = t.team_api_id
),

-- Set up the away team CTE
away AS (
    SELECT
        m.id,
        t.team_long_name,
        CASE
            WHEN m.home_goal > m.away_goal THEN 'MU Loss'
            WHEN m.home_goal < m.away_goal THEN 'MU Win'
            ELSE 'Tie'
        END AS outcome
    FROM match AS m
    LEFT JOIN team AS t
        ON m.awayteam_id = t.team_api_id
)

-- Select the date, team names, and goals
SELECT DISTINCT
    m.date,
    home.team_long_name AS home_team_name,
    away.team_long_name AS away_team_name,
    m.home_goal,
    m.away_goal

-- Join the CTEs to the match table
FROM match AS m
LEFT JOIN home
    ON m.id = home.id
LEFT JOIN away
    ON m.id = away.id

WHERE
    m.season = '2014/2015'
    AND (
        home.team_long_name = 'Manchester United'
        OR away.team_long_name = 'Manchester United'
    );
```

## Code Explanation

### 1. Define the `home` CTE

```sql
WITH home AS (
    SELECT
        m.id,
        t.team_long_name,
        CASE
            WHEN m.home_goal > m.away_goal THEN 'MU Win'
            WHEN m.home_goal < m.away_goal THEN 'MU Loss'
            ELSE 'Tie'
        END AS outcome
    FROM match AS m
    LEFT JOIN team AS t
        ON m.hometeam_id = t.team_api_id
),
```

The `home` CTE retrieves match IDs, home-team names, and match outcomes.

- `WITH home AS (...)` creates a CTE named `home`.
- `m.id` identifies each match.
- `t.team_long_name` retrieves the home team's name.
- `CASE` categorizes the result as a win, loss, or tie from the home team's perspective.
- `LEFT JOIN` connects the match table to the team table using `hometeam_id`.

The comma after the closing parenthesis separates the first CTE from the next one.

### 2. Define the `away` CTE

```sql
away AS (
    SELECT
        m.id,
        t.team_long_name,
        CASE
            WHEN m.home_goal > m.away_goal THEN 'MU Loss'
            WHEN m.home_goal < m.away_goal THEN 'MU Win'
            ELSE 'Tie'
        END AS outcome
    FROM match AS m
    LEFT JOIN team AS t
        ON m.awayteam_id = t.team_api_id
)
```

The `away` CTE retrieves match IDs, away-team names, and match outcomes.

The main difference is the join condition:

- `m.awayteam_id = t.team_api_id` retrieves the away team's name.
- The `CASE` outcomes are reversed to represent Manchester United's perspective when it plays as the away team.

**Note:** In these CTEs, the `outcome` column is calculated for every team, not exclusively for Manchester United. The main query currently uses the team names to retrieve matches, so the `outcome` columns are not needed in its final output. They become useful in the next exercise when filtering Manchester United's defeats.

### 3. Select the Main Query Columns

```sql
SELECT DISTINCT
    m.date,
    home.team_long_name AS home_team_name,
    away.team_long_name AS away_team_name,
    m.home_goal,
    m.away_goal
```

This selects the information needed for the final result.

| Column | Purpose |
|---|---|
| `m.date` | Date of the match |
| `home.team_long_name` | Name of the home team |
| `away.team_long_name` | Name of the away team |
| `m.home_goal` | Goals scored by the home team |
| `m.away_goal` | Goals scored by the away team |

`AS home_team_name` and `AS away_team_name` assign clear aliases to the team-name columns.

`DISTINCT` removes duplicate rows from the selected combination of columns. It does not guarantee one row per match if duplicate records differ in any selected value.

### 4. Join the CTEs to the Match Table

```sql
FROM match AS m
LEFT JOIN home
    ON m.id = home.id
LEFT JOIN away
    ON m.id = away.id
```

The main query uses `match` as its starting table and joins both CTEs using the match ID.

- `LEFT JOIN home` adds home-team information.
- `LEFT JOIN away` adds away-team information.
- `m.id = home.id` and `m.id = away.id` match the corresponding records for each game.

This allows the query to combine team names with the original match date and goals.

### 5. Filter the Season and Manchester United Matches

```sql
WHERE
    m.season = '2014/2015'
    AND (
        home.team_long_name = 'Manchester United'
        OR away.team_long_name = 'Manchester United'
    );
```

The `WHERE` clause applies two filtering requirements:

- `m.season = '2014/2015'` limits the results to the specified season.
- The `OR` condition includes matches where Manchester United played either at home or away.

Parentheses group the two team conditions so that the season restriction applies to both.

## Key Takeaways

- **CTEs:** Organize complex SQL queries into named, reusable query blocks.
- **`WITH`:** Introduces one or more CTEs before the main query.
- **`LEFT JOIN`:** Combines the CTEs with the original match records.
- **`DISTINCT`:** Removes duplicate combinations of selected column values.
- **`OR`:** Includes Manchester United matches regardless of whether the team played at home or away.

The result is a complete list of Manchester United's matches in the 2014/2015 season, including the date, opponents, and goals scored by both teams. This provides the foundation for the next step: identifying and ranking Manchester United's defeats.
