# 🧹 Clean Up with CTEs

## 🎯 Overview

In Chapter 2, we generated a list of countries and the number of matches in each country where there were **more than 10 total goals**.

The original query used a **subquery in the `FROM` statement** to filter the matches before counting them.

### Original Query

    SELECT
        c.name AS country,
        COUNT(sub.id) AS matches
    FROM country AS c
    INNER JOIN (
        SELECT
            country_id,
            id
        FROM match
        WHERE (home_goal + away_goal) >= 10
    ) AS sub
        ON c.id = sub.country_id
    GROUP BY country;

The subquery:

    SELECT
        country_id,
        id
    FROM match
    WHERE (home_goal + away_goal) >= 10

creates a list of matches with **10 or more total goals**.

---

# 🧩 Using a CTE

A **Common Table Expression (CTE)** allows us to move the subquery to the beginning of the query.

Instead of putting the subquery directly inside `FROM`, we give it a name using:

    WITH cte_name AS (
        ...
    )

We can then reference that CTE later in the main query as if it were a table.

---

# 📝 Instructions

**100 XP**

1. Complete the syntax to **declare your CTE**.
2. Select the `country_id` and match `id` from the `match` table in your CTE.
3. `LEFT JOIN` the CTE to the `league` table using `country_id`.

---

# ✅ Answer

    -- Set up your CTE
    WITH match_list AS (
        SELECT
            country_id,
            id
        FROM match
        WHERE (home_goal + away_goal) >= 10
    )

    -- Select league name and count of matches from the CTE
    SELECT
        l.name AS league,
        COUNT(match_list.id) AS matches
    FROM league AS l

    -- Join the CTE to the league table using country_id
    LEFT JOIN match_list
        ON l.id = match_list.country_id

    GROUP BY l.name;

---

# 🔍 Step-by-Step Explanation

## 1️⃣ Declare the CTE

The first part is:

    WITH match_list AS (
        ...
    )

Here:

- `WITH` → starts the CTE declaration.
- `match_list` → name of the CTE.
- `AS` → connects the name to the query.
- `( ... )` → contains the query that generates the CTE.

So:

    WITH match_list AS (...)

means:

> Create a temporary named result called `match_list`.

---

# 2️⃣ Select the Required Columns

Inside the CTE:

    SELECT
        country_id,
        id
    FROM match

We select:

- `country_id` → identifies the country/league associated with the match.
- `id` → identifies the match.

These are the columns needed later for the `JOIN` and `COUNT`.

---

# 3️⃣ Filter Matches with 10+ Goals

The CTE contains:

    WHERE (home_goal + away_goal) >= 10

This calculates the total goals in each match:

    home_goal + away_goal

and keeps only matches where the total is **10 or more**.

For example:

| home_goal | away_goal | Total | Included? |
|---:|---:|---:|:---|
| 5 | 5 | 10 | ✅ |
| 6 | 4 | 10 | ✅ |
| 7 | 3 | 10 | ✅ |
| 4 | 5 | 9 | ❌ |
| 8 | 2 | 10 | ✅ |

The resulting CTE contains only the qualifying matches.

---

# 4️⃣ Use the CTE in the Main Query

After declaring the CTE, we can reference it like a table:

    FROM league AS l
    LEFT JOIN match_list
        ON l.id = match_list.country_id

Notice that we do **not** need to repeat the filtering query.

Instead, we simply use:

    match_list

This is one of the main advantages of CTEs: the complicated preparation step has already been given a meaningful name.

---

# 5️⃣ LEFT JOIN the CTE

The exercise asks us to connect the CTE to the `league` table.

The join condition is:

    ON l.id = match_list.country_id

This connects:

    league.id
        ↓
    match_list.country_id

The relationship allows us to determine which league each qualifying match belongs to.

---

# 6️⃣ Why Use LEFT JOIN?

We start with:

    FROM league AS l

and use:

    LEFT JOIN match_list

A `LEFT JOIN` keeps **all leagues**, even if they do not have a match with 10 or more total goals.

For leagues without qualifying matches, `match_list.id` will be `NULL`.

For example:

| league | match_list.id |
|:---|---:|
| League A | 101 |
| League A | 102 |
| League B | NULL |
| League C | 201 |

---

# 7️⃣ Count the Matches

The main query uses:

    COUNT(match_list.id) AS matches

This counts the qualifying match IDs for each league.

Because `COUNT(column)` ignores `NULL` values, a league with no qualifying matches gets:

    0

rather than counting the unmatched `LEFT JOIN` row.

---

# 8️⃣ Group by League

Finally:

    GROUP BY l.name;

This tells SQL to calculate the count separately for every league.

The result will look conceptually like:

| league | matches |
|:---|---:|
| England Premier League | 2 |
| Germany 1. Bundesliga | 1 |
| Spain LIGA BBVA | 3 |
| Other League | 0 |

The exact results depend on the dataset.

---

# 🧠 Subquery vs CTE

## Original Subquery Version

    SELECT
        c.name AS country,
        COUNT(sub.id) AS matches
    FROM country AS c
    INNER JOIN (
        SELECT
            country_id,
            id
        FROM match
        WHERE (home_goal + away_goal) >= 10
    ) AS sub
        ON c.id = sub.country_id
    GROUP BY country;

## CTE Version

    WITH match_list AS (
        SELECT
            country_id,
            id
        FROM match
        WHERE (home_goal + away_goal) >= 10
    )

    SELECT
        l.name AS league,
        COUNT(match_list.id) AS matches
    FROM league AS l
    LEFT JOIN match_list
        ON l.id = match_list.country_id
    GROUP BY l.name;

### 💡 Main Difference

The subquery is placed directly inside the main query:

    FROM (
        ...
    ) AS sub

The CTE is declared **before** the main query:

    WITH match_list AS (
        ...
    )

and then referenced later:

    LEFT JOIN match_list

---

# 🔄 Query Flow

Think of the CTE as a preparation step:

    match table
        ↓
    Filter matches
    with 10+ total goals
        ↓
    match_list CTE
        ↓
    LEFT JOIN league
        ↓
    COUNT(match_list.id)
        ↓
    GROUP BY league
        ↓
    Final result

---

# 🔑 Key Takeaways

- 🧩 A CTE is declared using `WITH`.
- 🏷️ Give the CTE a meaningful name such as `match_list`.
- `AS` connects the CTE name to its query.
- The CTE selects `country_id` and `id`.
- `WHERE (home_goal + away_goal) >= 10` filters high-scoring matches.
- The CTE can be referenced like a regular table.
- `LEFT JOIN` connects the CTE to the `league` table.
- `l.id = match_list.country_id` is the join condition.
- `COUNT(match_list.id)` counts qualifying matches.
- `GROUP BY l.name` calculates the count separately for each league.
- CTEs can make complicated queries **cleaner and easier to read**.

# ⚡ CTE Syntax Cheat Sheet

## Basic CTE

    WITH cte_name AS (
        SELECT
            ...
        FROM table
        WHERE condition
    )

    SELECT
        ...
    FROM cte_name;

        ON l.id = match_list.country_id

# 🎯 Final Mental Model

> **`WITH` creates a named query result that you can use like a table in the main query.**

    WITH match_list AS (
        -- Prepare/filter data
    )

    SELECT
        -- Analyze/display data
    FROM league
    LEFT JOIN match_list
        -- Connect the prepared data
    GROUP BY ...;

### 🧠 Remember:

**CTE = Name the subquery first → use the name later.**
