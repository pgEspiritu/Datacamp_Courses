# ⚽ Using CASE and AVG to Derive Fractions

## 📝 Overview

`CASE` statements can return any value specified in the `THEN` clause.

When combined with aggregate functions such as `AVG()`, this becomes a powerful way to calculate **fractions, proportions, and percentages**.

A common pattern is:

    AVG(
        CASE
            WHEN condition_is_met THEN 1
            WHEN condition_is_not_met THEN 0
        END
    )

This allows us to calculate the **fraction of records that meet a particular condition**.

---

# 🧠 How Does AVG() Calculate a Fraction?

Suppose we have these match results:

| Match | Tie? | CASE Result |
|---|---|---:|
| Match 1 | Yes | 1 |
| Match 2 | No | 0 |
| Match 3 | Yes | 1 |
| Match 4 | No | 0 |
| Match 5 | Yes | 1 |

`AVG()` calculates:

    (1 + 0 + 1 + 0 + 1) / 5 = 0.60

Therefore:

    0.60 = 60%

So:

- `1` = condition is true
- `0` = condition is false
- `AVG()` = fraction of records where the condition is true

---

# ⚠️ Important: Correctly Identify 0 Values

When using this technique, it is important to correctly identify which records should receive `0`.

If a record is incorrectly excluded from the calculation by returning `NULL`, the average may be wrong.

Remember:

    1 → Include as a positive result
    0 → Include as a negative result
    NULL → Exclude from the calculation

Therefore, you need to carefully define both:

    WHEN condition_is_met THEN 1

and:

    WHEN condition_is_not_met THEN 0

---

# 🎯 Exercise

We want to examine the number of:

- 🟢 Wins
- 🔴 Losses
- 🟡 Ties

for each country.

The database contains matches from:

- `2013/2014`
- `2014/2015`

In this exercise, we specifically calculate the **fraction of tied games in each season**.

---

# 📋 Instructions

**100 XP**

- Within an `AVG()` function, complete the `CASE` statement by checking if `m.home_goal` is not equal to `m.away_goal`, assigning a value of `0` if this condition is met.
- Repeat this process to compare home and away goals in `'2014/2015'`, aliasing the result as `ties_2014_2015`.

---

# 💡 Solution

    SELECT 
        c.name AS country,

        -- Calculate the fraction of tied games in 2013/2014
        AVG(
            CASE
                WHEN m.season = '2013/2014'
                     AND m.home_goal = m.away_goal
                THEN 1

                WHEN m.season = '2013/2014'
                     AND m.home_goal != m.away_goal
                THEN 0
            END
        ) AS ties_2013_2014,

        -- Calculate the fraction of tied games in 2014/2015
        AVG(
            CASE
                WHEN m.season = '2014/2015'
                     AND m.home_goal = m.away_goal
                THEN 1

                WHEN m.season = '2014/2015'
                     AND m.home_goal != m.away_goal
                THEN 0
            END
        ) AS ties_2014_2015

    FROM country AS c

    LEFT JOIN matches AS m
        ON c.id = m.country_id

    GROUP BY country;

---

# 🔍 Understanding the CASE Logic

## 🟡 1. Identify Ties

A match is a tie when:

    m.home_goal = m.away_goal

Therefore:

    WHEN m.season = '2013/2014'
         AND m.home_goal = m.away_goal
    THEN 1

means:

> If the match is from the 2013/2014 season and the scores are equal, return `1`.

For example:

    Home goals = 2
    Away goals = 2

Result:

    1

---

# 🔴 2. Identify Non-Ties

A match is not a tie when:

    m.home_goal != m.away_goal

Therefore:

    WHEN m.season = '2013/2014'
         AND m.home_goal != m.away_goal
    THEN 0

means:

> If the match is from the 2013/2014 season and the scores are different, return `0`.

For example:

    Home goals = 3
    Away goals = 1

Result:

    0

---

# ❓ 3. Why No ELSE?

There is no `ELSE` clause.

Therefore, matches from other seasons return:

    NULL

For example:

    m.season = '2014/2015'

when calculating `ties_2013_2014` results in:

    NULL

Because `AVG()` ignores `NULL`, those matches are excluded from the calculation.

This is important because we only want the fraction of ties **within the specific season**.

---

# 📅 4. 2013/2014 Calculation

The first calculation is:

    AVG(
        CASE
            WHEN m.season = '2013/2014'
                 AND m.home_goal = m.away_goal
            THEN 1

            WHEN m.season = '2013/2014'
                 AND m.home_goal != m.away_goal
            THEN 0
        END
    ) AS ties_2013_2014

The result represents:

> Fraction of matches that were tied during the 2013/2014 season.

---

# 📅 5. 2014/2015 Calculation

The second calculation uses the same logic but changes the season:

    AVG(
        CASE
            WHEN m.season = '2014/2015'
                 AND m.home_goal = m.away_goal
            THEN 1

            WHEN m.season = '2014/2015'
                 AND m.home_goal != m.away_goal
            THEN 0
        END
    ) AS ties_2014_2015

The alias:

    ties_2014_2015

makes the output column easy to identify.

---

# 📊 Example of the Logic

Suppose a country has these matches in 2013/2014:

| Match | Score | Tie? | CASE |
|---|---|---|---:|
| 1 | 1–1 | Yes | 1 |
| 2 | 2–0 | No | 0 |
| 3 | 0–0 | Yes | 1 |
| 4 | 3–1 | No | 0 |
| 5 | 2–2 | Yes | 1 |

Then:

    AVG(1, 0, 1, 0, 1)

equals:

    3 / 5 = 0.60

Therefore:

    ties_2013_2014 = 0.60

That means **60% of the matches were ties**.

---

# 🔗 Why Use LEFT JOIN?

The query starts with:

    FROM country AS c

and then:

    LEFT JOIN matches AS m
        ON c.id = m.country_id

This connects each country with its matches.

The `LEFT JOIN` ensures that countries from the `country` table remain represented even if they have no matching rows.

---

# 📊 Why GROUP BY country?

We want a separate calculation for each country.

Therefore:

    GROUP BY country

means the `AVG()` calculations are performed separately for each country.

Conceptually:

| Country | Ties 2013/2014 | Ties 2014/2015 |
|---|---:|---:|
| Belgium | 0.xx | 0.xx |
| England | 0.xx | 0.xx |
| France | 0.xx | 0.xx |
| Germany | 0.xx | 0.xx |
| Italy | 0.xx | 0.xx |
| Spain | 0.xx | 0.xx |

# 🧠 The Three Possible CASE Results

For each season-specific calculation:

### 🟢 Tie

    home_goal = away_goal

Returns:

    1

### 🔴 Not a tie

    home_goal != away_goal

Returns:

    0

### ⚪ Different season

Returns:

    NULL

So the logic is:

    Tie       → 1
    Not tie   → 0
    Other     → NULL

Then:

    AVG()

calculates the fraction of ties.

---

# 🔢 Fraction vs Percentage

The query returns a **fraction**, not a percentage.

For example:

    0.25

means:

    25%

To convert a fraction to a percentage:

    fraction × 100

So:

| Fraction | Percentage |
|---:|---:|
| 0.10 | 10% |
| 0.25 | 25% |
| 0.50 | 50% |
| 0.75 | 75% |
| 1.00 | 100% |

---

# 🧩 General Pattern

This is the key pattern to remember:

    AVG(
        CASE
            WHEN condition_is_true
            THEN 1

            WHEN condition_is_false
            THEN 0
        END
    )

It calculates:

> **The fraction of records where the condition is true.**

# 📚 Examples

## Count the fraction of wins

    AVG(
        CASE
            WHEN result = 'Win' THEN 1
            WHEN result = 'Loss' THEN 0
        END
    )

## Count the fraction of ties

    AVG(
        CASE
            WHEN home_goal = away_goal THEN 1
            WHEN home_goal != away_goal THEN 0
        END
    )

## Count the fraction of successful applications

    AVG(
        CASE
            WHEN status = 'Approved' THEN 1
            WHEN status != 'Approved' THEN 0
        END
    )

---

# 🎯 Key Takeaways

- `CASE` can return `1`, `0`, or `NULL`.
- `AVG()` can use those values to calculate a **fraction**.
- `1` represents records that meet the condition.
- `0` represents records that do not meet the condition.
- `NULL` excludes records from the `AVG()` calculation.
- `AVG(1, 0, 1, 0)` produces `0.50`, or 50%.
- Be careful when defining the `0` condition; incorrectly returning `NULL` can change the calculation.
- Adding the season condition inside the `CASE` lets you calculate different seasons in separate columns.
- `GROUP BY country` calculates the fraction separately for each country.
- `LEFT JOIN` connects countries with their matches while retaining countries from the left table.

---

# ⚡ Quick Reference

### Fraction of records meeting a condition

    AVG(
        CASE
            WHEN condition THEN 1
            WHEN opposite_condition THEN 0
        END
    )

### Fraction of tied matches

    AVG(
        CASE
            WHEN home_goal = away_goal THEN 1
            WHEN home_goal != away_goal THEN 0
        END
    )

### Season-specific fraction

    AVG(
        CASE
            WHEN season = '2013/2014'
                 AND condition
            THEN 1

            WHEN season = '2013/2014'
                 AND opposite_condition
            THEN 0
        END
    )

### ⭐ Remember

> **`AVG(CASE WHEN condition THEN 1 WHEN opposite_condition THEN 0 END)` converts a logical condition into a fraction of records that satisfy it.**
