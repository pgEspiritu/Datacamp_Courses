# ⚽ CASE Statements Comparing Two Column Values — Part 2

## 🚌 Barcelona as the Away Team

Similar to the previous exercise, you will construct a query to determine the outcome of Barcelona's matches where they played as the **away team**.

You will learn how to combine these two queries in Chapters 2 and 3.

### ❓ Question

Did Barcelona's performance differ from the matches where they were the **home team**?

## 📝 Instructions

**100 XP**

- Complete the `CASE` statement to identify Barcelona's away team games as **wins, losses, or ties**.
- `LEFT JOIN` the `teams_spain` table's `team_api_id` column on the `matches_spain` table's `hometeam_id` column. This retrieves the identity of the **home team opponent**.
- Filter the query to only include matches where Barcelona (`awayteam_id = 8634`) was the **away team**.

## 💡 Solution

    -- Select matches where Barcelona was the away team
    SELECT
        m.date,
        t.team_long_name AS opponent,

        CASE
            WHEN home_goal < away_goal THEN 'Barcelona win!'
            WHEN home_goal > away_goal THEN 'Barcelona loss :('
            ELSE 'Tie'
        END AS outcome

    FROM matches_spain AS m

    LEFT JOIN teams_spain AS t
        ON m.hometeam_id = t.team_api_id

    -- Filter for Barcelona
    WHERE m.awayteam_id = 8634;

## 🔍 Explanation

This query determines the result of Barcelona's matches when **Barcelona was playing away from home**.

### 1️⃣ Select the Match Date

    SELECT
        m.date,

The `date` column is selected from the `matches_spain` table using the alias `m`.

### 2️⃣ Identify the Opponent

    t.team_long_name AS opponent

The `team_long_name` column comes from the `teams_spain` table.

It identifies the **home team**, which is Barcelona's opponent because Barcelona is playing as the away team.

The column is renamed using:

    AS opponent

So the output column is easier to understand.

### 3️⃣ Determine the Match Outcome

The `CASE` statement compares the number of goals scored by the home and away teams.

    CASE
        WHEN home_goal < away_goal THEN 'Barcelona win!'
        WHEN home_goal > away_goal THEN 'Barcelona loss :('
        ELSE 'Tie'
    END AS outcome

Because Barcelona is the **away team**:

- If `away_goal > home_goal` → 🏆 Barcelona wins
- If `away_goal < home_goal` → 😞 Barcelona loses
- If `away_goal = home_goal` → 🤝 Tie

### 📊 CASE Logic

| Condition | Barcelona's Result |
|---|---|
| `home_goal < away_goal` | 🏆 `Barcelona win!` |
| `home_goal > away_goal` | 😞 `Barcelona loss :(` |
| Otherwise | 🤝 `Tie` |

### 4️⃣ Join the Teams Table

    LEFT JOIN teams_spain AS t
        ON m.hometeam_id = t.team_api_id

The `matches_spain` table contains the `hometeam_id`, while the `teams_spain` table contains the corresponding `team_api_id`.

The join connects these two columns:

    matches_spain.hometeam_id
            ↓
    teams_spain.team_api_id

This allows us to retrieve the home team's name using:

    t.team_long_name

Since Barcelona is the **away team**, the home team is Barcelona's opponent.

### 5️⃣ Filter for Barcelona

    WHERE m.awayteam_id = 8634;

The `WHERE` clause keeps only matches where Barcelona's team ID is `8634` and therefore Barcelona was playing as the **away team**.

## 🧠 Why the CASE Logic Is Reversed

In the previous exercise, Barcelona was the **home team**.

Therefore:

    home_goal > away_goal
        ↓
    Barcelona win!

But in this exercise, Barcelona is the **away team**.

Therefore, the logic is reversed:

    away_goal > home_goal
        ↓
    Barcelona win!

This is an important concept when using `CASE` statements with home and away teams.

## 🔄 Home vs. Away Logic

### 🏠 Barcelona as Home Team

    CASE
        WHEN home_goal > away_goal THEN 'Barcelona win!'
        WHEN home_goal < away_goal THEN 'Barcelona loss :('
        ELSE 'Tie'
    END

### 🚌 Barcelona as Away Team

    CASE
        WHEN home_goal < away_goal THEN 'Barcelona win!'
        WHEN home_goal > away_goal THEN 'Barcelona loss :('
        ELSE 'Tie'
    END

The comparison changes because Barcelona's position changes.

## 💻 Complete Query

    -- Select matches where Barcelona was the away team

    SELECT
        m.date,
        t.team_long_name AS opponent,
        CASE
            WHEN home_goal < away_goal THEN 'Barcelona win!'
            WHEN home_goal > away_goal THEN 'Barcelona loss :('
            ELSE 'Tie'
        END AS outcome

    FROM matches_spain AS m

    LEFT JOIN teams_spain AS t
        ON m.hometeam_id = t.team_api_id

    -- Filter for Barcelona
    WHERE m.awayteam_id = 8634;

## 🎯 Key Takeaways

- Use `CASE` to classify match outcomes based on column comparisons.
- When a team is the **away team**, the win/loss logic must account for the away team's goals.
- Use `LEFT JOIN` to retrieve the opponent's name from another table.
- `hometeam_id` can be joined to `team_api_id` to identify the home team.
- `WHERE m.awayteam_id = 8634` filters the results to Barcelona's away matches.
- The same `CASE` structure can produce different results depending on whether the team is playing **home or away**.

### ⭐ General Pattern

    CASE
        WHEN home_goal < away_goal THEN 'Away team win'
        WHEN home_goal > away_goal THEN 'Away team loss'
        ELSE 'Tie'
    END AS outcome
