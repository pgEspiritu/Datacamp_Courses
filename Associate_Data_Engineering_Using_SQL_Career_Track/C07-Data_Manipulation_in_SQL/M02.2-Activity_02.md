# ⚽ Filtering your CASE Statement

## 📝 Overview

`CASE` statements can be used not only to **create categories**, but also to **filter rows** in the `WHERE` clause.

This is useful when you want to keep only rows that meet specific conditions.

### 💡 Basic Structure

    SELECT *
    FROM table
    WHERE 
        CASE 
            WHEN a > 5 THEN 'Keep'
            WHEN a <= 5 THEN 'Exclude'
        END = 'Keep';

The `CASE` statement acts like a **temporary filtering column**.

⚠️ When using `CASE` inside `WHERE`, you **do not give it an alias**.

---

## 🎯 Exercise: Find Bologna Wins

The goal is to generate a list of matches won by Italy's **Bologna** team.

Bologna's `team_id` is:

    9857

We need to identify Bologna wins whether Bologna played:

- 🏠 At home
- ✈️ Away

---

## 📋 Instructions

**100 XP**

1. Use the `CASE` statement in the `WHERE` clause to filter where `hometeam_id` is `9857` and home goals exceed away goals.
2. Use the `CASE` statement in the `WHERE` clause to filter where `awayteam_id` is `9857` and away goals exceed home goals.
3. End the `CASE` statement by excluding games that Bologna **did not** win.

---

## 💻 Solution

    SELECT 
        season,
        date,
        home_goal,
        away_goal
    FROM matches_italy
    WHERE 
        CASE 
            -- Find games where Bologna won at home
            WHEN hometeam_id = 9857 
                 AND home_goal > away_goal 
            THEN 'Bologna Win'

            -- Find games where Bologna won away
            WHEN awayteam_id = 9857 
                 AND away_goal > home_goal 
            THEN 'Bologna Win' 

            -- Exclude games not won by Bologna
        END IS NOT NULL;

---

## 🔍 Understanding the CASE Statement

### 🏠 1. Bologna wins at home

    WHEN hometeam_id = 9857 
         AND home_goal > away_goal 
    THEN 'Bologna Win'

Two conditions must be true:

| Condition | Meaning |
|---|---|
| `hometeam_id = 9857` | Bologna is the home team |
| `home_goal > away_goal` | Bologna scored more goals |

The `AND` means **both conditions must be true**.

Example:

    Bologna: 3 goals
    Opponent: 1 goal

Result:

    'Bologna Win'

---

### ✈️ 2. Bologna wins away

    WHEN awayteam_id = 9857 
         AND away_goal > home_goal 
    THEN 'Bologna Win'

Again, two conditions must be true:

| Condition | Meaning |
|---|---|
| `awayteam_id = 9857` | Bologna is the away team |
| `away_goal > home_goal` | Bologna scored more goals |

Example:

    Home team: 1 goal
    Bologna: 2 goals

Result:

    'Bologna Win'

---

## 🚫 3. Why `END IS NOT NULL`?

The `CASE` statement only returns `'Bologna Win'` when one of the two winning conditions is true.

If neither condition is true, there is no `ELSE`, so the `CASE` returns:

    NULL

Therefore:

    END IS NOT NULL

keeps only rows where the `CASE` successfully identified a Bologna win.

### 🧠 Think of it this way:

    CASE
        WHEN Bologna won at home → 'Bologna Win'
        WHEN Bologna won away → 'Bologna Win'
        ELSE → NULL
    END

Then:

    IS NOT NULL

means:

    "Keep only the rows where Bologna won."

---

## 📊 What Happens to Different Matches?

| Match situation | CASE result | `IS NOT NULL` | Keep? |
|---|---|---|---|
| Bologna wins at home | `'Bologna Win'` | TRUE | ✅ Yes |
| Bologna loses at home | `NULL` | FALSE | ❌ No |
| Bologna wins away | `'Bologna Win'` | TRUE | ✅ Yes |
| Bologna loses away | `NULL` | FALSE | ❌ No |
| Bologna draws | `NULL` | FALSE | ❌ No |
| Other teams play | `NULL` | FALSE | ❌ No |

## 🔑 Important Concept: CASE as a Filter

Normally, you may use a column directly in `WHERE`:

    WHERE hometeam_id = 9857

But you can also create a condition using `CASE`:

    WHERE 
        CASE
            WHEN condition THEN 'Keep'
        END IS NOT NULL

This allows you to combine **multiple conditions** into a single filtering expression.

---

## 🧩 Key SQL Concepts

### `CASE`

Creates conditional logic:

    CASE
        WHEN condition THEN result
        WHEN condition THEN result
        ELSE result
    END

### `AND`

Requires **both conditions** to be true:

    condition1 AND condition2

### `IS NOT NULL`

Keeps rows where the expression has a value:

    expression IS NOT NULL

### No `ELSE`

If no `WHEN` condition is satisfied, the `CASE` returns `NULL`.

---

## ⚡ Quick Reference

    -- CASE used as a filter
    WHERE
        CASE
            WHEN condition1 THEN 'Keep'
            WHEN condition2 THEN 'Keep'
        END IS NOT NULL

### For Bologna:

    WHERE
        CASE
            WHEN hometeam_id = 9857
                 AND home_goal > away_goal
            THEN 'Bologna Win'

            WHEN awayteam_id = 9857
                 AND away_goal > home_goal
            THEN 'Bologna Win'
        END IS NOT NULL

---

## 🎯 Key Takeaways

- `CASE` can be used inside the `WHERE` clause.
- A `CASE` in `WHERE` should **not be aliased**.
- Multiple conditions can be combined using `AND`.
- If no `WHEN` condition matches and there is no `ELSE`, `CASE` returns `NULL`.
- `IS NOT NULL` can then be used to keep only the rows where the desired condition was met.
- This technique is useful when filtering based on **complex conditional logic**.
