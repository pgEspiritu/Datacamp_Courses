# 🧩 CASE Statements Comparing Column Values

## ⚽ Barcelona Match Outcomes

Barcelona is considered one of the strongest teams in Spain's soccer league.

In this exercise, you will be creating a list of matches in the **2011/2012 season** where Barcelona was the *home team*. You will do this using a `CASE` statement that compares the values of two columns to create a new group — **wins, losses, and ties**.

In 3 steps, you will build a query that:

1. 🏆 Identifies a match's winner
2. 👥 Identifies the identity of the opponent
3. 🔎 Filters for Barcelona as the home team

Completing a query in this order will allow you to watch your results take shape with each new piece of information.

The `matches_spain` table currently contains Barcelona's matches from the **2011/2012 season**, and has two key columns:

- `hometeam_id`
- `awayteam_id`

These columns can be joined with the `teams_spain` table. However, you can only join `teams_spain` to one column at a time.

## 📝 Instructions

**100 XP**

- Create a `CASE` statement to identify matches as **home wins, home losses, or ties**.

## 💡 Solution

    SELECT
        date,

        -- Identify home wins, losses, or ties
        CASE
            WHEN home_goal > away_goal THEN 'Home win!'
            WHEN home_goal < away_goal THEN 'Home loss :('
            ELSE 'Tie'
        END AS outcome

    FROM matches_spain;

## 🔍 Explanation

The `CASE` statement compares the values in the `home_goal` and `away_goal` columns.

### 🏆 Home Win

    WHEN home_goal > away_goal THEN 'Home win!'

If the home team scores **more goals** than the away team, the match is classified as a **Home win!**

### 😞 Home Loss

    WHEN home_goal < away_goal THEN 'Home loss :('

If the home team scores **fewer goals** than the away team, the match is classified as a **Home loss :(**.

### 🤝 Tie

    ELSE 'Tie'

If neither team scores more goals than the other, the match is a **Tie**.

Because the only remaining possibility is that:

    home_goal = away_goal

the `ELSE` condition captures tied matches.

## 📊 CASE Logic

| Condition | Outcome |
|---|---|
| `home_goal > away_goal` | 🏆 `Home win!` |
| `home_goal < away_goal` | 😞 `Home loss :(` |
| Otherwise | 🤝 `Tie` |

## 🧠 Key Concept

A `CASE` statement can compare **two columns in the same row** and create a new categorical variable based on the comparison.

The general pattern is:

    CASE
        WHEN column_1 > column_2 THEN 'Category 1'
        WHEN column_1 < column_2 THEN 'Category 2'
        ELSE 'Category 3'
    END AS new_column

In this exercise:

    home_goal > away_goal
        ↓
    Home win!

    home_goal < away_goal
        ↓
    Home loss :(

    home_goal = away_goal
        ↓
    Tie

## 💻 Complete Query

    SELECT
        date,
        CASE
            WHEN home_goal > away_goal THEN 'Home win!'
            WHEN home_goal < away_goal THEN 'Home loss :('
            ELSE 'Tie'
        END AS outcome
    FROM matches_spain;

## 🎯 Key Takeaway

Use `CASE` statements when you need to **compare column values and convert the result into meaningful categories**.

Here, the numerical goal columns are transformed into a simple match outcome:

**Goals → Comparison → Category** ⚽➡️🔍➡️🏆
