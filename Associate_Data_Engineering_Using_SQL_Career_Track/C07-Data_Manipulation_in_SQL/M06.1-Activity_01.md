# 🧩 Add a Subquery to the SELECT Clause

## 🎯 Objective

Use a subquery inside the `SELECT` clause to compare:

1. The **average total goals for each league** in the `2013/2014` season
2. The **overall average total goals across all leagues** in the `2013/2014` season

The key idea is:

> **Main query = average goals per league**  
> **Subquery = overall average goals for the season**

---

# 📝 Original Question

Construct a query that calculates the average number of goals per match in each country's league.

### Instructions

- In the subquery, select the average total goals by **adding** `home_goal` and `away_goal`.
- Filter the subquery so that only the `'2013/2014'` season is included.
- In the main query, calculate the average total goals for each league.
- Filter the main query to the same `'2013/2014'` season.
- Group the results by the league `name`.

---

# ✅ Answer

    SELECT 
        l.name AS league,

        -- Average total goals for each league
        ROUND(AVG(m.home_goal + m.away_goal), 2) AS avg_goals,

        -- Overall average total goals for the 2013/2014 season
        (
            SELECT ROUND(AVG(home_goal + away_goal), 2)
            FROM match
            WHERE season = '2013/2014'
        ) AS overall_avg

    FROM league AS l

    LEFT JOIN match AS m
        ON l.country_id = m.country_id

    -- Filter the main query to the 2013/2014 season
    WHERE season = '2013/2014'

    GROUP BY l.name;

---

# 🔍 How the Query Works

## 1. Calculate total goals

For every match:

    home_goal + away_goal

For example:

    Home goals = 2
    Away goals = 1

    Total goals = 2 + 1
                = 3

---

## 2. Calculate the average for each league

The main query uses:

    AVG(m.home_goal + m.away_goal)

This calculates the average total goals for each league.

Because the query contains:

    GROUP BY l.name

the calculation is performed separately for every league.

---

## 3. Calculate the overall average using a subquery

The subquery is:

    (
        SELECT ROUND(AVG(home_goal + away_goal), 2)
        FROM match
        WHERE season = '2013/2014'
    ) AS overall_avg

This returns **one single value**:

    Average total goals across all matches
    in the 2013/2014 season

Because it is a SELECT subquery, it can be displayed alongside the league-level results.

---

# 🧠 Main Query vs. Subquery

| Part | What it calculates |
|---|---|
| `AVG(m.home_goal + m.away_goal)` | Average goals for each league |
| `SELECT AVG(home_goal + away_goal)` | Overall average goals |
| `WHERE season = '2013/2014'` in main query | Limits league results to 2013/2014 |
| `WHERE season = '2013/2014'` in subquery | Limits overall average to 2013/2014 |
| `GROUP BY l.name` | Creates one result per league |

---

# 📊 Conceptual Result

The result will have a structure similar to:

| league | avg_goals | overall_avg |
|---|---:|---:|
| England | 2.77 | 2.77 |
| France | 2.46 | 2.77 |
| Germany | 3.16 | 2.77 |
| Italy | 2.72 | 2.77 |
| Spain | 2.75 | 2.77 |

The exact values depend on the database.

Notice that:

- `avg_goals` changes for every league.
- `overall_avg` is the same value for every row.

That's because the subquery calculates **one overall value**.

# 🔄 Query Processing Mental Model

Think of the query like this:

    1. JOIN league and match
           ↓
    2. Filter to 2013/2014
           ↓
    3. Group matches by league
           ↓
    4. Calculate average goals per league
           ↓
    5. Run SELECT subquery
           ↓
    6. Calculate overall season average
           ↓
    7. Display both values

---

# ⚠️ Important: The Filters Are in Both Queries

The main query contains:

    WHERE season = '2013/2014'

The subquery also contains:

    WHERE season = '2013/2014'

This is important.

### Main query filter

Determines which matches are used to calculate:

    avg_goals

### Subquery filter

Determines which matches are used to calculate:

    overall_avg

If the subquery did **not** contain the season filter:

    (
        SELECT ROUND(AVG(home_goal + away_goal), 2)
        FROM match
    )

then `overall_avg` would represent the average across **all seasons**, not just `2013/2014`.

---

# 💡 Why Use a Subquery Here?

Without the subquery, you could calculate:

    Average goals per league

But you would not easily have the overall season average available in the same result.

The subquery lets you produce:

    League average
          +
    Overall season average

in the same result table.

This makes it possible to compare each league's performance with the overall season average.

---

# 🧠 Key Concept

### SELECT subquery

A subquery inside `SELECT` should return **one single value**.

Here:

    SELECT ROUND(AVG(home_goal + away_goal), 2)
    FROM match
    WHERE season = '2013/2014'

returns exactly one value.

That value is then added as:

    overall_avg

to every row returned by the main query.

---

# 🔑 Important SQL Pattern

    SELECT
        group_column,

        AVG(value) AS group_average,

        (
            SELECT AVG(value)
            FROM table
            WHERE filter
        ) AS overall_average

    FROM table

    WHERE filter

    GROUP BY group_column;

### Mental shortcut:

> **Main query = group-level calculation**  
> **SELECT subquery = overall comparison value**

---

# 🎯 Final Takeaway

This exercise demonstrates how a **SELECT subquery** can bring an aggregate value into a grouped query.

The main query answers:

> "What is the average number of goals for each league?"

The subquery answers:

> "What is the overall average number of goals for the entire 2013/2014 season?"

Together, they produce a result that allows you to compare **each league's average against the overall season average**.
