# 🪟 PARTITION BY a Column

The `PARTITION BY` clause allows you to calculate separate window values based on categories in your data.

For example, you can calculate the average goals scored for each season while keeping every individual match in the result set.

In this exercise, we examine matches played by **Legia Warszawa**, a football team in Poland, and compare their individual match performance with the seasonal averages for home and away goals.

The team ID for Legia Warszawa is `8673`.

---

## 🎯 Exercise

**Question:** Where do you see more outliers? Are Legia Warszawa's home or away games?

**Instructions (100 XP)**

- Complete the two window functions that calculate the home and away goal averages. Partition the window functions by `season` to calculate separate averages for each season.
- Filter the query to include only matches played by Legia Warszawa (`id = 8673`).

---

## ✅ Answer

    SELECT
        date,
        season,
        home_goal,
        away_goal,

        CASE
            WHEN hometeam_id = 8673 THEN 'home'
            ELSE 'away'
        END AS warsaw_location,

        -- Calculate average home and away goals separately by season
        AVG(home_goal) OVER (
            PARTITION BY season
        ) AS season_homeavg,

        AVG(away_goal) OVER (
            PARTITION BY season
        ) AS season_awayavg

    FROM match

    -- Filter for Legia Warszawa matches only
    WHERE
        hometeam_id = 8673
        OR awayteam_id = 8673

    ORDER BY (home_goal + away_goal) DESC;

---

## 🔍 Step-by-Step Explanation

### 1. Select match information

    SELECT
        date,
        season,
        home_goal,
        away_goal

These columns show the match date, season, and goals scored by both teams.

### 2. Identify whether Legia Warszawa played at home or away

    CASE
        WHEN hometeam_id = 8673 THEN 'home'
        ELSE 'away'
    END AS warsaw_location

This labels each match according to Legia Warszawa's location:

- `home` — Legia Warszawa was the home team.
- `away` — Legia Warszawa was the away team.

The `CASE` expression works correctly because the `WHERE` clause keeps only matches where Legia Warszawa was either the home or away team.

### 3. Calculate the average home goals per season

    AVG(home_goal) OVER (
        PARTITION BY season
    ) AS season_homeavg

This calculates the average **home-team goals** for each season across all matches included in the window's input data.

For example, all matches from `2011/2012` receive the same `season_homeavg` value, while matches from `2012/2013` receive that season's value.

### 4. Calculate the average away goals per season

    AVG(away_goal) OVER (
        PARTITION BY season
    ) AS season_awayavg

This calculates the average **away-team goals** for each season.

Both window functions use `PARTITION BY season`, but they average different columns.

**Important:** These are averages for all matches in each season, not just Legia Warszawa's matches. Window functions are evaluated before the final result is filtered by `WHERE` only when the window's input is the result after that `WHERE`. In this query, the `WHERE` filter is applied before the window functions, so the averages are actually calculated from **Legia Warszawa's matches only**.

To compare Legia Warszawa's performance against the averages for *all matches in each season*, the query needs to calculate the window averages before filtering to Legia Warszawa's matches, such as by using a CTE.

### 5. Filter Legia Warszawa's matches

    WHERE
        hometeam_id = 8673
        OR awayteam_id = 8673

This keeps only matches in which Legia Warszawa played, either at home or away.

### 6. Sort by total goals

    ORDER BY (home_goal + away_goal) DESC;

This sorts matches from the highest total goals to the lowest.

It helps bring high-scoring matches to the top, making unusual results easier to inspect.

## ⚠️ Important SQL Correction

If the goal is to compare Legia Warszawa's matches against **the average home and away goals for all matches in each season**, use this version:

    WITH season_averages AS (
        SELECT
            date,
            season,
            home_goal,
            away_goal,
            hometeam_id,
            awayteam_id,
            AVG(home_goal) OVER (
                PARTITION BY season
            ) AS season_homeavg,
            AVG(away_goal) OVER (
                PARTITION BY season
            ) AS season_awayavg
        FROM match
    )
    SELECT
        date,
        season,
        home_goal,
        away_goal,
        CASE
            WHEN hometeam_id = 8673 THEN 'home'
            ELSE 'away'
        END AS warsaw_location,
        season_homeavg,
        season_awayavg
    FROM season_averages
    WHERE
        hometeam_id = 8673
        OR awayteam_id = 8673
    ORDER BY (home_goal + away_goal) DESC;

The CTE calculates the seasonal averages using all matches first. The outer query then filters to Legia Warszawa's matches.

---

## 📊 How to Identify Outliers

An **outlier** is a result that differs substantially from the typical value.

Compare the actual goals with the corresponding seasonal average:

- **Home performance:** Compare `home_goal` with `season_homeavg`.
- **Away performance:** Compare `away_goal` with `season_awayavg`.

For a more precise comparison, calculate the differences:

    home_goal - season_homeavg

    away_goal - season_awayavg

Large positive or negative differences indicate matches that are further from the seasonal average.

The query alone does not establish whether home or away games have more outliers. You would need to inspect the results and compare the size of these differences.

---

## 🧠 Key Takeaways

1. `PARTITION BY season` calculates separate window values for each season.
2. `AVG(home_goal)` calculates the average home-team goals.
3. `AVG(away_goal)` calculates the average away-team goals.
4. The `WHERE` clause filters rows before window calculations are performed.
5. To compare a team's matches against league-wide seasonal averages, calculate the window averages before filtering to that team.
6. Sorting by total goals can help identify high-scoring matches, but it does not by itself establish which location has more statistical outliers.
