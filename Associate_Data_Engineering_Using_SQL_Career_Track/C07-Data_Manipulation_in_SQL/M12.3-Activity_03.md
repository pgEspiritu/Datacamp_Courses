# 🔄 Flip OVER Your Results

In the previous exercise, the `RANK()` window function ranked leagues from the lowest average goals to the highest.

By adding `DESC` inside the `ORDER BY` clause of `OVER()`, you can reverse the ranking so that the highest values receive Rank 1.

Example:

    SELECT
        id,
        RANK() OVER (ORDER BY home_goal DESC) AS rank
    FROM match;

In this example, matches are ranked according to `home_goal`, from highest to lowest.

---

## 🎯 Exercise

**Question:** Rank leagues according to their average total goals, from highest to lowest.

**Instructions (100 XP)**

- Select the league `name` and average total goals scored from `league` and `match`.
- Complete the window function to rank each league from **highest to lowest** average goals scored.
- Order the main query by the rank you created.

---

## ✅ Answer

    SELECT
        -- Select the league name and average goals scored
        name AS league,
        AVG(m.home_goal + m.away_goal) AS avg_goals,

        -- Rank leagues in descending order by average goals
        RANK() OVER (
            ORDER BY AVG(m.home_goal + m.away_goal) DESC
        ) AS league_rank

    FROM league AS l
    LEFT JOIN match AS m
        ON l.id = m.country_id
    WHERE m.season = '2011/2012'
    GROUP BY l.name

    -- Order the query by the rank you created
    ORDER BY league_rank;

---

## 🔍 Step-by-Step Explanation

### 1. Select the league name

    name AS league

Retrieves the league name and labels the output column `league`.

### 2. Calculate the average total goals

    AVG(m.home_goal + m.away_goal) AS avg_goals

Adds the home and away goals for each match, then calculates the average total goals for each league.

### 3. Rank leagues from highest to lowest

    RANK() OVER (
        ORDER BY AVG(m.home_goal + m.away_goal) DESC
    ) AS league_rank

Here's what each part does:

- `RANK()` generates the ranking.
- `OVER()` defines the window for the ranking calculation.
- `ORDER BY AVG(...)` ranks leagues according to their average total goals.
- `DESC` sorts the averages from highest to lowest.
- `AS league_rank` names the ranking column.

**The most important change from the previous exercise is `DESC`.**

Without `DESC`, the lowest average receives Rank 1. With `DESC`, the highest average receives Rank 1.

### 4. Join the tables

    FROM league AS l
    LEFT JOIN match AS m
        ON l.id = m.country_id

Connects each league to its corresponding matches.

### 5. Filter the season

    WHERE m.season = '2011/2012'

Includes matches from the 2011/2012 season.

### 6. Group by league

    GROUP BY l.name

Calculates one average total-goals value per league.

### 7. Order the final result

    ORDER BY league_rank;

Displays the leagues according to their assigned ranks, with Rank 1 first.

## 📊 Example Result

*Illustrative values only.*

| league | avg_goals | league_rank |
|---|---:|---:|
| League E | 2.80 | 1 |
| League C | 2.45 | 2 |
| League D | 2.45 | 2 |
| League B | 2.10 | 4 |
| League A | 1.80 | 5 |

Notice that League C and League D have the same average and therefore share Rank 2. The next rank is 4 because `RANK()` skips a position after a tie.

---

## 🧠 Two `ORDER BY` Clauses

| SQL clause | Purpose |
|---|---|
| `ORDER BY` inside `OVER()` | Determines how the ranks are assigned |
| Final `ORDER BY league_rank` | Determines the order in which rows appear |

These clauses serve different purposes, even though both use `ORDER BY`.

---

## 📌 Quick Reference

| Syntax | Ranking direction |
|---|---|
| `RANK() OVER (ORDER BY value)` | Lowest to highest |
| `RANK() OVER (ORDER BY value ASC)` | Lowest to highest |
| `RANK() OVER (ORDER BY value DESC)` | Highest to lowest |

### ⭐ Key takeaway

    RANK() OVER (
        ORDER BY AVG(m.home_goal + m.away_goal) DESC
    )

means:

**Rank each league by its average total goals, giving Rank 1 to the league with the highest average.**
