# Setting Up the Home Team CTE

In this course, we've covered ways in which you can use `CASE` statements, subqueries, Common Table Expressions (CTEs), and window functions in your queries to structure a data set that best meets your needs.

For this exercise, you will use all of these concepts to generate a list of matches in which Manchester United was defeated during the 2014/2015 English Premier League season.

Your first task is to create a query that filters for matches where Manchester United played as the home team. This query will become a Common Table Expression (CTE) in a later exercise.

## Instructions

**100 XP**

- Create a `CASE` statement that identifies each match as a win, loss, or tie for Manchester United.
- Fill out the logical operators for each `WHEN` clause in the `CASE` statement (greater than, less than, and equals).
- Join the tables using `hometeam_id` from `match` and `team_api_id` from `team`.
- Filter the query to include only games from the `'2014/2015'` season where Manchester United was the home team.

## SQL Solution

```sql
SELECT
    m.id,
    t.team_long_name,

    -- Identify matches as wins, losses, or ties for Manchester United
    CASE
        WHEN m.home_goal > m.away_goal THEN 'MU Win'
        WHEN m.home_goal < m.away_goal THEN 'MU Loss'
        ELSE 'Tie'
    END AS outcome

FROM match AS m

-- Join team using the home team's ID
LEFT JOIN team AS t
    ON m.hometeam_id = t.team_api_id

WHERE
    -- Filter for the 2014/2015 season and Manchester United as the home team
    m.season = '2014/2015'
    AND t.team_long_name = 'Manchester United';
```

## Code Explanation

### 1. `SELECT`

```sql
SELECT
    m.id,
    t.team_long_name,
```

- `m.id` retrieves the match ID.
- `t.team_long_name` retrieves the full name of the home team.
- `m` and `t` are table aliases for `match` and `team`, respectively.

### 2. `CASE` Statement

```sql
CASE
    WHEN m.home_goal > m.away_goal THEN 'MU Win'
    WHEN m.home_goal < m.away_goal THEN 'MU Loss'
    ELSE 'Tie'
END AS outcome
```

This classifies each match from Manchester United's perspective, since the query filters for matches in which Manchester United played at home.

| Condition | Outcome | Meaning |
|---|---|---|
| `home_goal > away_goal` | `MU Win` | Manchester United scored more goals than the away team. |
| `home_goal < away_goal` | `MU Loss` | Manchester United scored fewer goals than the away team. |
| `ELSE` | `Tie` | Both teams scored the same number of goals. |

The `CASE` statement evaluates the conditions in order. If neither of the first two conditions is true, the match is classified as a tie.

`AS outcome` assigns the name `outcome` to the resulting column.

### 3. `FROM match AS m`

```sql
FROM match AS m
```

Specifies the `match` table as the primary data source and assigns it the alias `m`.

This allows you to reference its columns using expressions such as `m.id`, `m.home_goal`, and `m.season`.

### 4. `LEFT JOIN team AS t`

```sql
LEFT JOIN team AS t
    ON m.hometeam_id = t.team_api_id
```

Combines the `match` and `team` tables using the home team's ID.

- `m.hometeam_id` identifies the home team in the match table.
- `t.team_api_id` identifies the corresponding team in the team table.
- `LEFT JOIN` retains all records from the left table, even when a matching team record is missing.

Because the `WHERE` clause requires `t.team_long_name = 'Manchester United'`, only records with a matching Manchester United team entry remain in the final result. In this particular query, the filter makes the result behave like an inner join for the selected team.

### 5. `WHERE` Clause

```sql
WHERE
    m.season = '2014/2015'
    AND t.team_long_name = 'Manchester United';
```

Filters the data using two conditions:

- `m.season = '2014/2015'` selects matches from the 2014/2015 season.
- `t.team_long_name = 'Manchester United'` selects matches where Manchester United was the home team.
- `AND` requires both conditions to be true.

## Expected Result Structure

The query returns three columns:

| id | team_long_name | outcome |
|---:|---|---|
| 1 | Manchester United | MU Win |
| 2 | Manchester United | Tie |
| 3 | Manchester United | MU Loss |

*The rows above are illustrative examples, not the actual query output.*

## Key Takeaways

- `CASE` categorizes match results as wins, losses, or ties.
- `LEFT JOIN` connects match records to team names using their IDs.
- `WHERE` filters records by season and home team.
- Table aliases (`m` and `t`) make SQL queries shorter and easier to read.
- This query can later be placed inside a CTE using `WITH` to support a larger analysis of Manchester United's defeats.
