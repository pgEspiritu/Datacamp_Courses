# 🪟 The match is OVER

The `OVER()` clause allows you to apply an aggregate function across a dataset without using `GROUP BY`.

This is similar to using a subquery in `SELECT`, but a window function provides a simpler way to calculate values across the existing result set.

## 🎯 Exercise

> Select the match `ID`, country `name`, `season`, `home_goal`, and `away_goal` from the `match` and `country` tables.
>
> Complete the query that calculates the **average** number of goals scored overall and then includes the **aggregate** value in each row using a **window** function.

## ✅ Answer

    SELECT
        -- Select the match id, country name, season, home, and away goals
        m.id,
        c.name AS country,
        m.season,
        m.home_goal,
        m.away_goal,

        -- Use a window to include the aggregate average in each row
        AVG(m.home_goal + m.away_goal) OVER() AS overall_avg

    FROM match AS m
    LEFT JOIN country AS c
        ON m.country_id = c.id;

## 🔍 Step-by-Step Explanation

### 1. Select the match ID

    m.id

This retrieves the unique ID of each match.

---

### 2. Select the country name

    c.name AS country

The `country` table contains the country name.

The query connects `match` and `country` using:

    m.country_id = c.id

The alias `country` makes the output column easier to understand.

---

### 3. Select the season

    m.season

This tells us which football season the match belongs to.

---

### 4. Select the home and away goals

    m.home_goal,
    m.away_goal

These columns contain the goals scored by the home and away teams.

---

### 5. Calculate total goals for each match

The expression:

    m.home_goal + m.away_goal

calculates the total number of goals scored in each match.

For example:

| home_goal | away_goal | Total |
|---:|---:|---:|
| 2 | 1 | 3 |
| 3 | 2 | 5 |
| 0 | 0 | 0 |

---

### 6. Calculate the overall average

The key part is:

    AVG(m.home_goal + m.away_goal) OVER() AS overall_avg

Break it down:

    AVG()
    → Calculate the average

    m.home_goal + m.away_goal
    → Total goals per match

    OVER()
    → Calculate across the entire result set

    AS overall_avg
    → Give the calculated column a name

---

## 🧠 Why Use `OVER()`?

Without `OVER()`, an aggregate function such as:

    AVG(m.home_goal + m.away_goal)

would normally summarize the rows into a single aggregate result.

With:

    AVG(m.home_goal + m.away_goal) OVER()

SQL calculates the average **while keeping every individual match row**.

Conceptually:

    Match 1 → 3 goals → overall average
    Match 2 → 5 goals → overall average
    Match 3 → 0 goals → overall average
    Match 4 → 2 goals → overall average

The same `overall_avg` value is displayed for every row.

---

## 📊 Example Result

The actual values depend on the dataset, but the structure would look like:

| id | country | season | home_goal | away_goal | overall_avg |
|---:|---|---|---:|---:|---:|
| 1 | Belgium | 2011/2012 | 2 | 1 | 2.74 |
| 2 | Belgium | 2011/2012 | 1 | 1 | 2.74 |
| 3 | France | 2011/2012 | 3 | 2 | 2.74 |
| 4 | Spain | 2011/2012 | 0 | 0 | 2.74 |

The important observation is that **`overall_avg` is repeated for every match**.

# 🔄 Subquery vs. Window Function

### Previous approach: `SELECT` subquery

    SELECT
        m.id,
        m.home_goal,
        m.away_goal,
        (
            SELECT AVG(home_goal + away_goal)
            FROM match
        ) AS overall_avg
    FROM match AS m;

### Window function approach

    SELECT
        m.id,
        m.home_goal,
        m.away_goal,
        AVG(m.home_goal + m.away_goal) OVER() AS overall_avg
    FROM match AS m;

The window function is more concise and is specifically designed for calculations across the existing result set.

---

# 🧠 Key Concept

### `OVER()` keeps the rows.

Remember:

    AVG() + GROUP BY
    → summarize rows

    AVG() OVER()
    → calculate across rows while keeping every row

This is the main reason window functions are so useful.

---

# 📌 Quick Reference

### Overall average

    AVG(column) OVER()

### Overall sum

    SUM(column) OVER()

### Overall count

    COUNT(*) OVER()

### Overall maximum

    MAX(column) OVER()

### Overall minimum

    MIN(column) OVER()

# ⭐ Key Takeaway

The most important part of this exercise is:

    AVG(m.home_goal + m.away_goal) OVER() AS overall_avg

It means:

> **Calculate the average total goals across the result set and place that same aggregate value alongside every individual match.**
