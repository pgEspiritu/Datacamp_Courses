# Add a Window Function

Fantastic! You now have a result set that retrieves the match date, home team, away team, and the goals scored by each team. One final question remains: **How badly did Manchester United lose in each match?**

To determine this, you'll add a window function to the main query that ranks matches by the absolute difference between `home_goal` and `away_goal`. This allows you to compare the score differences without having to consider whether Manchester United played as the home or away team.

The equation is provided; you just need to complete the window function.

## Instructions

**100 XP**

- Set up the CTEs so that the home and away teams each have a name, ID, and match outcome.
- Select the `date`, home team name, away team name, home goals, and away goals in the main query.
- Rank the matches by the difference in scores in **descending** order.

## SQL Solution

```sql
-- Set up the home team CTE
WITH home AS (
    SELECT
        m.id,
        t.team_long_name,
        CASE
            WHEN m.home_goal > m.away_goal THEN 'MU Win'
            WHEN m.home_goal < m.away_goal THEN 'MU Loss'
            ELSE 'Tie'
        END AS outcome
    FROM match AS m
    LEFT JOIN team AS t
        ON m.hometeam_id = t.team_api_id
),

-- Set up the away team CTE
away AS (
    SELECT
        m.id,
        t.team_long_name,
        CASE
            WHEN m.home_goal > m.away_goal THEN 'MU Loss'
            WHEN m.home_goal < m.away_goal THEN 'MU Win'
            ELSE 'Tie'
        END AS outcome
    FROM match AS m
    LEFT JOIN team AS t
        ON m.awayteam_id = t.team_api_id
)

-- Select columns and rank matches by goal difference
SELECT DISTINCT
    m.date,
    home.team_long_name AS home_team,
    away.team_long_name AS away_team,
    m.home_goal,
    m.away_goal,

    RANK() OVER (
        ORDER BY ABS(m.home_goal - m.away_goal) DESC
    ) AS match_rank

-- Join the CTEs to the match table
FROM match AS m
LEFT JOIN home
    ON m.id = home.id
LEFT JOIN away
    ON m.id = away.id

WHERE
    m.season = '2014/2015'
    AND (
        (
            home.team_long_name = 'Manchester United'
            AND home.outcome = 'MU Loss'
        )
        OR
        (
            away.team_long_name = 'Manchester United'
            AND away.outcome = 'MU Loss'
        )
    );
```

## Code Explanation

### 1. Home and Away CTEs

The `home` and `away` CTEs identify the teams involved in each match and classify the result as a win, loss, or tie from Manchester United's perspective.

- `home` joins `match.hometeam_id` to `team.team_api_id`.
- `away` joins `match.awayteam_id` to `team.team_api_id`.
- `CASE` assigns the appropriate outcome label.

These CTEs allow the main query to determine whether Manchester United lost at home or away.

### 2. `ABS()` — Absolute Difference

```sql
ABS(m.home_goal - m.away_goal)
```

- `m.home_goal - m.away_goal` calculates the difference between the home and away scores.
- `ABS()` converts the result to a nonnegative value.

For example:

| Home goals | Away goals | Difference | Absolute difference |
|---:|---:|---:|---:|
| 0 | 3 | -3 | 3 |
| 1 | 4 | -3 | 3 |
| 0 | 2 | -2 | 2 |
| 1 | 2 | -1 | 1 |

The absolute difference measures the size of the score gap regardless of which team scored more goals.

### 3. `RANK()` — Ranking the Matches

```sql
RANK() OVER (
    ORDER BY ABS(m.home_goal - m.away_goal) DESC
) AS match_rank
```

- `RANK()` assigns a rank to each result.
- `OVER()` defines how the ranking is calculated.
- `ORDER BY` determines the ranking order.
- `DESC` sorts the largest goal differences first.
- `AS match_rank` names the resulting column.

For example, a defeat by three goals ranks ahead of a defeat by two goals.

If multiple matches have the same absolute goal difference, they receive the same rank. `RANK()` skips subsequent rank numbers when ties occur.

### 4. Main Query and Joins

```sql
SELECT DISTINCT
    m.date,
    home.team_long_name AS home_team,
    away.team_long_name AS away_team,
    m.home_goal,
    m.away_goal
```

This retrieves the match date, both team names, and the scores. `DISTINCT` removes duplicate rows with identical selected values.

The two `LEFT JOIN` clauses connect the CTEs to the original `match` table using the match ID.

### 5. Filtering Manchester United's Defeats

```sql
WHERE
    m.season = '2014/2015'
    AND (
        (
            home.team_long_name = 'Manchester United'
            AND home.outcome = 'MU Loss'
        )
        OR
        (
            away.team_long_name = 'Manchester United'
            AND away.outcome = 'MU Loss'
        )
    );
```

This filters the results to:

- Matches from the 2014/2015 season.
- Matches where Manchester United lost at home, **or** matches where Manchester United lost away.

The parentheses ensure that the conditions are evaluated together correctly.

## Key Takeaways

- `ABS()` calculates the absolute difference between two scores.
- `RANK()` assigns rankings based on the specified ordering.
- `ORDER BY ... DESC` places the largest score differences first.
- CTEs simplify complex queries by separating team identification and outcome classification from the main analysis.
- Combining `CASE`, CTEs, joins, and window functions helps answer analytical questions using SQL.

**Important distinction:** This query ranks Manchester United's defeats by the absolute goal difference, not by the number of goals Manchester United scored or conceded alone. A larger score difference means a heavier defeat.
