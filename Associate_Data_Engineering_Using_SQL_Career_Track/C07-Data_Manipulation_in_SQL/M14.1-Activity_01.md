# 🪟 Exercise: Slide to the Left

## 🎯 Objective

Use sliding window functions to calculate the **running total** and **running average** of goals scored by FC Utrecht when playing at home during the `2011/2012` season.

The exercise demonstrates how `SUM()` and `AVG()` work with `OVER()`, `ORDER BY`, and `ROWS BETWEEN`.

## 📋 Instructions

Complete the window functions by:

- Calculating the running **total** of home goals scored by FC Utrecht.
- Calculating the running **average** of home goals scored.
- Ordering both calculations by `date`.
- Including all rows from the beginning of the season through the current match.

## ✅ Correct SQL Answer

    SELECT
        date,
        home_goal,
        away_goal,
        SUM(home_goal) OVER (
            ORDER BY date
            ROWS BETWEEN UNBOUNDED PRECEDING AND CURRENT ROW
        ) AS running_total,
        AVG(home_goal) OVER (
            ORDER BY date
            ROWS BETWEEN UNBOUNDED PRECEDING AND CURRENT ROW
        ) AS running_avg
    FROM match
    WHERE
        hometeam_id = 9908
        AND season = '2011/2012';

## 🔍 Step-by-Step Explanation

### 1. Filter FC Utrecht's home matches

    WHERE
        hometeam_id = 9908
        AND season = '2011/2012'

- `hometeam_id = 9908` selects matches where FC Utrecht plays at home.
- `season = '2011/2012'` restricts the results to that season.

### 2. Calculate the running total

    SUM(home_goal) OVER (
        ORDER BY date
        ROWS BETWEEN UNBOUNDED PRECEDING AND CURRENT ROW
    ) AS running_total

- `SUM(home_goal)` adds the home goals.
- `ORDER BY date` processes matches chronologically.
- `UNBOUNDED PRECEDING` starts at the first row in the window.
- `CURRENT ROW` ends the calculation at the current match.
- `running_total` is the name of the resulting column.

**Example:** If the home goals are `2`, `1`, and `3`, the running totals are `2`, `3`, and `6`.

### 3. Calculate the running average

    AVG(home_goal) OVER (
        ORDER BY date
        ROWS BETWEEN UNBOUNDED PRECEDING AND CURRENT ROW
    ) AS running_avg

This calculates the average home goals from the first match through the current match.

For example:

| Match | Home goals | Running total | Running average |
|---|---:|---:|---:|
| 1 | 2 | 2 | 2.00 |
| 2 | 1 | 3 | 1.50 |
| 3 | 3 | 6 | 2.00 |
| 4 | 0 | 6 | 1.50 |

*The values above are illustrative, not actual FC Utrecht match results.*

## 🧠 Important Concepts

| SQL expression | Purpose |
|---|---|
| `SUM(home_goal)` | Calculates the sum of home goals |
| `AVG(home_goal)` | Calculates the average of home goals |
| `OVER()` | Defines the window for the calculation |
| `ORDER BY date` | Establishes the order of matches |
| `UNBOUNDED PRECEDING` | Starts at the first row in the window |
| `CURRENT ROW` | Ends at the current row |

## ⭐ Key Takeaway

The difference between the two window functions is the aggregate being calculated:

- **`SUM()`** tells you how many home goals FC Utrecht has scored cumulatively.
- **`AVG()`** tells you the average number of home goals per match up to that point.

Both calculations update as the query moves through the matches in date order.

**Note:** Although the exercise asks whether FC Utrecht scores more goals at the end of the season as a home or away team, this query calculates only home-match statistics. To compare home and away performance, you would also need to analyze matches where FC Utrecht played as the away team.
