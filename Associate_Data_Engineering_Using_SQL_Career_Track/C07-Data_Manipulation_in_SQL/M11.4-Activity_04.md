# 🧩 Get Team Names with CTEs

## 📌 Overview

You've now explored two methods for answering the question:

> **How do you get both the home and away team names into one final query result?**

The methods covered so far are:

1. 🔍 Subqueries in `FROM`
2. 🔄 Correlated subqueries
3. 🧩 Common Table Expressions (CTEs)

This exercise explores the third method: **CTEs**.

CTEs are similar to the subquery method because they allow us to create an intermediate result. The main difference is the **syntax** and the **order in which the query steps are organized**.

---

# 📝 Exercise 1/3 — Create the Home-Team Query

## 🎯 Original Question

Select:

- `id` from `match`
- `team_long_name` from `team`

Then join the two tables using:

    match.hometeam_id = team.team_api_id

This query will be used as the basis for a CTE.

---

# ✅ Answer

    SELECT
        -- Select match id and team long name
        m.id,
        t.team_long_name AS hometeam

    FROM match AS m

    -- Join team to match using team_api_id and hometeam_id
    LEFT JOIN team AS t
        ON m.hometeam_id = t.team_api_id;

---

# 🔍 Step-by-Step Explanation

## 1. Start with the `match` table

    FROM match AS m

The `match` table contains the match information.

We give it the alias:

    m

This allows us to write:

    m.id
    m.hometeam_id

instead of:

    match.id
    match.hometeam_id

---

## 2. Join the `team` table

    LEFT JOIN team AS t

We need the `team` table because the `match` table contains the team's ID, while the `team` table contains the team's name.

The aliases are:

    m → match
    t → team

---

## 3. Match the Home Team ID

    ON m.hometeam_id = t.team_api_id

This is the key relationship.

The `match` table stores the home team's ID in:

    hometeam_id

The `team` table stores the corresponding team ID in:

    team_api_id

Therefore:

    m.hometeam_id = t.team_api_id

---

## 4. Select the Match ID

    m.id

The match ID identifies the match.

This is important because the next CTE will eventually need to connect the home-team information back to the original match.

---

## 5. Select the Team Name

    t.team_long_name AS hometeam

The `team_long_name` column contains the team's full name.

We rename it:

    AS hometeam

This makes the output easier to understand.

---

# 📊 Result Structure

The query produces something similar to:

| id | hometeam |
|---:|---|
| 1 | Team A |
| 2 | Team C |
| 3 | Team E |
| 4 | Team G |

The exact team names depend on the database.

---

# 🧠 Why Use a CTE?

This query will become a named query step using `WITH`.

Instead of putting the query directly inside the `FROM` clause like this:

    FROM (
        SELECT ...
    ) AS home

we can define it first:

    WITH home AS (
        SELECT ...
    )

Then use:

    FROM home

### 💡 Main Difference

**Subquery in `FROM`:**

    SELECT ...
    FROM (
        SELECT ...
    ) AS home;

**CTE:**

    WITH home AS (
        SELECT ...
    )
    SELECT ...
    FROM home;

Both approaches can create a similar intermediate result, but the CTE makes the preparation step easier to identify and organize.

---

# 🔄 Query Flow

The CTE approach will eventually follow this structure:

    WITH home AS (
        Get match ID
        +
        Get home team name
    ),
    away AS (
        Get match ID
        +
        Get away team name
    )
    SELECT ...
    FROM match
    LEFT JOIN home ...
    LEFT JOIN away ...

The current exercise is preparing the **home** portion.

---

# ⚠️ Important JOIN Condition

Make sure you use:

    ON m.hometeam_id = t.team_api_id

Do not confuse:

    hometeam_id

with:

    awayteam_id

The next exercise will create the corresponding query for the **away team**.

---

# 🔑 Key Takeaways

- A CTE is created using the `WITH` keyword.
- This exercise prepares the home-team information.
- `m.id` identifies the match.
- `t.team_long_name` provides the team's full name.
- `m.hometeam_id` connects to `t.team_api_id`.
- `AS hometeam` gives the team name a clear column name.
- The query will become a CTE in the next steps.
- 🧩 CTEs help organize complex SQL into clearly named steps.

## 📌 Quick Reference

    SELECT
        m.id,
        t.team_long_name AS hometeam
    FROM match AS m
    LEFT JOIN team AS t
        ON m.hometeam_id = t.team_api_id;
