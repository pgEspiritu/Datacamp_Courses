# ⚔️ In CASE of Rivalry

Barcelona and Real Madrid have been rival teams for more than 80 years. Matches between these two teams are given the name **El Clásico** (*The Classic*).

In this exercise, you will query a list of matches played between these two rivals, where **Barcelona** is the **home team**, categorizing the result as a **Barcelona win**, **Real Madrid win**, or **Tie** depending on multiple conditions.

## 📝 Instructions

**100 XP**

- Construct the `CASE` statement identifying who won each match.
- Fill in the **operators** to identify Barcelona or Real Madrid as the winner.

## 💡 Solution

    SELECT
        date,

        CASE
            WHEN hometeam_id = 8634 THEN 'FC Barcelona'
            ELSE 'Real Madrid CF'
        END AS home,

        CASE
            WHEN awayteam_id = 8634 THEN 'FC Barcelona'
            ELSE 'Real Madrid CF'
        END AS away,

        -- Identify possible home match outcomes
        CASE
            WHEN home_goal > away_goal
                 AND hometeam_id = 8634
                THEN 'Barcelona win!'

            WHEN home_goal < away_goal
                 AND awayteam_id = 8633
                THEN 'Real Madrid win!'

            ELSE 'Tie!'
        END AS outcome

    FROM matches_spain

    WHERE hometeam_id = 8634
      AND awayteam_id = 8633;

## 🔍 Explanation

This query identifies the outcome of **El Clásico** matches where:

- 🔵🔴 Barcelona is the home team
- ⚪ Real Madrid is the away team

The query uses multiple `CASE` statements to identify the teams and determine the winner.

## 1️⃣ Identify the Home Team

    CASE
        WHEN hometeam_id = 8634 THEN 'FC Barcelona'
        ELSE 'Real Madrid CF'
    END AS home

The `hometeam_id` is checked to determine which team is playing at home.

Since the query is filtered to:

    WHERE hometeam_id = 8634
      AND awayteam_id = 8633

we know that Barcelona is the home team.

The result is stored in a column called `home`.

## 2️⃣ Identify the Away Team

    CASE
        WHEN awayteam_id = 8634 THEN 'FC Barcelona'
        ELSE 'Real Madrid CF'
    END AS away

This `CASE` statement identifies the away team.

Because the `WHERE` clause specifies:

    awayteam_id = 8633

the away team is Real Madrid CF.

## 3️⃣ 🏆 Identify the Winner

The most important part of the query is the final `CASE` statement.

    CASE
        WHEN home_goal > away_goal
             AND hometeam_id = 8634
            THEN 'Barcelona win!'

        WHEN home_goal < away_goal
             AND awayteam_id = 8633
            THEN 'Real Madrid win!'

        ELSE 'Tie!'
    END AS outcome

Two conditions are checked.

### 🔵🔴 Barcelona Win

    WHEN home_goal > away_goal
         AND hometeam_id = 8634
        THEN 'Barcelona win!'

For Barcelona to win:

1. Barcelona must be the home team.
2. The home team must score more goals than the away team.

Both conditions must be `TRUE` because they are connected with `AND`.

### ⚪ Real Madrid Win

    WHEN home_goal < away_goal
         AND awayteam_id = 8633
        THEN 'Real Madrid win!'

For Real Madrid to win:

1. Real Madrid must be the away team.
2. The away team must score more goals than the home team.

Again, both conditions must be `TRUE`.

### 🤝 Tie

    ELSE 'Tie!'

If neither winning condition is satisfied, the match is classified as a tie.

Because the query only includes Barcelona vs. Real Madrid matches, the remaining possibility is that both teams scored the same number of goals.

## 📊 CASE Logic

| Condition | Result |
|---|---|
| `home_goal > away_goal AND hometeam_id = 8634` | 🔵🔴 Barcelona win! |
| `home_goal < away_goal AND awayteam_id = 8633` | ⚪ Real Madrid win! |
| Otherwise | 🤝 Tie! |

## 🧠 Understanding Multiple Conditions

This exercise demonstrates how multiple conditions can be combined inside a `CASE` statement.

The general structure is:

    CASE
        WHEN condition_1 AND condition_2 THEN result_1
        WHEN condition_3 AND condition_4 THEN result_2
        ELSE result_3
    END AS outcome

The `AND` operator means **both conditions must be true**.

For example:

    home_goal > away_goal
    AND
    hometeam_id = 8634

means:

> Barcelona is the home team **AND** the home team scored more goals.

Only when both conditions are true does SQL return:

    'Barcelona win!'

## 🔎 Filtering the Rivalry

The `WHERE` clause ensures that we are only looking at matches between the two teams:

    WHERE hometeam_id = 8634
      AND awayteam_id = 8633;

This means:

- `8634` → FC Barcelona 🔵🔴
- `8633` → Real Madrid CF ⚪

Therefore, the query specifically returns matches where:

**Barcelona 🏠 vs. Real Madrid ✈️**

## ⚠️ Important Observation

Because the `WHERE` clause already guarantees that:

    hometeam_id = 8634

and:

    awayteam_id = 8633

the team-ID checks inside the final `CASE` are somewhat redundant for this particular query.

However, they are useful for demonstrating how to combine **team identity + match result** within a `CASE` statement.

## 💻 Complete Query

    SELECT
        date,

        CASE
            WHEN hometeam_id = 8634 THEN 'FC Barcelona'
            ELSE 'Real Madrid CF'
        END AS home,

        CASE
            WHEN awayteam_id = 8634 THEN 'FC Barcelona'
            ELSE 'Real Madrid CF'
        END AS away,

        -- Identify possible home match outcomes
        CASE
            WHEN home_goal > away_goal
                 AND hometeam_id = 8634
                THEN 'Barcelona win!'

            WHEN home_goal < away_goal
                 AND awayteam_id = 8633
                THEN 'Real Madrid win!'

            ELSE 'Tie!'
        END AS outcome

    FROM matches_spain

    WHERE hometeam_id = 8634
      AND awayteam_id = 8633;

# 🎯 Key Takeaways

- `CASE` can contain multiple `WHEN` conditions.
- Use `AND` when **both conditions must be true**.
- `CASE` can combine numerical comparisons with categorical conditions.
- `home_goal > away_goal` identifies a home-team win.
- `home_goal < away_goal` identifies an away-team win.
- `ELSE` can handle the remaining outcome, such as a tie.
- `WHERE` can restrict the query to a specific matchup.
- Team IDs can be combined with goal comparisons to identify the winner.
- Multiple `CASE` statements can be used in the same `SELECT` statement.

# 🧩 Quick Reference

### Multiple Conditions

    CASE
        WHEN condition_1 AND condition_2 THEN 'Result 1'
        WHEN condition_3 AND condition_4 THEN 'Result 2'
        ELSE 'Other'
    END AS outcome

### Home-Team Win

    CASE
        WHEN home_goal > away_goal THEN 'Home win'
        ELSE 'Not a home win'
    END

### Away-Team Win

    CASE
        WHEN home_goal < away_goal THEN 'Away win'
        ELSE 'Not an away win'
    END

### Specific Team + Result

    CASE
        WHEN hometeam_id = team_id
             AND home_goal > away_goal
            THEN 'Team win!'

        WHEN awayteam_id = team_id
             AND away_goal > home_goal
            THEN 'Team win!'

        ELSE 'Not a win'
    END AS outcome
