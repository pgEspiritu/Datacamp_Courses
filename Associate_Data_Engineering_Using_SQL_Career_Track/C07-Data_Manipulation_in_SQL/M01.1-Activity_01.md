# Basic CASE Statements

## What is your favorite team?

The *European Soccer Database* contains data about 12,800 matches from 11 countries played between 2011–2015! Throughout this course, you will be shown filtered versions of the tables in this database in order to better explore their contents.

In this exercise, you will identify matches played between *FC Schalke 04* and *FC Bayern Munich*.

There are 2 teams identified in each match in the `hometeam_id` and `awayteam_id` columns, available to you in the filtered `matches_germany` table.

The ID can join to the `team_api_id` column in the `teams_germany` table, but you cannot perform a join on both at the same time.

However, you can perform this operation using a `CASE` statement once you've identified the `team_api_id` associated with each team.

## Instructions

**100 XP**

- Create a `CASE` statement that identifies whether a match in Germany included `FC Bayern Munich`, `FC Schalke 04`, or `Other` as the home team.

## Solution

    -- Identify the home team as Bayern Munich, Schalke 04, or Other

    SELECT
        CASE
            WHEN hometeam_id = 10189 THEN 'FC Schalke 04'
            WHEN hometeam_id = 9823 THEN 'FC Bayern Munich'
            ELSE 'Other'
        END AS home_team,
        COUNT(id) AS total_matches
    FROM matches_germany
    GROUP BY home_team;

## Explanation

The `CASE` statement checks the `hometeam_id` for each match:

| `hometeam_id` | `home_team` |
|---:|---|
| `10189` | FC Schalke 04 |
| `9823` | FC Bayern Munich |
| Any other ID | Other |

### How it works

    CASE
        WHEN hometeam_id = 10189 THEN 'FC Schalke 04'
        WHEN hometeam_id = 9823 THEN 'FC Bayern Munich'
        ELSE 'Other'
    END AS home_team

- `WHEN` checks whether the condition is true.
- `THEN` specifies the value to return when the condition is true.
- `ELSE` provides a value for all other cases.
- `END` closes the `CASE` statement.
- `AS home_team` gives the resulting column a name.

The `COUNT(id)` then counts how many matches fall into each category.

Finally, `GROUP BY home_team` groups the results by the category created by the `CASE` statement.

## Key Takeaway

A `CASE` statement can be used to **convert IDs or other values into meaningful categories** without requiring a separate join.

In this example:

    hometeam_id
        ↓
    CASE statement
        ↓
    home_team
        ↓
    COUNT(id)
        ↓
    total_matches
