# 🏠 Get Team Names with a Subquery

## 📝 Exercise 2/2 — Get Both Home and Away Team Names

### 🎯 Original Question

Add a second subquery to the `FROM` statement to get the **away team name**, changing only the `hometeam_id`.

Then:

- Left join the **home-team subquery** to the `match` table using `id`.
- Add a second **away-team subquery**.
- Left join the **away-team subquery** to the `match` table using `id`.
- Display the date, home team, away team, home goals, and away goals.

---

# ✅ Answer

    SELECT
        m.date,

        -- Get the home team name and away team name from the subqueries
        home.hometeam_name,
        away.awayteam_name,

        m.home_goal,
        m.away_goal

    FROM match AS m

    -- Join the home subquery to the match table
    LEFT JOIN (
        SELECT
            match.id,
            team.team_long_name AS hometeam_name
        FROM match
        LEFT JOIN team
            ON match.hometeam_id = team.team_api_id
    ) AS home
        ON home.id = m.id

    -- Join the away subquery to the match table
    LEFT JOIN (
        SELECT
            match.id,
            team.team_long_name AS awayteam_name
        FROM match
        LEFT JOIN team

            -- Get the away team ID in the subquery
            ON match.awayteam_id = team.team_api_id
    ) AS away
        ON away.id = m.id;

---

# 🔍 Step-by-Step Explanation

## 1. Start with the `match` table

    FROM match AS m

The `match` table provides the main match information:

- `date`
- `home_goal`
- `away_goal`
- `id`

The `id` is important because it allows us to connect the two subqueries back to the original match.

---

## 2. Create the Home-Team Subquery

    LEFT JOIN (
        SELECT
            match.id,
            team.team_long_name AS hometeam_name
        FROM match
        LEFT JOIN team
            ON match.hometeam_id = team.team_api_id
    ) AS home

This subquery gets:

    match.id
    +
    home team name

The important relationship is:

    match.hometeam_id = team.team_api_id

The result is given the alias:

    AS home

So the main query can reference:

    home.hometeam_name

---

## 3. Join the Home Subquery to `match`

    ON home.id = m.id

The subquery is connected to the original `match` table using the match ID.

Think:

    match.id
       ↓
    home.id

This ensures that the home team name belongs to the correct match.

---

## 4. Create the Away-Team Subquery

The second subquery follows almost exactly the same structure as the first one.

    LEFT JOIN (
        SELECT
            match.id,
            team.team_long_name AS awayteam_name
        FROM match
        LEFT JOIN team
            ON match.awayteam_id = team.team_api_id
    ) AS away

### 🔑 The Important Difference

For the home team:

    match.hometeam_id = team.team_api_id

For the away team:

    match.awayteam_id = team.team_api_id

Only the team ID being used changes.

---

## 5. Join the Away Subquery to `match`

    ON away.id = m.id

Again, the subquery is connected using the match ID.

    match.id
       ↓
    away.id

This makes sure that the away team belongs to the same match.

---

# 🧠 Why Two Subqueries?

The `match` table contains **two different team IDs**:

    hometeam_id
    awayteam_id

But both IDs refer to the same `team` table.

We therefore need to retrieve the team name twice:

    match.hometeam_id
          ↓
    team.team_api_id
          ↓
    hometeam_name


    match.awayteam_id
          ↓
    team.team_api_id
          ↓
    awayteam_name

The two subqueries give us two separate versions of the `team` information.

---

The complete query can be visualized as:

    match AS m
         │
         ├───────────────┐
         │               │
         ▼               ▼
    home subquery    away subquery
         │               │

    hometeam_name    awayteam_name

                 ▼
             Final Result

# ⚠️ Important JOIN Warning

The most important part of this exercise is understanding the different join conditions.

### Inside the home subquery:

    ON match.hometeam_id = team.team_api_id

### Inside the away subquery:

    ON match.awayteam_id = team.team_api_id

### Connecting the home subquery to `match`:

    ON home.id = m.id

### Connecting the away subquery to `match`:

    ON away.id = m.id

These are **different relationships**.

---

# 🧠 Mental Model

Remember the process as:

    1. Get home team name
           ↓
    2. Get away team name
           ↓
    3. Connect both results using match.id
           ↓
    4. Display the complete match information

Or more simply:

    HOME ID → HOME NAME
    AWAY ID → AWAY NAME
    MATCH ID → CONNECT EVERYTHING

---

# 🔑 Key Takeaways

- A single `team` table contains both home and away teams.
- The `match` table has separate IDs for the home and away teams.
- We can use **two subqueries** to retrieve the two team names.
- The home subquery uses `hometeam_id`.
- The away subquery uses `awayteam_id`.
- Both subqueries return the match `id`.
- Both subqueries are joined back to `match` using `id`.
- `LEFT JOIN` helps preserve the rows from the main `match` table.
- The aliases `home` and `away` make it easy to reference each subquery.

## 📌 Quick Reference

    -- Connect away subquery
    away.id = m.id
