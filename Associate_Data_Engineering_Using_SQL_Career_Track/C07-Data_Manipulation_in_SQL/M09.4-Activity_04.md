# 🧩 Nest a Subquery in FROM

## 🎯 Main Question

**What's the average number of matches per season where a team scored 5 or more goals? How does this differ by country?**

We have now reached **Step 3 of 3**.

The first two steps prepared the data:

    Step 1 → Find matches where at least one team scored 5+ goals
    Step 2 → Count those matches by country and season
    Step 3 → Calculate the average number of those matches per country

This final step uses **nested subqueries in the `FROM` clause** and then joins the result to the `country` table.

---

# 📝 Instructions 3/3

### ❓ Question

- Finally, declare the same query from Step 2 as a subquery in `FROM` with the alias `outer_s`.
- Left join it to the `country` table using the outer query's `country_id` column.
- Calculate an `AVG` of high-scoring `matches` per country in the main query.

### ✅ Answer

    SELECT
        c.name AS country,

        -- Calculate the average matches per season
        AVG(outer_s.matches) AS avg_seasonal_high_scores

    FROM country AS c

    -- Left join outer_s to country
    LEFT JOIN (
        SELECT
            country_id,
            season,
            COUNT(id) AS matches
        FROM (
            SELECT
                country_id,
                season,
                id
            FROM match
            WHERE home_goal >= 5
               OR away_goal >= 5
        ) AS inner_s

        -- Group qualifying matches by country and season
        GROUP BY country_id, season
    ) AS outer_s

    ON c.id = outer_s.country_id

    GROUP BY country;

# 🔍 Step-by-Step Explanation

## 1️⃣ The innermost subquery: `inner_s`

The deepest query is:

    SELECT
        country_id,
        season,
        id
    FROM match
    WHERE home_goal >= 5
       OR away_goal >= 5

This identifies matches where **at least one team scored 5 or more goals**.

For example:

| country_id | season | id |
|---:|:---|---:|
| 1 | 2012/2013 | 101 |
| 1 | 2012/2013 | 105 |
| 1 | 2013/2014 | 203 |
| 2 | 2012/2013 | 301 |

This subquery is given the alias:

    AS inner_s

So we can think of it as:

    inner_s = qualifying high-scoring matches

---

# 2️⃣ The middle subquery: `outer_s`

The next query uses `inner_s`:

    SELECT
        country_id,
        season,
        COUNT(id) AS matches
    FROM (
        ...
    ) AS inner_s
    GROUP BY country_id, season

This counts the qualifying matches for each **country and season**.

For example:

| country_id | season | matches |
|---:|:---|---:|
| 1 | 2012/2013 | 2 |
| 1 | 2013/2014 | 1 |
| 2 | 2012/2013 | 3 |
| 2 | 2013/2014 | 2 |

This entire query is then given the alias:

    AS outer_s

So:

    outer_s = number of high-scoring matches per country per season

---

# 3️⃣ Why is it called `outer_s`?

The names help us distinguish the different query levels:

    inner_s
        ↓
    Finds qualifying matches

    outer_s
        ↓
    Counts qualifying matches by country and season

    Main query
        ↓
    Calculates the average per country

💡 The `s` is simply part of the alias name. It does not have a special SQL meaning.

---

# 4️⃣ Start with the `country` table

The main query begins with:

    FROM country AS c

We need the country table because the result should display the **country name**, not just the numeric `country_id`.

The main query selects:

    c.name AS country

For example:

| id | name |
|---:|:---|
| 1 | England |
| 2 | Netherlands |
| 3 | Spain |

---

# 5️⃣ LEFT JOIN `outer_s` to `country`

We use:

    LEFT JOIN (...) AS outer_s
        ON c.id = outer_s.country_id

The join connects:

    country.id
          ↓
    outer_s.country_id

This allows us to associate each country's name with its calculated number of high-scoring matches.

---

# 🧠 Why use LEFT JOIN?

A `LEFT JOIN` keeps **all countries from the `country` table**, even if a country has no qualifying high-scoring matches.

Conceptually:

    country
       ↓
    LEFT JOIN
       ↓
    outer_s

Countries with matching records in `outer_s` get their calculated values.

Countries without matching records can still appear, with `NULL` values from `outer_s`.

---

# 6️⃣ Calculate the average

The main calculation is:

    AVG(outer_s.matches) AS avg_seasonal_high_scores

Remember that `outer_s.matches` represents:

> Number of matches where at least one team scored 5+ goals in a particular country and season.

So:

    AVG(outer_s.matches)

calculates the **average number of high-scoring matches per season for each country**.

For example, suppose one country has:

| season | matches |
|:---|---:|
| 2012/2013 | 2 |
| 2013/2014 | 4 |
| 2014/2015 | 3 |

Then the average is:

    (2 + 4 + 3) / 3 = 3

So the result for that country would be:

| country | avg_seasonal_high_scores |
|:---|---:|
| Example Country | 3.00 |

---

# 7️⃣ GROUP BY country

Finally:

    GROUP BY country;

This tells SQL to calculate the average separately for each country.

Without the `GROUP BY`, SQL would calculate one overall average.

With:

    GROUP BY country

we get:

    Country A → average high-scoring matches per season
    Country B → average high-scoring matches per season
    Country C → average high-scoring matches per season

---

# 🧩 Understanding All Three Query Levels

This is the most important part of the exercise.

### Level 1 — `inner_s`

    SELECT country_id, season, id
    FROM match
    WHERE home_goal >= 5
       OR away_goal >= 5

🎯 **Purpose:** Find high-scoring matches.

---

### Level 2 — `outer_s`

    SELECT
        country_id,
        season,
        COUNT(id) AS matches
    FROM (...)
    GROUP BY country_id, season

🎯 **Purpose:** Count high-scoring matches for each country and season.

---

### Level 3 — Main Query

    SELECT
        c.name AS country,
        AVG(outer_s.matches) AS avg_seasonal_high_scores
    FROM country AS c
    LEFT JOIN (...)
        ON c.id = outer_s.country_id
    GROUP BY country;

🎯 **Purpose:** Calculate the average number of high-scoring matches per season for each country.

---

# 🔄 Complete Data Flow

Think of the entire query as a pipeline:

    match
      ↓
    Filter:
    home_goal >= 5 OR away_goal >= 5
      ↓
    inner_s
      ↓
    COUNT(id)
      ↓
    GROUP BY country_id, season
      ↓
    outer_s
      ↓
    LEFT JOIN country
      ↓
    GROUP BY country
      ↓
    AVG(matches)
      ↓
    Final country-level result

💡 This is a great example of why nested subqueries can be useful.

Each layer performs **one logical transformation**.

---

# 🧠 Why Not Just Use AVG(COUNT())?

The problem requires an average of counts.

Conceptually, we want:

    AVG(
        COUNT(high_scoring_matches)
    )

But SQL generally cannot simply perform:

    AVG(COUNT(id))

at the same query level because `COUNT()` is already an aggregate operation.

Instead, we use multiple query levels:

    COUNT()
        ↓
    subquery
        ↓
    AVG()

This allows the result of `COUNT()` to become input for `AVG()`.

---

# 🔑 Key Takeaways

- 🧩 A subquery can be placed inside another subquery.
- 🔎 `inner_s` filters the original matches.
- 🔢 `outer_s` counts qualifying matches by country and season.
- 🌍 The main query joins `outer_s` to the `country` table.
- 📊 `AVG(outer_s.matches)` calculates the average number of qualifying matches per season.
- 🔗 `LEFT JOIN` connects the calculated results to country names.
- 📦 Each query level performs a separate transformation.
- `GROUP BY country_id, season` creates seasonal counts.
- `GROUP BY country` creates country-level averages.
- This approach is useful when you need an **aggregate of an aggregate**, such as an `AVG` of a `COUNT`.

    INNER SUBQUERY
        ↓
    Filter rows
        ↓
    MIDDLE SUBQUERY

        ↓

        ↓

        ↓

    📊 AVERAGE
    Average those seasonal counts by country

        ↓

    🌍 DISPLAY
    Show the country name and average
