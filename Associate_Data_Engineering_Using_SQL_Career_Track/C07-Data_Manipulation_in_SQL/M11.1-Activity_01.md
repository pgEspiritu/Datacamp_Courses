# 🏠 Get Team Names with a Subquery

## 📌 Overview

Let's solve a problem we've encountered a few times in this course:

> **How do you get both the home and away team names into one final query result?**

There are **4 techniques** that can be used:

1. 🔗 Joins
2. 🔍 Subqueries
3. 🔄 Correlated subqueries
4. 🧩 Common Table Expressions (CTEs)

This exercise focuses on using a **subquery in `FROM`** to get the home team name.

The next exercises will use other techniques to produce a similar result.

---

# 📝 Exercise 1/2 — Get the Home Team

## 🎯 Question

Create a query that joins `match` to `team` to get the identity of the **home team**.

This query will become the subquery used in the next step.

## ⚠️ Important Warning

If your code times out, you probably made a mistake in the `JOIN`.

Joining on the wrong fields can create a huge number of rows and make the query extremely slow.

Always carefully check your `ON` condition.

---

# 💡 Understanding the Tables

The `match` table contains:

- `id` → Match ID
- `hometeam_id` → ID of the home team
- `awayteam_id` → ID of the away team

The `team` table contains:

- `team_api_id` → Team ID
- `team_long_name` → Full team name

The relationship is:

    match.hometeam_id
        ↓
    team.team_api_id

Therefore:

    m.hometeam_id = t.team_api_id

---

# ✅ Answer

    SELECT
        m.id,
        t.team_long_name AS hometeam
    FROM match AS m
    INNER JOIN team AS t
        ON m.hometeam_id = t.team_api_id;

---

# 🔍 Step-by-Step Explanation

### 1. Start with the `match` table

    FROM match AS m

`m` is an alias for the `match` table.

This allows us to write:

    m.id
    m.hometeam_id

instead of repeatedly writing:

    match.id
    match.hometeam_id

---

### 2. Join the `team` table

    INNER JOIN team AS t

`t` is an alias for the `team` table.

We need this table because `match` contains the **team ID**, while `team` contains the **team name**.

---

### 3. Match the correct IDs

    ON m.hometeam_id = t.team_api_id

This is the most important part of the query.

The home team ID stored in `match` must match the team ID stored in `team`.

### Relationship

    match
    ┌────────────────┐
    │ hometeam_id    │
    └───────┬────────┘
            │
            │ =
            ▼
    team
    ┌────────────────┐
    │ team_api_id    │
    └────────────────┘

⚠️ **Do not join `hometeam_id` to an unrelated column.**

An incorrect join can produce an unnecessarily large result and may cause the query to time out.

---

### 4. Select the match ID

    m.id

This identifies the match.

---

### 5. Select the team name

    t.team_long_name AS hometeam

The `team_long_name` column contains the team's full name.

We rename it to:

    hometeam

This makes the result easier to understand.

---

# 📊 Result Structure

The query produces something similar to:

| id | hometeam |
|---:|---|
| 1 | KRC Genk |
| 2 | Beerschot AC |
| 3 | SV Zulte-Waregem |
| 4 | Sporting Lokeren |

The exact rows depend on the database.

---

# 🧠 Why This Becomes a Subquery

This query is only the **first step**.

We currently have:

    match ID + home team name

The next step will use this query as a **subquery in `FROM`**.

Conceptually:

    ┌─────────────────────────────┐
    │ match + team                │
    │                             │
    │ id | hometeam               │
    └──────────────┬──────────────┘
                   │
                   ▼
             Subquery in FROM
                   │
                   ▼
             Final query
                   │
                   ▼
       Home team + Away team

The goal is eventually to have **both team names in one result**.

---

# 🔑 Key Takeaways

- `match.hometeam_id` identifies the home team.
- `team.team_api_id` identifies the team in the `team` table.
- The correct join condition is:

    ON m.hometeam_id = t.team_api_id

- `t.team_long_name` provides the actual team name.
- `AS hometeam` gives the result column a meaningful name.
- The query can later be placed inside `FROM` as a subquery.
- ⚠️ Always check your `JOIN` fields carefully because an incorrect join can create a huge result set and cause a timeout.

## 🧠 Mental Model

    match.hometeam_id
          ↓
    team.team_api_id
          ↓
    team.team_long_name
          ↓
    AS hometeam

**ID → Match → Team Table → Team Name**
