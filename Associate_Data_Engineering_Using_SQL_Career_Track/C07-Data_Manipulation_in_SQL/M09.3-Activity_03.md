# 🧩 Nest a Subquery in FROM

## 🎯 Main Question

**What's the average number of matches per season where a team scored 5 or more goals? How does this differ by country?**

We are solving this problem step by step using **nested subqueries**.

The previous step identified matches where **at least one team scored 5 or more goals**. In this step, we will take that query and turn it into a **subquery in the `FROM` statement**.

Then, we will count how many qualifying matches occurred for each **country and season**.

💡 **Current workflow:**

    Step 1 → Find matches where a team scored 5+ goals
    Step 2 → Count those matches by country and season
    Step 3 → Calculate the average number of matches per season

---

# 📝 Instructions 2/3

### ❓ Question

- Turn the query from the previous step into a **subquery** in the `FROM` statement.
- `COUNT` the `match` table `id`s generated in the previous step.

### ✅ Answer

    -- Count match IDs
    SELECT
        country_id,
        season,
        COUNT(id) AS matches

    -- Set up and alias the subquery
    FROM (
        SELECT
            country_id,
            season,
            id
        FROM match
        WHERE home_goal >= 5
           OR away_goal >= 5
    ) AS subquery

    GROUP BY country_id, season;

---

# 🔍 Step-by-Step Explanation

## 1️⃣ Start with the previous query

The inner query is the query from **Step 1**:

    SELECT
        country_id,
        season,
        id
    FROM match
    WHERE home_goal >= 5
       OR away_goal >= 5

This produces a list containing only matches where **at least one team scored 5 or more goals**.

For example:

| country_id | season | id |
|---:|:---|---:|
| 1 | 2012/2013 | 101 |
| 1 | 2012/2013 | 105 |
| 1 | 2013/2014 | 203 |
| 2 | 2012/2013 | 301 |

The actual dataset will contain many more rows.

---

# 2️⃣ Put the previous query inside `FROM`

We place the previous query inside parentheses:

    FROM (
        SELECT
            country_id,
            season,
            id
        FROM match
        WHERE home_goal >= 5
           OR away_goal >= 5
    ) AS subquery

This makes the result of the inner query behave like a **temporary table**.

### 🧠 Think of it this way:

    match
       ↓
    Filter matches
    where a team scored 5+
       ↓
    subquery
       ↓
    Count the matches

---

# 3️⃣ Give the subquery an alias

We use:

    AS subquery

The alias gives the temporary result a name.

So:

    FROM (
        ...
    ) AS subquery

means:

> "Take the result of this query and temporarily call it `subquery`."

💡 A subquery in the `FROM` clause should have an alias so the outer query can refer to it as a table-like result.

---

# 4️⃣ Count the match IDs

The outer query uses:

    COUNT(id) AS matches

This counts the number of qualifying match IDs produced by the subquery.

For example, if the subquery produces:

| country_id | season | id |
|---:|:---|---:|
| 1 | 2012/2013 | 101 |
| 1 | 2012/2013 | 105 |
| 1 | 2012/2013 | 110 |

then:

    COUNT(id)

returns:

    3

So `matches` represents the **number of matches where at least one team scored 5 or more goals**.

---

# 5️⃣ Group by country and season

We use:

    GROUP BY country_id, season;

This means we calculate the count separately for every combination of:

- 🌍 `country_id`
- 📅 `season`

For example:

| country_id | season | matches |
|---:|:---|---:|
| 1 | 2012/2013 | 3 |
| 1 | 2013/2014 | 2 |
| 2 | 2012/2013 | 1 |
| 2 | 2013/2014 | 4 |

Now we have the **number of qualifying matches per country per season**.

---

# 🧩 Why Do We Need This Extra Step?

The original question asks for:

> **The average number of matches per season**

But we cannot simply calculate:

    AVG(COUNT(id))

at the same query level.

Instead, we need to perform the calculations in stages.

### Step 1 — Filter

Find matches where a team scored 5+ goals.

    WHERE home_goal >= 5
       OR away_goal >= 5

### Step 2 — Count

Count those matches for each country and season.

    COUNT(id)

### Step 3 — Average

In the next step, calculate the average of those seasonal counts.

💡 This is exactly why nested subqueries are useful: **each query level performs one transformation.**

---

# 🧠 Mental Model

Think of the query as two layers:

    ┌─────────────────────────────────────┐
    │ OUTER QUERY                         │
    │                                     │
    │ COUNT(id)                           │
    │ GROUP BY country_id, season         │
    │                                     │
    │        ↑                            │
    │        │                            │
    │   Filtered match list               │
    │        │                            │
    │        ↓                            │
    │ INNER SUBQUERY                      │
    │                                     │
    │ SELECT country_id, season, id       │
    │ FROM match                           │
    │ WHERE home_goal >= 5                │
    │    OR away_goal >= 5                │
    └─────────────────────────────────────┘

### In simple terms:

**Inner query:**  
🔎 Find the qualifying matches.

**Outer query:**  
🔢 Count those matches by country and season.

---

# 🔑 Key Takeaways

- A query can be placed inside the `FROM` clause as a **subquery**.
- A `FROM` subquery behaves like a temporary table.
- The subquery must be given an alias:
  
    AS subquery

- `COUNT(id)` counts the qualifying matches.
- `GROUP BY country_id, season` produces one count for each country-season combination.
- This step produces the **number of qualifying matches per season for each country**.
- The next step can use these counts to calculate the **average number of matches per season**.

---

# ⚡ Quick Reference

### FROM subquery structure

    SELECT
        ...
    FROM (
        SELECT
            ...
        FROM table
        WHERE condition
    ) AS subquery;

### Count after filtering

    SELECT
        country_id,
        season,
        COUNT(id) AS matches
    FROM (
        SELECT
            country_id,
            season,
            id
        FROM match
        WHERE home_goal >= 5
           OR away_goal >= 5
    ) AS subquery
    GROUP BY country_id, season;

### 🧩 Overall pattern

    INNER QUERY
    ↓
    Filter rows
    ↓
    FROM subquery
    ↓
    COUNT rows
    ↓
    GROUP BY country + season
    ↓
    Next step: calculate AVG(matches)
