# Data Engineering and Big Data

## Course Overview

- **Type:** Conceptual course; no coding required.
- **Purpose:** Build enough understanding of data engineering to communicate with data engineering teams.
- **Course chapters:**
  1. Data engineering, big data, data scientists, and data pipelines
  2. Data storage, data structures, SQL, and storage solutions
  3. Data processing, scheduling, parallel computing, and cloud computing
- **Example company:** Spotflix, a fictional music streaming company.

## Data Workflow

Data generally flows through **four steps**:

1. **Collect & Ingest**
   - Collect data from sources such as web traffic, surveys, and media consumption.
   - Store the collected data in raw format.
2. **Prepare**
   - Clean and organize data.
   - Find missing values.
   - Find duplicate values.
   - Convert data into a more organized format.
3. **Exploit**
   - Explore data.
   - Visualize data.
   - Build dashboards.
   - Track changes.
   - Compare datasets.
4. **Experiment / Predict**
   - Run experiments.
   - Evaluate different options.
   - Build predictive models.
   - Example: forecast stock prices.

**Workflow:** Collect & Ingest → Prepare → Exploit → Experiment / Predict

## Data Engineers

Data engineers are primarily responsible for the **first step** of the workflow: **ingesting and storing collected data**.

They lay the groundwork for:

- Data analysts
- Data scientists
- Machine learning engineers

If data is scattered, corrupted, or difficult to access, there is little useful data available for preparation, exploration, or experimentation.

### Core Objective

> Deliver the **correct data**, in the **right form**, to the **right people**, as **efficiently as possible**.

### Responsibilities

- Ingest data from different sources.
- Optimize databases for analysis.
- Manage data corruption.
- Develop, construct, test, and maintain data architectures.
- Build and maintain databases.
- Build large-scale processing systems.
- Process and handle massive amounts of data.
- Build data pipelines.

## Big Data

The growth of **big data** has increased the demand for data engineers.

### Definition

**Big data** is data so large that it is difficult to process using traditional data management methods.

### Major Sources of Big Data

In order of volume, major sources include:

1. **Sensors and device data**
2. **Social media data**
3. **Enterprise data**
4. **VoIP data**

## The Five Vs of Big Data

Big data is commonly characterized by **five Vs**:

| V | Meaning | Description |
|---|---|---|
| **Volume** | Quantity | The quantity of data points |
| **Variety** | Type | The type and nature of data |
| **Velocity** | Speed | How fast data is generated and processed |
| **Veracity** | Trustworthiness | How trustworthy the data sources are |
| **Value** | Actionability | How useful or actionable the data is |
