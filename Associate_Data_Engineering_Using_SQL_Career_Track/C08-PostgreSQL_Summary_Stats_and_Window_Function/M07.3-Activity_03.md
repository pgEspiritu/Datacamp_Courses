# Minimum Country Medals by Year

In the previous exercises, we used `MAX()` and `SUM()` as window functions to calculate running maximums and running totals.

We can also use other aggregate functions, such as `MIN()`, as window functions.

A **running minimum** identifies the lowest value encountered so far as we move through an ordered set of rows.

In this exercise, we will calculate the minimum number of gold medals earned by France in each Olympic year from 2000 onward.

## Instructions

**100 XP**

Return the following columns:
- `Year` – the Olympic year.
- `Medals` – the number of gold medals earned by France in that year.
- `Min_Medals` – the minimum number of gold medals earned so far.

Order the results by year in ascending order.

## SQL Solution

```sql
WITH France_Medals AS (
    SELECT
        Year,
        COUNT(*) AS Medals
    FROM Summer_Medals
    WHERE
        Country = 'FRA'
        AND Medal = 'Gold'
        AND Year >= 2000
    GROUP BY Year
)
SELECT
    Year,
    Medals,
    MIN(Medals) OVER (
        ORDER BY Year ASC
    ) AS Min_Medals
FROM France_Medals
ORDER BY Year ASC;
```

## Explanation

### 1. Create the CTE: `France_Medals`

```sql
WITH France_Medals AS (
    SELECT
        Year,
        COUNT(*) AS Medals
    FROM Summer_Medals
    WHERE
        Country = 'FRA'
        AND Medal = 'Gold'
        AND Year >= 2000
    GROUP BY Year
)
```

This Common Table Expression (CTE) calculates the total number of gold medals earned by France in each Olympic year from 2000 onward.

- `WHERE Country = 'FRA'` filters the records to France.
- `Medal = 'Gold'` includes only gold medal records.
- `Year >= 2000` limits the records to 2000 onward.
- `COUNT(*)` counts the gold medal records.
- `GROUP BY Year` calculates the total medals separately for each year.

The resulting CTE contains one row per Olympic year and its corresponding gold medal count.

### 2. Calculate the running minimum

```sql
MIN(Medals) OVER (
    ORDER BY Year ASC
) AS Min_Medals
```

This is the main part of the exercise.

- `MIN(Medals)` identifies the lowest medal count.
- `OVER()` applies the calculation as a window function, preserving individual rows.
- `ORDER BY Year ASC` processes the years chronologically, from oldest to newest.
- `AS Min_Medals` assigns a descriptive name to the resulting column.

As each year is processed, SQL compares the current year's medal count with the lowest count encountered in previous years.

### 3. Sort the final results

```sql
ORDER BY Year ASC;
```

This sorts the displayed results chronologically, from the earliest year to the latest year.

## Example of a Running Minimum

Suppose France earned the following gold medal counts:

| Year | Medals |
|---|---:|
| 2000 | 13 |
| 2004 | 11 |
| 2008 | 16 |
| 2012 | 10 |
| 2016 | 12 |

The running minimum would be:

| Year | Medals | Min_Medals |
|---|---:|---:|
| 2000 | 13 | 13 |
| 2004 | 11 | 11 |
| 2008 | 16 | 11 |
| 2012 | 10 | 10 |
| 2016 | 12 | 10 |

Notice how `Min_Medals` changes only when the current year's medal count is lower than the previous minimum.

- In 2000, the minimum is 13.
- In 2004, the count drops to 11, establishing a new minimum.
- In 2008, the count increases to 16, so the minimum remains 11.
- In 2012, the count drops to 10, establishing a new minimum.
- In 2016, the count increases to 12, so the minimum remains 10.

## Key Takeaways

| SQL Function / Clause | Purpose |
|---|---|
| `MIN()` | Finds the lowest value |
| `MIN() OVER()` | Calculates a minimum while preserving individual rows |
| `ORDER BY Year ASC` | Processes records chronologically |
| `GROUP BY Year` | Calculates medal totals separately for each year |

**Remember:** `MIN(Medals) OVER (ORDER BY Year ASC)` calculates a running minimum. Unlike `SUM()`, which accumulates values, or `MAX()`, which tracks the highest value, `MIN()` retains the lowest value encountered so far.

You can apply the same concept to other datasets, such as tracking the lowest annual expenses, minimum monthly sales, or lowest recorded temperature over time.
