# Paging Events

## Objective

Divide the 666 unique events in the Summer Olympics dataset into exactly 111 approximately equal-sized groups, arranged alphabetically by event name.

Since 666 is evenly divisible by 111, each group will contain exactly **6 events**.

## SQL Solution

```sql
WITH Events AS (
    SELECT DISTINCT
        Event
    FROM Summer_Medals
)

SELECT
    -- Split up the distinct events into 111 unique groups
    Event,
    NTILE(111) OVER (
        ORDER BY Event ASC
    ) AS Page
FROM Events
ORDER BY Event ASC;
```

## Explanation

### 1. Create the CTE: `Events`

```sql
WITH Events AS (
    SELECT DISTINCT
        Event
    FROM Summer_Medals
)
```

This Common Table Expression (CTE) retrieves all unique Olympic events.

- `SELECT DISTINCT Event` removes duplicate event names.
- `FROM Summer_Medals` retrieves the records from the dataset.

The result contains 666 distinct events.

### 2. Apply `NTILE(111)`

```sql
NTILE(111) OVER (
    ORDER BY Event ASC
) AS Page
```

- `NTILE(111)` divides the 666 events into exactly 111 groups.
- `ORDER BY Event ASC` arranges the events alphabetically before distributing them.
- `AS Page` assigns a name to the resulting group number.

Since there are 666 events and 111 groups:

\[
666 \div 111 = 6
\]

Each page will contain exactly 6 events.

### 3. Sort the final output

```sql
ORDER BY Event ASC;
```

This displays the events in alphabetical order.

| Event | Page |
|---|---:|

| 100M Freestyle | 1 |

| ... | ... |
| Last alphabetical events | 111 |

*Illustrative output only. Actual event names and page assignments depend on the dataset's alphabetical ordering.*

## Key Takeaways

- `DISTINCT` ensures that each event appears only once before paging.
- `NTILE(111)` divides the events into 111 groups.
- `ORDER BY Event ASC` determines the alphabetical distribution.
- Each group contains exactly 6 events because 666 is evenly divisible by 111.

**Remember:** `NTILE()` is useful for dividing large datasets into manageable groups. When the total number of rows is evenly divisible by the number of groups, every group receives the same number of rows.
