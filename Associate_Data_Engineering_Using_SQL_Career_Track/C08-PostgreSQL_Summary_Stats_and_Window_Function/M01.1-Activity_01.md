# Numbering Rows

The simplest application of window functions is numbering rows. Numbering rows allows you to easily fetch the *n*th row. For example, it would be difficult to retrieve the 35th row in a table if each row did not have a number.

## Instructions

**100 XP**

- Number each row in the dataset.

## SQL Solution

```sql
SELECT
    *,
    -- Assign a number to each row
    ROW_NUMBER() OVER() AS Row_N
FROM Summer_Medals
ORDER BY Row_N ASC;
```

## Explanation

- `SELECT *` — Retrieves all columns from the `Summer_Medals` table.
- `ROW_NUMBER() OVER()` — Assigns a unique sequential number to each row, starting at `1`.
- `AS Row_N` — Names the generated row-number column `Row_N`.
- `FROM Summer_Medals` — Specifies the table to retrieve data from.
- `ORDER BY Row_N ASC` — Sorts the results by row number in ascending order.

**Key takeaway:** `ROW_NUMBER()` assigns a unique number to each row. Since `OVER()` does not specify an ordering, the numbering order is not guaranteed to be consistent between executions. To control the numbering, use `OVER (ORDER BY column_name)` with an appropriate column.
