# Ranking Athletes by Medals Earned

## Objective

Rank each athlete according to the total number of medals they have earned.

The athlete with the highest medal count receives the highest ranking (Rank 1). Athletes with identical medal counts should receive the same rank.

## SQL Solution

```sql
WITH Athlete_Medals AS (
    SELECT
        Athlete,
        COUNT(*) AS Medals
    FROM Summer_Medals
    GROUP BY Athlete
)

SELECT
    Athlete,
    Medals,
    -- Rank athletes by the medals they've won
    RANK() OVER (
        ORDER BY Medals DESC
    ) AS Rank_N
FROM Athlete_Medals
ORDER BY Medals DESC;
```

## Explanation

### 1. Create the CTE: `Athlete_Medals`

```sql
WITH Athlete_Medals AS (
    SELECT
        Athlete,
        COUNT(*) AS Medals
    FROM Summer_Medals
    GROUP BY Athlete
)
```

This Common Table Expression (CTE) calculates the total number of medals earned by each athlete.

- `SELECT Athlete` retrieves each athlete's name.
- `COUNT(*) AS Medals` counts the number of medal records associated with each athlete.
- `GROUP BY Athlete` groups the records by athlete, allowing SQL to calculate each athlete's total medal count.

The result is a summarized dataset containing one row per athlete.

### 2. Apply the `RANK()` function

```sql
SELECT
    Athlete,
    Medals,
    RANK() OVER (
        ORDER BY Medals DESC
    ) AS Rank_N
FROM Athlete_Medals
```

- `Athlete` displays the athlete's name.
- `Medals` displays the total number of medals earned.
- `RANK()` assigns a ranking based on the medal count.
- `ORDER BY Medals DESC` ranks athletes from the highest medal count to the lowest.
- `AS Rank_N` gives the ranking column its name.

**Why use `RANK()` instead of `ROW_NUMBER()`?**

`ROW_NUMBER()` assigns a unique number to every athlete, even when two athletes have the same medal count.

In contrast, `RANK()` gives athletes with identical medal counts the same ranking.

### 3. Sort the final output

```sql
ORDER BY Medals DESC;
```

This sorts the final results from the athlete with the most medals to the athlete with the fewest medals.

## Expected Output Concept

| Athlete | Medals | Rank_N |
|---|---:|---:|
| Athlete A | 10 | 1 |
| Athlete B | 8 | 2 |
| Athlete C | 8 | 2 |
| Athlete D | 6 | 4 |
| Athlete E | 5 | 5 |

*Illustrative output only; actual values depend on the dataset.*

Notice that:
- Athlete A receives Rank 1 because they have the most medals.
- Athletes B and C both receive Rank 2 because they have the same medal count.
- Athlete D receives Rank 4 because `RANK()` skips Rank 3 after the tie.

## Key Takeaways

- `COUNT(*)` calculates the total number of medal records for each athlete.
- `GROUP BY Athlete` summarizes the records into one row per athlete.
- `RANK()` assigns the same rank to athletes with identical medal counts.
- `ORDER BY Medals DESC` ranks athletes from highest to lowest medal count.
- `RANK()` skips subsequent ranking numbers after ties.

**Remember:** Use `RANK()` when tied athletes should receive the same rank and gaps in the ranking are acceptable. If you want rankings without gaps, use `DENSE_RANK()` instead.
