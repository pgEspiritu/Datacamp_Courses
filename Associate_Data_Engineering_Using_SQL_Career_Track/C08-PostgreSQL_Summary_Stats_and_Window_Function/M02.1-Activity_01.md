# Numbering Olympic Games in Descending Order

You have already learned how to number rows in the `Summer_Medals` dataset. In this exercise, you will reverse the numbering so that the most recent Olympic years receive the lowest row numbers.

## Instructions

**100 XP**

- Assign a number to each year in which Summer Olympic Games were held so that rows with the most recent years have lower row numbers.

## SQL Solution

```sql
SELECT
    Year,
    -- Assign the lowest numbers to the most recent years
    ROW_NUMBER() OVER (
        ORDER BY Year DESC
    ) AS Row_N
FROM (
    SELECT DISTINCT Year
    FROM Summer_Medals
) AS Years
ORDER BY Year;
```

## Explanation

- `SELECT DISTINCT Year` — Retrieves each Olympic year only once.
- `ROW_NUMBER() OVER (ORDER BY Year DESC)` — Assigns row numbers starting with `1` for the most recent year, followed by progressively larger numbers for older years.
- `AS Row_N` — Names the generated row-number column.
- `ORDER BY Year` — Displays the final results in ascending chronological order, from the oldest year to the most recent.

## Example Output

| Year | Row_N |
|---:|---:|
| 1896 | Highest number |
| 1900 | ... |
| 1904 | ... |
| ... | ... |
| 2012 | 1 |

*The row numbers above are illustrative; the exact numbers depend on the distinct years in the dataset.*

**Key takeaway:** The `ORDER BY Year DESC` inside `OVER()` controls how row numbers are assigned, while the final `ORDER BY Year` controls how the results are displayed. Therefore, the most recent year receives row number `1`, even though it appears last in the displayed results.
