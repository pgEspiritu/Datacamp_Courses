# Running Totals of Athlete Medals

A **running total**, also called a **cumulative sum**, calculates the accumulated sum of values as you move through an ordered set of rows.

In this exercise, we will calculate the cumulative number of gold medals earned by each USA athlete from the 2000 Summer Olympics onward.

## Instructions

**100 XP**

Return the following columns:
- `Athlete` – the athlete's name.
- `Medals` – the total number of gold medals earned by the athlete.
- `Cumulative_Medals` – the running total of medals, calculated in alphabetical order by athlete name.

## SQL Solution

```sql
WITH Athlete_Medals AS (
    SELECT
        Athlete,
        COUNT(*) AS Medals
    FROM Summer_Medals
    WHERE
        Country = 'USA'
        AND Medal = 'Gold'
        AND Year >= 2000
    GROUP BY Athlete
)
SELECT
    -- Calculate the running total of athlete medals
    Athlete,
    Medals,
    SUM(Medals) OVER (
        ORDER BY Athlete ASC
    ) AS Cumulative_Medals
FROM Athlete_Medals
ORDER BY Athlete ASC;
```

## Explanation

### 1. Create the CTE: `Athlete_Medals`

```sql
WITH Athlete_Medals AS (
    SELECT
        Athlete,
        COUNT(*) AS Medals
    FROM Summer_Medals
    WHERE
        Country = 'USA'
        AND Medal = 'Gold'
        AND Year >= 2000
    GROUP BY Athlete
)
```

This Common Table Expression (CTE) calculates the total number of gold medals earned by each USA athlete from 2000 onward.

- `WHERE` filters the records to USA gold medalists from 2000 onward.
- `COUNT(*)` counts the medal records for each athlete.
- `GROUP BY Athlete` groups the records by athlete.

The resulting CTE contains one row per athlete and their total gold medals.

### 2. Calculate the running total

```sql
SUM(Medals) OVER (
    ORDER BY Athlete ASC
) AS Cumulative_Medals
```

- `SUM(Medals)` calculates the accumulated medal count.
- `OVER()` turns `SUM()` into a window function, allowing the query to retain individual athlete rows.
- `ORDER BY Athlete ASC` determines the order in which the running total is calculated, from A to Z.
- `AS Cumulative_Medals` assigns a descriptive name to the resulting column.

### 3. Sort the final results

```sql
ORDER BY Athlete ASC;
```

This sorts the displayed results alphabetically by athlete name.

**Important:** The `ORDER BY` inside `OVER()` determines the calculation sequence, while the final `ORDER BY` determines the display order. In this example, both use the same alphabetical order.

## Example of a Running Total

Suppose the CTE produces the following results:

| Athlete | Medals |
|---|---:|
| Athlete A | 3 |
| Athlete B | 2 |
| Athlete C | 4 |
| Athlete D | 1 |

The running total is calculated as follows:

| Athlete | Medals | Cumulative_Medals |
|---|---:|---:|
| Athlete A | 3 | 3 |
| Athlete B | 2 | 5 |
| Athlete C | 4 | 9 |
| Athlete D | 1 | 10 |

The calculation works this way:

1. Athlete A: 3
2. Athlete B: 3 + 2 = 5
3. Athlete C: 5 + 4 = 9
4. Athlete D: 9 + 1 = 10

## Key Takeaways

- `SUM()` calculates the total of a numeric column.
- `SUM() OVER()` calculates a window-based sum without collapsing individual rows.
- `ORDER BY` inside `OVER()` determines the sequence of the running total.
- `GROUP BY` first calculates each athlete's medal count.
- The running total represents the accumulated medals across the alphabetically ordered athletes, not the medals earned by each athlete individually.

**Note:** The original query used `Max_Medals` as the alias. Since the calculation uses `SUM()`, `Cumulative_Medals` is a more accurate and descriptive alias.
