# Numbering Olympic Athletes by Medals Earned

Row numbering can also be used for ranking. By ordering athletes according to their medal counts inside the `OVER()` clause, you can assign row number `1` to the athlete with the most medals, row number `2` to the next athlete, and so on.

## Instructions 2/2

**50 XP**

- Having wrapped the previous query in the `Athlete_Medals` CTE, rank each athlete by the number of medals they have earned.

## SQL Solution

```sql
WITH Athlete_Medals AS (
    SELECT
        -- Count the number of medals each athlete has earned
        Athlete,
        COUNT(*) AS Medals
    FROM Summer_Medals
    GROUP BY Athlete
)
SELECT
    -- Number each athlete by how many medals they've earned
    Athlete,
    ROW_NUMBER() OVER (
        ORDER BY Medals DESC
    ) AS Row_N
FROM Athlete_Medals
ORDER BY Medals DESC;
```

## Explanation

- `WITH Athlete_Medals AS (...)` — Creates a Common Table Expression (CTE) that temporarily stores each athlete's medal count.
- `COUNT(*) AS Medals` — Counts the medal records for each athlete.
- `GROUP BY Athlete` — Groups the records so each athlete has one row.
- `ROW_NUMBER() OVER (ORDER BY Medals DESC)` — Assigns a unique sequential number, starting with `1` for an athlete with the highest medal count.
- `AS Row_N` — Names the generated row-number column.
- `ORDER BY Medals DESC` — Displays the athletes from the highest medal count to the lowest.

**Key takeaway:** The inner `ORDER BY` determines how `ROW_NUMBER()` assigns numbers, while the outer `ORDER BY` determines the final display order.

**Note:** If two athletes have the same medal count, `ROW_NUMBER()` still assigns them different numbers. Their relative order may be unpredictable unless you add a tie-breaker, such as `Athlete`, to the window's `ORDER BY` clause.
