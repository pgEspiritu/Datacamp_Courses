# Numbering Olympic Athletes by Medals Earned

Row numbering can also be used for ranking. By counting the medals each athlete has earned and ordering the rows by medal count, you can identify the athletes with the most medals.

## Instructions 1/2

**50 XP**

- **1**
- **2**

For each athlete, count the number of medals they have earned.

## SQL Solution

```sql
SELECT
    -- Count the number of medals each athlete has earned
    Athlete,
    COUNT(Medal) AS Medals
FROM Summer_Medals
GROUP BY Athlete
ORDER BY Medals DESC;
```

## Explanation

- `SELECT Athlete` — Retrieves the athlete's name.
- `COUNT(Medal) AS Medals` — Counts the medal records for each athlete.
- `FROM Summer_Medals` — Uses the Summer Olympics medal dataset.
- `GROUP BY Athlete` — Groups records by athlete so each athlete has one result row.
- `ORDER BY Medals DESC` — Sorts athletes from the highest medal count to the lowest.

**Why isn't `DISTINCT` needed here?**

`GROUP BY Athlete` already produces one row per athlete name, so `DISTINCT Athlete` is unnecessary.

**Key takeaway:** This query calculates each athlete's medal total. In the next step, you can use `ROW_NUMBER()` with `ORDER BY Medals DESC` to assign a ranking number to each athlete.
