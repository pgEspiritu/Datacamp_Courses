# Reigning Weightlifting Champions

A reigning champion is a champion who wins the competition in both the previous and current years. To determine whether a champion is reigning, you need to place the current and previous years' champions in the same row so that their values can be compared.

## Instructions 1/2

**50 XP**

- Return each year's gold medalists in the Men's 69KG weightlifting competition.

## SQL Solution

```sql id="v8x3nk"
SELECT
    -- Return each year's champions' countries
    DISTINCT Year,
    Country AS Champion
FROM Summer_Medals
WHERE
    Discipline = 'Weightlifting'
    AND Event = '69KG'
    AND Gender = 'Men'
    AND Medal = 'Gold'
ORDER BY Year ASC;
```

## Explanation

- `SELECT DISTINCT Year` — Returns each Olympic year only once.
- `Country AS Champion` — Displays the gold medal-winning country under the column name `Champion`.
- `FROM Summer_Medals` — Retrieves data from the Summer Olympics medal dataset.
- `Discipline = 'Weightlifting'` — Filters for weightlifting.
- `Event = '69KG'` — Selects the men's 69-kilogram weightlifting event.
- `Gender = 'Men'` — Filters for men's competitions.
- `Medal = 'Gold'` — Retrieves gold medal results.
- `ORDER BY Year ASC` — Displays the results chronologically, from oldest to newest.

**Key takeaway:** This query identifies each year's champion. In the next exercise, you can use `LAG()` to retrieve the previous year's champion and compare the two results.
