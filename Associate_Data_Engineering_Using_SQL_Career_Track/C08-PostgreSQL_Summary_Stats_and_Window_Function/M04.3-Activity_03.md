# Last Country by Name

## Objective

Retrieve the year and host city of each Olympic Games, together with the last host city in chronological order.

## SQL Solution

```sql
WITH Hosts AS (
    SELECT DISTINCT
        Year,
        City
    FROM Summer_Medals
)

SELECT
    Year,
    City,
    -- Get the last city in which the Olympic games were held
    LAST_VALUE(City) OVER (
        ORDER BY Year ASC
        RANGE BETWEEN
            UNBOUNDED PRECEDING AND
            UNBOUNDED FOLLOWING
    ) AS Last_City
FROM Hosts
ORDER BY Year ASC;
```

## Explanation

### 1. Create the CTE: `Hosts`

```sql
WITH Hosts AS (
    SELECT DISTINCT
        Year,
        City
    FROM Summer_Medals
)
```

This Common Table Expression (CTE) retrieves the unique combination of Olympic year and host city.

- `SELECT DISTINCT Year, City` removes duplicate year-and-city combinations.
- This is necessary because the `Summer_Medals` dataset contains many records for each Olympic Games, as each medal record may repeat the host city.

### 2. Use `LAST_VALUE()` to retrieve the last host city

```sql
LAST_VALUE(City) OVER (
    ORDER BY Year ASC
    RANGE BETWEEN
        UNBOUNDED PRECEDING AND
        UNBOUNDED FOLLOWING
) AS Last_City
```

Let's break this down:

- `LAST_VALUE(City)` retrieves the last city within the window frame.
- `ORDER BY Year ASC` arranges the Olympic Games chronologically, from the earliest to the most recent.
- `UNBOUNDED PRECEDING` includes all rows from the beginning of the ordered window.
- `UNBOUNDED FOLLOWING` extends the window frame through the final row.

**Why do we need `UNBOUNDED FOLLOWING`?**

By default, when an ordered window uses `LAST_VALUE()`, its frame generally ends at the current row (or its peers). This means it may return the current row's city rather than the last city in the entire dataset.

By explicitly setting:

```sql
RANGE BETWEEN
    UNBOUNDED PRECEDING AND
    UNBOUNDED FOLLOWING
```

we make the window frame cover the entire ordered dataset. Therefore, every row receives the same final host city.

### 3. Sort the final output

```sql
ORDER BY Year ASC;
```

This sorts the displayed results chronologically. Remember that this outer `ORDER BY` controls the output order, while the `ORDER BY` inside `OVER()` controls the order used by the window function.

## Expected Output Concept

| Year | City | Last_City |
|---|---|---|
| 2000 | Sydney | London |
| 2004 | Athens | London |
| 2008 | Beijing | London |
| 2012 | London | London |

*Illustrative output only. The actual result depends on the years and host cities available in the dataset.*

## Key Takeaways

- `LAST_VALUE()` retrieves the last value within a window frame.
- `ORDER BY Year ASC` determines the chronological sequence.
- `UNBOUNDED PRECEDING` starts the frame at the first row.
- `UNBOUNDED FOLLOWING` extends the frame to the final row.
- Without an appropriate window frame, `LAST_VALUE()` may return the current row's value instead of the final value in the dataset.

**Remember the difference:**
- `FIRST_VALUE()` retrieves the first value in the ordered window.
- `LAST_VALUE()` retrieves the last value in the specified window frame.
