# First Athlete by Name

## Objective

Retrieve all male athletes who have won a gold medal, together with the first athlete in alphabetical order.

## SQL Solution

```sql
WITH All_Male_Medalists AS (
    SELECT DISTINCT
        Athlete
    FROM Summer_Medals
    WHERE Medal = 'Gold'
        AND Gender = 'Men'
)

SELECT
    -- Fetch all athletes and the first athlete alphabetically
    Athlete,
    FIRST_VALUE(Athlete) OVER (
        ORDER BY Athlete ASC
    ) AS First_Athlete
FROM All_Male_Medalists;
```

## Explanation

### 1. Create the CTE: `All_Male_Medalists`

```sql
WITH All_Male_Medalists AS (
    SELECT DISTINCT
        Athlete
    FROM Summer_Medals
    WHERE Medal = 'Gold'
        AND Gender = 'Men'
)
```

This Common Table Expression (CTE) creates a temporary result set containing the names of male athletes who have won gold medals.

- `SELECT DISTINCT Athlete` retrieves unique athlete names, preventing duplicates.
- `WHERE Medal = 'Gold'` filters the records to gold medalists only.
- `AND Gender = 'Men'` limits the results to male athletes.

### 2. Use `FIRST_VALUE()` to retrieve the first athlete

```sql
SELECT
    Athlete,
    FIRST_VALUE(Athlete) OVER (
        ORDER BY Athlete ASC
    ) AS First_Athlete
FROM All_Male_Medalists;
```

- `Athlete` displays each athlete's name.
- `FIRST_VALUE(Athlete)` retrieves the first athlete's name based on the specified ordering.
- `ORDER BY Athlete ASC` sorts the names alphabetically from A to Z within the window.
- `AS First_Athlete` assigns a descriptive name to the resulting column.

Because the window is ordered alphabetically, `FIRST_VALUE()` returns the alphabetically first athlete for every row.

## Key Takeaways

- `FIRST_VALUE()` retrieves the first value in an ordered window.
- `ORDER BY Athlete ASC` determines which athlete comes first alphabetically.
- Unlike `GROUP BY`, a window function preserves all individual athlete rows.
- The same first athlete is displayed alongside every athlete because the window uses the complete result set.

**Remember:** `FIRST_VALUE()` does not remove or group rows. It adds a column containing the first value according to the window's ordering.
