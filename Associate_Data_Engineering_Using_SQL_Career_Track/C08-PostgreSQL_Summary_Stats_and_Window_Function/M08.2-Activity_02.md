# 🏅 Moving Maximum of Chinese Athletes' Medals

## 🎯 Objective
- Calculate the maximum gold medals earned by Chinese athletes from the year 2000 onwards.
- Compare the **last two athletes and the current athlete**.
- Use a sliding window with `ROWS BETWEEN 2 PRECEDING AND CURRENT ROW`.
- Sort athletes alphabetically by name.

## 💻 SQL Solution
```sql
WITH Chinese_Medals AS (
    SELECT
        Athlete,
        COUNT(*) AS Medals
    FROM Summer_Medals
    WHERE
        Country = 'CHN'
        AND Medal = 'Gold'
        AND Year >= 2000
    GROUP BY Athlete
)

SELECT
    -- Select the athletes and the medals they've earned
    athlete,
    Medals,

    -- Get the maximum medals from the last two and current rows
    MAX(Medals) OVER (
        ORDER BY athlete ASC
        ROWS BETWEEN 2 PRECEDING AND CURRENT ROW
    ) AS Max_Medals

FROM Chinese_Medals
ORDER BY Athlete ASC;
```

## 🔍 Code Explanation

### 1. 📋 Common Table Expression (CTE)
- `WITH Chinese_Medals AS (...)`
  - Creates a temporary result set named `Chinese_Medals`.
  - Retrieves athletes from the `Summer_Medals` table.
  - Filters the records using:
    - `Country = 'CHN'` → Includes China only.
    - `Medal = 'Gold'` → Includes gold medals only.
    - `Year >= 2000` → Includes Olympic records from 2000 onwards.
  - Groups records by `Athlete`.
  - Uses `COUNT(*)` to calculate the total gold medals earned by each athlete.

### 2. 📊 Window Function: MAX()
- `MAX(Medals) OVER (...)`
  - Calculates the highest medal count within the defined frame.
  - Returns a maximum value for every athlete.
  - Does not collapse the result into a single row.

### 3. 🪟 Frame Definition
```sql
ROWS BETWEEN 2 PRECEDING AND CURRENT ROW
```
- `2 PRECEDING` → Includes the two rows before the current athlete.
- `CURRENT ROW` → Includes the current athlete.
- `MAX(Medals)` → Returns the highest medal count among these three rows.
- The frame moves forward one athlete at a time.

### 4. 🔤 Alphabetical Ordering
- `ORDER BY athlete ASC` inside `OVER()`:
  - Arranges athletes alphabetically.
  - Determines which athletes are considered the previous two rows.
- `ORDER BY Athlete ASC` outside `OVER()`:
  - Sorts the final output alphabetically.

## 📈 Understanding the Sliding Window

| Athlete | Gold Medals | Previous Two + Current | Max_Medals |
|---|---:|---|---:|
| Athlete A | 5 | 5 | 5 |
| Athlete B | 8 | 5, 8 | 8 |
| Athlete C | 3 | 5, 8, 3 | 8 |
| Athlete D | 10 | 8, 3, 10 | 10 |
| Athlete E | 6 | 3, 10, 6 | 10 |

- *Note: Illustrative values and athlete names only.*

## 🧠 Key Takeaways
- `PRECEDING` allows a window function to look backward at previous rows.
- `2 PRECEDING` includes the two rows before the current row.
- `CURRENT ROW` includes the current record.
- `MAX()` identifies the highest value within the frame.
- `ORDER BY athlete ASC` determines the alphabetical sequence of the sliding window.
- Frames allow you to examine previous or following rows without using `LAG()` or `LEAD()`.

## 💡 Remember
- **`1 PRECEDING`** → Previous row.
- **`2 PRECEDING`** → Previous two rows.
- **`CURRENT ROW`** → Current row.
- **`1 FOLLOWING`** → Next row.
- **`MAX()`** → Highest value within the defined frame.

**Formula to remember:**
```sql
MAX(column_name) OVER (
    ORDER BY sort_column
    ROWS BETWEEN 2 PRECEDING AND CURRENT ROW
)
```
- This calculates a **moving maximum using the previous two rows and the current row**.
