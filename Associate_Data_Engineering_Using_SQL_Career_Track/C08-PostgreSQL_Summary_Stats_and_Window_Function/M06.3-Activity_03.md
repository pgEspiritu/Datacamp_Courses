# Top, Middle, and Bottom Thirds: Calculating the Average

## Objective

Calculate the average number of medals earned by athletes in each of the three groups (top, middle, and bottom thirds).

This exercise continues from the previous activity, where `NTILE(3)` was used to divide athletes into three approximately equal-sized groups based on their medal counts.

## SQL Solution

```sql id="c8v4pa"
WITH Athlete_Medals AS (
    SELECT
        Athlete,
        COUNT(*) AS Medals
    FROM Summer_Medals
    GROUP BY Athlete
    HAVING COUNT(*) > 1
),

Thirds AS (
    SELECT
        Athlete,
        Medals,
        NTILE(3) OVER (
            ORDER BY Medals DESC
        ) AS Third
    FROM Athlete_Medals
)

SELECT
    -- Get the average medals earned in each third
    Third,
    AVG(Medals) AS Avg_Medals
FROM Thirds
GROUP BY Third
ORDER BY Third ASC;
```

## Explanation

### 1. Create the CTE: `Athlete_Medals`

```sql id="n23c7q"
WITH Athlete_Medals AS (
    SELECT
        Athlete,
        COUNT(*) AS Medals
    FROM Summer_Medals
    GROUP BY Athlete
    HAVING COUNT(*) > 1
)
```

This calculates the total number of medals earned by each athlete.

- `COUNT(*) AS Medals` counts the medal records for each athlete.
- `GROUP BY Athlete` groups the records by athlete.
- `HAVING COUNT(*) > 1` includes only athletes who have earned more than one medal.

### 2. Create the CTE: `Thirds`

```sql id="v2z7q1"
Thirds AS (
    SELECT
        Athlete,
        Medals,
        NTILE(3) OVER (
            ORDER BY Medals DESC
        ) AS Third
    FROM Athlete_Medals
)
```

This assigns each athlete to one of three groups based on their medal count.

- `NTILE(3)` divides the athletes into three approximately equal-sized groups.
- `ORDER BY Medals DESC` places athletes with the highest medal counts first.
- `Third` stores the assigned group number.

The group classifications are:

| Third | Classification |
|---:|---|
| 1 | Top Third |
| 2 | Middle Third |
| 3 | Bottom Third |

### 3. Calculate the average using AVG()

```sql id="b4j8m2"
SELECT
    Third,
    AVG(Medals) AS Avg_Medals
FROM Thirds
GROUP BY Third
ORDER BY Third ASC;
```

- `AVG(Medals)` calculates the average medal count for each group.
- `GROUP BY Third` groups athletes according to their assigned third.
- `ORDER BY Third ASC` displays the results from the top third to the bottom third.

## Understanding the Average

The `AVG()` function calculates the arithmetic mean by dividing the total medal count by the number of athletes in each group.

For example, consider three athletes with the following medal counts:

| Athlete | Medals |
|---|---:|
| Athlete A | 10 |
| Athlete B | 8 |
| Athlete C | 6 |
| **Total** | **24** |

## Key Takeaways

- `NTILE(3)` divides athletes into three approximately equal-sized groups.
- `AVG(Medals)` calculates the average medal count within each group.
- `GROUP BY Third` produces one summary row for each group.
- `ORDER BY Third ASC` displays the groups in top-to-bottom order.

**Remember:** The first CTE calculates medal totals per athlete, the second CTE assigns each athlete to a third, and the final query calculates the average medal count for each third.
