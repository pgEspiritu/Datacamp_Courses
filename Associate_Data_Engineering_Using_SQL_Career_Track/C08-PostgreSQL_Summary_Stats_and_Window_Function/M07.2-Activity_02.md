# Maximum Country Medals by Year

Calculating the **maximum medals earned so far** helps determine whether a country has achieved a new medal record in a particular year.

In this exercise, we will compare the number of gold medals earned by China, South Korea, and Japan in each Olympic year from 2000 onward against their highest gold medal count in previous years.

## Instructions

**100 XP**

Return the following columns:
- `Year` – the Olympic year.
- `Country` – the country's code.
- `Medals` – the number of gold medals earned by the country in that year.
- `Max_Medals` – the highest number of gold medals earned by that country up to and including the current year.

Order the results by country and year in ascending order.

## SQL Solution

```sql
WITH Country_Medals AS (
    SELECT
        Year,
        Country,
        COUNT(*) AS Medals
    FROM Summer_Medals
    WHERE
        Country IN ('CHN', 'KOR', 'JPN')
        AND Medal = 'Gold'
        AND Year >= 2000
    GROUP BY Year, Country
)
SELECT
    -- Return the maximum medals earned so far per country
    Year,
    Country,
    Medals,
    MAX(Medals) OVER (
        PARTITION BY Country
        ORDER BY Year ASC
    ) AS Max_Medals
FROM Country_Medals
ORDER BY Country ASC, Year ASC;
```

## Explanation

### 1. Create the CTE: `Country_Medals`

```sql
WITH Country_Medals AS (
    SELECT
        Year,
        Country,
        COUNT(*) AS Medals
    FROM Summer_Medals
    WHERE
        Country IN ('CHN', 'KOR', 'JPN')
        AND Medal = 'Gold'
        AND Year >= 2000
    GROUP BY Year, Country
)
```

This CTE calculates the number of gold medals earned by each selected country in every Olympic year from 2000 onward.

- `WHERE` filters the records to China (`CHN`), South Korea (`KOR`), and Japan (`JPN`).
- `Medal = 'Gold'` includes only gold medal records.
- `Year >= 2000` limits the records to 2000 onward.
- `COUNT(*)` counts the gold medal records.
- `GROUP BY Year, Country` calculates the medal count separately for each country in each year.

The resulting CTE contains one row per country per Olympic year.

### 2. Calculate the maximum medals earned so far

```sql
MAX(Medals) OVER (
    PARTITION BY Country
    ORDER BY Year ASC
) AS Max_Medals
```

This is the main part of the exercise.

- `MAX(Medals)` identifies the highest medal count within the window.
- `OVER()` applies the calculation as a window function, preserving individual rows.
- `PARTITION BY Country` separates the calculations by country. Each country has its own independent maximum.
- `ORDER BY Year ASC` processes the years chronologically, allowing the maximum to be updated as each year is considered.
- `AS Max_Medals` assigns a name to the resulting column.

**Why use `PARTITION BY Country`?**

Without it, the maximum would be calculated across all three countries together. With it, China, South Korea, and Japan each have their own running maximum.

### 3. Sort the final results

```sql
ORDER BY Country ASC, Year ASC;
```

This sorts the output alphabetically by country code and then chronologically by year.

## Example of a Running Maximum

Suppose a country's gold medal counts across five Olympic years are:

| Year | Country | Medals |
|---|---|---:|
| 2000 | CHN | 10 |
| 2004 | CHN | 12 |
| 2008 | CHN | 8 |
| 2012 | CHN | 15 |
| 2016 | CHN | 11 |

The running maximum is:

| Year | Country | Medals | Max_Medals |
|---|---|---:|---:|
| 2000 | CHN | 10 | 10 |
| 2004 | CHN | 12 | 12 |
| 2008 | CHN | 8 | 12 |
| 2012 | CHN | 15 | 15 |
| 2016 | CHN | 11 | 15 |

Notice how `Max_Medals` changes only when the current year's medal count exceeds the previous maximum.

- In 2000, the maximum is 10.
- In 2004, the country sets a new record of 12.
- In 2008, the count drops to 8, so the maximum remains 12.
- In 2012, the country sets a new record of 15.
- In 2016, the count drops to 11, so the maximum remains 15.

## Key Takeaways

| SQL Clause / Function | Purpose |
|---|---|
| `MAX()` | Finds the highest value |
| `MAX() OVER()` | Calculates a maximum while preserving individual rows |
| `PARTITION BY Country` | Calculates a separate maximum for each country |
| `ORDER BY Year ASC` | Processes records chronologically |
| `GROUP BY Year, Country` | Calculates medal totals per country per year |

**Remember:** `MAX() OVER (PARTITION BY Country ORDER BY Year ASC)` calculates a running maximum for each country. Unlike a running sum, the running maximum does not add values together; it only retains the highest value encountered so far.

This makes it useful for identifying whether a country has established a new medal record in a particular Olympic year.
