# Ranking Athletes from Multiple Countries

## Objective

Rank athletes from Japan and South Korea according to the number of medals they have earned since 2000.

The ranking should:
- Be calculated separately for each country.
- Give athletes with identical medal counts the same rank.
- Not skip ranking numbers after ties.

To achieve this, we use `DENSE_RANK()` together with `PARTITION BY`.

## SQL Solution

```sql
WITH Athlete_Medals AS (
    SELECT
        Country,
        Athlete,
        COUNT(*) AS Medals
    FROM Summer_Medals
    WHERE
        Country IN ('JPN', 'KOR')
        AND Year >= 2000
    GROUP BY Country, Athlete
    HAVING COUNT(*) > 1
)

SELECT
    Country,
    Athlete,
    -- Rank athletes in each country by the medals they've won
    DENSE_RANK() OVER (
        PARTITION BY Country
        ORDER BY Medals DESC
    ) AS Rank_N
FROM Athlete_Medals
ORDER BY Country ASC, Rank_N ASC;
```

## Explanation

### 1. Create the CTE: `Athlete_Medals`

```sql
WITH Athlete_Medals AS (
    SELECT
        Country,
        Athlete,
        COUNT(*) AS Medals
    FROM Summer_Medals
    WHERE
        Country IN ('JPN', 'KOR')
        AND Year >= 2000
    GROUP BY Country, Athlete
    HAVING COUNT(*) > 1
)
```

This CTE calculates the total number of medals earned by each athlete from Japan and South Korea since 2000.

- `Country` retrieves the athlete's country.
- `Athlete` retrieves the athlete's name.
- `COUNT(*) AS Medals` counts the medal records for each athlete.
- `Country IN ('JPN', 'KOR')` filters the dataset to Japan and South Korea.
- `Year >= 2000` includes records from 2000 onward.
- `GROUP BY Country, Athlete` calculates medal totals separately for each athlete within each country.
- `HAVING COUNT(*) > 1` retains only athletes who have earned more than one medal.

**Important:** `WHERE` filters individual records before grouping, while `HAVING` filters the grouped results after aggregation.

### 2. Apply `DENSE_RANK()` with `PARTITION BY`

```sql
SELECT
    Country,
    Athlete,
    DENSE_RANK() OVER (
        PARTITION BY Country
        ORDER BY Medals DESC
    ) AS Rank_N
FROM Athlete_Medals
```

Let's break down the window function:

- `DENSE_RANK()` assigns rankings without skipping numbers after ties.
- `PARTITION BY Country` separates the athletes into country-specific groups.
- `ORDER BY Medals DESC` ranks athletes from the highest medal count to the lowest.
- `AS Rank_N` names the resulting ranking column.

**Why use `PARTITION BY Country`?**

Without partitioning, Japanese and South Korean athletes would be ranked together.

With `PARTITION BY Country`, each country's ranking starts independently at Rank 1.

**Why use `DENSE_RANK()` instead of `RANK()`?**

`DENSE_RANK()` does not skip ranking numbers when athletes have identical medal counts.

### 3. Sort the final output

```sql
ORDER BY Country ASC, Rank_N ASC;
```

This sorts the results:
1. Alphabetically by country.
2. By ranking from lowest rank number to highest within each country.

## Key Takeaways

- `GROUP BY Country, Athlete` calculates medal totals for each athlete within each country.
- `HAVING COUNT(*) > 1` excludes athletes with only one medal.
- `PARTITION BY Country` creates separate ranking groups.
- `DENSE_RANK()` assigns equal rankings to tied values without skipping numbers.
- `ORDER BY Medals DESC` ranks athletes from highest to lowest medal count.

### Quick Comparison

| Function | Ties | Skips ranking numbers? |
|---|---|---|
| `ROW_NUMBER()` | Different numbers | No |
| `RANK()` | Same number | Yes |
| `DENSE_RANK()` | Same number | No |

**Remember:** When ranking multiple groups independently, use `PARTITION BY` to separate the groups. When you want tied values to share a rank without gaps, use `DENSE_RANK()`.
