# Reigning Champions by Gender

You have already learned how to retrieve the previous year's champion using `LAG()`. However, when working with multiple events or genders, you need to use `PARTITION BY` to ensure that champions are compared only within the same group.

## Instructions

**100 XP**

- Return the previous champions of each year's event by gender.

## SQL Solution

```sql
WITH Tennis_Gold AS (
    SELECT DISTINCT
        Gender,
        Year,
        Country
    FROM Summer_Medals
    WHERE
        Year >= 2000
        AND Event = 'Javelin Throw'
        AND Medal = 'Gold'
)
SELECT
    Gender,
    Year,
    Country AS Champion,
    -- Fetch the previous year's champion by gender
    LAG(Country) OVER (
        PARTITION BY Gender
        ORDER BY Year ASC
    ) AS Last_Champion
FROM Tennis_Gold
ORDER BY Gender ASC, Year ASC;
```

## Explanation

- `WITH Tennis_Gold AS (...)` — Creates a Common Table Expression (CTE) containing the gold medal-winning countries for the selected event.
- `SELECT DISTINCT Gender, Year, Country` — Retrieves unique combinations of gender, year, and country.
- `Year >= 2000` — Includes Olympic results from 2000 onward.
- `Event = 'Javelin Throw'` — Filters the records to the Javelin Throw event.
- `Medal = 'Gold'` — Retrieves only gold medal results.
- `Country AS Champion` — Renames the country column to `Champion`.
- `LAG(Country)` — Retrieves the country from the previous row.
- `PARTITION BY Gender` — Creates separate partitions for men and women, ensuring their champions are compared independently.
- `ORDER BY Year ASC` inside `OVER()` — Arranges each gender's records chronologically.
- `ORDER BY Gender ASC, Year ASC` — Displays the final results by gender and then by year.

## Example Output

| Gender | Year | Champion | Last_Champion |
|---|---:|---|---|
| Men | 2000 | Country A | NULL |
| Men | 2004 | Country B | Country A |
| Men | 2008 | Country B | Country B |
| Women | 2000 | Country C | NULL |
| Women | 2004 | Country D | Country C |
| Women | 2008 | Country D | Country D |

*The country names are illustrative.*

## Key Takeaway

`PARTITION BY Gender` ensures that `LAG()` retrieves the previous champion only within the same gender.

For example:
- The previous men's champion is compared only with the current men's champion.
- The previous women's champion is compared only with the current women's champion.

**Important:** Although the CTE is named `Tennis_Gold`, the query actually retrieves Javelin Throw results. You could rename it to `Javelin_Gold` for better readability, but the original name does not affect query execution.
