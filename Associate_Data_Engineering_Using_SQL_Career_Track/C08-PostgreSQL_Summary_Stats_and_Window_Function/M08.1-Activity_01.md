# 🏅 Moving Maximum of Scandinavian Athletes' Medals

## 🎯 Objective
- Use a **sliding window (frame)** to calculate the maximum gold medals earned by Scandinavian countries.
- Compare only the **current year and the next year**.
- Apply the SQL window function `MAX()` with `ROWS BETWEEN`.

## 💻 SQL Solution
```sql
WITH Scandinavian_Medals AS (
    SELECT
        Year,
        COUNT(*) AS Medals
    FROM Summer_Medals
    WHERE
        Country IN ('DEN', 'NOR', 'FIN', 'SWE', 'ISL')
        AND Medal = 'Gold'
    GROUP BY Year
)

SELECT
    -- Select each year's medals
    year,
    medals,

    -- Get the maximum medals from the current and next years
    MAX(medals) OVER (
        ORDER BY year ASC
        ROWS BETWEEN CURRENT ROW AND 1 FOLLOWING
    ) AS Max_Medals

FROM Scandinavian_Medals
ORDER BY Year ASC;
```

## 🔍 Code Explanation

### 1. 📋 Common Table Expression (CTE)
- `WITH Scandinavian_Medals AS (...)`
  - Creates a temporary result set named `Scandinavian_Medals`.
  - Filters records from the `Summer_Medals` table.
  - Includes only Scandinavian countries:
    - Denmark (`DEN`)
    - Norway (`NOR`)
    - Finland (`FIN`)
    - Sweden (`SWE`)
    - Iceland (`ISL`)
  - Filters gold medals using `Medal = 'Gold'`.
  - Groups records by `Year`.
  - Uses `COUNT(*)` to calculate the total gold medals per year.

### 2. 📊 Window Function: MAX()
- `MAX(medals) OVER (...)`
  - Calculates the maximum medal count within the defined window.
  - Does not group or collapse the final result rows.
  - Returns a maximum value for each year.

### 3. 🪟 Frame Definition
```sql
ROWS BETWEEN CURRENT ROW AND 1 FOLLOWING
```
- `CURRENT ROW` → Includes the current year's medal count.
- `1 FOLLOWING` → Includes the next row's medal count.
- `MAX()` → Returns the higher medal count between the two rows.
- The frame moves forward one row at a time.

### 4. ↕️ Ordering
- `ORDER BY year ASC` inside `OVER()`:
  - Determines the chronological order of rows.
  - Controls how the sliding window moves.
- `ORDER BY Year ASC` outside `OVER()`:
  - Sorts the final query results in ascending order.

## 📈 Understanding the Sliding Window

| Current Year | Next Year | Maximum Medals |
|---|---|---|
| 2000: 20 | 2004: 30 | 30 |
| 2004: 30 | 2008: 25 | 30 |
| 2008: 25 | 2012: 40 | 40 |
| 2012: 40 | 2016: 35 | 40 |
| 2016: 35 | No following row | 35 |

- *Note: Illustrative values only.*

## 🧠 Key Takeaways
- `ROWS BETWEEN` defines which physical rows are included in a window function calculation.
- `CURRENT ROW` refers to the row currently being evaluated.
- `1 FOLLOWING` includes the next row.
- `MAX()` identifies the highest value within the frame.
- The last row only considers its own value because no following row exists.
- The sliding window moves forward as SQL evaluates each row.

## 💡 Remember
- **Window Function:** Determines what calculation to perform.
- **Frame:** Determines which rows are used as input.
- **ORDER BY:** Determines the sequence in which the sliding window operates.

**Formula to remember:**
```sql
MAX(column_name) OVER (
    ORDER BY sort_column
    ROWS BETWEEN CURRENT ROW AND 1 FOLLOWING
)
```
- This calculates a **moving maximum using the current row and the next row**.
