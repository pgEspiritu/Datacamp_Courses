# Top, Middle, and Bottom Thirds

## Objective

Divide athletes into three approximately equal-sized groups based on the total number of medals they have earned.

The three groups are:

1. **Top Third (1):** Athletes with the highest medal counts.
2. **Middle Third (2):** Athletes with moderate medal counts.
3. **Bottom Third (3):** Athletes with the lowest medal counts.

To accomplish this, we use the `NTILE(3)` window function.

## SQL Solution

```sql id="4f8b9e"
WITH Athlete_Medals AS (
    SELECT
        Athlete,
        COUNT(*) AS Medals
    FROM Summer_Medals
    GROUP BY Athlete
    HAVING COUNT(*) > 1
)

SELECT
    Athlete,
    Medals,
    -- Split athletes into thirds by their earned medals
    NTILE(3) OVER (
        ORDER BY Medals DESC
    ) AS Third
FROM Athlete_Medals
ORDER BY Medals DESC, Athlete ASC;
```

## Explanation

### 1. Create the CTE: `Athlete_Medals`

```sql id="2e8k5x"
WITH Athlete_Medals AS (
    SELECT
        Athlete,
        COUNT(*) AS Medals
    FROM Summer_Medals
    GROUP BY Athlete
    HAVING COUNT(*) > 1
)
```

This CTE calculates the total number of medals earned by each athlete.

- `SELECT Athlete` retrieves the athlete's name.
- `COUNT(*) AS Medals` counts the medal records for each athlete.
- `GROUP BY Athlete` groups the records by athlete.
- `HAVING COUNT(*) > 1` includes only athletes who have earned more than one medal.

### 2. Apply `NTILE(3)`

```sql id="84g6qb"
NTILE(3) OVER (
    ORDER BY Medals DESC
) AS Third
```

- `NTILE(3)` divides the athletes into three approximately equal-sized groups.
- `ORDER BY Medals DESC` arranges athletes from the highest medal count to the lowest before assigning groups.
- `AS Third` names the resulting column.

The assigned values represent:

| Third | Group | Description |
|---:|---|---|
| 1 | Top Third | Athletes with the highest medal counts |
| 2 | Middle Third | Athletes with moderate medal counts |
| 3 | Bottom Third | Athletes with the lowest medal counts |

### 3. Sort the final output

```sql id="6g6gds"
ORDER BY Medals DESC, Athlete ASC;
```

This sorts the results:
- First, by medal count in descending order.
- Second, alphabetically by athlete name when medal counts are identical.

The second sorting condition makes the displayed order easier to read. However, note that it does not affect the ordering used inside `NTILE()`.

## Key Takeaways

- `COUNT(*)` calculates the total number of medals earned by each athlete.
- `GROUP BY Athlete` produces one record per athlete.
- `HAVING COUNT(*) > 1` excludes athletes with only one medal.
- `NTILE(3)` divides the athletes into three approximately equal-sized groups.
- `ORDER BY Medals DESC` ensures that athletes with the highest medal counts are placed in the first group.

**Remember:** Unlike `RANK()` and `DENSE_RANK()`, `NTILE()` focuses on distributing rows into approximately equal-sized groups. Athletes with identical medal counts may be assigned to different thirds if they fall across a group boundary.
