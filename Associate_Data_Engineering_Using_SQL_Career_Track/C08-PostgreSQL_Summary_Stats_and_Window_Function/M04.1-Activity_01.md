# Future Gold Medalists

Fetching functions allow you to retrieve values from different rows and display them alongside the current row. When working with time-ordered data, you can use the `LEAD()` function to look ahead and retrieve a future value.

This is useful when comparing a current value with a value from a future period or competition.

## Instructions

**100 XP**

- For each year, fetch the current gold medalist and the gold medalist three competitions ahead of the current row.

## SQL Solution

```sql
WITH Discus_Medalists AS (
    SELECT DISTINCT
        Year,
        Athlete
    FROM Summer_Medals
    WHERE
        Medal = 'Gold'
        AND Event = 'Discus Throw'
        AND Gender = 'Women'
        AND Year >= 2000
)
SELECT
    -- For each year, fetch the current and future medalists
    Year,
    Athlete,
    LEAD(Athlete, 3) OVER (
        ORDER BY Year ASC
    ) AS Future_Champion
FROM Discus_Medalists
ORDER BY Year ASC;
```

## Explanation

- `WITH Discus_Medalists AS (...)` — Creates a CTE containing the gold medalists for the selected event.
- `SELECT DISTINCT Year, Athlete` — Retrieves unique year-and-athlete combinations.
- `Medal = 'Gold'` — Filters for gold medalists.
- `Event = 'Discus Throw'` — Selects the Discus Throw event.
- `Gender = 'Women'` — Filters for the women's competition.
- `Year >= 2000` — Includes results from 2000 onward.
- `LEAD(Athlete, 3)` — Retrieves the athlete's name from three rows after the current row.
- `OVER (ORDER BY Year ASC)` — Arranges the records chronologically before retrieving future values.
- `AS Future_Champion` — Names the column containing the future gold medalist.
- `ORDER BY Year ASC` — Displays the results from oldest to newest.

## Understanding LEAD(Athlete, 3)

The number `3` tells SQL to look three rows ahead.

<text weight="medium" size="sm">Illustrative example</text>

| Current Year | Athlete | Future_Champion |
|---:|---|---|
| 2000 | Athlete A | Athlete D |
| 2004 | Athlete B | Athlete E |
| 2008 | Athlete C | Athlete F |
| 2012 | Athlete D | NULL |

**Key takeaway:** `LEAD(Athlete, 3)` retrieves the athlete from three records ahead, not necessarily three calendar years ahead. If there are fewer than three following rows, the result is `NULL`.
