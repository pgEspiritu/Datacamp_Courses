# Reigning Weightlifting Champions

A reigning champion is a champion who wins the competition in both the previous and current years. To identify reigning champions, you need to retrieve the previous year's champion and compare it with the current year's champion.

## Instructions 2/2

**50 XP**

- Having wrapped the previous query in the `Weightlifting_Gold` CTE, get the previous year's champion for each year.

## SQL Solution

```sql
WITH Weightlifting_Gold AS (
    SELECT
        -- Return each year's champions' countries
        Year,
        Country AS Champion
    FROM Summer_Medals
    WHERE
        Discipline = 'Weightlifting'
        AND Event = '69KG'
        AND Gender = 'Men'
        AND Medal = 'Gold'
)
SELECT
    Year,
    Champion,
    -- Fetch the previous year's champion
    LAG(Champion) OVER (
        ORDER BY Year ASC
    ) AS Last_Champion
FROM Weightlifting_Gold
ORDER BY Year ASC;
```

## Explanation

- `WITH Weightlifting_Gold AS (...)` — Creates a Common Table Expression (CTE) containing the gold medal-winning country for each matching year.
- `Year` — Returns the year of the Olympic competition.
- `Country AS Champion` — Renames the `Country` column to `Champion`.
- `LAG(Champion)` — Retrieves the champion value from the previous row. The default offset is `1`, so writing `LAG(Champion, 1)` would produce the same result.
- `OVER (ORDER BY Year ASC)` — Orders the rows chronologically before retrieving the previous champion.
- `AS Last_Champion` — Names the new column containing the previous champion.
- `ORDER BY Year ASC` — Displays the final results from oldest to newest.

## Example Output

| Year | Champion | Last_Champion |
|---:|---|---|
| 2000 | Country A | `NULL` |
| 2004 | Country B | Country A |
| 2008 | Country B | Country B |
| 2012 | Country C | Country B |

*The country names are illustrative.*

**Key takeaway:** `LAG()` retrieves a value from a previous row, allowing you to compare the current champion with the previous recorded champion. The first row returns `NULL` because no earlier row exists.

**Note:** `LAG()` looks at the previous available record, which may not be from the immediately preceding Olympic Games if the event has no recorded result for an intervening year.
