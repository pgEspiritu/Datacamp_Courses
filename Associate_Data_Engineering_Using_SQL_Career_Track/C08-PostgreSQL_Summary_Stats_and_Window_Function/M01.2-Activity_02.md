# Numbering Olympic Games in Ascending Order

The Summer Olympics dataset contains the results of the games held between 1896 and 2012. The first Summer Olympics were held in 1896, the second in 1900, and so on. By numbering the years, you can easily identify when a particular edition of the Summer Olympics took place.

## Instructions

**100 XP**

- Assign a number to each year in which Summer Olympic Games were held.

## SQL Solution

```sql
SELECT
    Year,
    -- Assign numbers to each year
    ROW_NUMBER() OVER() AS Row_N
FROM (
    SELECT DISTINCT
        Year
    FROM Summer_Medals
    ORDER BY Year ASC
) AS Years
ORDER BY Year ASC;
```

## Explanation

- `SELECT DISTINCT Year` — Retrieves each Olympic year only once, avoiding duplicate years caused by multiple medal records.
- `FROM Summer_Medals` — Retrieves the data from the `Summer_Medals` table.
- `ORDER BY Year ASC` — Sorts the years from earliest to latest.
- `ROW_NUMBER() OVER()` — Assigns a sequential number to each row.
- `AS Row_N` — Names the new row-number column `Row_N`.
- `ORDER BY Year ASC` — Displays the final results in ascending order by year.

**Key takeaway:** Use `DISTINCT` to get one row per Olympic year before numbering the rows. The first year receives `Row_N = 1`, the second year receives `Row_N = 2`, and so on.

**Note:** The original query selected both `Year` and `City` in the subquery, which could produce multiple rows for a year if different cities were present. Since the task is to number each year, selecting only `DISTINCT Year` is sufficient.
